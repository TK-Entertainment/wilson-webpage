**這章在回答**：Ch13 講的是岩石裡的「面」，這章講的是「線」：被拉長的礫石、排成一列的針狀礦物、斷層面上的擦痕、兩組面相交的交線。線理比面更直接地記錄了岩石「往哪裡被拉」或「往哪裡滑」，所以是運動學分析最常用的資料。但不是每一種線理都代表同一件事：有的是應變橢球的 X 軸，有的只是兩個面的交線，有的是斷層滑動方向。這章的重點就是分清楚每一種線理記錄了什麼，以及什麼時候能拿它推搬運方向。

**考前 30 秒**

1. **線理**：一個方向比另外兩個長得多的組構元素。**線型**（lineament）是航照、衛星影像、地形圖上判斷出的大尺度線狀構造，不是岩石裡的組構。
2. 三類：**貫穿線理**（形成 L 組構）、**表面線理**（只在某個面上，例如擦痕）、**幾何線理**（不是實體：褶皺軸、交面線理）。
3. **拉伸線理、礦物線理** ≈ 應變橢球的 **X 軸**；**礦物纖維**可以長在 **ISA₁** 方向，也可以垂直開裂的脈壁。
4. **串腸構造**：硬層被平行層面**伸張**拉斷；串腸軸垂直伸張方向。褶皺和串腸常一起出現：**樞紐增厚、翼部伸張成串腸**。
5. **窗櫺構造**：軟硬層界面的尖狀波紋，**硬層凸向軟層**；因為是力學成因，**不能當面向指標**。和拱彎褶皺一樣是黏度差造成的。
6. 脆性區：擦痕有**機械磨蝕**（溝痕）和**纖維生長**兩種；纖維脈分**同向脈**（從壁往中間長、和圍岩同礦物、crack-seal）和**反向脈**（從中間帶往兩壁長、成分不同，約 350 °C 以下）。
7. 位態：**趨向**＋**傾伏角**；在某個面上可以用**側傾角**（rake，線和該面走向的夾角）。
8. 拉伸線理通常平行搬運方向（運動學 **a 軸**），應變越大越接近；**褶皺軸可以和拉伸線理平行，也可以垂直**，所以不能用褶皺軸推搬運方向。

## 1. 定義與分類 ★

**線理**：組構元素中，一個方向比另外兩個方向長得多。

| 類別 | 例子 |
|---|---|
| **非構造（原生）線狀構造** | 繩狀熔岩、流動線理、柱狀玄武岩的柱子、排列的扁長礫石、沉積岩的溝鑄型、排列的化石 |
| **構造線狀構造** | 被拉長的物體、應變的礦物集合體、礫岩的礫石、兩組面的交線 |
| **幾何定義的線狀構造** | 褶皺樞紐線、夾皺軸 |

依分布方式，又可以分成：

- **貫穿線理**：貫穿整塊岩石，構成 **L 組構**。
- **表面線理**：只在某一個面上，例如斷層面上的擦痕。
- **幾何線理**：不是實體，例如褶皺軸、交面線理。

**線型 vs. 線理**：**線型**是在航照、衛星影像或地形圖上判斷出來的線狀構造（例如紐西蘭南島的大平移斷層在雷達地形影像上切過山脊）；**線理**是岩石實際呈現的線狀組構。前者是地形、影像上的特徵，後者是岩石裡的組構。

## 2. 塑性變形中的線理 ★

**構造岩**（接 Ch13）：

- **L 構造岩**：線理是主要的組構，面狀組構很弱或沒有（例如被拉成棒狀的礫岩、眼球片麻岩的強烈拉伸線理）→ 收縮應變。
- **LS 構造岩**：面狀組構＋貫穿線理。
- **S 構造岩**：幾乎沒有線理 → 落在 Flinn 圖的壓扁區。

課本封面那塊被強烈變形的複相礫岩是 L 構造岩（收縮應變），但旁邊的花崗岩礫石幾乎沒變形，因為它比周圍的基質硬。所以**用礫石算應變時要注意礫石和基質的強度差**。

### 拉伸線理

被拉長的礫石、顆粒或礦物集合體排成的線，大致代表應變橢球的 **X 軸**（最大伸長方向）。

### 礦物線理

礦物或礦物集合體排成線，形成的方式有**再結晶**、**溶解／沉澱**、**剛體旋轉**。碎裂作用、壓溶、再結晶都會在變形中改變礦物和礦物集合體的形狀。

**礦物纖維線理**：纖維可能沿瞬時伸長方向 **ISA₁** 長，也可能**垂直於張開的脈壁**長，兩者不一定相同（第 4 節）。

台灣例子：台東太麻里中新世盧山層有伸張線理和礦物線理。

### 交面線理

後來的葉理切過層理或更早的葉理時，在面上留下的交線。同一塊岩石中有好幾代線理時，依相對年代編號：**L₀** 是原生的線，**L₁、L₂ … Lₙ** 是依序形成的次生線理（和 Ch13 的 Sₙ 一樣）。

- 層理–劈理的交線：軸面劈理時**平行褶皺軸**。
- 橫切褶皺（Ch13）：交面線理和褶皺軸**不平行**。

**夾皺線理 vs. 交面線理**：夾皺線理是舊葉理被皺起來的小褶皺**樞紐**（實體的皺紋）；交面線理是兩組面的**交線**（不一定有皺紋）。

## 3. 串腸構造與窗櫺構造 ★

### 串腸構造

硬層被**平行層面伸張**拉斷成一節一節（花蓮神秘谷長春層）。

- **縮頸–膨脹構造**（pinch-and-swell）：還沒斷，只是一段細一段粗，呈圓柱狀。
- **串腸軸**是一種線理，**垂直**伸張方向。如果兩個方向都伸張（壓扁應變），會形成巧克力塊狀的串腸。
- 和應變橢球的關係：串腸代表層面方向有**伸長**；串腸軸平行 Y（平面應變時），伸張方向是 X。

**褶皺和串腸常一起出現**：同一層硬層，在褶皺的**樞紐增厚**、**翼部被拉長成串腸**。所以同一層同時有縮短和伸張的證據，並不矛盾。

### 窗櫺構造

多層岩石變形時，**不同硬度**（黏度差）的岩性**界面**上形成的**尖狀波紋**，它的軸是一種線理。

- **比較硬的岩性呈凸起，凸進軟的岩性**；尖端指向硬層（和 Ch12 的尖瓣–圓弧褶皺一樣）。
- 因為是**力學**成因（取決於哪邊比較硬），**不能當面向指標**判斷地層上下。
- 台灣例子：台東太麻里中新世盧山層。

**窗櫺和拱彎褶皺哪裡像**：兩者都是平行界面縮短、由黏度差控制的不穩定性；窗櫺就是界面上的拱彎（硬層一側凸起、軟層一側成尖）。

## 4. 脆性區的線理 ★

**非平面的剪裂**含有伸張段，纖維在伸張段生長，形成局部的線理。

### 擦痕

斷層面上的**擦痕線**（slickenlines，在擦痕面 slickenside 上）主要有兩種：

| 種類 | 怎麼形成 | 特徵 |
|---|---|---|
| **機械磨蝕**（溝痕、刻痕 striation） | 堅硬的物體或**粗糙體**在面上刻出線狀溝痕 | 出現在**滑動時沒有張開**的面上；1951 年玉里地震的地表破裂有這種擦痕 |
| **纖維生長**（滑動纖維） | 斷層滑動時，礦物順著滑動方向在張開的空隙結晶 | 常伴隨**階狀構造**（steps），可判斷滑動方向 |

同一個斷層面上（例如蛇紋岩）有**兩組互相垂直**的礦物線理，代表在**兩個不同應力場**下滑動過。

**判斷滑動方向的指標**（Angelier 1994）：礦物階梯、構造刻痕、Riedel 剪裂、縫合線尖峰、交替的磨光面、張裂隙、共軛剪裂、拋物線痕、熔岩中變形的氣泡（接 Ch10 的運動學指標）。

### 纖維脈

在張裂隙中，纖維（例如**滑石**）**垂直裂隙壁**生長，記錄裂隙張開的方向。脈的生長方式有兩種：

<VeinGrowthFig />

| | **同向脈** synaxial | **反向脈** antiaxial |
|---|---|---|
| 生長方向 | 從**脈壁往中間**長 | 從**中間帶往兩側脈壁**長 |
| 最老的部分 | 靠**脈壁** | **中間帶** |
| 礦物 | 和**圍岩相同**的礦物 | 真正的纖維狀礦物，和**圍岩不同** |
| 機制 | **crack-seal**：反覆裂開、間歇癒合 | 脈沿兩側的兩個生長面變寬 |
| 條件 | | 變質作用開始到中綠色片岩相（約 **350 °C**）以下；例：反向石膏脈 |

### 變形帶中的線理

多孔砂岩的變形帶（Entrada 砂岩，猶他州）之間沒變形的岩塊呈**雪茄狀**，線理沿傾向往下，反映這些雪茄形岩塊的長軸方向。

**脆性和塑性區的礦物線理差在哪**：塑性區的礦物線理是整塊岩石的**貫穿組構**，由再結晶和壓溶形成，記錄應變（X 軸）；脆性區的線理多半只在**斷層面、脈裡**（表面線理），由磨蝕或在張開空隙中的纖維生長形成，記錄**滑動或張開方向**。

## 5. 線狀構造的位態

| 量 | 定義 |
|---|---|
| **趨向** trend | 線投影到水平面上的方位（羅盤方向） |
| **傾伏角** plunge | 在平行趨向的垂直面上，線和水平面的夾角 |
| **側傾角** rake／pitch | 線躺在某個面上時，線和**該面走向**的夾角 |

斷層擦痕常用側傾角記錄：先量斷層面的走向、傾角，再量擦痕和走向的夾角，之後用赤平投影換成趨向和傾伏（立體投影頁）。

<details>
<summary>【例題 完整解】一條擦痕在一個走向 N0°E（000）、往東傾 60° 的斷層面上，側傾角 90°。它的趨向和傾伏角多少？</summary>

側傾角 90° 表示擦痕垂直走向，也就是沿著傾向往下 → 趨向 = 傾向 **090**，傾伏角 = 斷層傾角 **60°**。這條斷層是純傾滑斷層。

</details>

## 6. 線理和搬運方向 ★

**Sander 的運動學軸**（已不太使用）：**a 軸**是搬運方向，**c 軸**垂直剪切面，b 軸垂直前兩者。

**線理平行 a 軸還是 b 軸？** 大多數情況下，**線理平行 a 軸**（搬運方向）；而且**應變越大，線理越往 a 軸轉**。

**褶皺軸和拉伸線理**：

- 褶皺軸可以**平行**拉伸線理，也可以**垂直**。
- 在剪切帶中，褶皺剛形成時軸可以和搬運方向夾任何角度，隨應變累積、褶皺變緊，軸會往搬運方向轉。
- **純剪**：褶皺軸和拉伸線理最後**完全平行**；**簡單剪切**：**接近平行**。
- 所以**用褶皺的對稱去推搬運方向並不可靠**。

**拉伸線理 = 搬運方向投影到剪切面上**，但這是在簡單剪切的假設下才成立。純剪時根本沒有「搬運方向」，所以**從拉伸線理推搬運方向之前，一定要先有應變模型**（純剪、簡單剪切或兩者組合）。

<summary>自我檢測 6</summary>

1. 為什麼從拉伸線理推搬運方向前要先有應變模型？
2. 褶皺軸能不能用來推搬運方向？

**答案**：(1) 簡單剪切時拉伸線理會隨應變轉向搬運方向（a 軸），可以代表它；純剪時沒有單一的搬運方向，線理只代表 X 軸。不同模型下，線理和搬運方向的關係不同。(2) 不可靠。褶皺軸可以平行也可以垂直拉伸線理，而且會隨應變轉動。

</details>

## 容易混淆的地方

| 容易搞混 | 正確理解 |
|---|---|
| 線型 = 線理？ | 線型是**影像、地形**上的大尺度線；線理是**岩石**裡的組構 |
| 所有線理都是 X 軸？ | 只有拉伸、礦物線理大致是 X；**交面、夾皺、褶皺軸**是幾何線理；擦痕是**滑動方向** |
| 串腸軸平行伸張方向？ | 串腸軸**垂直**伸張方向 |
| 窗櫺可以判斷上下？ | **不行**，形狀由硬度差決定 |
| 窗櫺的尖端指向軟層？ | 硬層凸向軟層，**尖端指向硬層** |
| 同向脈中間最老？ | 同向脈**靠壁最老**；反向脈才是**中間最老** |
| 褶皺軸一定垂直搬運方向？ | 可以平行也可以垂直，應變大時會**轉向搬運方向** |
| 側傾角 = 傾伏角？ | 側傾角在**面上**量（和走向夾角）；傾伏角在**垂直面**量（和水平夾角） |

## 章末綜合題

<details>
<summary>1.（課堂複習題）窗櫺構造和拱彎褶皺哪裡相似？</summary>

都由**黏度差**控制、在平行層面（界面）縮短時形成的不穩定性；硬的一側決定形狀。窗櫺是界面上的尖狀波紋，硬層凸起、尖端指向硬層，和多層拱彎中軟層形成的尖瓣一樣。

</details>

<details>
<summary>2.（課堂複習題）串腸構造和應變橢球有什麼關係？</summary>

串腸代表層面方向**伸長**：伸張方向接近 X 軸，串腸軸垂直伸張方向。平面應變時串腸軸平行 Y；壓扁應變時層面兩個方向都伸長，形成巧克力塊狀的串腸。

</details>

<details>
<summary>3.（課堂複習題）脆性區和塑性區形成的礦物線理差在哪？</summary>

塑性區：貫穿整塊岩石，由再結晶、壓溶、旋轉形成，記錄應變的 X 軸；脆性區：多半只在斷層面或脈中，由磨蝕或在張開空間中的纖維生長形成，記錄滑動或張開方向。

</details>

<details>
<summary>4.（判讀）一個剪切帶裡，拉伸線理往 120° 傾伏 10°，褶皺軸往 300° 傾伏 8°，褶皺很緊。搬運方向大概是什麼？</summary>

褶皺軸和拉伸線理幾乎平行（120 和 300 是同一條線的兩端），褶皺又很緊 → 應變很大，褶皺軸已經轉到搬運方向。如果是簡單剪切，搬運方向大約是 **120–300 方向**（西北西–東南東）。要判斷往哪一邊搬運，還要看剪切方向指標（S–C 組構、旋轉碎斑、Ch13 的剪切帶）。

</details>
