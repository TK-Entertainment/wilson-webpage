---
title: 公式總表
description: 地球構造第 1–10 章的必背公式
---

| 主題 | 公式 |
|---|---|
| 應變 | e = (l−l₀)/l₀；s = 1+e；λ = s²；γ = tanψ；R = X/Y |
| Flinn | k = (X/Y − 1)/(Y/Z − 1) |
| 體積變化 | Δ = (V − V₀)/V₀ |
| 靜岩壓 | σV = ρgz（~26–30 MPa/km） |
| Mohr | σn = (σ1+σ3)/2 + (σ1−σ3)/2·cos2θ；σs = (σ1−σ3)/2·sin2θ |
| 平均應力 | σm = (σ1+σ2+σ3)/3 |
| 單軸應變 | σH = ν/(1−ν)·σV；σdiff = (1−2ν)/(1−ν)·σV |
| 熱應力 | ΔσH = EαΔT/(1−ν) |
| 彈性 | σ = Ee；σs = μγ；μ = E/2(1+ν)；K = E/3(1−2ν)；Vs = √(G/ρ) |
| 黏性 | σs = ηγ̇；Maxwell tM = η/G |
| Maxwell / Kelvin | ė = σ̇/E + σ/η；σ = Eε + η dε/dt |
| Bingham / Prandtl | τ = τy + ηγ̇；ε = σ/E + εp |
| 冪律潛變 | ė = Aσⁿ exp(−Q/RT) |
| 褶皺主導波長 | L = 2πt(ηL/6ηM)^(1/3) |
| Byerlee | σs = 0.85σn；σs = 50 + 0.6σn |
| 摩擦強度 | σ1 − σ3 ≥ βρgz(1−λ)；β = 3 / 1.2 / 0.75 |
| Coulomb | σs = C + μσn；θ = 45° + φ/2；有效 σs = C + μ(σn − pf) |
| Griffith | σs² = 4T(σn + T)（壓為正）；C = 2T；UCS = 8T |
| 應力集中 | σtip = σr(1 + 2a/c) |
| 水力破裂 | Pf \> σ3 + T |
| 節理流量 | Q = −ρg b³ HΔP / 12μ |
| 位移–長度 | Dmax = γLⁿ |
| Coulomb 應力變化 | ΔCFS = Δτs − μ(Δσn − Δp) |
| 應力形狀比 | Φ = (σ2−σ3)/(σ1−σ3) |
| InSAR | Δφ = 4π(R1−R2)/λ（一環 = λ/2） |
| 單位 | 1 kbar = 100 MPa；1 GPa = 10 kbar；1 bar = 10⁵ Pa |
