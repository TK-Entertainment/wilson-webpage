---
title: 公式總表
description: 地球構造第 1–10 章的必背公式
---

| 主題 | 公式 |
|---|---|
| 應變 | $e = (l-l_0)/l_0$；$s = 1+e$；$\lambda = s^2$；$\gamma = \tan\psi$；$R = X/Y$ |
| Flinn | $k = \dfrac{X/Y - 1}{Y/Z - 1}$ |
| 體積變化 | $\Delta = (V - V_0)/V_0$ |
| 靜岩壓 | $\sigma_V = \rho g z$（約 26–30 MPa/km） |
| Mohr 圓 | $\sigma_n = \frac{\sigma_1+\sigma_3}{2} + \frac{\sigma_1-\sigma_3}{2}\cos 2\theta$；$\sigma_s = \frac{\sigma_1-\sigma_3}{2}\sin 2\theta$ |
| 平均應力 | $\sigma_m = (\sigma_1+\sigma_2+\sigma_3)/3$ |
| 單軸應變 | $\sigma_H = \frac{\nu}{1-\nu}\sigma_V$；$\sigma_{\text{diff}} = \frac{1-2\nu}{1-\nu}\sigma_V$ |
| 熱應力 | $\Delta\sigma_H = \dfrac{E\alpha\Delta T}{1-\nu}$ |
| 彈性 | $\sigma = Ee$；$\sigma_s = \mu\gamma$；$\mu = \frac{E}{2(1+\nu)}$；$K = \frac{E}{3(1-2\nu)}$；$V_s = \sqrt{G/\rho}$ |
| 黏性 | $\sigma_s = \eta\dot\gamma$；Maxwell $t_M = \eta/G$ |
| Maxwell／Kelvin | $\dot e = \dot\sigma/E + \sigma/\eta$；$\sigma = E\varepsilon + \eta\,d\varepsilon/dt$ |
| Bingham／Prandtl | $\tau = \tau_y + \eta\dot\gamma$；$\varepsilon = \sigma/E + \varepsilon_p$ |
| 冪律潛變 | $\dot e = A\sigma^n\exp(-Q/RT)$ |
| 褶皺主導波長 | $L = 2\pi t\left(\dfrac{\eta_L}{6\eta_M}\right)^{1/3}$ |
| Byerlee | $\sigma_s = 0.85\sigma_n$；$\sigma_s = 50 + 0.6\sigma_n$（MPa） |
| 摩擦強度 | $\sigma_1 - \sigma_3 \ge \beta\rho g z(1-\lambda)$；$\beta = 3,\ 1.2,\ 0.75$ |
| Coulomb | $\sigma_s = C + \mu\sigma_n$；$\theta = 45^\circ + \varphi/2$；有效 $\sigma_s = C + \mu(\sigma_n - p_f)$ |
| Griffith | $\sigma_s^2 = 4T(\sigma_n + T)$（壓為正）；$C = 2T$；UCS $= 8T$ |
| 應力集中 | $\sigma_{\text{tip}} = \sigma_r(1 + 2a/c)$ |
| 水力破裂 | $P_f > \sigma_3 + T$ |
| 節理流量 | $Q = -\dfrac{\rho g\,b^3}{12\mu}H\Delta P$ |
| 位移–長度 | $D_{\max} = \gamma L^n$ |
| Coulomb 應力變化 | $\Delta\mathrm{CFS} = \Delta\tau_s - \mu(\Delta\sigma_n - \Delta p)$ |
| 應力形狀比 | $\Phi = \dfrac{\sigma_2-\sigma_3}{\sigma_1-\sigma_3}$ |
| InSAR | $\Delta\phi = \dfrac{4\pi}{\lambda}(R_1 - R_2)$（一環 = $\lambda/2$） |
| 單位 | 1 kbar = 100 MPa；1 GPa = 10 kbar；1 bar = 10⁵ Pa |
