**這章在回答**：野外看到一條斷層，怎麼確定它真的是斷層？怎麼看出它往哪個方向動？能不能從很多條斷層的擦痕，反推當時的應力？這一章把整門課的推理方向倒過來：Ch1 到 Ch9 是「應力 → 變形」，這裡是「變形 → 應力」，從運動學分析走回動力學分析。

**考前 30 秒**

1. 判定斷層：**斷層面**（擦痕、階狀）＋ **斷層帶**（角礫、斷層泥、糜稜岩）＋ **構造錯動**（不連續、地層重複或缺失、拖曳、次生破裂）＋ **地形**（斷錯河等）。
2. 擦痕只記錄**最後幾次**滑動，不一定平行總位移。
3. 運動學指標：**鬆弛階 → 纖維、受阻階 → 縫合線**；Riedel：**R 同向（~15°）、R′ 反向（~75°）、P（−15°）、T（張裂，平行 σ1）**。
4. 共軛斷層：**σ1 平分銳角、交線 = σ2**。
5. **Wallace–Bott**：滑動方向平行面上的**最大分解剪應力**；前提：平面斷層、剛性斷塊、無旋轉、單期、均勻應力場。
6. 簡化應力張量 **4 個未知數**：3 個主軸方向 + $\Phi = \frac{\sigma_2-\sigma_3}{\sigma_1-\sigma_3}$；資料 \> 4，通常 10–20 條以上。
7. 震源機制：**黑色含 T、白色含 P**；中央白正斷層、中央黑逆斷層；**P、T ≠ σ1、σ3**（只有斷層和 σ1 夾 45° 時才重合）。

## 1. 怎麼判定斷層存在

斷層是原本完整的岩石受剪力產生破裂、兩側沿破裂面滑動的結果。所以判定斷層存在，不只要確定有**破裂面或破裂帶**，還要確定有**岩體滑動造成的現象**（p.18）：

1. **斷層面**的確定：擦痕（滑動線）、階梯構造。
2. **斷層帶**的確定：斷層角礫、斷層泥、糜稜岩（Ch9）。
3. **斷盤的相對滑動造成的構造變化**：(1) 原本連續的構造被錯開；(2) 地層**重複或缺失**；(3) 斷盤中產生**拖曳褶皺**或**次生破裂**。
4. **斷層引起的地形變化**：斷錯河、斷層崖、三角切面、斷層池、斷頭河等。

## 2. 運動學指標：斷層往哪個方向動 ★

古應力分析的目標，是用斷層的量測資料算出**古應力張量**，替脆性構造的運動學分析加上動力學（應力方向）的解釋。第一步是確定每條斷層的**滑動方向和方向感**。

**基本假設**：斷層面上的線理（擦痕、纖維）代表位移方向。但要注意，它**只記錄最後幾次滑動**，不一定平行整條斷層的總位移向量。

運動學指標分三大類（p.2）：

**(1) 礦物成長與縫合線**：斷層面上的不規則形成一個個階，滑動時有的階被拉開、有的被擠壓。

<StepsFibersFig />

**溶滑痕**（slickolite）：在石灰岩陡傾的層面上，滑動加上壓溶形成的、垂直不連續的擦痕面，富含不溶物質、形狀不規則，介於擦痕面和縫合線之間（p.4）。

**(2) 次生破裂**（Riedel 模型）：主斷層旁會長出和它成固定角度的小破裂（p.5–6），幾何就是 Ch2–3 的右移剪切帶：

<SubsidiaryFig />

| 裂隙 | 和主滑動面 M 的角度 | 運動 |
|---|---|---|
| **R** | 約 15°（R 和 M 的銳角指向本盤的運動方向） | **同向**（和主斷層一樣，例如右移） |
| **R′** | 約 75° | **反向**（左移） |
| **P** | 約 −15°（和 R 對稱） | 同向 |
| **T** | 約 45°，平行 σ1 | 張裂，可被礦物充填 |

在斷層面上看（剖面），R 像小角度的正「斷層」、R′ 像反向的逆「斷層」（p.5）。實驗中，剪切帶先長出 R 和 R′，後來 R 再被 P 破裂連接起來，形成連續的斷層（p.6）。

**(3) 刻劃、礦物成長與擦痕面**：硬的突起或碎屑在斷層面上犁出溝痕，尾端常有尖的突起或碎屑本身（p.7）；脊–溝線理；新月形的**顫動擦痕**（chatter marks）；**皺紋線**（corrugation）：斷層泥在滑動時堆積成的大型溝紋，例如 1951 年玉里地震的地表破裂（徐鐵良教授攝）。

**走滑雙重構造**：平移斷層在鬆弛的地方形成張扭（transtensile）雙重構造，受阻的地方形成壓扭（transpressive）雙重構造（p.3）。

## 3. 從運動學到應力：共軛斷層 ★

**前提**（p.8）：古應力指標必須只記錄**小應變**、沒有太多旋轉，應變軸和應力軸才能對應起來。大應變、非共軸的變形中，有限應變軸會一直旋轉（Ch2–3），就不能直接拿來當應力軸。例如左階排列的雁行岩脈，也可以當古應力指標（岩脈垂直 σ3）。

**最簡單的情況：一對共軛斷層**（p.9–10，就是 Ch1 的 Anderson）。一右移一左移（或兩條傾向相反的正斷層）的共軛剪裂：

- 兩條斷層的**交線 = σ2**；
- **σ1 平分銳角**，σ3 平分鈍角。

在赤平投影上：兩個大圓的交點就是 σ2；過 σ2 的大圓（垂直 σ2 的面）上，σ1 在兩個大圓夾銳角的那一側，和兩者等角；σ3 和 σ1 夾 90°。

**假設**：岩石均向、應力場方向不變、斷塊的旋轉可以忽略；而且是**正交對稱**：兩對成因相關的裂面同時存在。從動力學看，均勻均向的岩石在應力狀態碰到破壞包絡線時，依 Mohr–Coulomb 準則產生剪裂（Ch7）。

## 4. 應力反演：Wallace–Bott 假設 ★

大部分地區的斷層不是整齊的一對，而是方向各異的一群。這時用 **Wallace–Bott 假設**（考古題：這個假設主張什麼？）：

> 平面破裂上的滑動，可以假設**平行該面上的最大分解剪應力**。

也就是說，給定一個應力狀態，每一個方向的面上都有一個確定的剪應力方向，斷層就沿著它滑。反過來，量一群斷層的位態和滑動方向（含方向感），就能找出讓所有斷層的擦痕都「對得上」的應力，這叫**應力反演**（斷層滑動反演）。

**先預測**：同一個正斷層應力場（σ1 垂直），一條斜交 σ3 的正斷層，擦痕會是純粹的傾移嗎？

<WallaceBottDemo />

**這個假設隱含的條件**（考古題：成功的古應力分析要有哪些前提？）：斷層是**平面**、斷塊是**剛性**的、斷塊的**旋轉可以忽略**、所有斷層都在**單一期**變形中、在**均勻的應力場**下活動。有多期變形時，要先把資料分期再分別反演。

**能求出什麼：簡化應力張量**。對應力張量加上一個等向分量，或乘上一個常數，主軸方向和應力橢球的形狀都不會變，滑動方向也不會變。所以從擦痕只能求**相對大小**。取 λ = −σ3、k = 1/(σ1 − σ3)，

$$
\begin{pmatrix} \sigma_1 & 0 & 0 \\ 0 & \sigma_2 & 0 \\ 0 & 0 & \sigma_3 \end{pmatrix} \;\longrightarrow\; k\left[\begin{pmatrix} \sigma_1 & 0 & 0 \\ 0 & \sigma_2 & 0 \\ 0 & 0 & \sigma_3 \end{pmatrix} + \lambda I\right] = \begin{pmatrix} 1 & 0 & 0 \\ 0 & \Phi & 0 \\ 0 & 0 & 0 \end{pmatrix}, \qquad \Phi = \frac{\sigma_2-\sigma_3}{\sigma_1-\sigma_3},\ 0 \le \Phi \le 1
$$

只剩 **4 個未知數**：三個主軸的方向（3 個角度）和形狀比 Φ。所以資料至少要多於 4 條滑動面，實務上通常要 10–20 條以上（作業 10-01 用 Angelier 1979 在克里特島的 10 條正斷層，老師提醒理想上約要 40 條）。常用軟體：FaultKin。

<PhiFig />

**應力軸交換**（作業 10-02，Hu & Angelier 2004）：當兩個主應力大小接近時，小的擾動（例如斷層活動、裂谷張開造成的局部應力變化）就能讓它們的方向互換。**低 Φ** 有利 σ2/σ3 交換（例如原本的正斷層體制，σ2、σ3 互換後，會形成和原本正斷層垂直的另一組正斷層）；**高 Φ** 有利 σ1/σ2 交換（例如正斷層和平移斷層體制互換）。所以一個地區看到兩組互相垂直的同類斷層，不一定代表兩期不同的構造事件。

**切線–線理圖**（p.15）：把每條斷層畫成它的極點，再在極點上畫一個箭頭：箭頭沿著 M 面（包含線理和斷層面極點的面）的切線方向，表示**下盤相對上盤**的運動。一群斷層的箭頭排列，能直接看出主應力軸的大致位置。

## 5. 震源機制 ★

地震本身也提供斷層滑動的資訊。由 P 波的初動（或用波形反演地震矩張量）可以畫出**震源機制**（海灘球）：

<BeachballFig />

- **判讀**：黑色是壓縮初動象限（含 T 軸），白色是伸張初動象限（含 P 軸）。中央白 → 正斷層；中央黑 → 逆斷層；四個象限 → 平移斷層。
- 兩個節面中哪一個是**真正的斷層面**，除非有餘震分布等其他資料，否則**無法確定**（震源機制本身對兩個面是對稱的）。
- **P、T 軸 ≠ σ1、σ3**：P、T 軸永遠平分兩個節面（和節面夾 45°），所以只有斷層剛好和 σ1 夾 45° 時兩者才重合。真實斷層通常和 σ1 夾約 30°（Ch7），甚至是沿既有弱面再活動的任意方向；**低角度逆衝斷層**的 P、T 軸和主應力差最多（Hu et al. 2007）。所以用一群震源機制做應力反演，也要用和斷層滑動資料一樣的 Wallace–Bott 方法，而不是直接把 P、T 當成 σ1、σ3。

**答案**：(1) 黑色壓縮初動（含 T）、白色伸張初動（含 P）；中央白正斷層、中央黑逆斷層、四象限平移。(2) 兩個節面在初動分布上是對稱的。(3) P、T 平分節面、和節面夾 45°，而斷層通常和 σ1 夾約 30° 或沿既有弱面；只有斷層和 σ1 夾 45° 時相等。

## 容易混淆的地方

| 容易搞混 | 正確理解 |
|---|---|
| 擦痕 = 總位移方向？ | 擦痕只記錄**最後幾次**滑動 |
| 鬆弛階形成縫合線？ | 鬆弛階長**纖維**；受阻階形成**縫合線** |
| R 是反向剪裂？ | **R 同向**、**R′ 反向** |
| T 破裂垂直 σ1？ | T 是張裂，**平行 σ1**、垂直 σ3 |
| 應力反演可以得到應力的絕對大小？ | 只能得到主軸方向和 **Φ**（相對大小） |
| Φ = 0 是 σ1 = σ2？ | Φ = 0 是 **σ2 = σ3**；Φ = 1 是 σ1 = σ2 |
| 兩個節面都是斷層面？ | 只有一個是，無法單從震源機制判斷 |
| P 軸 = σ1？ | 只有斷層和 σ1 夾 45° 時才相等 |
| 兩組垂直的正斷層一定是兩期？ | 也可能是 σ2/σ3 **應力軸交換** |

<summary>1.（觀念）用構造分析的層次，說明從野外量測到古應力張量的完整流程。</summary>

幾何：量每條斷層的走向傾角、擦痕的方向（trend/plunge 或 rake）。運動學：用纖維、縫合線、Riedel 剪裂等指標判斷每條斷層的滑動方向感，並確認是單一期（必要時分期）。動力學：假設 Wallace–Bott（滑動平行最大分解剪應力），在剛性斷塊、無旋轉、均勻應力場的前提下做應力反演，求出 σ1、σ2、σ3 的方向和 Φ（簡化應力張量，4 個未知數，需要 10–20 條以上資料）。構造：把古應力放回區域構造，解釋造山帶或盆地的演化，並和震源機制、現地應力（Ch4–5）比較。

</details>

<details>
<summary>2.（考古）一條右移斷層旁看到四組小破裂，怎麼用它們確認主斷層是右移的？</summary>

畫出主斷層 M。和 M 夾約 15°、同樣右移的是 R；夾約 75°、左移的是 R′；夾約 −15° 的是 P；夾約 45°、被礦物充填的是 T（張裂，平行 σ1）。如果 R 和 M 的銳角、T 的方向都符合右移剪切帶的幾何（Ch2–3：T 沿 135°、R 沿 −15°），而 R′ 是左移，就確認主斷層是右移。

</details>

<details>
<summary>3.（計算）一個應力狀態 σ1 = 100、σ2 = 60、σ3 = 20 MPa。Φ 是多少？如果加上 30 MPa 的孔隙壓（全部主應力減 30），Φ 變不變？擦痕方向變不變？</summary>

Φ = (60 − 20)/(100 − 20) = **0.5**。減去孔隙壓：(70, 30, −10)，Φ = (30 + 10)/(70 + 10) = **0.5**，不變。擦痕方向也不變，因為等向分量不影響主軸方向和形狀（這正是應力反演只能得到簡化應力張量的原因），但孔隙壓會影響斷層**會不會**滑（Ch7）。

</details>

<details>
<summary>4.（作業 10-02）如果裂谷張開後發生 σ2/σ3 或 σ1/σ2 的應力軸交換，會觀察到什麼構造？</summary>

原本正斷層體制（σ1 垂直、σ3 垂直裂谷軸）。σ2/σ3 交換（低 Φ 時容易）：σ3 轉到平行裂谷軸，形成和原本正斷層**垂直**的另一組正斷層，地塹被橫向切成格子狀。σ1/σ2 交換（高 Φ 時容易）：σ1 變成水平、σ2 變成垂直，原本的正斷層體制變成平移斷層體制，出現平移斷層或在既有正斷層上產生斜移擦痕。兩種情況都可能在同一期應力場中發生，不代表不同的構造事件。

</details>
