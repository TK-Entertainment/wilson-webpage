**這章在回答**：岩石在什麼應力下會破？破裂面會朝哪個方向？為什麼剪裂不在剪應力最大的 45°？為什麼岩石比理論上弱很多？Ch6 說淺處的岩石是脆性的，這一章就是脆性區裡發生的事；它的結果直接接到 Ch8（張裂：節理）和 Ch9（剪裂長大：斷層）。

**考前 30 秒**

1. 三種破裂：**張裂**（Mode I，⊥ σ3）、**剪裂**（Mode II／III，和 σ1 夾 ~30°、共軛、交線平行 σ2）、**閉合**（Mode IV，縫合線，⊥ σ1）。
2. 圍壓 ↑：強度 ↑、延展性 ↑；孔隙壓 ↑：相當於降低圍壓；溫度 ↑：強度 ↓、延展性 ↑；應變率 ↑：強度 ↑、偏脆性。
3. Coulomb：$\sigma_s = C + \sigma_n\tan\varphi$；剪裂面法線和 σ1 夾 $\theta = 45^\circ + \varphi/2$，所以**面和 σ1 夾 45° − φ/2 ≈ 30°**。
4. Griffith：$\sigma_s^2 = 4T(\sigma_n + T)$；C = 2T；單壓強度 ≈ 8T。尖端應力集中 $\sigma_{tip} = \sigma_r(1 + 2a/c)$。
5. 孔隙壓讓 Mohr 圓**往左移、半徑不變** → 水力破裂。既有斷層沒有內聚力，比較容易滑（Byerlee）。
6. 變形帶只在**高孔隙**顆粒介質；比剪裂寬、位移小、降低滲透率。

## 1. 破裂的種類與方位 ★

脆性區的變形機制有：破裂、摩擦滑動，以及兩種「脆性流」：**顆粒流**（顆粒平移、轉動，靠顆粒邊界的摩擦滑動調節，常見於孔隙多的岩石和沉積物）和**碎裂流**（再加上顆粒破碎，在中尺度上看起來是連續的、韌性的）。另外有一種**粉碎化**（pulverization）：顆粒強烈破碎但沒有剪位移，應變率極高（\> 100 s⁻¹），和大地震的高速破裂有關。

破裂依兩側的相對運動分類：

<FractureModesFig />

| 破裂 | 模式 | 和主應力的關係 |
|---|---|---|
| 張裂：節理、裂縫、脈 | Mode I 張開 | **⊥ σ3**、平行 σ1 |
| 剪裂（mm–dm 的小位移） | Mode II 滑動、III 撕裂 | 共軛一對，各和 σ1 夾約 30°；交線平行 σ2；σ1 平分銳角 |
| 閉合：縫合線 | Mode IV | **⊥ σ1** |
| 混合型（hybrid） | 剪 + 張 | 介於兩者之間 |

> **易錯**：投影片 p.7 提醒，教科書 Fig. 7.6 的 Mode IV 不應畫出任何滑動位移，它只有閉合。

## 2. 什麼條件下會脆、會韌：四個環境因子 ★

考古題：請以岩石力學實驗的應力–應變曲線為基礎，畫出圍壓、孔隙壓、溫度、應變率四個因子對曲線的影響，並討論它們對岩石力學性質的影響。

| 因子增加 | 強度 | 延展性 | 實驗例子 |
|---|---|---|---|
| 圍壓 P<sub>c</sub> | ↑ | ↑ | 大理石：圍壓 0–14 MPa 時破裂後應力下降；21 MPa 以上持續塑性流動。超過臨界圍壓（埋藏深度），岩石塑性變形時仍保持強度 |

## 3. 破壞準則：Mohr 圓碰到包絡線就破 ★

把很多次實驗中岩石**破裂當下**的應力狀態畫成 Mohr 圓，這些圓的包絡線就是**破壞包絡線**。在 Mohr 圖上判斷：

- 圓在包絡線內：**穩定**的應力狀態，岩石承受得住；
- 圓和包絡線相切：**臨界**應力狀態，正要破裂；
- 圓穿出包絡線：**不可能**的狀態，在到達之前早就破了。

**Coulomb 準則**（壓縮區）：岩石破裂要同時克服內聚力和面上的摩擦（正應力越大，摩擦越大），像物體在斜面上要突破最大靜摩擦力：

$$
\sigma_s = C + \sigma_n\tan\varphi = C + \mu\,\sigma_n
$$

大多數岩石 φ ≈ 30°（μ ≈ 0.6）。

**破裂朝哪個方向？** 圓和直線相切的點，從圓心看過去和 σ1 端夾 2θ。因為切點的半徑垂直切線，而切線的傾角是 φ，幾何上得到

$$
2\theta = 90^\circ + \varphi \quad\Rightarrow\quad \theta = 45^\circ + \frac{\varphi}{2}
$$

θ 是 σ1 和破裂面**法線**的夾角，所以**破裂面和 σ1 夾 90° − θ = 45° − φ/2 ≈ 30°**。一對共軛剪裂（一條右移、一條左移）夾約 60°，σ1 平分這個銳角。

**為什麼不在 45°？**（考古題、Hw01）

<Why30Fig />

**Griffith 準則**（張力區）：從微裂隙的應力集中推導出來（第 4 節），在 Mohr 圖上是一條躺著的拋物線：

$$
\sigma_s^2 = 4T(\sigma_n + T)
$$

它和橫軸交在 σn = −T（抗張強度），在 σn = 0 時 σs = 2T，所以 **C = 2T**；也可以推出**單軸抗壓強度 = 8T**（實驗上抗壓強度是抗張強度的 10–50 倍）。

**組合的 Griffith–Coulomb 準則**：張力區用拋物線、壓縮區用直線 σs = 2T + μσn。對非孔隙岩石，Griffith 在壓縮區也還算合理；對孔隙介質（砂、砂岩），組合準則相當實際。Coulomb 直線也只適用有限的圍壓範圍：低圍壓時包絡線較陡、高圍壓時較緩，整體像一條躺著的拋物線。到了很高的圍壓（韌性區）則用 **von Mises 準則**：剪應力是常數，包絡線變成水平。

**先預測**：σ1 = 60、σ3 = 20 MPa 的岩石不會破。如果只增加孔隙壓，它最後會產生張裂還是剪裂？如果差應力很小呢？

<FailureDemo />

**圓碰到包絡線的哪一段，就形成哪種破裂**：

| 應力狀態 | 碰到哪段 | 破裂 |
|---|---|---|
| σ3 為張應力、差應力小（圓小） | 左端 −T 點 | **張裂**（節理、脈），⊥ σ3 |
| σ3 \< 0、差應力較大 | Griffith 拋物線段 | **混合型破裂**，和 σ1 夾角 \< 30° |
| σ3 \> 0 | Coulomb 直線 | **共軛剪裂**，和 σ1 夾 ~30° |
| 高圍壓 | 包絡線變平 | 剪力帶、分散的變形帶（脆–塑轉換） |
| 很高圍壓 | von Mises | 塑性流動，剪切帶和 σ1 夾 ~45° |

**張裂需要什麼條件？** 圓要碰到左端，必須**差應力小於 4T**（圓的直徑比 4T 小，才能在碰到拋物線之前先碰到 −T），而且有效的 σ3 要到 −T。這是 Ch8 節理形成條件的基礎。

## 4. 為什麼岩石比理論弱：Griffith 裂隙 ★

考古題：**為什麼晶體實際上的強度比理論強度低這麼多？**

1920 年代 Griffith 認為：任何材料天生就有很多**微裂隙**（顆粒邊界、顆粒之間的空隙、顆粒內部的裂隙），統稱 **Griffith 裂隙**。受力時微裂隙尖端會產生**應力集中**，即使遠方的應力遠小於材料的抗張強度，尖端的張應力也足以超過強度，裂隙就開始擴展。

<GriffithFig />

$$
\sigma_{\text{tip}} = \sigma_r\left(1 + \frac{2a}{c}\right)
$$

裂隙越扁（a/c 越大），應力集中越大。一旦裂隙開始長大，長寬比變得更大，應力集中更強，於是**越長越快**。這也是為什麼大的樣本比小的弱：含有大裂隙的機率比較高（「瑕疵讓世界美麗」，p.22）。

**破裂怎麼長大**：裂隙尖端前方有一個**破裂推進區**（process zone），裡面的微缺陷擴張、連接，宏觀裂隙才能成長。剪裂尖端的 Griffith 裂隙會長出平行 σ1 的**翼裂隙**；翼裂隙又被新的剪裂截斷，這個過程隨主裂隙成長一再重複。所以剪切型裂隙看起來像小斷層，但它**不會沿著自己的面成長**，而是一直孵化出新的張裂。

**破裂的末端與交互作用**（p.25）：翼裂隙、分枝斷層（splay）、**馬尾狀**（horsetailing，片麻岩中剪裂末端常見），以及 **Riedel 剪裂**：R 是同向剪裂、R′ 是反向剪裂（Ch10）。

> **易錯**：投影片 p.25 把 R、R′ 的「同向／反向」標反了，以 Ch10 和教科書為準：**R（R1）同向、R′（R2）反向**。

**既有的面理**（層理、葉理、板劈理）也會影響破裂：在某個方位範圍內，岩石會沿著面理破壞（因為面理的強度較低），超出這個範圍才會切穿面理（p.26）。

<details>
<summary>【例題 ★ 完整解】一個長寬比 100 : 1 的微裂隙，遠場張應力 1 MPa，尖端應力多少？岩石抗張強度 50 MPa 時會不會擴展？</summary>

a/c = 100（a 是長半軸、c 是短半軸，比值不變），σ<sub>tip</sub> = 1 × (1 + 200) = **201 MPa**，遠大於 50 MPa，**會擴展**。只要遠場張應力超過 50/201 ≈ 0.25 MPa 就夠了，這就是岩石實際強度遠低於理論強度的原因。

</details>

**答案**：(1) 材料天生的微裂隙和瑕疵；尖端應力集中，遠場應力不大也能讓裂隙擴展。(2) σ<sub>tip</sub> = σ<sub>r</sub>(1 + 2a/c)；3 倍。(3) 傾斜裂隙的尖端仍有局部張應力；平行 σ1。

</details>

## 5. 孔隙壓、既有斷層與 Byerlee 摩擦 ★

**有效應力**：孔隙流體的壓力抵銷了一部分正應力，

$$
\sigma_s = C + \mu(\sigma_n - p_f), \qquad \sigma = \bar\sigma + p_f
$$

孔隙壓增加時，平均應力降低，Mohr 圓**往左（張力方向）移、半徑不變**（考古題：流體壓力對斷層作用的影響）。σ3′ 仍為正時碰到 Coulomb 直線 → 剪裂；圓夠小、移到碰到張力端 → **張裂**。更精確地說，孔隙壓對正應力的效果是 Δσn = φp<sub>f</sub> + (1 − φ)αp<sub>f</sub>（φ 孔隙率、α Biot 孔彈參數）。

**自然的水力破裂**（p.31）：砂岩的孔隙和裂隙充滿液體時，裂隙尖端的液壓超過 σ3，沿裂隙方向產生張應力；當張開應力大於孔隙液壓和顆粒的閉合應力總和（σ<sub>o</sub> \> σ<sub>cp</sub> + σ<sub>cg</sub>），裂隙尖端就往前擴展。

**什麼會提高孔隙壓？**（考古題）快速沉積造成的超壓；岩石逆衝覆蓋在沉積物上的載重；孔隙流體的熱膨脹；含水礦物脫水（伊萊石、石膏、蛋白石）；油母質轉化成烴類。

**既有斷層再活動**（p.27）：已經存在的斷層沒有內聚力，只要克服摩擦就會滑：

$$
\text{既有斷層：}\ \mu_f = \sigma_s/\sigma_n, \qquad \text{新斷層：}\ \sigma_s = C_f + \mu\sigma_n
$$

所以 Mohr 圓還沒碰到新斷層的包絡線時，就可能先讓既有斷層滑動（在互動圖中打開「既有斷層」比較）。這就是 Ch1 Anderson 理論的限制之一：既有的弱面會先再活動，方向不受 30° 規則限制。

**Byerlee 定律 ★**（考古題）：

$$
\sigma_s = 0.85\,\sigma_n\ (\sigma_n < 200\ \mathrm{MPa}); \qquad \sigma_s = 50 + 0.6\,\sigma_n\ (\sigma_n > 200\ \mathrm{MPa})
$$

除了幾種富水的黏土礦物（伊萊石、蛭石、蒙脫石）和蛇紋岩之外，**摩擦和岩性幾乎無關**。因為這種普遍性，可以用它估計天然斷層的強度（Ch6 的強度剖面）。為什麼 μ ≈ 0.6–0.85？它反映的是粗糙面之間接觸點（凸點）的剪斷，而接觸的真實面積隨正應力成比例增加，和岩石種類關係不大。

## 6. 孔隙岩石裡的變形帶 ★

考古題：**什麼是變形帶？和破裂有什麼不同？**

<DeformationBandsFig />

- 只出現在**高孔隙的顆粒介質**，尤其是孔隙砂岩。
- 和同樣位移的剪裂相比，變形帶**更寬、位移小**，不會發展出大的錯動；常以單一條、群集或帶狀出現，伴隨滑動面。
- 通常**降低孔隙率和滲透率**（顆粒破碎、壓實、膠結），所以會成為油氣或地下水的阻隔，野外常形成突起的稜。
- 低孔隙或無孔隙的岩石則形成一般的剪裂或張裂。

**依機制分類**（p.34–35）：

| 類型 | 機制 | 條件 |
|---|---|---|
| 崩解帶 | 顆粒流（顆粒邊界滑動、轉動） | 未固結的砂、膠結差的砂岩；常和局部重力有關（頁岩貫入、下方鹽移動） |
| 頁矽酸鹽帶 | 片狀礦物排列、沾污 | 片狀礦物 \> 10–15% |
| 黏土塗抹 | 黏土被拖曳成連續的層 | 黏土 \> ~40% |
| 碎裂帶 | 顆粒破碎（碎裂作用） | 埋深約 1.5–3 km 的弱固結層 |
| 溶解再膠結帶 | 溶解、膠結 | 較深（\> 2–3 km、\> 90 °C） |

不同類型的變形帶在**埋藏的不同階段**形成，因為孔隙率、滲透率、圍壓、應力狀態和膠結程度都會隨時間改變；一個地區的變形帶疊加關係，記錄了它的埋藏、岩化和抬升歷史（p.36）。

**答案**：(1) 變形帶只在高孔隙介質，比較寬、位移小、不會有大錯動。(2) 降低孔隙率和滲透率，形成流體的阻隔。(3) 崩解帶、頁矽酸鹽帶、黏土塗抹、碎裂帶、溶解再膠結帶。

## 容易混淆的地方

| 容易搞混 | 正確理解 |
|---|---|
| θ = 45° + φ/2 是破裂面和 σ1 的夾角？ | θ 是 σ1 和**法線**的夾角；破裂面和 σ1 夾 **45° − φ/2 ≈ 30°** |
| 剪裂發生在剪應力最大的 45°？ | 發生在 σs − μσn 最大的約 30° |
| σ3 平分共軛剪裂的銳角？ | **σ1** 平分銳角 |
| 張裂 ⊥ σ1？ | 張裂 **⊥ σ3**、平行 σ1；縫合線才 ⊥ σ1 |
| 孔隙壓讓 Mohr 圓變小？ | 圓**往左移、大小不變** |
| C = T？ | Griffith：**C = 2T**，單壓強度 = 8T |
| 應變率快 → 延展性高？ | 應變率快 → 強度高、**偏脆性** |
| 變形帶 = 小斷層？ | 變形帶只在高孔隙岩石，寬、位移小、不會有大錯動 |
| R 是反向剪裂？ | **R 同向、R′ 反向**（投影片 p.25 標反） |

<details>
<summary>1.（考古）影響岩體中破裂面發育的因子有哪些？各因子的影響為何？</summary>

應力狀態（差應力大小、σ3 是否為張應力，決定張裂或剪裂、方向）；圍壓（高圍壓偏韌性、強度高）；孔隙壓（降低有效應力，造成水力破裂）；溫度（高溫偏韌性、強度低）；應變率（快則偏脆性）；岩石性質（強度、孔隙率：高孔隙形成變形帶；E 大的硬層容易節理）；既有的面理和弱面（沿面理破壞或再活動）；抬升、冷卻和風化（例如錫安國家公園棋盤台地的水平破裂順層理、垂直破裂和剝露時的冷卻與應力釋放有關，被風化加強）。

</details>

<details>
<summary>2.（考古）在三軸壓縮破壞試驗中，為什麼剪裂面的位置通常不在剪應力最大的地方？用 Mohr 圖說明。</summary>

剪裂要克服內聚力和面上的摩擦，摩擦和正應力成正比，所以決定的是 σs − μσn，而不是 σs。45° 面上剪應力最大但正應力也大；往 σ1 靠近時正應力下降得比剪應力快。在 Mohr 圖上，圓和 Coulomb 直線的切點在 2θ = 90° + φ，所以破裂面和 σ1 夾 45° − φ/2，φ ≈ 30° 時約 30°。

</details>

<details>
<summary>3.（應用）一個逆衝斷層下盤的砂岩被快速覆蓋，孔隙壓升高到接近靜岩壓。用 Mohr 圖說明可能發生什麼破裂，以及對斷層的影響。</summary>

孔隙壓接近靜岩壓，有效應力很小，Mohr 圓往左移到接近原點：差應力小的話碰到張力端，產生水力破裂（張裂、脈）；差應力大的話碰到 Coulomb 線，產生剪裂。對逆衝斷層而言，有效正應力大幅降低，摩擦阻力變小，斷層可以在很小的差應力下滑動（解釋大型低角度逆衝斷層為什麼能移動）。

</details>

<details>
<summary>4.（計算）σ1 = 50、σ3 = 10 MPa 的岩石，T = 5 MPa、μ = 0.6。孔隙壓要增加到多少，才會破裂？是張裂還是剪裂？</summary>

差應力 40 MPa \> 4T = 20 MPa，所以不會是張裂，會先碰到 Coulomb 線（剪裂）。半徑 r = 20，切線條件：r = (2T + μ c′) cos φ … 用 r = c′ sin φ + C cos φ（C = 2T = 10，φ = 31°）：20 = 0.515 c′ + 10 × 0.857 → c′ = (20 − 8.57)/0.515 ≈ 22.2。原本圓心 30，所以 **p<sub>f</sub> ≈ 7.8 MPa** 時剪裂，破裂面和 σ1 夾約 30°。可以用互動圖驗證。
