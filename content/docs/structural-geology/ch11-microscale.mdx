**這章在回答**：同樣是石英，為什麼在淺處會碎、在深處卻像麥芽糖一樣流動？Ch6 用流動定律描述「岩石怎麼流」，這章鑽進礦物顆粒裡面，看流動實際上是怎麼發生的：原子層怎麼滑動、缺陷怎麼移動、顆粒怎麼重新長出來。看懂這些，就能反過來從薄片裡的顯微構造，讀出變形時的溫度和應力。

**考前 30 秒**

1. **溫度指標** $T_h = T/T_m$（都用絕對溫度）：低溫（\< 0.3）差排滑動、機械雙晶；中溫（0.3–0.7）差排潛變（滑動 + 爬升）、恢復、再結晶；高溫（\> 0.7）擴散潛變、顆粒邊界滑動（超塑性）。
2. 脆性 → 塑性的溫度：**石英約 300 °C、長石約 450 °C**（再結晶：方解石約 300、石英約 350、長石約 450 °C）。
3. **刃差排**：差排線 ⊥ 滑動方向，只能**爬升**（要空缺）；**螺旋差排**：差排線 ∥ 滑動方向，可以**側向滑動**。爬升、側滑都要溫度。
4. 恢復：差排排成**差排牆** → **次晶粒**（\< 5°）→ 波狀消光。再結晶：**次晶粒旋轉**（\> 10° 算新顆粒）或**顆粒邊界遷移**（隆丘成核）。
5. **動態再結晶**：有軸差應力，顆粒變小，**顆粒大小 → 古應力**（古壓力計 $d = A\sigma_d^{-i}$）；**靜態再結晶**：應力移除後，大顆粒、直邊界、**120° 三接點**。
6. 流動定律：差排滑動 = **指數**；差排潛變 = **冪律**（n = 3–5）；擴散潛變 = **n = 1 + 顆粒大小** $d^{-r}$（r = 2–3）。

## 1. 脆性與塑性、溫度指標 ★

**脆性**變形會破壞原子鍵、產生破裂；**塑性**變形是晶格在不失去連續性的情況下改變形狀。兩者都可以在宏觀上表現成「流動」：碎裂流看起來也像流，但機制是破裂加摩擦滑動（Table 11.1）。

| 領域 | 機制 |
|---|---|
| 脆性流 | 顆粒流（granular flow）、碎裂流（cataclastic flow）、摩擦滑動 |
| 塑性流 | 擴散作用、雙晶作用、差排潛變（晶體塑性作用） |

**溫度指標**（homologous temperature）：

$$
T_h = \frac{T}{T_m}\qquad(\text{兩者都用 K})
$$

同樣 400 °C，對熔點低的方解石已經很「熱」，對熔點高的長石還很「冷」。用 T<sub>h</sub> 才能比較不同礦物：

| T<sub>h</sub> | 狀態 | 主要機制 |
|---|---|---|
| 0–0.3 | 低溫塑性 | **差排滑動**、**機械雙晶** |
| 0.3–0.7 | 中溫塑性 | **差排潛變**（滑動 + 爬升）、恢復、再結晶 |
| 0.7–1 | 高溫塑性 | **擴散潛變**、顆粒邊界滑動超塑性（GBSS） |

<HomologousFig />

這也是 Homework 11-01 的題目：「說明三種塑性行為的變形機制，並比較其發生的溫度範圍」。

**石英和長石的分界**：石英約 **300 °C** 開始塑性，長石約 **450 °C**。所以在 300–450 °C（綠片岩相）的剪切帶裡，**石英已經塑性、再結晶成細小等粒顆粒，長石還是脆性破裂**。投影片的 Cap de Creus（西班牙，華力西造山）糜稜岩就是這種狀態：石英重結晶、雲母長出剪切帶、長石大多還是破裂的碎塊（Homework 11-02）。

## 2. 淺處的變形機制

- **碎裂流**：顆粒間破裂、顆粒內破裂、沿破裂和顆粒邊界的摩擦滑動、顆粒旋轉，合起來造成的流動。
- **剝落**（spalling / flaking）：壓力低、顆粒接觸面積小時，接觸點附近崩下小碎片。
- **跨粒破裂**（transgranular fracturing）：圍壓高（\> 約 1 km 深）時，破裂把顆粒劈成大小差不多的幾塊。

**為什麼高孔隙岩石特別容易發生顆粒內破裂？** 孔隙多 → 顆粒之間只有少數接觸點 → 應力集中在接觸點上，局部應力遠大於平均應力，顆粒從接觸點裂開。

## 3. 機械雙晶 ★

**變形雙晶**：晶格沿雙晶面做一小段簡單剪切，剪過的部分和原本的晶格成鏡像。**不破壞晶格**，所以是塑性機制。常見於對稱性低的礦物：三方的**方解石**、白雲石，三斜的長石。

- 低溫就能發生（方解石 \< 約 200 °C），應變小。
- 需要的剪應力超過一個臨界值，約 **10 MPa**。
- 理想上應力和雙晶滑動面夾 **45°**。

**方解石應變計**：雙晶記錄了應力的方向。

1. 每一顆有雙晶的方解石，量它的 c 軸和雙晶面的極點（萬向旋轉台）。
2. c 軸、雙晶面極點和 σ1 落在**同一個大圓**上。
3. 把很多顆的資料畫在立體投影上，統計出 σ1 的方向。
4. 量雙晶的總寬度和垂直雙晶面的顆粒大小，可以算出這一顆的**總剪應變**。

## 4. 點缺陷與擴散 ★

**點缺陷**：空缺（少一個原子）、替代雜質、間隙雜質。對塑性流動最重要的是**空缺**：原子跳進旁邊的空缺，等於空缺往反方向移動，這就是**擴散**。在應力作用下，空缺有方向性地移動，顆粒就慢慢改變形狀。

| 機制 | 擴散路徑 | 特點 |
|---|---|---|
| **Nabarro–Herring 潛變** | 穿過晶體內部（體擴散） | 需要高溫 |
| **Coble 潛變** | 沿著顆粒邊界 | 路徑短，效率較高 |
| **壓溶** | 沿顆粒邊界的**薄層流體** | 「濕的」Coble 潛變；低溫就能發生 |

**壓溶**（化學壓密）：顆粒受壓大的接觸面溶解，物質搬到受壓小的地方沉澱。體積減少、孔隙率和滲透率下降，砂岩變得更緊密、更強。石英砂岩在約 **90 °C** 就有濕擴散。野外例子：太麻里的變質砂岩，板劈理和層面平行，就是壓溶造成的。

**超塑性潛變**（顆粒邊界滑動超塑性，GBSS）：顆粒沿著邊界互相滑動，邊界上的空隙由擴散即時補上，所以**滑動時不用克服摩擦**。

- 應變可以超過 **1000%**，但顆粒內部幾乎看不到變形痕跡，也**不會形成顆粒形狀的優選方向**。
- 條件：軸差應力小、溫度高、**顆粒很細**（擴散路徑短）。通常先經過動態再結晶讓顆粒變細，才進入超塑性。
- 進入後岩石變得很軟，需要的應力變小，叫**應變軟化**；在韌性斷層帶中很普遍。
- 應變速率和顆粒大小的關係：$\dot\varepsilon \propto d^{-r}$，r = 2–3，所以又叫**顆粒大小相關潛變**。

## 5. 線缺陷：差排 ★

**差排**是晶格中**可以移動的線缺陷**。差排移動造成晶體內部的**滑移**（slip）。差排線是「已經滑過的部分」和「還沒滑的部分」的交界。滑移面通常是原子密度最高的面。

| | **刃差排** edge | **螺旋差排** screw |
|---|---|---|
| 樣子 | 晶格中多插了一片**半片原子面**（多半面），差排線是它的邊緣 | 原子排成**螺旋梯**，螺旋的軸是差排線 |
| 差排線 vs. 滑動方向 | **垂直** | **平行** |
| 怎麼移動 | 像**毛毛蟲**一節一節往前 | 像**撕紙**，一點一點往旁邊剪開 |
| 遇到障礙 | 只有一個滑動面，不能側滑，只能**爬升**（需要空缺接收多半面最下面的原子） | 可以**側向滑動**（cross-slip）換到另一個滑動面 |
| 符號 | ┴ 或 ┬（看多半面在滑動面上方或下方） | |

<DislocationFig />

**脆性的滑動面 vs. 塑性的滑移面**：斷層的滑動面是真的斷開、兩邊摩擦滑動；晶體的滑移面上原子鍵**一次只斷開差排線那一排**，差排掃過去之後晶格又接回完整，整個晶體沒有失去連續性。

**差排潛變** = 差排的產生、移動和消滅。只有滑動（glide）的叫**差排滑動**，低溫就能發生；但差排會在障礙物前**堆積**（pile-up），彼此卡住，越變形越難變形，叫**應變硬化**。要繞過障礙，刃差排要**爬升**、螺旋差排要**側滑**，這兩件事都需要能量，也就是**溫度**：石英約 **300 °C**、長石約 **500 °C** 以上才行。

## 6. 恢復與再結晶 ★

差排和雙晶會讓顆粒內部存有**應變能**，晶格不在最低能量狀態。溫度夠高時，顆粒會想辦法降低這個能量。

**恢復**（recovery）：差排靠滑動和爬升**重新排列**，正負差排互相抵消，剩下的排成一道道**差排牆**（傾斜晶界）。差排牆把顆粒切成**次晶粒**，彼此方位只差幾度（\< 5°）。在顯微鏡下看到的是**波狀消光**、變形帶。

**再結晶**（recrystallization）：恢復繼續下去，長出沒有應變的新顆粒。兩種方式：

| | 次晶粒旋轉再結晶 | 顆粒邊界遷移再結晶 |
|---|---|---|
| 怎麼長 | 更多差排移進次晶粒邊界，方位差越來越大 | 邊界從低能量的顆粒往高能量（差排多）的顆粒推進 |
| 什麼時候算新顆粒 | 方位差 \> **10°** | 推進出去的一塊變成新顆粒（**隆丘成核** bulging nucleation） |
| 驅動力 | 差排累積在邊界 | 兩邊顆粒的應變能差 |

<RecrystFig />

**動態 vs. 靜態再結晶**：

| | 動態再結晶 | 靜態再結晶（退火） |
|---|---|---|
| 應力 | 有軸差應力（變形中） | 均勻應力或應力移除後 |
| 顆粒 | **變小**（顆粒細化） | **變大** |
| 特徵 | 新顆粒斜交主葉理；核—幔構造 | 無應變、**直的顆粒邊界、120° 三接點**（泡沫構造） |
| 用途 | **顆粒大小記錄應力**；開始溫度：方解石約 300、石英約 350、長石約 450 °C | 原本的應力資訊被抹掉 |

**核—幔構造**（灰泥牆構造）：大顆粒石英外圍一圈次晶粒和新顆粒，中間留著舊的核心。動態再結晶容易從拉張區開始。

1. 波狀消光代表顆粒內部發生了什麼？

## 7. 古壓力計與流動定律 ★

**古壓力計**：動態再結晶的顆粒大小，由當時的軸差應力決定，應力越大顆粒越小：

$$
d = A\,\sigma_d^{-i}
$$

A、i 由實驗決定，在 log-log 圖上是直線。量薄片裡再結晶顆粒的大小，就能估計變形時的軸差應力。

**三種流動定律**（接 Ch6 的投影片 34–43）：通式 $\dot\varepsilon = A\,f(\sigma_d)\,e^{-E^*/RT}\,f(d)$。

| 機制 | 流動定律 | 應力的影響 | 顆粒大小 |
|---|---|---|---|
| **差排滑動**（低溫、指數潛變） | $\dot\varepsilon = A\,e^{\sigma_d}\,e^{-E^*/RT}$ | 指數 | 無關 |
| **差排潛變**（中高溫、冪律潛變） | $\dot\varepsilon = A\,\sigma_d^{\,n}\,e^{-E^*/RT}$，n = 3–5 | 冪次 | 無關 |
| **擴散潛變**（高溫、顆粒大小敏感） | $\dot\varepsilon = A\,\sigma_d\,e^{-E^*/RT}\,d^{-r}$，r = 2–3 | **線性**（n = 1，牛頓黏性） | 越細越快 |

冪律潛變是最常用的，地殼甚至地函都適用。**下部地殼和地函的細粒岩石在高溫下**，擴散潛變特別重要。

**變形機制圖**：橫軸溫度、縱軸應力，標出每個區域由哪個機制主導，再畫上不同應變速率的等值線。實驗資料要外推到地質上的應變速率（10⁻¹²–10⁻¹⁵ s⁻¹），所以不確定性很大。

**作業 Box 11.3**：深度—強度圖怎麼來？淺處用摩擦定律（Byerlee，強度隨深度線性增加），深處用冪律潛變流動定律（溫度隨深度上升，強度指數下降），兩條線取較小的那個，就是 Ch6 的岩石圈強度剖面。

<summary>自我檢測 7</summary>

1. 為什麼動態再結晶的顆粒大小可以當古壓力計？
2. 三種流動定律中，哪一種和顆粒大小有關？應力的指數各是多少？
3. 為什麼深度—強度圖的淺處和深處要用不同的定律？

**答案**：(1) 動態再結晶的穩定顆粒大小由軸差應力決定，d = Aσ<sub>d</sub><sup>−i</sup>，應力越大顆粒越小。(2) 擴散潛變，ε̇ ∝ d<sup>−r</sup>。應力：差排滑動是指數、差排潛變 n = 3–5、擴散潛變 n = 1。(3) 淺處溫度低、以摩擦滑動為主（脆性）；深處溫度高、以塑性潛變為主，強度隨溫度快速下降。

## 容易混淆的地方

| 容易搞混 | 正確理解 |
|---|---|
| 溫度指標用 °C？ | 一定用**絕對溫度**（K） |
| 雙晶是脆性？ | **塑性**，晶格沒斷 |
| 刃差排可以側滑？ | 刃差排只能**爬升**；**螺旋差排**才能側滑 |
| 差排線和滑動方向 | 刃差排**垂直**、螺旋差排**平行** |
| 次晶粒就是新顆粒？ | 次晶粒方位差 \< 5°；**\> 10°** 才算新顆粒 |
| 動態再結晶讓顆粒變大？ | 動態**變小**；靜態（退火）才變大、120° 三接點 |
| 擴散潛變的 n？ | n = 1（線性），但和顆粒大小 d<sup>−r</sup> 有關 |

## 章末綜合題

<details>
<summary>1.（觀念）一顆石英從 200 °C 慢慢加熱到 600 °C 並持續受力，依序會看到哪些顯微構造？</summary>

200 °C：脆性破裂為主，可能有少量差排滑動、應變硬化。約 300 °C：差排可以爬升，開始恢復，出現波狀消光、變形帶、次晶粒。約 350 °C 以上：動態再結晶（隆丘成核、次晶粒旋轉），顆粒變細，出現核—幔構造。更高溫：顆粒邊界遷移更快、顆粒變大；若顆粒夠細，可能出現擴散潛變和超塑性。

</details>

<details>
<summary>2.（應用）兩個糜稜岩的再結晶石英顆粒，A 是 20 μm、B 是 100 μm。哪一個變形時的軸差應力比較大？</summary>

A。d = Aσ<sub>d</sub><sup>−i</sup>，顆粒越小應力越大。

</details>

<details>
<summary>3.（比較）用表格比較脆性滑動面和晶體的滑移面</summary>

脆性：真正斷開、兩側摩擦滑動、失去連續性、和圍壓有關（Byerlee）。晶體滑移：差排掃過，一次只斷一排鍵，掃過後晶格完整、保持連續性，和溫度有關（爬升、側滑需要熱活化）。

</details>
