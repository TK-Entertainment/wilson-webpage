---
title: 名詞解釋速查
description: 常考構造名詞的一兩句話解釋
---

109、112 學年度考過的名詞（每題 4 分）全部列在這裡，用一兩句話就能拿分。

| 名詞 | 解釋 |
|---|---|
| Kinematic analysis | 重建岩石質點從未變形到變形狀態的運動（平移、旋轉、應變），不涉及力；例如由擦痕判斷剪動方向。 |
| Viscoelastic (Maxwell) model | 彈簧與唧筒串聯；加載瞬間彈性變形，之後黏性流動；卸載只恢復彈性部分。短期彈性、長期黏性，例如地函。 |
| Kelvin viscoelastic | 彈簧與唧筒並聯；應變延遲增加、卸載後慢慢完全恢復，無永久應變。 |
| Competency | 抗流力，岩層相對於鄰層抵抗流動（變形）的能力，即黏度對比；強硬層會褶皺或串腸化。 |
| Perfectly plastic / strain hardening / softening | 達降伏應力後應力不變、應變持續增加／需要更大應力才能繼續變形（差排纏結）／所需應力變小（粒徑變小、糜稜岩化）。 |
| Chocolate tablet boudinage | 兩個方向都受層平行伸張，強硬層被切成方塊狀串腸（像巧克力片）。 |
| Pure shear / simple shear | 共軸、無內部渦度、兩條垂直 apophyses／非共軸、剪動面不變、質點沿剪動方向直線移動、主軸旋轉。 |
| Homogeneous deformation | 直線仍直、平行線仍平行、圓變橢圓；變形在各處相同。 |
| Deviatoric vs differential stress | 總應力減去平均應力的張量（改形狀）／σ1 − σ3 的純量，等於 Mohr 圓直徑。 |
| Deviatoric vs mean stress | 改形狀的非等向部分／(σ1+σ2+σ3)/3，只改體積。 |
| Byerlee's law | σs = 0.85σn（\< 200 MPa）、50 + 0.6σn（\> 200 MPa）；摩擦與岩性無關（黏土礦物例外），可估天然斷層強度。 |
| Flinn diagram | X/Y 對 Y/Z 作圖表示應變橢球形狀；k = 1 平面應變、k \> 1 prolate（L）、k \< 1 oblate（S）。 |
| Growth fault | 同沉積斷層；上盤地層加厚、楔形、越深越陡、近斷層較粗。 |
| Elongation vs stretching | e = (l−l₀)/l₀／s = l/l₀ = 1 + e。 |
| Plumose structure | 節理面上的羽狀紋，從起點向外輻射，指出破裂傳播方向。 |
| Deformation band | 孔隙砂岩中的毫米級變形帶（顆粒重排、破碎），位移小、通常降低孔隙率和滲透率。 |
| Hydraulic fracturing | 孔隙流體壓力把 Mohr 圓往左推，P<sub>f</sub> \> σ3 + T 時產生張裂。 |
| Strain ellipsoid & principal strain axes | 單位球均質變形後的橢球；三個互相垂直的半軸 X ≥ Y ≥ Z。 |
| Mylonitic rocks | 韌性剪切帶中由晶體塑性（動態再結晶）造成粒徑變小、具葉理的斷層岩。 |
| Pseudotachylite | 斷層摩擦熱造成局部熔融、急冷形成的玻璃質斷層岩，古地震證據。 |
| Heave & throw | 垂直斷層走向剖面上，傾向離距的水平分量／垂直分量。 |
| Trishear | 斷層尖端前方三角形剪動帶分散應變，形成斷層擴展褶皺的運動學模型。 |
| Restraining stepover | 平移斷層躍階處產生縮短，形成擠壓脊／推隆構造（相對：releasing → 拉張盆地）。 |
| Griffith crack | 材料中先天存在的微裂隙，尖端應力集中使材料強度遠低於理論值。 |
| Wing crack | 剪裂尖端長出、平行 σ1 的張裂（Mode I）。 |
| Stylolite | 壓溶形成的鋸齒狀閉合面，⊥ σ1（Mode IV）。 |
| Thin-/thick-skinned | 變形只在滑脫面以上的沉積蓋層／基盤和深部斷層也參與變形。 |
| Wallace–Bott hypothesis | 斷層滑動方向平行該面上的最大分解剪應力；古應力反演的基礎。 |
