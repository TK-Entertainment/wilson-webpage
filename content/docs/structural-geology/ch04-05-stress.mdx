**本章重點**

1. Mohr 圓：**σn = (σ1+σ3)/2 + (σ1−σ3)/2·cos2θ**，**σs = (σ1−σ3)/2·sin2θ**（θ 是 σ1 與**面的法線**的夾角）。
2. **平均應力**只改體積；**偏差應力**才改形狀。**差應力** σ1−σ3 = Mohr 圓直徑。
3. 單軸應變參考態 **σ<sub>H</sub> = ν/(1−ν)·σ<sub>V</sub>**；抬升冷卻讓砂岩進入張應力 → 節理。

預設值是作業 Hw05（σ1 = 50 MPa 垂直、σ3 = 22 MPa、斷層傾角 60° → θ = 60°）。破壞包絡線：σn \< 0 用 Griffith 拋物線 σs² = 4T(σn + T)，σn ≥ 0 用 Coulomb 直線 σs = 2T + μσn。增加孔隙壓 p<sub>f</sub> 會把圓**往左推、半徑不變**：圓先碰到左側就是張裂（節理），碰到直線就是剪裂。

## 定義與單位

- 力：體力（重力、磁力，與質量成正比）、面力（與面積成正比）。水平應力主要來自板塊（地函對流、板塊力），垂直應力來自上覆岩層重量。
- 1 Pa = 1 N/m²；1 bar = 10⁵ Pa；1 MPa = 10 bar；1 kbar = 100 MPa；1 GPa = 10 kbar。地質慣例**壓為正**（工程相反）。
- 靜岩壓 σ<sub>V</sub> = ρgz：1 km、ρ = 2650 → **26 MPa**；梯度約 **30 MPa/km（0.3 kbar/km）**。靜水壓 = ρ<sub>w</sub>gz。
- 應力張量（二階張量，3² = 9 個分量；σ<sub>xy</sub>：作用在垂直 x 軸的面上、方向平行 y）。適當選座標可讓剪應力全為 0 → 對角線 = 主應力 σ1 ≥ σ2 ≥ σ3。
- 剪應力符號：Mohr 慣例順時針為負；張量慣例另計。

> σ<sub>m</sub> = (σ11 + σ22 + σ33)/3 總應力 = 平均應力（等向） + 偏差應力（非等向）  
> 差應力 σ<sub>d</sub> = σ1 − σ3 = 2σ<sub>s,max</sub>（θ = 45° 時剪應力最大）

> **易錯：****偏差應力**（deviatoric）是張量的一部分（σ<sub>ij</sub> − σ<sub>m</sub>δ<sub>ij</sub>）；**差應力**（differential）是一個數 σ1 − σ3。即使偏差應力的 σ3 − σ<sub>m</sub> \< 0，總應力在岩石圈中通常仍全為壓應力（p.52）。完美靜岩狀態下差應力 = 0。

## 現地應力量測

- **裸孔崩落（borehole breakouts）**：井壁破裂剝落方向**平行 σ<sub>h</sub>（最小水平應力）**、垂直 σ<sub>H</sub>。
- **套鑽法（overcoring）**：應變鬆弛法，最大膨脹方向 = σ<sub>H</sub>，至少 6 個應力計才能求 3D。
- **水力劈裂法**：加壓到產生張裂，維持裂隙張開的壓力 ≈ σ<sub>h</sub>；知道抗張強度可算 σ<sub>H</sub>。
- 地質構造（新的斷層崖、褶皺軸、張裂、火山口排列）、震源機制。地表是**主應力面**（自由面剪應力為零）；地形、斷層帶會使應力場偏轉。

## 參考應力狀態

- 靜岩／靜水參考態：σ1 = σ2 = σ3。**有效應力** = 總應力 − 孔隙壓。**超額孔隙壓**：被不透水頁岩包住的砂岩，埋藏時流體排不出去。
- **單軸應變參考態**（應變單軸、應力不是）：沉積盆地壓密。ν = 0.25 → σ<sub>H</sub> = σ<sub>V</sub>/3。ν = 0.3 → σ<sub>diff</sub> = (1−2ν)/(1−ν)·σ<sub>V</sub> = 0.57σ<sub>V</sub>，約 13 MPa/km。p–q 圖：埋藏時平均與差應力都增加。
- **熱效應**：Δσ<sub>H</sub> = E·α·ΔT/(1−ν)。例：ΔT = 100 °C、ν = 0.25、E = 100 GPa、α = 7×10⁻⁶ → **水平應力降低 93 MPa**。
- 埋藏與抬升：σ<sub>H</sub> = \[ν/(1−ν)\]Δσ<sub>V</sub> + \[E/(1−ν)\]αΔT。**頁岩永遠在壓縮區，砂岩抬升時進入張應力區** → 楊氏模數高、泊松比低的硬層（砂岩、石灰岩）先產生節理；砂岩產生張裂所需的臨界孔隙壓也比頁岩低。（考古題）
- **殘留應力**：埋藏時顆粒接觸處累積應力，膠結後抬升，部分應力被鎖在顆粒內。**構造應力** = 總應力 −（參考態 + 殘留 + 熱 + 地球潮汐等）。

## 板塊力與應力場

- Slab pull（老冷海洋板塊最大）、ridge push（高處正斷層、遠處逆斷層）、basal drag（可驅動或阻擋）、collisional resistance（陸–陸碰撞最大）。
- 水平擠壓漸增：正斷層 → **平移** → 逆斷層（中間會經過應力軸交換）。喜馬拉雅：南側山麓逆斷層、高原正斷層、東部平移（側向擠出）。
- 台灣最大主應力軌跡呈**扇形**，北台灣順時針旋轉（聚合加上琉球海溝後退、張裂）。
