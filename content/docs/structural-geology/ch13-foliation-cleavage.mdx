**這章在回答**：變質岩裡到處是一片一片的面：板岩可以剝成薄片，片岩閃閃發亮，片麻岩有深淺條帶。這些面是怎麼來的？為什麼越深越熱，面就從「劈理」變成「片理」？更實用的問題是：在一片板岩裡，層理已經看不清楚，劈理才是最明顯的面。這時候怎麼分辨哪個是層理、哪個是劈理？兩者的夾角又能告訴我們什麼？答案是：劈理通常平行褶皺的軸面，所以只要量層理和劈理，就能知道自己站在褶皺的哪一翼、地層有沒有倒轉。

**考前 30 秒**

1. **組構**：**L**（線狀）、**S**（面狀）、**LS**。**L 構造岩 ↔ 收縮應變**（雪茄形），**LS ↔ 平面應變**，**S ↔ 壓扁應變**（餅形），對應 Flinn 圖。
2. **葉理系列**（泥質岩，由淺到深）：**壓密劈理 → 鉛筆狀劈理 → 板劈理（250–350 °C，膨潤石 → 伊萊石）→ 千枚岩劈理（低綠色片岩相，白雲母＋綠泥石）→ 片理 → 片麻岩葉理**。約 **350–375 °C** 以上離開劈理、進入片理和糜稜岩葉理。
3. **離斷劈理**都是**分域**的：**劈理域 C**（雲母、壓溶殘留）夾**微劈石域 M**（沒變形）；**QF 域**（石英長石）和 **M 域**（雲母）。
4. 劈理最重要的形成機制是**壓溶**；劈理大約是應變橢球的 **XY 面**、垂直縮短方向，通常伴隨**體積損失**，應變落在**壓扁區**。
5. **軸面劈理**平行褶皺軸面。**正常翼：劈理比層理陡**（或兩者反向傾）；**倒轉翼：層理比劈理陡**、同向傾。
6. **劈理折射**：劈理在硬層（砂岩）陡、軟層（頁岩）緩，因為軟層在翼部被層間剪切。
7. **橫切劈理**：劈理和同期褶皺軸面不平行 → **轉換壓縮**；**右剪 → 劈理相對軸跡逆時針**，左剪 → 順時針。
8. **Sₙ／Fₙ／Dₙ**：S₀ 層理、S₁ 第一期葉理；和 S₁ 同期的褶皺是 F₁，變形期是 D₁。

## 1. 組構與構造岩 ★

**組構**是礦物或礦物集合體有**方向性**的排列，而且**貫穿**整塊岩石（顯微到公分尺度都看得到）。

| 類型 | 組構元素 |
|---|---|
| **線狀組構**（線理，L） | 一個方向特別長，例如被拉長的礫石、柱狀礦物 |
| **面狀組構**（葉理，S） | 片狀、板狀，例如雲母排成的面 |
| 散亂組構 | 沒有方向性 |
| 原生組構 | 岩石形成時就有：層理、岩漿的流動層 |
| 構造組構 | 強烈變形的變質岩中發展出來的 |

**構造岩**是構造組構發展得很透徹的岩石。依組構分成三種，正好對應 Ch2–3 的 **Flinn 圖**：

| 構造岩 | 組構 | 應變橢球 | Flinn 圖 |
|---|---|---|---|
| **L 構造岩** | 線理為主，面狀組構很弱或沒有 | 雪茄形（長橢球） | **收縮區**（k \> 1） |
| **LS 構造岩** | 兩者都有 | 三軸 | **平面應變**（k ≈ 1） |
| **S 構造岩** | 面狀為主，幾乎沒有線理 | 餅形（扁橢球） | **壓扁區**（k \< 1） |

LS 構造岩從葉理面上看，可以看到線理；從垂直葉理的方向看，只看到一層一層的面。

## 2. 葉理的種類：隨溫度的系列 ★

**葉理**（folium，拉丁文「葉子」）泛指變質岩裡任何面狀或彎曲的面狀構造，也包括原生的層理和岩漿層。分成：

- **原生葉理**：沉積或岩漿形成時就有。
- **次生（構造）葉理**：構造作用造成，包括**劈理**、**片理**、**片麻岩葉理**、**糜稜岩葉理**。構造地質學裡講「葉理」，通常專指這一類。

泥質岩（富含黏土）的葉理，隨埋藏深度和溫度變化成一個系列：

<CleavageSeriesFig />

| 階段 | 條件 | 怎麼形成 |
|---|---|---|
| **壓密劈理** | 成岩、壓密 | 埋藏時礦物顆粒轉向、孔隙塌陷；頁岩的頁理就是這種。石灰岩中的**縫合線劈理**是一種（壓）溶解劈理 |
| **鉛筆狀劈理** | 平行層面縮短剛開始 | 大的碎屑葉狀矽酸鹽被褶皺、轉動；細顆粒沿垂直縮短方向的帶發生**壓溶**、長出新黏土。岩石沿 **S₀ 和 S₁ 兩組面**一起裂開，成為鉛筆狀碎塊 |
| **板劈理** | 變質作用開始，約 **250–350 °C** | 葉狀矽酸鹽非常強烈的平行排列；黏土的層間水減少，**膨潤石（含水）→ 伊萊石** |
| **千枚岩劈理** | **低綠色片岩相** | 黏土和伊萊石反應成細粒**白雲母**和**綠泥石**；介於板劈理和片理之間，有絲絹光澤 |
| **片理** | **綠色片岩相**以上 | 雲母變粗，並長出其他變質礦物；用指標礦物命名，例如**石榴子石–黑雲母片岩**。有大的硬顆粒（石榴子石）時，片理呈波狀繞過它 |
| **片麻岩葉理** | 高變質度 | 淺色（石英＋長石）與深色（黑雲母、角閃石、輝石）條帶交替（見第 6 節） |

**分界**：約 **350–375 °C** 以上，就離開「劈理」的範圍，進入**片理**和**糜稜岩葉理**。除了溫度，岩性也有影響：雲母多、顆粒細的岩石，比較容易形成連續、密集的劈理。

**台灣的例子**：利吉混同層的基質泥岩被強烈剪切，形成鱗片狀葉理（scaly foliation）；板岩帶的變質砂岩，是脈絡形的間隔劈理。

## 3. 劈理的微觀長相：分域、夾皺劈理

**離斷劈理**（disjunctive cleavage）都是**分域**的：**劈理域**（C，cleavage domain）夾著沒怎麼變形的**微劈石域**（M，microlithon）。劈理域富含雲母、黏土和壓溶留下的不溶物；微劈石域保留原本的岩石。

| 種類 | 長相 | 常見岩石 |
|---|---|---|
| **縫合線劈理** | 鋸齒狀的壓溶面 | 石灰岩 |
| **脈絡形**（交織）劈理 | 彎曲、互相連接的劈理域 | 砂岩 |
| 上面兩種 | 劈理域之間間距大，所以叫**間隔劈理** | |
| **連續劈理** | 間距非常小，肉眼看不到分域；分成粗糙型和平滑型，粗糙型會發展成平滑型 | 細粒岩石 |

板劈理、千枚岩劈理在顯微鏡下也是分域的：**QF 域**（石英、長石）和 **M 域**（雲母，葉狀矽酸鹽多）交替。

**夾皺劈理**（crenulation cleavage）：原本已經有一組葉理，又受到和它**小角度斜交**的縮短，葉理被皺成一系列小褶皺（crenulation），新的劈理沿著小褶皺的翼部發展。

- **對稱**夾皺劈理：小褶皺兩翼一樣。
- **不對稱**（S 形）夾皺劈理。
- **截斷式**（discrete）：新劈理面很清楚地切斷舊葉理；**連接式**（zonal）：舊葉理在劈理帶裡連續彎過去。

## 4. 劈理和褶皺 ★

**軸面劈理**：和褶皺同時形成、**平行褶皺軸面**的劈理。一般來說劈理**垂直縮短方向**，代表應變橢球的 **XY 面**。

### 樞紐附近的劈理

拱彎時硬層（砂岩）樞紐帶外弧伸張、內弧縮短（Ch12 的正交撓曲），旁邊軟層（頁岩）的劈理會跟著調整：

- 硬層**上方**的頁岩：硬層平行層面縮短，劈理**垂直層理**。
- 硬層**下方**的頁岩：配合下面砂岩的外弧伸張，劈理**平行層理**。
- 兩者之間劈理消失的地方是**中立點**。
- 褶皺前的平行層面縮短量和黏度比，決定劈理的分布。

### 劈理折射

劈理在**砂岩裡接近垂直**，進到**頁岩裡轉成低角度**，像光線折射。原因是軟層在翼部被**層間剪切**（flexural shear）：如果層和層之間沒有滑動，界面兩側的應變必須相容，軟層就要靠沿層理的簡單剪切或體積變化來調整，劈理被強烈轉動。

軸面劈理在褶皺上會散開成扇形：**收斂扇**（劈理往核部收斂，軟層常見）和**發散扇**（往外發散，硬層常見）。

### 用層理–劈理的夾角判斷翼部 ★

**前提**：劈理和褶皺**同時形成**（劈理平行 F₁ 的軸面）。

| 位置 | 層理和劈理的關係 |
|---|---|
| **正常翼**（地層新的在上） | **劈理比層理陡**；或兩者**往相反方向傾** |
| **倒轉翼** | **層理比劈理陡**，兩者**往同一邊傾** |
| 樞紐 | 兩者大角度相交 |

**為什麼**：軸面劈理的傾角就是軸面的傾角。正常翼的層面從樞紐往外變緩，所以比軸面緩；倒轉翼的層面轉過了垂直，還繼續往軸面那一側倒，所以比軸面陡。

**面向朝下**的褶皺（例如偃臥褶皺又被褶皺）規則會反過來：面向朝下部分的正常翼，層理比劈理陡；倒轉翼劈理比較陡。所以使用前要先確定地層的上下（交錯層、粒級層）。如果劈理和層理的關係在同一個大構造裡前後矛盾，代表**褶皺和劈理不是同時形成的**。

<BedCleavDemo />

**在板岩帶怎麼分辨層理和劈理**：(1) 找**岩性變化**：砂岩夾層、顏色條帶、粒級層才是層理，劈理面上同一片岩石的組成都一樣；(2) 劈理面上有時看得到層理的**交線**（條紋）；(3) 劈理在砂岩和頁岩裡會**折射**，層理不會；(4) 劈理通常比層理密而規則。

<summary>【例題 ★ 完整解】Homework 13-01：露頭 A 中層理和劈理都往東傾，層理比劈理陡。B（向西倒轉的褶皺，露頭在中間的陡翼）和 C（直立的向斜）哪一個是正確的大構造？</summary>

**思路**：劈理是軸面劈理。看露頭 A 的層理–劈理關係，判斷它在正常翼還是倒轉翼，再看哪一張剖面在露頭位置有對應的翼部。

**步驟**：

1. 露頭 A：層理陡、往東傾（約 80°）；劈理較緩、也往東傾（約 50°）。層理比劈理陡，而且同向傾 → **倒轉翼**。
2. 剖面 C 是**直立向斜**：兩翼都是正常翼，軸面直立，軸面劈理應該近乎垂直、比兩翼的層理都陡。露頭 A 不可能出現在 C 裡。
3. 剖面 B：上方有往西閉合的類背斜（虛線）、下方接類向斜，露頭位置是兩者共用的陡翼，層面往東傾但已經轉過垂直，是**倒轉翼**；軸面往東傾，劈理也往東傾、比層理緩。和 A 吻合。

**答案**：**B**。露頭 A 的層理比劈理陡、同向傾，代表倒轉翼；只有 B 在這個位置有倒轉翼。

**陷阱**：要先確認劈理是軸面劈理、地層面向朝上；如果劈理是後期疊加的，或地層面向朝下，規則就不能直接套用。

</details>

## 5. 劈理和應變

**大部分劈理大致平行應變橢球的 XY 面**，而且形成時有**相當大的體積損失**。

**怎麼知道體積損失**：用原始形狀已知的**應變標記**：板岩中的**退色斑**（原本是球形）、形狀已知的化石。把量到的軸比和原始形狀比較，就能算出體積變化 Δ = (V − V₀)/V₀。

**板岩的應變資料完全落在壓扁區**（餅形應變橢球）。主要原因是**壓溶**（濕擴散）：垂直縮短方向的礦物被溶掉、帶走，體積減少，在縮短方向上壓扁，卻沒有對應的伸長。所以劈理幾乎總是和**壓扁應變**相關。

## 6. 剪切、高變質度的葉理

### 剪切帶（伸張型夾皺劈理）

在 S 葉理上斜切出一組 **C′** 面，**錯開**原本的葉理：

- 由**簡單剪切**（非共軸）造成，**不是褶皺**。
- 是判斷**剪切方向**的關鍵指標。
- 和一般的夾皺劈理（平行層面縮短造成）要分清楚。

### 橫切劈理 ★

**橫切劈理**和同期褶皺的軸面**不平行**，被它切過的褶皺叫**橫切褶皺**。發生在**轉換壓縮**（transpression：純剪＋簡單剪切）的環境。

<TransectFig />

- **右剪**（dextral transpression）：劈理相對同期的褶皺樞紐**逆時針**。
- **左剪**：劈理相對樞紐**順時針**。

### 片麻條帶

石英岩和花崗質岩石缺少雲母，葉理靠礦物轉向和壓扁形成。**片麻條帶**是淺色（石英＋長石）和深色（黑雲母＋角閃石＋輝石）條帶交替，在高變質度、高應變下形成。條帶的來源有四種：

| 來源 | 說明 |
|---|---|
| a. **繼承原岩** | 原本是砂岩、泥岩互層，砂岩變成石英岩、泥岩變成雲母片岩 |
| b. **移位作用** | 褶皺的樞紐被截斷、脫離，成為新的成分條帶 |
| c. **變質分異** | 離子擴散，排出某些成分，形成長石石英富集帶和鐵鎂礦物富集帶 |
| d. **火成作用** | 部分熔融的岩漿沿弱面一層一層侵入（lit-par-lit） |

### 移位作用 ★

水平縮短、垂直伸張持續進行時，褶皺越來越緊，**翼部被拉薄，最後樞紐脫離**，早期的層被轉成一組新的**移位葉理**。

**線索**：(1) 岩性有規律地重複；(2) 葉理和層理平行；(3) 出現小的**等斜褶皺**和**褶皺鉤**（被截斷的樞紐）。

所以在高變形區，看起來平行的「層理」可能根本不是原本的層理，而是移位後的葉理。

### 糜稜岩葉理

在大位移的剪切帶和逆衝帶中，**強烈的非共軸應變**把顆粒壓扁、拉長，**就算原本沒有層也會形成**；間距比片麻條帶細（mm–cm）。

## 容易混淆的地方

| 容易搞混 | 正確理解 |
|---|---|
| 葉理 = 劈理？ | 劈理是**低溫**的葉理；350–375 °C 以上叫片理、片麻岩葉理、糜稜岩葉理 |
| L 構造岩 ↔ 壓扁？ | **L ↔ 收縮**（雪茄形），**S ↔ 壓扁**（餅形） |
| 倒轉翼劈理比較陡？ | 倒轉翼是**層理比劈理陡**；正常翼才是劈理比較陡 |
| 層理–劈理規則任何時候都能用？ | 前提是**軸面劈理、同期、面向朝上**；面向朝下規則相反 |
| 劈理平行最大伸長方向？ | 劈理是 **XY 面**、**垂直**最大縮短方向 Z |
| 夾皺劈理和剪切帶一樣？ | 夾皺劈理是**縮短**皺起舊葉理；剪切帶是**簡單剪切**錯開舊葉理 |
| 片麻條帶一定是原本的層？ | 可能是繼承原岩，也可能是**移位作用、變質分異、lit-par-lit 侵入** |

## 章末綜合題

<details>
<summary>1.（課堂複習題）原生、次生、構造葉理差在哪？在變形、變質過的沉積岩裡，怎麼認出原生葉理？</summary>

原生葉理是岩石形成時就有的（層理、岩漿層）；次生（構造）葉理是變形造成的（劈理、片理、片麻岩葉理、糜稜岩葉理）。認原生葉理：找岩性和成分的變化（砂、泥互層）、沉積構造（交錯層、粒級層、波痕）、化石層；劈理面上同一片的組成不變，而且劈理會折射。

</details>

<details>
<summary>2.（課堂複習題）破裂帶和劈理、葉理差在哪？</summary>

破裂帶是一些分開的不連續面，間距大，面和面之間的岩石沒有組構；劈理、葉理是**貫穿**整塊岩石的組構，由礦物排列或分域（劈理域＋微劈石）構成，是應變的一部分，不只是破裂。

</details>

<details>
<summary>3.（課堂複習題）什麼條件有利於形成連續（密集）劈理？</summary>

**細粒、富含雲母或黏土**的岩石，溫度較高（接近板劈理到千枚岩劈理的條件），壓溶作用旺盛、應變大。粗粒、雲母少的岩石（砂岩）只會形成間隔劈理。

</details>

<details>
<summary>4.（課堂複習題）怎麼用劈理和更早的葉理（層理）之間的夾角預測大尺度褶皺幾何？</summary>

假設劈理是軸面劈理：劈理的位態就是軸面位態；在每個露頭比較層理和劈理的傾角和傾向，判斷正常翼（劈理陡或反向傾）、倒轉翼（層理陡、同向傾）；層理和劈理的交線是褶皺軸方向；把露頭排起來，就能畫出背斜、向斜樞紐的位置和伸向（見 Homework 13-02）。

</details>

<details>
<summary>5.（判讀）一片板岩中，劈理面上看到很細的條紋，和劈理的傾向線斜交。這些條紋是什麼？能用來做什麼？</summary>

是層理和劈理的**交面線理**（Ch14）。它平行兩組面的交線，在軸面劈理的情況下平行褶皺軸，可以用來求褶皺軸的方位和傾伏。

</details>
