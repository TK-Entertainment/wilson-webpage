**本章重點**

1. 三種基本元件：**彈簧**（彈性，σ = Ee）、**唧筒**（黏性，σ = ηė）、**摩擦塊**（塑性，達降伏應力才動）。
2. 組合：**Kelvin = 彈簧∥唧筒**（延遲、可完全恢復）；**Maxwell = 彈簧—唧筒串聯**（短期彈性、長期黏性，適合地函）。
3. 上部地殼由 **Byerlee 摩擦**控制（強度隨深度增加），深部由**冪律潛變**控制（隨溫度降低），交點就是脆–塑轉換。

## 彈性

> σn = E·e（Hooke） σs = μ·γ（μ = G，剪力模數） μ = E/\[2(1+ν)\] V<sub>s</sub> = √(G/ρ)  
> 泊松比 ν = −e<sub>x</sub>/e<sub>z</sub>（側向 ÷ 軸向的負值）；側限時 σ<sub>x</sub> = σ<sub>y</sub> = ν/(1−ν)·σ<sub>z</sub>  
> 體積模數 K = Δp/(ΔV/V₀) = E/\[3(1−2ν)\] = 2(1+ν)μ/\[3(1−2ν)\]；可壓性 = 1/K  
> ν = (V<sub>p</sub>² − 2V<sub>s</sub>²)/\[2(V<sub>p</sub>² − V<sub>s</sub>²)\]

- 地殼岩石 E ≈ 10–100 GPa；石英 72/0.16、鹽 40/~0.38、砂岩 10–20/0.21–0.38、花崗岩 ~50/0.1–0.25、石灰岩 80、鑽石 1050–1200。
- ν = 0.5：不可壓縮（流體），σ<sub>z</sub> = σ<sub>x</sub> 靜水反應。岩石多為 0.2–0.33（~0.25），側向應力約為 σ1 的 1/3。**ν 越大越不能壓縮**。
- 彈性三種：線彈性、完美彈性（非線性但加卸載同路徑）、**彈性滯後**（加卸載路徑不同）。

## 黏性與塑性

- 牛頓流體 σs = ηγ̇；黏度單位 Pa·s（1 poise = 0.1 Pa·s）。水 10⁻³、冰河 10¹¹⁻¹²、室溫玻璃 10¹⁴、鹽 10¹⁴⁻²⁰、岩石 ~10¹⁷、地函 ~10²¹ Pa·s。
- 流體剪切時 σ1 與剪動面夾 45°（= 小應變時的 ISA3 方向）。
- **Competency（抗流力）**（考古題）：相對黏度，抵抗流動的能力。強硬層形成最方正的串腸構造。拱彎褶皺主導波長 **L = 2πt(η<sub>L</sub>/6η<sub>M</sub>)<sup>1/3</sup>**。
- 塑性：超過降伏點後加上永久應變；微觀機制是**差排運動、擴散、雙晶**。晶體缺陷：點缺陷、線缺陷（刃差排、螺旋差排）、面缺陷。
- **完全塑性**（St. Venant）：應力不能超過降伏應力，應變持續累積。**應變硬化**：差排纏結、堆積，需要更大應力；**應變軟化**：例如糜稜岩化使粒徑變小、顆粒邊界滑動變容易。（考古題）

## 組合模型與常數

| 模型 | 組合 | 組成方程式 | 地質應用 |
|---|---|---|---|
| Prandtl（彈塑性） | 彈簧—摩擦塊 串聯 | ε = σ/E + ε<sub>p</sub> | 地殼斷層破裂、深部剪切帶 |
| Bingham（黏塑性） | 唧筒∥摩擦塊 | τ = τ<sub>y</sub> + ηγ̇（τ \> τ<sub>y</sub>） | 熔岩、土石流、岩漿庫、海底山崩 |
| Kelvin（黏彈性） | 彈簧∥唧筒 | σ = Eε + η dε/dt | 延遲、完全可恢復（暫態潛變） |
| Maxwell（黏彈性）（考古題） | 彈簧—唧筒 串聯 | ė = σ̇/E + σ/η | 震後鬆弛、冰河後回彈、地函 |
| Burgers | Maxwell + Kelvin 串聯 | — | 最接近天然岩石 |

> Maxwell 鬆弛時間 t<sub>M</sub> = η/G（應力衰減到 1/e ≈ 37%）

> **投影片數字要注意：**p.23 寫 η = 10²¹ Pa·s、G = 63 GPa → t<sub>M</sub> = 4.76×10⁸ s = 15 年。但 10²¹/6.3×10¹⁰ = 1.6×10¹⁰ s ≈ **500 年**；4.76×10⁸ s 對應的是 η ≈ 3×10¹⁹ Pa·s（和同頁集集地震 15–80 年、0.5–4×10¹⁹ Pa·s 一致）。考試若要算，記得自己用公式算。

## 實驗與潛變

- 三軸試驗：圍壓 ~1 GPa、溫度到 1400 °C、應變率 10⁻³–10⁻⁸ s⁻¹（遠快於地質速率）。**實驗應變率越快越偏脆性；越慢越偏塑性**。
- 同系溫度 T<sub>H</sub> = T/T<sub>m</sub>（K）：低溫 \< 0.3、中 0.3–0.7、高 \> 0.7；潛變多在 T<sub>H</sub> \> 0.5。
- 潛變曲線：**初期**（暫態，應變率遞減）→ **二期**（穩態，線性）→ **三期**（加速至破壞）。例：池上斷層、草嶺山崩。
- Yule marble：溫度越高、應變率越慢，強度越低。橄欖石單晶：不同滑移系強度不同 → 地函非均向性 → **剪切波分離**。
- 名詞：**韌性**＝保持連續性的變形風格（尺度相關）；**塑性**＝晶體內差排機制的永久變形；**脆性**＝摩擦區。四種組合：脆性、韌脆性、脆韌性（寬剪切帶、中心有裂隙）、韌性。

## 流動定律與岩石圈強度

> ė = A·f(σ<sub>d</sub>)·exp(−Q/RT) 冪律潛變 **ė = Aσ<sub>d</sub>ⁿ exp(−Q/RT)**（n = 1 為牛頓流體）  
> 完整式 ė = Aσⁿd⁻ᵐf<sub>H₂O</sub>ʳ exp\[−(Q + pV)/RT\]（溫度、應力、應變率、粒徑、成分、流體）  
> Byerlee：σs = 0.85σn（σn \< 200 MPa）；σs = 50 + 0.6σn（σn \> 200 MPa）  
> 摩擦強度 σ1 − σ3 ≥ βρgz(1 − λ)：β = 3 逆斷層、1.2 平移、0.75 正斷層；λ = 孔隙壓/上覆壓

**強度剖面（應變率 10⁻¹⁴ s⁻¹、地溫梯度 25 °C/km）**

<img src="/img/notes/structural-geology/ch06-rheology/02.png" alt="強度剖面（應變率 10⁻¹⁴ s⁻¹、地溫梯度 25 °C/km）" width="736" height="478" />

用投影片 p.40 的參數算出（ρ = 2700、λ = 0.4；A 以 GPa⁻ⁿs⁻¹ 計，和 112 學年考卷的表一致）。每條線取兩者中較小的值：淺處由 Byerlee 決定，逆斷層強度最高、正斷層最低；深處冪律潛變隨溫度快速變弱。交點是脆–塑轉換（逆斷層約 9 km）。這張圖就是考古題「反斷層、平移、正斷層的差應力隨深度變化」的答案。

- 石英 ~300–350 °C（10–12 km）以下變塑性；長石 ~500 °C（20–30 km）；橄欖石到 ~50 km 仍為脆性。
- 流變分層：**果醬三明治**（強上地殼、弱下地殼、強上部地函）、**焦糖布蕾**（只有地殼強，地函弱）、**香蕉船**（高孔隙壓，整體弱）。冷岩石圈有多個強層；熱岩石圈強層變薄。
- 粒徑很小（\< 10–100 μm）或低應力時，變成**擴散潛變**（牛頓流）。**鹽為何垂直移動**：密度低（~2.2），低溫低壓就能塑性流動（黏度低），浮力驅動貫入。
- 地震深度分布（Parkfield）：孕震帶約 3–13 km，上下都是無震帶（淺部未固結、深部潛變）。
- **薄皮構造**：變形集中在基底滑脫面以上的沉積蓋層（滑脫面由泥岩、蒸發岩、高孔隙壓組成）；**厚皮構造**：基盤與深部斷層也參與。台灣 AA′ 與 DD′ 剖面：北港高區（基盤高區）、中地殼脫偶增強。（考古題加分題）
- 類比模型：乾石英砂（脆性 Mohr–Coulomb）、矽膠（黏彈性，模擬下地殼）、蜂蜜（低黏度牛頓流體，模擬軟流圈）。
