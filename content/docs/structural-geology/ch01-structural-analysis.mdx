**這章在回答**：構造地質要研究什麼？資料從哪裡來？為什麼斷層只有正、逆、平移三種基本型？

**考前 30 秒**

1. 構造分析四種：**幾何**、**運動學（kinematic）**、**動力學（dynamic）**、<strong>構造（tectonic）</strong>分析。
2. 線用 **trend／plunge**（三位數方位），面用 **strike／dip**；面上線用 **rake（pitch）**。
3. **Anderson**：σ<sub>V</sub>=σ1 正斷層（~60°），σ<sub>V</sub>=σ2 平移，σ<sub>V</sub>=σ3 逆斷層（~30°）。

**主線**：先看構造長什麼樣（幾何）→ 再問它怎麼動（運動學）→ 再問什麼力造成的（動力學）→ 最後放回板塊尺度（構造分析）。這一章介紹資料來源、描述方位的方法，以及把應力和斷層類型連起來的 Anderson 理論。後面各章會把每一步展開。

★ = 考試重點。

## 1. 怎麼描述方位

- **線**：trend（走向方位，三位數）／plunge（傾伏角）。
- **面**：strike（走向）／dip（傾角）。
- **面上的線**：rake（pitch），在面上量的角度。

## 2. 資料從哪裡來

| 來源 | 特點 |
|---|---|
| 野外觀察 | 看到的是最終結果，變形歷史未知 |
| 實驗 | 看得到漸進變形；三軸變形儀 σ1 \> σ2 = σ3（圍壓） |
| 數值模擬 | 例：顆粒離散元素模擬斷層擴展褶皺，下盤當剛性基盤，斷層尖端前方地層越陡、甚至倒轉 |
| 遙測與大地測量 | 衛星影像、正射航照、InSAR、DEM、LiDAR、GPS/GNSS |
| 地球物理 | 震測剖面、重力（mGal）、磁力（nT；台灣約 45,000 nT）、震源機制 |
| 其他 | 薄片／SEM、現地應力（裸孔崩落、水力破裂、套鑽，見 Ch4–5）、定年、沉積盆地分析 |

**幾個常考的細節**

- **InSAR**：干涉相位差 Δφ = 4π(R1−R2)/λ。**一個完整干涉環（2π）= 視衛星方向變化半個波長**。C 波段 ~6 cm、L 波段 ~24 cm、X 波段 ~3 cm，波長越短解析度越好。
- 雷達側視：升軌南→北、向東照；降軌北→南、向西照。會有前坡縮短（foreshortening）、疊置（layover）。
- DEM／SRTM：固定基線干涉，30 m／90 m。**LiDAR**：多重回波（樹頂、樹枝、地面）→ 分出 DSM（地表物）和 DTM（地面）。
- **震測剖面**：縱軸是**雙程走時**，反射來自聲阻抗（密度 × 速度）的突變。
- **應變率**單位 s⁻¹，地質應變率約 **10⁻¹³ – 10⁻¹⁵ s⁻¹**。GPS 算出喜馬拉雅–西藏一般 \< 3×10⁻⁶ /yr ≈ 10⁻¹³ s⁻¹。

**類比模型**要能代表自然，必須滿足三種相似：

1. **幾何相似**：形狀成比例。
2. **運動相似**：形狀、位置的改變和時間成比例。
3. **動力相似**：內聚力、黏滯度對比、內摩擦角成比例。

例：Tapponnier 的黏土擠出實驗 → 印度擠入，亞洲**側向擠出**。

## 3. Anderson 斷層理論：應力決定斷層類型 ★

<img src="/img/notes/structural-geology/ch01-structural-analysis/01.png" alt="Anderson 斷層理論：哪一個主應力是垂直的" width="721" height="270" />

推理：

1. 地表是自由面，不能承受剪應力 → 一定有一個主應力**垂直**地表。
2. 剩下兩個主應力水平。看「垂直的是哪一個」就決定斷層類型：

| 垂直的主應力 | 斷層 | 傾角 |
|---|---|---|
| σ<sub>V</sub> = σ1 | 正斷層 | ~60° |
| σ<sub>V</sub> = σ2 | 平移斷層 | 垂直 |
| σ<sub>V</sub> = σ3 | 逆斷層 | ~30° |

3. Coulomb 剪裂面與 σ1 夾約 30°、包含 σ2（原因見 Ch7）。所以 **σ1 平分共軛斷層的銳角，σ3 平分鈍角**。

> **易錯**：Anderson 的限制（作業 Hw03）：(1) 斷層不一定在完整岩石中新生，既有弱面（摩擦強度較低）會先再活動；(2) 斷層位態會隨漸進變形旋轉；(3) 應力軌跡會隨深度改變，例如沿著區域滑脫面。

## 4. 本章出現的構造名詞

<img src="/img/notes/structural-geology/ch01-structural-analysis/slide-p16.webp" alt="地塹與躍階構造：壓縮躍階形成擠壓脊、伸張躍階形成拉張盆地" width="640" height="389" />

*圖：地塹與躍階構造。來源：Fossen, H. (2016) *Structural Geology*, 2nd ed., Cambridge University Press；胡植慶〈地球構造〉課程投影片 Ch1 p.16。*

- **生長斷層（growth fault）★**（考古題）：和沉積同時活動的斷層，常是鏟狀（listric）、形成半地塹。辨識：
  - 下落盤（上盤）地層**較厚**；
  - 地層呈**楔形**，越往下越陡；
  - 靠近斷層較粗粒；
  - 下斷塊逐漸旋轉沉陷。
  - 例：山腳斷層。
- **拖曳**：<strong>正牽引（normal drag）</strong>地層彎曲方向和斷層運動同向（摩擦造成，凸形）；<strong>反牽引（reverse drag）</strong>方向相反，例如曲面斷層上盤的滾動背斜（rollover，見 Ch9）。
- **躍階（stepover）**：平移斷層錯開時，壓縮躍階（restraining）→ 擠壓脊；伸張躍階（releasing）→ 拉張盆地（pull-apart）。
- **貫入體（diapir）**：圍岩中的捕獲岩越靠近岩體邊緣越扁長（應變越大）；周圍形成邊緣向斜（rim syncline）。
- **變形帶**：Entrada 砂岩中可見，顆粒破碎、孔隙率降低（詳見 Ch7）。
