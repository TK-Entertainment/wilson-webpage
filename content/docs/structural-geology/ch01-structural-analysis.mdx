## 1. 構造分析的四個層次 ★

構造地質學研究岩石圈裡的褶皺、斷層和其他變形構造：它們長什麼樣、怎麼形成、為什麼形成。研究變形岩石有幾個途徑：**野外觀察、實驗、數值模擬**，再加上遙測和地球物理。野外看到的永遠是**最終結果**，變形的過程（漸進變形）和真實歷史是未知的；實驗和模擬則能看到變形一步一步發生，但要確保它真的代表自然（第 4 節）。

要從一個看到的構造推到它的成因，要一層一層往上推，這就是**構造分析**：

<AnalysisLevelsFig />

1. **幾何分析**：描述構造的形狀、位態、分布。這是其他所有分析的基礎。例如褶皺的軸面、樞紐線、褶皺軸；圓柱形 vs 非圓柱形褶皺；協調褶皺（沿軸面形狀重複）vs 不協調褶皺。
2. **運動學分析**：岩石質點怎麼移動、變形了多少，不問原因。例如用擦痕、拖曳褶皺判斷斷層往哪滑（第 5 節），用應變橢圓量變形（Ch2–3）。
3. **動力學分析**：什麼力（應力）造成這個運動。應力（Ch4–5）、破壞準則（Ch7）、Anderson 理論（第 6 節）都屬於這一層。
4. **構造分析**（tectonic analysis）：把前三者放到盆地或造山帶的尺度。例如台灣現今的最大主應力軌跡呈扇形分布，北台灣的應力軸順時針旋轉，反映的是聚合和琉球海溝後退的轉換（投影片 p.44）。

另外，**微構造分析**用光學顯微鏡和 SEM 看微觀尺度的變形，四個層次都會用到。

**構造地質 vs 構造學**：構造地質處理「構造」本身（岩石的幾何組態）；構造學（tectonics）處理產生一整套特徵構造的**外在、區域性過程**，例如區域伸張應力造成一系列鏟狀斷層和同構造層序。課程裡常見的構造型態（tectonic style）還有：**鹽構造**（鹽密度低、在低溫高壓下就能塑性流動，主要垂直往上穿過上覆地層）、**新構造**（現在還在進行的地殼運動和應力場）、**微構造**。

**尺度**也很重要：同一個地區的斷層樣式在不同尺度下可能不一樣（北海 Gullfaks 油田，p.42），所以觀察時要注意自己在哪個尺度。時間尺度用**應變率**（單位 s⁻¹）描述：地質應變率大約 **10⁻¹³ 到 10⁻¹⁵ s⁻¹**。

## 2. 描述方位：位態與赤平投影 ★

幾何分析的第一步，是把面和線的方向量下來、寫成數字：

<OrientationFig />

- **面**：strike / dip。課堂用**右手法則**：面對走向方向時，面往右手邊傾，所以傾向 = 走向 + 90°，寫成例如 030/40。
- **線**（褶皺軸、擦痕、線理）：plunge → trend，例如 25 → 080。**trend 要寫三位數**（040 而不是 40），一看就知道是方位而不是角度。
- **面上的線**：rake（pitch），在面上從走向量到這條線的角度。

量到的資料要畫在**赤平投影**上：想像一個球，面和線都通過球心，只看它們和**下半球**的交會，再投影到水平的圓上。面變成一條**大圓**，線變成一個**點**；面也可以用它的法線（**極點**）代表，在大量資料時比較清楚。

<StereonetDemo />

用赤平投影可以很快看出資料的規律（p.39–40）：均勻的資料集中成一團；圓柱形褶皺各處層面的極點會排成一個大圓（**π 圖**），這個大圓的極點就是**褶皺軸**；位態不一致的大範圍可以先切成幾個**均勻的子區**再分析。實際作圖練習見〈赤平投影題解〉。

<details>
<summary>【例題 ★ 完整解】某面 030/40（右手法則），它的傾向和極點是多少？擦痕 rake 90° 時，擦痕的 plunge/trend 是多少？</summary>

**第一步：傾向。** 右手法則，傾向 = 030 + 90 = **120°**。

**第二步：極點。** 法線朝傾向的反方向、往下：trend = 120 + 180 = **300°**；plunge = 90 − 40 = **50°**。所以極點是 50 → 300。

**第三步：rake 90°。** 從走向量 90° 就是沿著傾斜方向往下，也就是最大傾斜線：plunge = 傾角 = **40°**，trend = 傾向 = **120°**。可以在上面的互動圖驗證：把線設成 40 → 120，會落在大圓上。

</details>

## 3. 資料從哪裡來

| 來源 | 特點 |
|---|---|
| 野外觀察 | 最直接，但只看到最終結果；要採定向標本才能做後續分析 |
| 實驗 | 看得到漸進變形；三軸變形儀 σ1 \> σ2 = σ3（圍壓） |
| 數值模擬 | 例：顆粒離散元素模擬斷層擴展褶皺，下盤當剛性基盤，斷層尖端前方地層越來越陡、甚至倒轉 |
| 遙測與大地測量 | 衛星影像、正射航照、InSAR、DEM、LiDAR、GPS/GNSS |
| 地球物理 | 震測剖面、重力、磁力、震源機制 |
| 其他 | 薄片／SEM、現地應力量測（Ch4–5）、定年、沉積盆地分析 |

**InSAR（合成孔徑雷達干涉）**：衛星在兩個時間拍同一地區，比較兩次雷達回波的**相位差**。相位差包含地表高程、變形、大氣和雜訊；扣掉高程（用 DEM）和大氣，剩下的就是兩次之間的**地表變形**，畫成一圈一圈的干涉環。

<InSARFig />

<details>
<summary>【例題 ★ 完整解】為什麼一個完整的干涉環（2π）代表視衛星方向的變化是半個波長？用 C 波段（λ = 5.6 cm）看到 5 個干涉環，地表移動多少？</summary>

**第一步：寫相位差。** 相位差 = 2π × 路徑差 / λ。雷達波從衛星到地面、再從地面回到衛星，地面沿視線（LOS）移動 d，去程和回程都多（或少）了 d，路徑差 = 2d：Δφ = 2π · 2d/λ = 4πd/λ。

**第二步：一個干涉環。** Δφ = 2π → 4πd/λ = 2π → **d = λ/2**。

**第三步：代數字。** 一環 = 5.6/2 = 2.8 cm，5 環 = **14 cm**（沿視衛星方向，不一定是垂直或水平的真實位移）。

</details>

其他常考細節：

- 雷達是**側視**的，所以有**前坡縮短**（foreshortening）和**疊置**（layover）。衛星大多是繞極衛星：升軌由南往北、向東照；降軌由北往南、向西照。
- 波長越短解析度越好：X 波段 ~3 cm、C 波段 ~6 cm、L 波段 ~24 cm（L 波段能穿透植被，在山區比較好用）。
- **SRTM** 用的是固定基線干涉（兩支天線同時拍），沒有時間差，所以沒有變形和大氣的干擾，只得到地形：全球南北緯 60° 內，30 m（1 弧秒）和 90 m（3 弧秒）的 DEM。
- **LiDAR**（光達）：一個雷射脈衝會有多次回波（樹頂、樹枝、地面），只取最後的地面回波可以去掉植被，得到 **DTM／DEM**（裸露地面），保留第一次回波則是 **DSM**（地表物）。在台灣植被茂密的山區，用來找活動斷層的地形線形特別有用（例如金山斷層）。
- **震測剖面**：縱軸是**雙程走時**，不是深度；反射來自聲阻抗（密度 × 速度）突變的界面。
- **重力異常**單位 mGal；**磁力**單位 nT（1 T = 1 Wb/m²，1 nT = 10⁻⁹ T；台灣的地磁場約 45,000 nT）。
- **GPS/GNSS** 速度場可以算應變率。

<details>
<summary>【換你算】GPS 算出喜馬拉雅–西藏的應變率約 3×10⁻⁶ /yr，換成 s⁻¹ 是多少？和一般地質應變率比較。</summary>

**提示**：一年 ≈ 3.15×10⁷ s。

**答案**：3×10⁻⁶ / 3.15×10⁷ ≈ **10⁻¹³ s⁻¹**，落在地質應變率（10⁻¹³ 到 10⁻¹⁵ s⁻¹）的快端，因為這是全世界最活躍的碰撞帶。

</details>

## 4. 實驗與類比模型：怎樣才能代表自然

**三軸變形儀**（triaxial rig）把圓柱形岩樣放在圍壓下，再從軸向加壓，所以 **σ1 \> σ2 = σ3**（σ2 = σ3 = 圍壓）。應力的單位是 Pa（MPa）。實驗看得到岩石從變形到破裂的整個過程，例如砂岩裡形成**變形帶**（Ch7），在 SEM 下可以看到顆粒破碎、滑動和旋轉（顆粒流）。

**類比模型**（例如砂盒、黏土、矽膠）要能代表自然，必須按比例縮小所有物理性質，滿足三種相似：

1. **幾何相似**（尺度模型）：形狀和尺寸成比例。
2. **運動相似**：形狀、位置的改變和時間成比例。
3. **動力相似**：內聚力、黏滯度對比成比例，內摩擦角相同。為什麼摩擦角要「相同」而不是「成比例」？因為 Coulomb 準則 σ<sub>s</sub> = C + σ<sub>n</sub> tan φ 裡，tan φ 是無因次的，縮小模型時不會跟著縮。

兩個課堂的例子：

- **砂盒模擬台灣斜向聚合**：用一個**剛性塊體**（backstop）代表菲律賓海板塊的前緣。「剛性」的意思是塊體內部不變形，只有整體移動和旋轉。這個假設合不合理？如果塊體本身強度遠大於被推的沉積物，就是合理的近似。
- **Tapponnier 的黏土實驗（1982）**：用一塊剛性的擠入體壓進黏土，黏土沿著一組平移斷層往側邊被擠出去，對應印度擠入、亞洲**側向擠出**（lateral extrusion）。這也說明了**剛體變形**（塊體只有平移、旋轉，例如擠出的斷塊沿平移斷層移動）和**非剛體變形**（內部形狀改變，例如褶皺、地殼增厚）的差別。

## 5. 從構造推運動：幾個常考的構造

運動學分析的核心是：**從地層、斷層的形狀，推回它們是怎麼動的**。

**生長斷層（growth fault）★**：和沉積作用同時活動的斷層（同沉積斷層），常見於沉積盆地邊緣，多為鏟狀正斷層，形成半地塹。例如台北盆地的山腳斷層。

<GrowthFaultFig />

怎麼從鑽井或震測資料認出一條沒有出露的生長斷層？看上盤（下落盤）的原生構造：

1. 靠近斷層的地層**比遠處厚**；
2. 地層呈**楔形**，而且**越往下越陡**；
3. 靠近斷層的沉積物**較粗**（相變）；
4. 下斷塊**逐漸旋轉、沉陷**。

為什麼會這樣？斷層每動一次，上盤就往下落一點、空出一些空間，這個空間靠斷層最大，被沉積物填滿，所以靠斷層那側堆得比較厚。每一層沉積之後，下面的斷層還會繼續動、上盤繼續沿鏟狀斷層旋轉，所以越老的地層被轉得越多、越陡。

**鏟狀斷層與上盤變形**：斷層彎曲時，上盤要跟著變形才能貼合斷層面，可以用同向（synthetic）或反向（antithetic）的簡單剪切來調節（p.6）。斷層的彎曲形狀因此也透露了滑動方向。

**拖曳（drag）**：沒有擦痕時，可以用斷層旁地層的彎曲判斷運動方向，但要分清楚兩種：

**躍階（stepover）**：平移斷層並不是一條直線，常常一段一段錯開排列：

**其他：**

- **貫入體（diapir）**：岩漿或鹽強行侵入時擠壓圍岩，圍岩裡的包體（捕獲岩）**越靠近岩體邊緣越扁長**（應變越大），周圍形成**邊緣向斜**（rim syncline）。
- **向斜軸部向外滑動的逆衝斷層**（out-of-the-syncline faults，p.10）：不是所有逆衝斷層都從底部滑脫面分出來；向斜兩翼被擠得越來越近，軸部的岩石空間不夠，就沿著小逆衝斷層往外擠出去。
- **擦痕**（slickenlines）：斷層面上的磨蝕痕跡，直接記錄局部的滑動方向。**縫合線**（stylolites）：壓溶作用形成的鋸齒狀面，垂直於最大壓縮方向。

1. 如何從鑽井或震測資料判斷一條沒出露的斷層是生長斷層？
2. 為什麼生長斷層上盤的地層越往下越陡？

## 6. Anderson 斷層理論：應力決定斷層類型 ★

這是把實驗室的岩石力學和野外看到的斷層連起來的理論（英國地球物理學家 E. M. Anderson 提出）。推理只有三步：

**第一步：一定有一個主應力是垂直的。** 地表和空氣接觸，空氣不能對地表施加剪應力，所以地表是一個**沒有剪應力的面**。沒有剪應力的面就是主應力面（Ch4），它的法線方向（垂直）就是一個主應力方向。地下淺處也大致如此。

**第二步：剩下兩個主應力是水平的。** 三個主應力互相垂直。

**第三步：看哪一個是垂直的。** 三軸實驗告訴我們，岩石的剪裂面會**包含 σ2**、和 σ1 夾約 30°（Ch7 會從 Mohr–Coulomb 準則推出：θ = 45° − φ/2，φ ≈ 30°）。所以：

| 垂直的主應力 | σ1 的方向 | 斷層 | 傾角 |
|---|---|---|---|
| σ<sub>V</sub> = σ1 | 垂直 | 正斷層 | ~60°（= 90° − 30°） |
| σ<sub>V</sub> = σ2 | 水平 | 平移斷層 | 直立 |
| σ<sub>V</sub> = σ3 | 水平 | 逆斷層 | ~30° |

**先預測**：如果岩石的內摩擦角很小（例如含水的黏土），正斷層會變得比較陡還是比較緩？想好再拉。

<AndersonDemo />

一對共軛斷層都包含 σ2，**σ1 平分兩條斷層的銳角，σ3 平分鈍角**。所以在野外看到一對共軛斷層，可以直接推回應力軸的方向（Ch10 的古應力分析就是從這裡延伸）。

> **易錯：Anderson 的限制**（作業 Hw03）：(1) 斷層不一定在完整岩石中新生，強度較低的既有弱面會先再活動，方向就不受 30° 規則限制；(2) 斷層的位態會隨漸進變形旋轉，現在看到的傾角不一定是剛形成時的傾角；(3) 應力軌跡會隨深度改變，例如在區域滑脫面附近，主應力不再垂直或水平。

<summary>【換你算】一組共軛正斷層，一條傾角 62°、另一條往反方向傾 62°。σ1、σ3 在哪裡？岩石的內摩擦角大約多少？</summary>

</details>

<summary>自我檢測 6</summary>

1. 為什麼地表附近一定有一個主應力是垂直的？
2. 三種 Anderson 斷層各對應哪個主應力垂直？傾角大約多少？為什麼？
3. 共軛斷層和主應力的幾何關係？

**答案**：(1) 地表不能承受剪應力，是主應力面，法線（垂直）是主應力方向。(2) σ1 垂直 → 正斷層 ~60°；σ2 垂直 → 平移斷層直立；σ3 垂直 → 逆斷層 ~30°；因為剪裂面和 σ1 夾約 30°。(3) 都包含 σ2；σ1 平分銳角、σ3 平分鈍角。(4) 既有弱面會先動；斷層會隨變形旋轉；應力軌跡隨深度改變。

## 容易混淆的地方

| 容易搞混 | 正確理解 |
|---|---|
| 運動學 = 動力學？ | 運動學只描述怎麼動；動力學問什麼力（應力）造成的 |
| trend 寫 40 就好？ | 寫三位數 040，避免和角度混淆 |
| 一個干涉環 = 一個波長？ | 半個波長，因為雷達波來回兩趟 |
| 震測剖面縱軸是深度？ | 是雙程走時，要用速度模型換成深度 |
| 生長斷層的下盤變厚？ | **上盤**（下落盤）靠斷層變厚 |
| 滾動背斜是正牽引？ | 是**反牽引**（往斷層下彎，和運動方向相反） |
| σ1 平分共軛斷層的鈍角？ | σ1 平分**銳角**，σ3 平分鈍角 |
| 正斷層傾角 ~30°？ | 正斷層 ~60°，逆斷層 ~30° |

## 章末綜合題

<details>
<summary>1.（觀念）用構造分析的四個層次，說明從「野外看到一組共軛正斷層」到「推論這個地區在伸張」的推理過程。</summary>

幾何：量兩組斷層的走向、傾角（約 60°、互相反向傾），畫在赤平投影上。運動學：用擦痕、拖曳判斷兩組都是上盤往下（正斷層）。動力學：依 Anderson 理論，兩條斷層都包含 σ2，σ1 平分銳角 → σ1 垂直、σ3 水平且垂直斷層走向。構造：σ3 水平代表這個方向在伸張，再結合區域資料（例如盆地、生長斷層）解釋為伸張構造環境。

</details>

<details>
<summary>2.（考古）何謂生長斷層？發育在什麼環境？有什麼特性？如何由鑽井岩心或震測資料判斷一個未出露的斷層是生長斷層？</summary>

和沉積同時活動的斷層（同沉積斷層），常見於沉積盆地邊緣、伸張環境（半地塹），多為鏟狀正斷層，例如山腳斷層。特性：上盤（下落盤）地層靠斷層變厚、呈楔形、越深越陡；靠斷層粗粒；下斷塊逐漸旋轉沉陷；常伴隨滾動背斜。從鑽井比對同一層在斷層兩側的厚度（上盤較厚），從震測剖面看楔形、往深處傾角變大的反射層。

</details>

<details>
<summary>3.（計算）用 L 波段（λ = 24 cm）的 InSAR 觀測一次地震，震央附近數到 4 個干涉環。沿視衛星方向的位移多少？如果改用 C 波段（5.6 cm），會看到幾個環？</summary>

L 波段一環 = 12 cm，4 環 = **48 cm**。C 波段一環 = 2.8 cm，48/2.8 ≈ **17 環**。波長短，環比較密（解析度高），但變形太大或植被茂密時容易失相干、數不清楚。

</details>

<details>
<summary>4.（觀念）一位學生說：「這塊類比模型是真實山脈的 1/100,000，所以內摩擦角也要縮成 1/100,000。」對嗎？</summary>

不對。內摩擦角（tan φ）是無因次量，動力相似要求它**相同**，不是等比例縮小；要按比例縮小的是有因次的量，例如長度、內聚力、黏滯度對比。

</details>
