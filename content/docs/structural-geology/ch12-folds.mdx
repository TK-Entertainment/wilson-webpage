**這章在回答**：野外看到一個彎曲的岩層，要怎麼描述它（形狀、方位、多緊）？它是怎麼彎起來的（被擠彎、被推彎、還是被動地跟著流）？反過來，從褶皺的形狀和小褶皺的方向，能不能推回大構造的位置和應力？前半章是「描述」，後半章是「機制」。

**考前 30 秒**

1. 名詞：**樞紐點**（曲率最大）→ 連成**樞紐線**；直的樞紐線 = **褶皺軸**；多層的樞紐線連成**軸面**；**包絡面**切過各樞紐。
2. 方位分類：**軸面傾角**（0–10° 偃臥 … 80–90° 直立）＋**樞紐線傾伏角**（0–10° 水平 … 80–90° 垂直）。**翼間角**決定緊密度（0° 等斜）。
3. **Ramsay 等傾角線**：Class 1 向內弧收斂（1A 軸部薄、**1B 平行褶皺**層厚不變、1C 翼部稍薄）；**Class 2 相似褶皺**，等傾角線平行軸面；Class 3 向內弧發散。
4. **背斜／向斜**看地層新舊（核部老 = 背斜）；**類背斜／類向斜**只看形狀。
5. **寄生褶皺**：Z 形（長翼相對短翼**順時針**）、S 形（逆時針）、M 形（對稱）。順著傾伏方向看，**類背斜由左到右 Z–M–S**，類向斜反過來。
6. **拱彎**：硬層比圍岩黏，平行層面縮短 → Class 1B；**Biot–Ramberg** $L_d = 2\pi h\left(\dfrac{\eta_L}{6\eta_M}\right)^{1/3}$。**被動褶皺**（層面無力學作用）→ Class 2。
7. **曲滑**：沿層面滑動，擦痕在**反曲點最大**、樞紐為零，兩翼方向相反；**正交撓曲**：外弧伸張、內弧縮短，有**中立面**。

## 1. 幾何名詞 ★

- **樞紐點**：一層褶皺層曲率最大的點。三維中連起來是**樞紐線**；曲率大的區域是**樞紐帶**。
- **褶皺軸**：樞紐線常常是彎的；如果是直線，就叫褶皺軸。
- **軸面**：兩層以上的樞紐線連成的面。
- **翼部**：樞紐兩側較平直的部分；翼部上曲率方向改變的地方是**反曲點**。
- **包絡面**：同一層沿途各個樞紐的切面，代表把小褶皺「燙平」之後的整體層面。
- **圓柱形褶皺**：樞紐線是直的，可以由一條直線（褶皺軸）平行移動掃出整個褶皺面；**非圓柱形**：樞紐線彎曲。

<FoldPartsFig />

**用立體投影找褶皺軸**（π 法與 β 法，接 Ch 立體投影）：圓柱形褶皺各處層面的**極點**落在同一個大圓上（π 圓），這個大圓的極點就是褶皺軸；或者把各層面的**大圓**畫出來，它們交於一點（β 點）就是褶皺軸。點越集中在一個大圓上，褶皺越接近圓柱形。

## 2. 褶皺的分類 ★

### 依形狀

| 類型 | 特徵 |
|---|---|
| 協調褶皺 harmonic | 沿著軸面方向，各層形狀重複、相似 |
| 不協調褶皺 disharmonic | 沿軸面方向，各層的波長和形狀不同（層的力學性質差異大） |
| **急折帶** kink band | 平直翼、尖銳樞紐；平分翼間角的面和軸面不同 |
| **尖頂褶皺** chevron | 尖銳、角狀、協調 |
| 同心褶皺 concentric | 弧是圓 |
| **箱形褶皺** box | 兩組共軛軸面，頂部寬平；要有弱的底層讓上方層**滑脫**，常伴隨基底滑脫斷層 |
| **尖瓣–圓弧褶皺** cuspate-lobate | 硬、軟兩層的界面：**圓弧凸向軟層、尖瓣指向硬層**（南方澳豆腐岬：變質砂岩與板岩） |

### 依方位

| 軸面傾角 | 名稱 | 樞紐線傾伏角 | 名稱 |
|---|---|---|---|
| 0–10° | **偃臥** recumbent | 0–10° | 水平 |
| 10–30° | 緩傾 | 10–30° | 緩傾伏 |
| 30–60° | 中傾 | 30–60° | 中傾伏 |
| 60–80° | 陡傾 | 60–80° | 陡傾伏 |
| 80–90° | **直立** upright | 80–90° | 垂直 |

### 背斜、向斜、類背斜、類向斜

| 名稱 | 看什麼 | 定義 |
|---|---|---|
| **類背斜** antiform | 只看形狀 | 兩翼由樞紐往下、往外傾 |
| **類向斜** synform | 只看形狀 | 槽狀 |
| **背斜** anticline | 形狀 + 地層新舊 | 面向朝上的類背斜（**核部老**） |
| **向斜** syncline | 形狀 + 地層新舊 | 面向朝上的類向斜（**核部新**） |
| 背斜形向斜 antiformal syncline | | 面向朝下的類背斜（形狀拱起，但核部新；例如偃臥褶皺再被褶皺） |
| 向斜形背斜 synformal anticline | | 面向朝下的類向斜 |

**面向**（facing）：沿著軸面，地層由老到新的方向。只有知道地層上下（例如交錯層、粒級層）才能判斷背斜或向斜。

### 依翼間角（緊密度）

翼間角越小，褶皺越緊、應變越大。翼間角 0° 叫**等斜褶皺**（isoclinal）。

### Ramsay 等傾角線分類

在褶皺的剖面上，把同一層**外弧**和**內弧**上傾角相同的點連起來，就是等傾角線：

| 類型 | 等傾角線 | 層厚 | 名稱 |
|---|---|---|---|
| **1A** | 向內弧收斂（強） | 軸部比翼部**薄** | |
| **1B** | 向內弧收斂，垂直層面 | 垂直層面量的厚度**處處相同** | **平行褶皺**（圓弧就是同心褶皺） |
| **1C** | 向內弧收斂（弱） | 翼部比軸部稍薄 | |
| **2** | **彼此平行**，平行軸面 | 軸部厚、翼部薄；但**平行軸面**量的厚度處處相同 | **相似褶皺**（內外弧形狀相同） |
| **3** | 向內弧**發散** | 軸部厚、翼部薄得多 | |

<RamsayFig />

**平行褶皺 vs. 相似褶皺**的力學意義：平行褶皺（1B）代表**硬層**，彎的時候層厚不變，主動拱彎；相似褶皺（2）代表**軟岩**，物質從翼部流到軸部，容易變形。兩種硬層夾一層軟層時，軟層常是 1C、3 型，形成**尖瓣指向硬層**。

## 3. 對稱、伸向與寄生褶皺 ★

**對稱 vs. 不對稱**：包絡面和軸面大約垂直（±10°）是對稱褶皺，否則是不對稱褶皺，有**長翼**和**短翼**。

**伸向**（vergence）：上翼相對於下翼的位移方向，可以說「東伸」「西伸」，或「順時針、逆時針」（軸面相對於假想對稱褶皺的視旋轉方向）。

**寄生褶皺**：大褶皺（一級）上附著的小褶皺（二級以上）。

| 形狀 | 特徵 |
|---|---|
| **Z 形** | 長翼相對短翼**順時針**旋轉，像字母 Z |
| **S 形** | 長翼相對短翼**逆時針**旋轉，像字母 S |
| **M 形** | 對稱，兩翼等長，在大褶皺的**樞紐帶** |

**怎麼用**：沿著傾伏方向看（down-plunge），一個**類背斜**的寄生褶皺**由左到右是 Z → M → S**；**類向斜**反過來是 S → M → Z。原因是曲滑時上層往樞紐方向滑：類背斜左翼的上層往右上滑，是順時針的剪切，長出 Z 形。所以小褶皺的不對稱方向會「指向」大褶皺的樞紐，可以從一個露頭的小褶皺推出大構造的樞紐在哪一邊。

<ParasiticFig />

**同軸變形下**：層面平行最快縮短方向（ISA₃）時形成對稱褶皺；層面斜交時形成不對稱褶皺。

## 4. 主動褶皺：拱彎 ★

**三種褶皺機制**：

| 機制 | 力的方向 | 層的角色 | 結果 |
|---|---|---|---|
| **拱彎** buckling（最常見） | 平行層面縮短 | 硬層比圍岩黏，**主導**褶皺形狀 | 圓滑、平行（Class 1B）、近正弦 |
| **折彎** bending | 和層面斜交 | 被外力推彎 | 盆地、岩石圈受載、斷層上方 |
| **被動褶皺** passive | 任意 | 層只是記號，**沒有力學作用** | 相似褶皺（Class 2） |

**拱彎**：一層硬層夾在比較軟（黏度低）的基質中，平行層面受壓。硬層沒辦法均勻縮短，就會彎起來，而且會選一個**主導波長**。

**Biot–Ramberg 方程式**（牛頓黏性）：

$$
L_d = 2\pi h\left(\frac{\eta_L}{6\eta_M}\right)^{1/3}
$$

L<sub>d</sub> 是主導波長（弧長），h 是層厚，η<sub>L</sub>、η<sub>M</sub> 是層和基質的黏度。**弧長和層厚成正比、和黏度比的立方根成正比**。所以同一組岩層裡，**薄的層波長短、厚的層波長長**。反過來，量野外褶皺的弧長／層厚，就能估計黏度比。

**先預測**：一層 10 cm 的砂岩，黏度比從 1000 變成 8000，波長變幾倍？層厚變成 20 cm 呢？

<BucklingDemo />

**考慮平行層面增厚**：拱彎前層會先縮短增厚，用增厚後的層厚 h<sub>T</sub> 和應變比 T = X/Z（應變橢圓長短軸比，T 越大越扁）修正，括號裡多一個和 T 有關的項，得到修正後的主導波長 L<sub>d</sub><sup>T</sup>。完整式子請看投影片和課本（文字版抽不清楚，這裡不寫出來以免抄錯）。重點是：**層先增厚，波長會變長**。

大部分岩石其實是冪律流變（Ch11）：**n 越大，褶皺長得越快，平行層面的縮短越少**。很多天然褶皺的 L/h \< 10。

**樞紐帶的應變**：硬層的**外弧被拉長、內弧被縮短**，中間有一個沒有應變的**中立面**。外弧產生垂直層面的張裂或斜交的正斷層；內弧產生軸面劈理、剪裂或共軛逆斷層。拱彎前的平行層面縮短可以減少甚至消除外弧的伸張區。

**多層**：

- 兩層以上硬層夾軟層時，軟層形成 1A、3 型褶皺，**尖瓣指向硬層**。
- **接觸應變帶**：硬層拱彎時，周圍軟岩受影響的範圍約一個波長，超過就幾乎沒有影響。硬層之間的距離小於這個範圍，彼此會互相影響；靠得越近，越像一層厚度更大的單層。
- **薄層先褶皺**，之後厚層的長波長褶皺接管；薄層變成附著在上面的不對稱寄生褶皺。

(1000/6)^(1/3) = 166.7^(1/3) = 5.50。L<sub>d</sub> = 2π × 0.10 m × 5.50 = **3.46 m**。弧長／層厚 ≈ 35。

**答案**：(1) 平行層面縮短，且層比圍岩硬（黏度大）；形成圓滑、近正弦的平行褶皺（Class 1B）。(2) 和層厚成正比、和黏度比的立方根成正比。(3) 外弧伸張：垂直層面的張裂、正斷層；內弧縮短：軸面劈理、剪裂、共軛逆斷層。

## 5. 被動褶皺與折彎

**被動褶皺**：層面沒有力學作用，只是被流動帶著走的記號。簡單剪切造成的被動褶皺是**完美的相似褶皺**（Class 2），而且是協調的。常見於糜稜岩帶（剪切褶皺）、推覆體中的流動褶皺。

**折彎**（力和層面斜交）的各種尺度：

1. **布丁構造**（串腸構造）之間的層被動彎曲。
2. **逆衝斷層的斷坡上方**：斷層轉折褶皺（fault-bend fold，坪–坡–坪）。
3. 斷層尖端還沒出露地表時，前方形成**斷層擴展褶皺**（fault-propagation fold；三角變形帶是一種）。
4. 再活動斷層上方。
5. 淺層侵入體、**鹽底辟**、泥貫入體的上方：把上覆層頂起來。

<details>
<summary>自我檢測 5</summary>

1. 被動褶皺為什麼是相似褶皺？
2. 斷層擴展褶皺和斷層轉折褶皺差在哪？

**答案**：(1) 層面沒有力學作用，物質只是被剪切帶著平移，每一層的形狀都一樣，平行軸面量的厚度不變。(2) 擴展褶皺在還沒出露的斷層尖端前方形成；轉折褶皺是上盤經過斷坡（坪–坡–坪的轉折）時被彎起來。

</details>

## 6. 層內怎麼調整：曲滑、曲流、正交撓曲 ★

| 機制 | 怎麼調整 | 應變分布 | 結果 |
|---|---|---|---|
| **曲滑** flexural slip | 沿層面（或很薄的軟層）滑動，像彎一疊撲克牌 | 滑動在**反曲點最大**、往樞紐減到 0；**兩翼方向相反** | 層厚不變，Class 1B；軟層面上有**擦痕** |
| **曲流** flexural flow | 剪應變均勻分布在翼部的層內（塑性） | 樞紐 0、往翼部增加；軸跡兩側剪切方向相反 | **沒有中立面** |
| **正交撓曲** orthogonal flexure | 原本垂直層面的線一直保持垂直 | **外弧伸張、內弧縮短** | 平行褶皺，有**中立面**；只適用於開闊褶皺，變緊後由曲滑、曲流接手 |

**尖頂褶皺**：典型情況是**硬層**（石英岩、燧石）夾**薄的軟層**（頁岩、千枚岩），平行層面縮短時以曲滑形成。樞紐處會有**空間問題**：軟層塑性流進樞紐，或硬層在樞紐**塌陷**、產生逆斷層（out-of-hinge fault）。外弧伸張處常有張裂脈。

**急折帶**：富含層狀矽酸鹽、層理很好的異向性岩石，在低溫（低變質度）下形成。公分到公寸寬、邊界很尖銳，跨過邊界葉理突然轉向。

- 共軛的急折帶：軸面和縮短方向斜交，σ1 和 ISA₃ 大致**平分**兩組（應變越小越準）。
- 尖頂褶皺：軸面**垂直**縮短方向。
- 實驗中應變夠大（約 50%）時，共軛的急折帶會合併成尖頂褶皺；但天然變形很少這麼大，公分級的經典尖頂褶皺多半是多層岩石平行層面縮短時以曲滑形成的。

## 7. 疊加褶皺與特殊褶皺

**疊加褶皺**（多期變形）：第一期褶皺再被第二期褶皺，形成干涉圖案（例如條帶狀鐵礦層的蛋盒、新月形、蘑菇形圖案）。分類依據：兩期褶皺軸的相對方位、第一期軸面和第二期的夾角。偃臥褶皺再被褶皺時，會出現**背斜形向斜**（台東太麻里）。

**劍鞘褶皺**：極度非圓柱形的褶皺，樞紐線彎成像劍鞘。在**高應變剪切帶**或**崩移帶**中，把原本小小的不規則放大而成（花蓮神秘谷）。

**剪切帶中的褶皺**：初期樞紐線和線理、搬運方向夾大角度；成熟期樞紐線高度彎曲、再被褶皺，可以平行、斜交或垂直搬運方向；長翼被拉薄，發生**移位作用**（transposition）。

**聖誕樹褶皺**：大類背斜形成後又受**垂直縮短**（σv = σ1），寄生褶皺伸向看起來「反了」，常伴隨近水平的軸面劈理。

**淺層的褶皺**：

- 重力控制的**軟沉積物變形**：不穩定的三角洲坡、大陸坡、崩移體的趾部（非圓柱形）。
- **泥底辟、砂岩貫入**：埋藏後不久液化、流體化（觸發：重力負載、傾斜層、地震、隕石撞擊）。
- **鹽底辟**：往上移動時把上覆層彎曲、褶皺。
- 構造褶皺：逆衝斷層尖端前方的斷層擴展褶皺。

## 容易混淆的地方

| 容易搞混 | 正確理解 |
|---|---|
| 類背斜 = 背斜？ | 類背斜只看形狀；**背斜要核部老**（面向朝上） |
| 平行褶皺 = 平行軸面厚度不變？ | 平行褶皺（1B）是**垂直層面**厚度不變；**相似褶皺**（2）才是平行軸面厚度不變 |
| 尖瓣指向軟層？ | **尖瓣指向硬層**，圓弧凸向軟層 |
| 類背斜的寄生褶皺左 S 右 Z？ | 順著傾伏看，類背斜**左 Z、中 M、右 S** |
| 曲滑擦痕在樞紐最多？ | 在**反曲點**最多，樞紐為零 |
| 波長只看層厚？ | 也看**黏度比的立方根** |
| 被動褶皺是平行褶皺？ | 被動褶皺是**相似褶皺**（Class 2） |
