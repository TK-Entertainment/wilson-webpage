**這講在回答**：什麼東西才算「礦物」？礦物學研究什麼、和其他學科有什麼關係？人類是怎麼一步一步知道晶體內部的原子是規則排列的？礦物怎麼分類、怎麼命名？以及實習要用的薄片是怎麼做出來的？

**考前 30 秒**

1. 定義五條件：**天然產出、固體、高度規則的原子排列、一定（不必固定）且均勻的化學成分、通常由無機作用形成**。
2. 邊界例子：人造寶石 ✗、營養師說的「礦物質」✗、下水道的方解石 ✓、冰和水銀 ✓、天然氣水合物 ✗、石油和煤 ✗、結石 ✗、石墨 ✓；火山玻璃和褐鐵礦是**似礦物**；鋯石被輻射破壞成非晶質（**輻射變晶**）仍算礦物。
3. 五大分科：**描述礦物學、結晶學、結晶化學、分類學、地質產狀（共生）**。
4. 歷史主線：Agricola 1556 → **Steno 1669 面角守恆** → **Haüy 晶胞** → Wollaston 1809 反射測角器 → **Nicol 1828 偏光** → Sorby 1850s 偏光顯微鏡看薄片 → X 光繞射證明原子規則排列。
5. **分類有規律**（依陰離子或陰離子團）；**命名沒有規律**（顏色、成分、性質、地名、人名、晶形）。
6. 薄片：切割 → 金剛砂磨平 → AB 膠貼載玻片 → 細切、磨到 **0.03 mm**。

### 先認識的名詞

| 名詞 | English | 一句話 |
|---|---|---|
| 礦物 | mineral | 天然、固體、原子規則排列、成分一定且均勻、通常無機形成的物質 |
| 似礦物 | mineraloid | 像礦物但缺少規則排列或固定成分，例如火山玻璃、褐鐵礦、蛋白石 |
| 結晶質／非晶質 | crystalline / amorphous | 原子規則排列／不規則排列 |
| 輻射變晶 | metamict | 原本結晶，因內含 U、Th 的輻射破壞而變成非晶質（如鋯石），仍稱礦物 |
| 端成分 | end-member | 成分連續變化的礦物（固溶體）兩端的純成分 |
| 共生 | paragenesis | 礦物和其他礦物一起出現的特徵組合 |
| 面角守恆定律 | law of constancy of interfacial angles (Steno's law) | 同種礦物的晶體，對應晶面的夾角相同 |
| 晶胞 | unit cell | 晶體中最小的重複單位 |
| 測角器 | goniometer | 量晶面夾角的儀器 |
| 薄片 | thin section | 磨到 0.03 mm 厚、貼在載玻片上的岩石切片 |

## 1. 什麼算礦物 ★

**地質學**研究地球自形成以來的組成物質和結構變化；**礦物學**從原子、分子開始，討論晶胞（具有結構和對稱性）的排列規則，以及礦物的各種物理、化學性質。礦物是地球的基本材料（Hawthorne 1993），所以礦物學有**普遍性**（地球的基本物質）也有**重要性**（始終是地球科學的核心）。

課本的定義（從嚴；社會大眾的用法比較寬）：

> 礦物是**天然產出**的**固體**，具有**高度規則的原子排列**，以及**一定（但不必固定）而均勻的化學組成**；通常由**無機作用**形成。

每一個條件都要會用例子判斷。關鍵是一條一條檢查，只要有一條不符合就不是礦物：

| 條件 | 符合 ✓ | 不符合 ✗ | 為什麼 |
|---|---|---|---|
| 天然產出 | 下水道中自然沉澱的方解石；冰、水銀 | 人造礦物、人造寶石；營養師說的「礦物質」 | 下水道雖然是人造環境，但沉澱過程是自然的；「礦物質」指的是微量元素，不是礦物 |
| 一定、均勻的成分 | 石英 SiO₂（成分均一）；白雲石 Ca(Mg,Fe,Mn)(CO₃)₂ | 天然氣水合物（以甲烷為主的混合物） | 「一定」不等於「固定」：成分可以在端成分之間連續變化（固溶體），但要能寫成一個化學式 |
| 規則原子排列 | 結晶質；輻射變晶的鋯石仍算 | 火山玻璃、褐鐵礦 → 似礦物 | 火山玻璃成分變化大又非晶質；褐鐵礦是含水氧化鐵加上非晶質成分的混合 |
| 通常無機形成 | 霰石、方解石、磁鐵礦、螢石、黃鐵礦、硫、磷灰石；石墨 | 人體生成的磷灰石、結石；石油、煤 | 石油和煤是有機作用形成且沒有固定成分；石墨雖然是煤經高溫高壓變來的，但它本身是無機的純碳晶體 |

<strong>冰算不算？</strong>算：天然、固體、規則排列、成分固定（H₂O）、無機。<strong>水銀算不算？</strong>課堂列為 O：自然汞是唯一的液態礦物，它在 −39 °C 以下才結晶，算是「固體」條件的例外，傳統上仍列為礦物。

<strong>為什麼天然氣水合物不算？</strong>它是低溫高壓下，固態水的晶格包住大量甲烷形成的；壓力降低或溫度升高就分開成水和天然氣。它的「成分」是以甲烷為主的混合物，沒有一定的化學式。

**廣義的定義**（不在課本範圍）：高溫高壓合成的礦物（模擬地函、地核）、微生物控制的礦物沉澱和溶解、人造沸石（分子篩、離子交換、催化劑），在研究上也都被當成礦物學的一部分。

【例題 ★ 完整解】判斷下列哪些是礦物：(a) 紅寶石戒指上的人造剛玉　(b) 澎湖玄武岩中的橄欖石　(c) 蛋白石　(d) 腎結石

**解**：(a) 人造 → 不是天然產出，✗。(b) 天然、固體、結晶、成分 (Mg,Fe)₂SiO₄ 在端成分間變化、無機 → ✓。(c) 蛋白石 SiO₂·nH₂O 是非晶質（沒有規則排列）→ 似礦物，✗。(d) 生物體產生，不是無機作用 → ✗。

【換你算】(a) 珍珠（碳酸鈣，由貝類分泌）(b) 鐘乳石中的方解石 (c) 煤 (d) 鑽石——哪些是礦物？（答案：b、d 是；a 是生物作用，c 是有機且成分不固定。）

## 2. 礦物學研究什麼

### 五大分科 ★

| 分科 | 在做什麼 |
|---|---|
| **描述礦物學**（descriptive mineralogy） | 測量、記錄能幫助描述和鑑定礦物的物理性質（L04） |
| **結晶學**（crystallography） | 研究固體物質中原子的排列（期末 L11–L13） |
| **結晶化學**（crystal chemistry） | 連結化學成分、內部結構和物理性質；一種礦物由**晶體結構 + 化學成分**共同定義（L09） |
| **分類學**（classification） | 像生物分類一樣把礦物有邏輯地分類；目前有效礦物約 6000 多種（L05） |
| **地質產狀**（geologic occurrence） | 礦物出現的地質環境，以及和其他礦物的特徵組合（**共生**）（L07） |

注意結晶化學那句話的意思：**同樣的成分、不同的結構就是不同的礦物**（例如方解石和霰石都是 CaCO₃；紅柱石、矽線石、藍晶石都是 Al₂SiO₅），**同樣的結構、不同的成分也是不同的礦物**（例如鎂橄欖石和鐵橄欖石）。

有效礦物的數目每年都在增加：2016 年 5224 種、2020 年 5562 種、2023 年 5955 種，投影片列 2024 年 6237、2025 年 6145（兩個數字順序對不上，可能是不同資料來源，記「約 6000 多種、持續增加」即可）。新礦物由國際礦物學會（IMA）的新礦物與命名委員會審查。

### 和其他學科的關係

礦物學是地球科學許多分支的中心：構造地質、大地構造、地質定年、岩石學、地球化學、隕石與行星地質、古生物、地質微生物、環境礦物、經濟地質、地球物理、礦物物理。幾個例子：

- **隕石**：鐵隕石由兩種鐵鎳合金組成，鐵紋石（kamacite，Ni ~5.5%）和鎳紋石（taenite，Ni 27–65%）；拋光後用硝酸酒精腐蝕，會出現交錯的**威氏交紋（Widmanstätten pattern）**。
- **地質微生物**：細菌可以把赤鐵礦中的鐵還原。
- **經濟地質**：從金紅石、鈦鐵礦提煉鈦做腳踏車。
- 礦物學之外：無機化學（原子結合方式相同，但礦物學只研究天然固體）、**材料科學**（礦物學可以說是最早的材料科學）、寶石學、土壤學（礦物提供 N、P、K 等養分）、生物學（骨頭和牙齒是磷灰石；魚的耳石是碳酸鈣）、奈米科學、藝術（顏料、陶瓷、釉料）、考古（燧石、黑曜岩、鹽）。

## 3. 礦物學史：怎麼知道原子是規則排列的 ★

<HistoryFig />

把這段歷史當成一個問題的推理過程來讀：**晶體的外形為什麼那麼規則？**

1. **Agricola（1494–1555）**：日耳曼人，1556 年出版《論金屬》（*De Re Metallica*），之後兩百年都是金屬礦業的經典，被稱為「礦物學之父」「地質學的始祖」。這時候的礦物學主要是**描述**。
2. **Steno（1638–1686）**：丹麥人，1669 年研究石英晶體，提出**面角守恆定律**：不論晶體受環境影響長成多歪，對應晶面的夾角都相同（實際上會略有偏差）。這是第一次發現外形背後有**不變的規律**。
3. **測角器**：為了量面角，1780 年代有接觸式測角器，**1809 年 Wollaston 發明反射式測角器**，量得更準；1890 年代又有雙圓測角器。
4. **Haüy（1743–1822）**：提出晶體是由相同的小單位（integral molecules）堆起來的，這個概念幾乎原封不動地留在現代結晶學中，就是**晶胞**。這解釋了面角守恆：既然是同樣的小單位堆起來，晶面只能沿著特定方向，夾角自然固定。例如石榴子石的十二面體。
5. **Nicol（1828）**：發明能產生偏振光的裝置（尼科爾稜鏡），使得系統性地研究晶體的光學性質成為可能。
6. **Sorby（1826–1908）**：1850 年代用偏光顯微鏡觀察岩石薄片，到今天仍是鑑定礦物和岩石組織最有用的方法（接 L06）。
7. **X 光繞射**：直接證明結晶物質中原子是規則排列的（投影片寫 1920 年；一般教科書記 1912 年 von Laue 的實驗）。現在還可以用高解析度穿透式電子顯微鏡（HRTEM）直接看到電氣石的 Si₆O₁₈ 環。

<StenoFig />

> **易錯**：面角守恆說的是**晶面之間的夾角**（或晶面法線的夾角）固定，**不是**晶面的大小或形狀固定。歪晶的晶面大小可以差很多。

## 4. 分類與命名 ★

**分類是有規律的**：依主要的陰離子或陰離子團（大多數礦物只有一種）分類。投影片列了 15 類：

| | 類別 | 代表礦物 |
|---|---|---|
| 1 | 自然元素 | 自然金 Au |
| 2 | 硫化物及硫鹽 | 黃鐵礦 FeS₂ |
| 3 | 鹵化物 | 石鹽 NaCl |
| 4 | 氧化物及氫氧化物 | 磁鐵礦 Fe₃O₄ |
| 5 | 硝酸鹽 | 硝石 KNO₃ |
| 6 | 碳酸鹽 | 方解石 CaCO₃ |
| 7 | 硼酸鹽 | 硼砂 Na₂B₄O₇·10H₂O |
| 8 | 硫酸鹽 | 石膏 CaSO₄·2H₂O |
| 9 | 鉻酸鹽 | 鉻鉛礦 PbCrO₄ |
| 10 | 鎢酸鹽 | 白鎢礦 CaWO₄ |
| 11 | 鉬酸鹽 | 鉬鉛礦 PbMoO₄ |
| 12 | 磷酸鹽 | 磷灰石 Ca₅(PO₄)₃(F,Cl,OH) |
| 13 | 砷酸鹽 | 鈷華 Co₃(AsO₄)₂·8H₂O |
| 14 | 釩酸鹽 | 釩鉛礦 Pb₅Cl(VO₄)₃ |
| 15 | 矽酸鹽 | 鈉沸石 Na₂Al₂Si₃O₁₀·2H₂O |

為什麼依陰離子分？因為同一個陰離子團的礦物，結構和性質比較相近（例如碳酸鹽都會和酸反應冒泡），而且常在相似的地質環境中出現。

**命名沒有規律**：可以依顏色、化學成分、物理性質、地名、人名、晶形等任何主題命名：

| 命名依據 | 例子 |
|---|---|
| 顏色 | 鈉長石 Albite（拉丁文 albus 白）；菱錳礦 Rhodochrosite（希臘文 rhodon 玫瑰，粉紅色） |
| 化學成分 | 鉻鐵礦 Chromite（含大量 Cr） |
| 物理性質 | 磁鐵礦 Magnetite（磁性）；黃鐵礦 Pyrite（希臘文 pyros 火，敲擊會冒火花） |
| 地名 | 鋅鐵尖晶石 Franklinite（美國紐澤西 Franklin）；北投石 Hokutolite（台灣北投，L07） |
| 人名 | 矽線石 Sillimanite（耶魯大學 Silliman 教授） |
| 晶形 | 十字石 Staurolite（希臘文 stauros 十字，十字形雙晶） |

## 5. 薄片製作

為什麼要做薄片？因為薄片可以**比手標本更精準、更詳細地判斷岩石或礦物**，看得到礦物內部的特徵（解理、雙晶、環帶、包裹體），而且大部分礦物磨到夠薄就會透光，可以用偏光顯微鏡看光學性質。

<ThinSectionFig />

- **材料**：標本、載玻片、AB 膠、玻璃板、金剛砂。
- **器具**：岩石切割機、烤盤、薄片切割研磨機、薄片拋光機。
- **標準厚度 0.03 mm（30 μm）**。為什麼要固定厚度？因為正交偏光下的干涉色由「厚度 × 雙折射率」決定（L08），厚度固定，干涉色才能用來比較、鑑定礦物。沒磨好的薄片太厚，石英、長石會出現黃色而不是一階灰白。

實習口號：**薄片比生命重要！**（每片都有編號，借用時要小心。）

## 容易混淆

| 這個 | 那個 | 差別 |
|---|---|---|
| 一定的成分 | 固定的成分 | 一定 = 可以寫成化學式、可在端成分間變化；固定 = 完全不變 |
| 似礦物 | 輻射變晶礦物 | 似礦物從來沒有規則排列（火山玻璃）；輻射變晶是原本結晶、後來被輻射破壞（鋯石），仍算礦物 |
| 礦物 | 礦物質 | 礦物質是營養學用語，指微量元素 |
| 分類 | 命名 | 分類依陰離子、有規律；命名沒有規律 |
| 面角守恆 | 晶面大小 | 守恆的是夾角，晶面大小可以不同 |
| Steno | Haüy | Steno 發現規律（面角守恆）；Haüy 提出解釋（晶胞） |

## 章末綜合題

1. 有人說：「實驗室在高溫高壓下合成的橄欖石和澎湖的橄欖石成分、結構都一樣，所以它也是礦物。」依課本定義評論這句話，並說明廣義定義怎麼看。
