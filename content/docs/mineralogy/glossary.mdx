## L01–L03　礦物科學

| 名詞 | English | 定義 |
|---|---|---|
| 礦物 | mineral | 天然產出的固體，具高度規則的原子排列，以及一定（不必固定）而均勻的化學成分；通常由無機作用形成 |
| 似礦物 | mineraloid | 像礦物但缺少規則原子排列或固定成分，例如火山玻璃、褐鐵礦、蛋白石 |
| 結晶質 | crystalline | 原子在三維空間規則、週期性排列 |
| 非晶質 | amorphous | 原子沒有長程規則排列 |
| 輻射變晶 | metamict | 礦物內的 U、Th 衰變輻射破壞晶格，使原本結晶變成非晶質（如鋯石），仍稱礦物 |
| 合成礦物 | synthetic mineral | 人工製造、成分結構和天然礦物相同的物質；依課本定義不算礦物 |
| 端成分 | end-member | 成分連續變化的礦物系列中，兩端的純成分 |
| 礦物學 | mineralogy | 從原子排列出發，研究礦物的結構、對稱與物理化學性質的科學 |
| 描述礦物學 | descriptive mineralogy | 測量並記錄有助於描述、鑑定礦物的物理性質 |
| 結晶學 | crystallography | 研究固體物質中原子排列的科學 |
| 結晶化學 | crystal chemistry | 研究化學成分、內部結構與物理性質之間的關係 |
| 分類學 | classification | 依邏輯把礦物分類（主要依陰離子或陰離子團） |
| 地質產狀 | geologic occurrence | 礦物出現的地質環境，以及和其他礦物的特徵組合 |
| 共生 | paragenesis | 礦物和其他礦物一起出現的特徵組合 |
| 面角守恆定律 | law of constancy of interfacial angles (Steno's law) | 同種礦物的晶體不論長成什麼形狀，對應晶面之間的夾角都相同 |
| 晶胞 | unit cell | 晶體結構中最小的重複單位（源自 Haüy 的 integral molecule） |
| 測角器 | goniometer | 測量晶面夾角的儀器（接觸式、反射式） |
| 偏光顯微鏡 | polarizing (petrographic) microscope | 加裝上下偏光鏡、用來觀察礦物光學性質的顯微鏡 |
| X 光繞射 | X-ray diffraction (XRD) | 用 X 光照射晶體產生繞射，證明並測定原子規則排列 |
| 威氏交紋 | Widmanstätten pattern | 鐵隕石拋光腐蝕後，鐵紋石與鎳紋石交錯形成的條紋 |
| 命名 | nomenclature | 礦物的命名方式，可依顏色、成分、性質、地名、人名、晶形等，沒有固定規則 |
| 薄片 | thin section | 岩石切片貼在載玻片上並磨到 0.03 mm 厚，供偏光顯微鏡觀察 |
| 金剛砂 | carborundum / emery (abrasive) | 研磨薄片用的磨料 |
| 載玻片 | glass slide | 黏貼岩石切片的玻璃片 |

## L04　物理性質

| 名詞 | English | 定義 |
|---|---|---|
| 晶形 | crystal form | 晶體被平整晶面包圍成的規則立體幾何形狀 |
| 晶癖 | crystal habit | 單一晶體或晶體集合體的一般外形 |
| 自形 | euhedral | 晶面發育完整、清楚可辨 |
| 半自形 | subhedral | 只有部分晶面 |
| 他形 | anhedral | 沒有晶面，因生長時和其他晶體競爭空間 |
| 顯晶質 | phanerocrystalline | 肉眼或放大鏡看得到個別顆粒 |
| 隱晶質 | aphanitic (cryptocrystalline) | 顆粒太小，肉眼或放大鏡看不清楚 |
| 集合體 | aggregate | 許多晶體聚在一起的形態 |
| 塊狀／粒狀／緊密狀 | massive / granular / compact | 沒有晶面的塊體／粒子狀集合體／非常緻密的細粒集合體 |
| 薄片狀／雲母狀／刃片狀 | lamellar / micaceous / bladed | 薄板層疊／可剝成薄片／像刀刃般扁長 |
| 纖維狀／針狀／放射狀 | fibrous / acicular / radiating | 細纖維／細針／從中心向外放射 |
| 樹枝狀／帶狀／同心圓狀 | dendritic / banded / concentric | 分枝狀／條帶狀／一圈一圈 |
| 葡萄狀／球狀／乳房狀／腎狀 | botryoidal / globular / mammillary / reniform | 小球簇集／球形／大而圓的隆起／腎臟形 |
| 鐘乳狀 | stalactitic | 像鐘乳石般垂掛 |
| 晶洞 | geode | 岩石空洞內壁長滿晶體 |
| 鮞狀／豆狀 | oolitic / pisolitic | 魚卵大小的小球／豌豆大小的小球 |
| 吸收光譜 | absorption spectrum | 記錄礦物吸收哪些波長的光的圖 |
| 晶體場轉變 | crystal field transition | 過渡金屬的 3d 軌道在晶體場中分裂，吸收相當於能階差的可見光而呈色 |
| 分子間電荷轉移 | molecular orbital (charge transfer) transition | 價電子在相鄰離子間移動而吸收光（如 Fe²⁺–Fe³⁺），是許多藍色礦物的成因 |
| 色心 | color center | 晶格缺陷抓住電子或電子空洞而吸收光（紫螢石、煙水晶） |
| 雜質致色 | solid impurity | 混入少量其他礦物而改變顏色 |
| 自色 | idiochromatic | 顏色來自礦物本身的化學成分（如橄欖石的 Fe²⁺） |
| 他色 | allochromatic | 顏色來自外來雜質（如紅寶石、祖母綠的 Cr³⁺） |
| 光澤 | luster | 礦物表面反射、散射光的整體外觀 |
| 金屬光澤／半金屬光澤 | metallic / submetallic luster | 像金屬一樣刺眼的反光／介於金屬和非金屬之間 |
| 金剛光澤 | adamantine luster | 比金屬弱、比玻璃強的閃亮光澤（鑽石） |
| 玻璃光澤 | vitreous luster | 像玻璃的光澤（石英、方解石） |
| 松脂光澤 | resinous luster | 像松脂（閃鋅礦、蛇紋石） |
| 油脂光澤 | greasy luster | 像塗了一層油（石鹽、硫黃） |
| 珍珠光澤 | pearly luster | 像珍珠（白雲母、滑石） |
| 絲絹光澤 | silky luster | 像絲綢，纖維狀礦物（石棉、纖維石膏） |
| 土狀光澤 | earthy (dull) luster | 沒有光澤（高嶺土、褐鐵礦） |
| 條痕 | streak | 礦物粉末的顏色，在條痕板上刻畫取得 |
| 條痕板 | streak plate | 未上釉的素燒瓷板 |
| 螢光 | fluorescence | 受光照射時發光，停止照射立即停止 |
| 磷光 | phosphorescence | 停止照射後仍持續發光 |
| 解理 | cleavage | 礦物沿鍵結較弱、面間距較大的原子平面平整裂開的傾向 |
| 立方體解理 | cubic cleavage | 三組互相垂直（方鉛礦、石鹽） |
| 八面體解理 | octahedral cleavage | 四組（螢石） |
| 菱形十二面體解理 | dodecahedral cleavage | 六組（閃鋅礦） |
| 菱面體解理 | rhombohedral cleavage | 三組、不互相垂直（方解石） |
| 柱狀解理 | prismatic cleavage | 兩組平行柱長（輝石 87°／93°、角閃石 124°／56°） |
| 底面（軸面）解理 | basal (pinacoidal) cleavage | 一組，可剝成薄片（雲母） |
| 裂理 | parting | 沿雜質、包裹體、離溶等缺陷造成的弱面裂開；不連續，不是晶體固有性質 |
| 斷口 | fracture | 沒有特定弱面、不沿固定方向的破裂 |
| 貝殼狀／纖維狀／鋸齒狀／不規則斷口 | conchoidal / fibrous (splintery) / hackly / irregular fracture | 弧形貝殼面／纖維或針狀／尖銳鋸齒／不規則 |
| 硬度 | hardness | 礦物抵抗刻劃的能力 |
| 摩氏硬度 | Mohs hardness scale | 以十種礦物排出的相對硬度順序（1 滑石 … 10 金剛石） |
| 絕對硬度 | absolute hardness | 以儀器量測、可比較倍數的硬度 |
| 韌性 | tenacity | 礦物抵抗破裂、彎曲、變形的性質 |
| 脆性／延展性／可切性 | brittle / malleable / sectile | 一敲就碎／可敲成薄片／小刀可切成薄片 |
| 撓曲性／彈性 | flexible / elastic | 可彎但不回復／彎曲後會回復 |
| 密度 | density (ρ) | 質量除以體積 |
| 比重 | specific gravity (G) | 礦物重量與同體積水重的比值 |
| 比重天平 | Jolly balance | 量空氣中重與水中重以求比重的彈簧天平，G = W<sub>a</sub>／(W<sub>a</sub> − W<sub>w</sub>) |
| 反磁性 | diamagnetic | 電子全部成對，外加磁場時產生微弱反向磁性，被磁鐵輕微排斥 |
| 順磁性 | paramagnetic | 有不成對電子但磁矩亂排；外加磁場時順向排列、被微弱吸引 |
| 鐵磁性 | ferromagnetic | 磁矩自發排列，移除外加磁場仍保有磁性（磁鐵礦） |
| 磁感率 | magnetic susceptibility | 物質在外加磁場中被磁化的程度 |
| 居禮點 | Curie point | 鐵磁性物質失去永久磁性的溫度（磁鐵礦 580 °C） |
| 放射性 | radioactivity | 含 U、Th 等元素衰變放出 α、β、γ 射線 |
| 蓋格計數器 | Geiger counter | 偵測放射線的儀器 |
| 壓電性 | piezoelectricity | 受定向壓力時兩端產生等量正負電荷（石英、電氣石） |
| 熱電性 | pyroelectricity | 受熱時產生電荷（電氣石） |

## L05　分類與寶石

| 名詞 | English | 定義 |
|---|---|---|
| 自然元素 | native elements | 由單一元素組成的礦物（金、硫、石墨） |
| 硫化物／硫鹽 | sulfides / sulfosalts | 以 S²⁻ 為陰離子的礦物（黃鐵礦、方鉛礦） |
| 氧化物／氫氧化物 | oxides / hydroxides | 以 O²⁻ 或 OH⁻ 為陰離子（磁鐵礦、剛玉） |
| 鹵化物 | halides | 以 Cl⁻、F⁻ 等鹵素為陰離子（石鹽、螢石） |
| 碳酸鹽 | carbonates | 含 CO₃²⁻（方解石、白雲石） |
| 磷酸鹽 | phosphates | 含 PO₄³⁻（磷灰石） |
| 硫酸鹽 | sulfates | 含 SO₄²⁻（石膏、重晶石） |
| 矽酸鹽 | silicates | 以 SiO₄ 四面體為基本單位 |
| 矽氧四面體 | silica tetrahedron (SiO₄) | 一個 Si 被四個 O 包圍的四面體 |
| 島狀矽酸鹽 | nesosilicates | 四面體不共用氧，獨立存在（橄欖石、石榴子石） |
| 對狀矽酸鹽 | sorosilicates | 兩個四面體共用一個氧（綠簾石） |
| 環狀矽酸鹽 | cyclosilicates | 四面體連成環（電氣石、綠柱石） |
| 鏈狀矽酸鹽 | inosilicates | 四面體連成單鏈（輝石）或雙鏈（角閃石） |
| 層狀矽酸鹽 | phyllosilicates | 四面體連成平面層（雲母、黏土） |
| 架狀矽酸鹽 | tectosilicates | 四個角全部共用，連成三維骨架（石英、長石） |
| 同質異形 | polymorph | 化學成分相同、結構不同（方解石與霰石；紅柱石、矽線石、藍晶石） |
| 固溶體 | solid solution | 成分在兩個端成分之間連續變化的礦物系列 |
| 副礦物 | accessory mineral | 岩石中含量很少、不影響岩石命名的礦物（鋯石、磷灰石） |
| 礦物群 | mineral group | 結構相同、成分不同的一群礦物（石榴子石群、尖晶石群） |
| 斜方輝石／單斜輝石 | orthopyroxene (Opx) / clinopyroxene (Cpx) | 斜方晶系的輝石（紫蘇輝石）／單斜晶系的輝石（普通輝石、透輝石） |
| 寶石 | gemstone | 美觀、耐久、稀少而可作裝飾的礦物或岩石 |
| 斑晶 | phenocryst | 岩漿冷卻時先結晶出的較大晶體 |
| 捕獲晶 | xenocryst | 岩漿上升時從圍岩或地函帶來的外來晶體 |
| 熱液 | hydrothermal fluid | 被岩漿或地熱加熱的水溶液，可溶解、搬運並沉澱元素 |
| 結晶分化作用 | fractional crystallization | 岩漿冷卻時礦物依序結晶並分離，使剩餘岩漿成分改變 |
| 同化混染作用 | assimilation / contamination | 岩漿熔融並吸收圍岩，使成分改變 |
| 偉晶岩 | pegmatite | 晶體特別粗大的火成岩，常產電氣石、綠柱石 |
| 岩基 | batholith | 規模最大的侵入岩體（> 100 km²），多為花崗岩類 |
| 岩株 | stock | 岩基凸出的小型侵入體（\< 100 km²） |

## L06　光性礦物學（一）

| 名詞 | English | 定義 |
|---|---|---|
| 光性礦物學 | optical mineralogy | 用偏光顯微鏡觀察礦物光學性質以鑑定礦物 |
| 電磁波 | electromagnetic radiation | 以波動傳遞的輻射能；可見光是其中一小段 |
| 橫波 | transverse wave | 振動方向垂直前進方向的波 |
| 反射 | reflection | 光在界面返回，入射角等於反射角 |
| 折射 | refraction | 光進入另一介質時速度改變而偏折 |
| 斯涅耳定律 | Snell's law | n₁ sin i = n₂ sin r |
| 折射率 | refractive index (n) | 光在真空中的速度除以在物質中的速度 |
| 色散 | dispersion | 不同波長的光折射率不同，使白光分成光譜 |
| 未偏振光 | unpolarized light | 在垂直前進方向的平面上各方向都在振動的光 |
| 偏振光 | (plane-)polarized light | 只在一個平面上振動的光 |
| 下偏光鏡（起偏器） | polarizer (lower polar) | 載物台下方，只讓南北向振動的光通過 |
| 上偏光鏡（檢偏器） | analyzer (upper polar) | 鏡筒中，只讓東西向振動的光通過 |
| 目鏡 | ocular (eyepiece) | 眼睛觀察的鏡頭 |
| 物鏡 | objective | 靠近薄片、負責放大的鏡頭 |
| 物鏡轉盤 | revolving nosepiece | 轉換不同倍率物鏡的轉盤 |
| 附加板插槽 | accessory slot | 插入石膏試板等附加板的位置 |
| 旋轉載物台 | rotating stage | 可旋轉並有角度刻度的薄片平台 |
| 聚光鏡 | condenser | 把光線聚集到薄片上的透鏡 |
| 光圈 | diaphragm | 調整光線量的開孔 |
| 十字絲 | cross-hairs | 目鏡中的十字線，對準上下偏光鏡方向 |
| 開放偏光（單偏光） | open nicol; plane-polarized light (PPL) | 只使用下偏光鏡觀察 |
| 正交偏光 | crossed nicols; cross-polarized light (XPL) | 上下偏光鏡都使用，振動方向互相垂直 |
| 浮影 | relief | 礦物與周圍物質因折射率差異而顯現的邊緣對比 |
| 正浮影／負浮影 | positive / negative relief | 礦物折射率高於／低於周圍 |
| 貝克線 | Becke line | 兩物質界面的亮線；提升鏡筒時向折射率高的一側移動 |
| 加拿大膠／環氧樹脂 | Canada balsam / epoxy | 黏貼薄片的膠，折射率約 1.537 |
| 閃突起 | twinkling (change of relief on rotation) | 旋轉載物台時浮影明顯改變（白雲母、方解石） |
| 等向性 | isotropic | 各方向光學性質相同（等軸晶系、玻璃） |
| 非等向性 | anisotropic | 各方向光學性質不同 |
| 多色性 | pleochroism | 不同方向吸收不同波長的光，旋轉時色調改變 |
| 吸光性 | absorption | 不同方向吸收相近波長但強弱不同，旋轉時深淺改變 |
| 鐵鎂礦物 | mafic minerals | 富含 Mg、Fe 的深色礦物（橄欖石、輝石、角閃石、黑雲母） |
| 長英質礦物 | felsic minerals | 富含長石和石英的淺色礦物 |

## L08　光性礦物學（二）

| 名詞 | English | 定義 |
|---|---|---|
| 雙晶 | twinning | 兩個以上同種晶體依一定規律（非平行）連生，消光位置或干涉色不同 |
| 聚片雙晶 | polysynthetic (lamellar) twinning | 很多薄片雙晶交替排列，呈黑白條紋（斜長石） |
| 簡單雙晶（卡式雙晶） | simple twin (Carlsbad twin) | 兩個個體組成的雙晶（正長石） |
| 格子雙晶 | cross-hatched (tartan) twinning | 兩組雙晶交叉成格子（微斜長石） |
| 環帶 | (chemical) zoning | 晶體不同生長階段成分不同，呈一圈一圈的構造 |
| 消光 | extinction | 正交偏光下礦物變黑 |
| 全消光 | complete (constant) extinction | 旋轉一圈都是黑的（等向性礦物、不透明礦物、玻璃） |
| 平行消光 | parallel extinction | 解理或晶稜平行十字絲時消光 |
| 對稱消光 | symmetrical extinction | 十字絲平分兩組解理夾角時消光 |
| 斜消光 | inclined extinction | 解理與十字絲斜交時消光 |
| 波狀消光 | undulose (undulatory) extinction | 黑影像波浪掃過顆粒（石英） |
| 消光角 | extinction angle | 解理（或晶體長邊）與消光位置之間的夾角 |
| 雙折射 | double refraction | 光進入非等向性礦物後分成兩道折射光 |
| 雙折射率 | birefringence | 最大與最小折射率之差（方解石 0.17） |
| 光軸 | optic axis | 光沿此方向前進時不發生雙折射 |
| 一軸晶 | uniaxial | 一個光軸（六方、正方晶系） |
| 二軸晶 | biaxial | 兩個光軸（斜方、單斜、三斜晶系） |
| 正常光（o 光） | ordinary ray (o-ray) | 振動方向垂直光軸、折射率 ω（No）不隨方向改變的光 |
| 異常光（e 光） | extraordinary ray (e-ray) | 振動方向含光軸分量、折射率隨方向改變的光；平行光軸時為 ε（Ne） |
| 光率體 | optical indicatrix | 以各振動方向折射率為長度畫出的立體 |
| 正光性 | optically positive | 一軸晶 ε > ω，光率體沿光軸拉長（石英） |
| 負光性 | optically negative | 一軸晶 ε \< ω，光率體沿光軸壓扁（方解石） |
| 干涉 | interference | 兩道光波疊加而加強或抵消 |
| 光程差 | retardation (Δ) | 兩道光穿過薄片後的路程差，Δ = 厚度 × 雙折射率 |
| 干涉色 | interference color | 兩道光在上偏光鏡干涉後的顏色 |
| 干涉色階 | order (of interference color) | 依光程差每約 550 nm 分為一階、二階、三階… |
| 干涉色表 | Michel-Lévy (interference color) chart | 光程差、厚度、雙折射率與干涉色的對照圖 |
| 光性方位 | optical orientation | 薄片切面相對於晶體光學軸的方向 |

|---|---|---|
| 山金 | lode gold | 原生在岩石裂隙或礦脈中的金 |
| 砂金 | placer gold | 原生金風化後被河流搬運堆積的金 |
| 熱液礦脈 | hydrothermal vein | 熱水在裂隙中沉澱礦物形成的脈 |
