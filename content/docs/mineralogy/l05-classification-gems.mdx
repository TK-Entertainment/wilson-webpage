**這講在回答**：依化學成分分類後，每一類有哪些代表礦物、各有什麼辨認重點和用途？矽酸鹽為什麼還要依「四面體怎麼連」再細分？寶石是怎麼從火山活動中來的？

**考前 30 秒**

1. 分類依**陰離子（團）**：自然元素 → 硫化物 → 氧化物／氫氧化物 → 鹵化物 → 碳酸鹽 → 磷酸鹽 → 硫酸鹽 → 矽酸鹽。
2. 矽酸鹽依 SiO₄ 四面體共用幾個氧：**島（橄欖石、石榴子石）→ 對（綠簾石）→ 環（電氣石、堇青石）→ 單鏈（輝石）→ 雙鏈（角閃石）→ 層（雲母、黏土）→ 架（石英、長石）**；Si : O 從 1 : 4 到 1 : 2。
3. 幾個「唯一」或「最」：自然汞是**唯一液態礦物**；閃鋅礦幾乎是**鋅的唯一來源**；辰砂幾乎是**汞的唯一來源**；方鉛礦是**分布最廣的鉛礦物**；黃鐵礦是**分布最廣的硫化物**；斜長石是**自然界最多的礦物**；鋯石是**三大岩類最常見的副礦物**。
4. 剛玉：**含 Cr 紅寶石；含 Ti（和 Fe）藍寶石**。Al₂SiO₅ 三兄弟：**藍晶石（高壓）、紅柱石（低壓）、矽線石（高溫）**。
5. 火山寶石三途徑：**斑晶**（日光石、月光石、黃玉、鋯石）、**捕獲晶**（鑽石、尖晶石、剛玉、石榴子石、橄欖石）、**熱液**（祖母綠、綠松石、電氣石、海藍寶）。

### 先認識的名詞

| 名詞 | 一句話 |
|---|---|
| 同質異形（polymorph） | 成分相同、結構不同（方解石／霰石；紅柱石／矽線石／藍晶石；硫砷銅礦／呂宋礦） |
| 固溶體 | 成分在兩個端成分間連續變化（橄欖石 Mg ⇄ Fe） |
| 副礦物 | 岩石中含量很少的礦物（鋯石、磷灰石、榍石） |
| 礦物群（group） | 結構相同、成分不同的一群礦物（石榴子石群、尖晶石群） |
| 斑晶 | 岩漿冷卻時先結晶出的較大晶體 |
| 捕獲晶 | 岩漿上升時從圍岩或地函帶上來的晶體 |
| 熱液 | 岩漿或地熱加熱的水溶液，可以溶解、搬運、沉澱元素 |

## 1. 自然元素與硫化物

**自然元素**：只由一種元素組成。金屬類（Au、Ag、Cu、Hg）通常延展性好、比重大；非金屬類（S、C）。

| 礦物 | 記憶點 |
|---|---|
| 自然金 Au | 岩金、砂金、伴生金、不可見金；溶於**水銀**和**氰化物**（也溶於王水） |
| 自然銀 Ag | 硬度只有 2.5–3 |
| 自然銅 Cu | 銅多半和硫結合成硫化物，自然銅較少 |
| 自然汞 Hg | 常溫液態，−39 °C 才結晶；**唯一的液態礦物** |
| 硫黃 S | 硫化氫或硫化物氧化形成；斜方硫加熱到 96 °C 變成針狀的單斜硫（同質異形） |
| 石墨 C | 熔點近 3900 °C、耐腐蝕、不活潑；和鑽石同為純碳（同質異形） |

**硫化物**：多是金屬光澤、比重大，**條痕**和**硬度**是辨認關鍵。多由**熱液作用**形成，是重要的金屬礦石。

| 礦物 | 記憶點 |
|---|---|
| 方鉛礦 PbS | **分布最廣的鉛礦物**；立方體解理；熱液；常和閃鋅礦共生 |
| 閃鋅礦 ZnS | 幾乎是**鋅的唯一來源**；和方鉛礦共生 |
| 黃銅礦 CuFeS₂ | 最重要的銅礦物之一；**硬度小於小刀** |
| 黃鐵礦 FeS₂ | **分布最廣的硫化物**；在**還原的沉積環境**形成；分解形成褐鐵礦和硫酸；**硬度大於小刀** |
| 辰砂 HgS | 高級紅色染料；幾乎是**汞的唯一來源** |
| 雄黃 As₄S₄ | 中藥材；提取砷 |
| 雌黃 As₂S₃ | 製造砷化物；**古代的修正液**（信口雌黃） |
| 輝銻礦 Sb₂S₃ | 柱狀或針狀；分布最廣的銻礦物；硬度只有 2 |
| 硫砷銅礦 Cu₃AsS₄ | 需要**高溫熱液**：金瓜石有、九份（低溫）沒有；和呂宋礦是同質異相 |

## 2. 氧化物、氫氧化物、鹵化物

| 礦物 | 記憶點 |
|---|---|
| 剛玉 Al₂O₃ | H 9；**紅寶石含 Cr（紅）**；**藍寶石含 Ti（藍）**；含 Fe 黑、含 Ni 黃、含 V 綠；金剛砂（研磨劑） |
| 磁鐵礦 Fe₃O₄ | 強磁性；**最重要的煉鐵礦物** |
| 赤鐵礦 Fe₂O₃ | 磁鐵礦**氧化**變成赤鐵礦；條痕紅；也是重要的鐵礦 |
| 金紅石 TiO₂ | 提取鈦的主要礦物；**最重要的白色顏料**（鈦白粉）；水晶中的「髮晶」 |
| 尖晶石 MgAl₂O₄（AB₂O₄） | 純的無色；尖晶石其實是一個礦物群 |
| 褐鐵礦 FeO(OH)·nH₂O | **不是單一礦物**，是多種含水氧化鐵的天然混合物 → 似礦物 |
| 石鹽 NaCl | 立方體解理；藍色岩鹽是**輻射造成的色心**，不是雜質 |

## 3. 碳酸鹽、磷酸鹽、硫酸鹽

**碳酸鹽**的共同點：遇稀鹽酸會冒泡（放出 CO₂），但程度不同，這是區分它們的方法。

| 礦物 | 記憶點 |
|---|---|
| 方解石 CaCO₃ | 菱面體解理；**冷稀鹽酸劇烈冒泡**；無色透明的叫**冰洲石**，用作光學材料（明顯雙折射） |
| 霰石 CaCO₃ | 中國稱**文石**；和方解石同質異形，**會自然轉變成方解石**，加熱會變快 |
| 白雲石 CaMg(CO₃)₂ | 冷鹽酸反應弱；**磨成粉末**或用**加熱的稀鹽酸**才會冒泡 |
| 孔雀石 Cu₂(CO₃)(OH)₂ | **含銅礦物風化**後形成；綠色、遇 HCl 起泡 |

**磷酸鹽**：**磷灰石** Ca₅(PO₄)₃(F,Cl,OH)，H 5，提取磷的重要材料；骨頭、牙齒的成分。

**硫酸鹽**：

| 礦物 | 記憶點 |
|---|---|
| 北投石 (Ba,Pb)SO₄ | 重晶石和硫酸鉛礦的混合，結晶時包了微量**鐳**（放射性）；L07 詳述 |
| 石膏 CaSO₄·2H₂O | 主要在沉積作用形成；**H 2**；在沙漠或鹽灘中結晶時包裹大量沙粒、板狀交錯生長（沙漠玫瑰） |
| 硬石膏 CaSO₄ | 石膏加熱超過約 200 °C 脫水而成 |

## 4. 矽酸鹽：依四面體的連結再分類 ★

矽酸鹽是最大的一類，地殼大部分都是矽酸鹽。基本單位是 **SiO₄ 四面體**（Si 在中心、四個 O 在頂點）。四面體之間可以**共用頂點的氧**，共用越多，連成的結構越大：

| 結構 | 共用氧 | 單位 | 代表礦物 |
|---|---|---|---|
| **島狀** neso | 0 | SiO₄ | 橄欖石、石榴子石、鋯石、Al₂SiO₅（藍晶石、紅柱石、矽線石）、十字石、黃玉、榍石、硬綠泥石 |
| **對狀** soro | 1 | Si₂O₇ | 綠簾石 |
| **環狀** cyclo | 2（成環） | Si₆O₁₈ | 電氣石、綠柱石、堇青石 |
| **單鏈** ino | 2（成鏈） | SiO₃ | 輝石：紫蘇輝石、透輝石、普通輝石 |
| **雙鏈** ino | 2 和 3 | Si₄O₁₁ | 角閃石：閃玉、陽起石、普通角閃石、藍閃石 |
| **層狀** phyllo | 3 | Si₂O₅ | 雲母（白雲母、黑雲母）、黏土（高嶺石、蒙脫石、伊萊石）、滑石、蛇紋石 |
| **架狀** tecto | 4 | SiO₂ | 石英、蛋白石、長石（正長石、斜長石） |

### 各結構的代表礦物

**島狀**：
- **橄欖石群**：鎂橄欖石 Mg₂SiO₄ ⇄ 鐵橄欖石 Fe₂SiO₄（固溶體）；**含鐵越多顏色越深**（淡黃綠 → 綠 → 黑）。
- **石榴子石群** A₃B₂(SiO₄)₃，A = Ca、Mg、Fe²⁺、Mn²⁺；B = Al、Fe³⁺、Cr³⁺。例如鈣鋁榴石 Ca₃Al₂(SiO₄)₃、錳鋁榴石 Mn₃Al₂(SiO₄)₃。主要在**變質岩**，可作研磨料。
- **鋯石** ZrSiO₄：**三大岩類最常見的副礦物**；鋯和鉿的主要來源。
- **Al₂SiO₅ 三兄弟**（同質異形）：**藍晶石**（區域變質、中高壓；Al 配位數 6）、**紅柱石**、**矽線石**。
- **十字石**：中等程度區域變質。**黃玉**：無色或淺黃。**榍石** CaTiSiO₅：**高色散**，光通過會變成強烈的七彩霓光；H 5。**硬綠泥石**：綠泥石 H 2–3，硬綠泥石 H 6.5；強烈多色性。

**對狀**：**綠簾石**，晶粒越細顏色越淺；熱液作用在含鈣岩石上形成，**斜長石熱液蝕變**後變成綠簾石。

**環狀**：**堇青石**（常見的**熱變質**礦物）；**電氣石**（含鐵黑色，含鋰、錳、銫玫瑰色；結晶好的寶石叫**碧璽**）。

**單鏈（輝石）**：
- 紫蘇輝石 (Mg,Fe)SiO₃：**鐵 > 30% 紫蘇輝石、10–30% 古銅輝石、\< 10% 頑火輝石**（都是斜方輝石 Opx）。
- 透輝石 CaMgSi₂O₆：含鐵增加，淺灰 → 綠 → 深綠 → 黑綠。
- 普通輝石 Ca(Mg,Fe)Si₂O₆（單斜輝石 Cpx）：沒什麼經濟用途。

**雙鏈（角閃石）**：
- **閃玉**（軟玉）Ca₂(Mg,Fe)₅Si₈O₂₂(OH)₂：無數極細的纖維緊密交織，**韌性極大**、不易裂。
- **陽起石**：閃玉的成分長成一根根針狀。
- **普通角閃石**：成分複雜，含 Na、Ca、Al。
- **藍閃石**：**含鈉角閃石**，藍色（低溫高壓變質，L07）。

**層狀**：
- **蛇紋石** Mg₃Si₂O₅(OH)₄：富鎂岩石熱液蝕變；石棉的重要來源。
- **白雲母**：總是和石英共生；偉晶岩中晶體巨大，是天然白雲母的唯一來源。**黑雲母**：雲母中分布最廣。
- **高嶺石**：**長石風化**而成，陶瓷主要原料。**滑石**：H 1。**蒙脫石**：吸水膨脹，用於止瀉、貓砂、火山泥面膜。**伊萊石**。

**架狀**：
- **石英** SiO₂：**碧玉**（含氧化鐵的緻密塊狀）、**玉髓**（纖維狀，介於蛋白石和石英之間）、**瑪瑙**（同心層狀）、**燧石**（隱晶質）都是石英。
- **正長石** KAlSi₃O₈：肉紅色或白色，條痕白。
- **鈉長石** NaAlSi₃O₈（Ab₉₀–₁₀₀）：有**聚片雙晶**細紋；**斜長石是自然界最多的礦物**。
- **蛋白石** SiO₂·nH₂O：非晶質 → 似礦物。

## 5. 火山與寶石

<GemOriginFig />

火山活動用三種途徑產生寶石：

| 途徑 | 過程 | 寶石 |
|---|---|---|
| ① **斑晶** phenocryst | 岩漿本身冷卻結晶（和**結晶分化作用**有關） | 日光石（銅鈦拉長石）、月光石（微斜混鈉長石）、黃玉（含氟矽酸鹽）、鋯石 |
| ② **捕獲晶** xenocryst | 岩漿熔融圍岩後殘留下來的礦物、或從地函帶上來的（和**同化混染作用**有關） | 鑽石（高溫高壓純碳）、尖晶石（高溫壓鎂鋁氧化物）、剛玉（高溫變質氧化鋁）、石榴子石（高壓變質）、橄欖石（地函岩石） |
| ③ **熱液** hydrothermal | 熱水把元素帶到岩石裂隙中換質、取代、沉澱 | 祖母綠、綠松石、電氣石（偉晶岩與熱液）、海藍寶（偉晶脈與熱液） |
| 其他 | 和火山有關 | 黑曜岩、蛋白石、玉髓 |

<strong>為什麼鑽石一定是捕獲晶？</strong>鑽石只在地函深處的高溫高壓下穩定，岩漿本身在地殼淺處不可能結晶出鑽石，所以只能是岩漿（金伯利岩）快速上升時從地函帶上來的。

附帶的岩體名詞：**岩基**（batholith）是最大的侵入岩體，> 100 km²，不是一次事件形成，多為花崗岩類；**岩株**（stock）是岩基凸出來的小部分，\< 100 km²；另有岩蓋、岩脈、岩床。

## 容易混淆

| 這個 | 那個 | 差別 |
