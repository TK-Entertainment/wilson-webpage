**這講在回答**：拿到一顆手標本，不用儀器（或只用小刀、條痕板、磁鐵、稀鹽酸），可以看哪些性質來鑑定它？這些性質為什麼會這樣——它們和礦物內部的結構、成分有什麼關係？

**考前 30 秒**

1. 物理性質 = **內部結構 + 化學成分的巨觀表現**。四大類：和**光**有關（顏色、光澤、條痕、螢光）、和**結構**有關（解理、裂理、斷口、硬度、韌性）、和**質量**有關（比重）、**其他**（磁性、放射性、壓電／熱電）。
2. 顏色四種成因：**晶體場轉變、分子間電荷轉移、色心、雜質**；**自色**來自本身成分（橄欖石 Fe²⁺），**他色**來自外來雜質（紅寶石、祖母綠都是 Cr³⁺，結構不同所以顏色不同）。
3. 顏色不可靠，**條痕**比較可靠（粉末顏色）：黃鐵礦、黃銅礦條痕綠黑；赤鐵礦條痕紅；金條痕金黃。硬度 > 6–7 的礦物畫不出條痕。
4. 解理沿**鍵結弱、面間距大**的面；六類：立方、八面體、菱形十二面體、菱面體、柱狀、底面。**輝石 87°／93°、角閃石 124°／56°**。
5. 摩氏硬度 1–10：**滑石、石膏、方解石、螢石、磷灰石、正長石、石英、黃玉、剛玉、金剛石**；是相對順序，不等距。
6. 比重 **G = W<sub>a</sub> ／（W<sub>a</sub> − W<sub>w</sub>）**；取決於原子種類和堆積方式。
7. 磁性：**反磁性**（大部分）、**順磁性**（有不成對電子）、**鐵磁性**（磁鐵礦，居禮點 580 °C）。

## 1. 晶形與晶癖

礦物的物理性質，是它內部組成的巨觀表現，具體來說就是**晶體結構和化學成分**。第一個看到的是外形。

**晶形**：晶體被平整的晶面包圍，呈現規則的立體幾何形狀，例如立方體、八面體、立方八面體、十二面體（方沸石在電子顯微鏡下是四角三八面體）。同一種晶形也會長歪（歪立方體、不對稱八面體），但面角不變（L03 面角守恆）。

**晶面發展的好壞**：

<FormFig />

- **自形（euhedral）**：晶面完整、銳利，容易辨認。課本的圖幾乎都是自形。
- **半自形（subhedral）**：只有部分晶面。
- **他形（anhedral）**：沒有晶面，因為生長時要和其他晶體**競爭空間**，沒有自由空間長出晶面。

**顯晶質與隱晶質**：顯晶質（肉眼或放大鏡看得到顆粒）可以描述單一晶體的形狀（粒狀、板狀、柱狀、針狀、片狀）或集合體的形狀（有規律：纖維狀、束狀、放射狀、晶簇；無規律：粒狀、柱狀、片狀集合體）；隱晶質只能描述集合體（有規律：鮞狀、腎狀、鐘乳和石筍、分泌體（杏仁體，由外往內成層沉澱）、結核體（由內往外沉澱）；無規律：土狀、塊狀、粉末狀）。

**晶癖（habit）**：晶體成長的習性，描述單一晶體或集合體的一般外形。投影片的例子：

| 晶癖 | 例子 | 晶癖 | 例子 |
|---|---|---|---|
| 塊狀 massive | 大理石 | 樹枝狀 dendritic | 氧化錳（錳鋇礦） |
| 粒狀 granular | 橄欖石 | 帶狀 banded | 瑪瑙 |
| 緊密狀 compact | 高嶺土 | 同心圓狀 concentric | 孔雀石 |
| 薄片狀 lamellar | 石墨 | 葡萄狀 botryoidal | 瑪瑙、藍銅礦 |
| 雲母狀 micaceous | 白雲母 | 球狀 globular | 菱鋅礦 |
| 刃片狀 bladed | 輝銻礦 | 鐘乳狀 stalactitic | 方解石 |
| 纖維狀 fibrous | 石棉 | 晶洞 geode | 紫水晶 |
| 針狀 acicular | 針鎳礦 | 鮞狀 oolitic／豆狀 pisolitic | 鮞狀石灰岩／鋁土礦 |
| 放射狀 radiating | 金紅石、銀星石 | 乳房狀 mammillary／腎狀 reniform | 赤鐵礦 |

## 2. 和光有關的性質

### 光和礦物的作用

可見光波長約 350–750 nm（投影片數字；常見寫法 400–700 nm），能量 E = hν = hc／λ，**波長越長能量越小**。光照到礦物上，有的反射、有的散射、有的折射進入礦物；進入的光一部分被吸收，剩下的穿透出來到達眼睛，**我們看到的顏色就是沒被吸收、穿透出來的那些波長的組合**。用光譜儀量出哪些波長被吸收，就是**吸收光譜**（例如綠柱石的吸收光譜中有致色元素、分子振動、晶格振動的吸收峰）。

### 顏色的四種成因 ★

**① 晶體場轉變**：第一列過渡元素（Ti、V、Cr、Mn、Fe、Co、Ni、Cu）有部分填滿的 3d 軌道。氣態離子的五個 3d 軌道能量相同；放進對稱的球形電子雲中，五個一起被抬高，仍然相同；但在礦物中，離子被陰離子組成的多面體包圍，電場不對稱，3d 軌道就**分裂成不同能階**。這個能量差剛好相當於可見光，所以會吸收特定波長，看到的是**補色**。

<CrystalFieldFig />

- **自色**：顏色來自礦物本身的離子。橄欖石的橄欖綠來自本身的 Fe²⁺。
- **他色**：礦物本身無色，因為夾雜少量雜質離子而有顏色。**紅寶石**是含 Cr³⁺ 的剛玉（Al₂O₃）；**祖母綠**是含 Cr³⁺ 的綠柱石（Be₃Al₂Si₆O₁₈）。

<strong>同樣是 Cr³⁺，為什麼一紅一綠？</strong>因為結構不同：剛玉是氧化物，氧以六方最密堆積排列，Cr³⁺ 填在層間；綠柱石是環狀矽酸鹽，Cr³⁺ 周圍的六個氧同時和 SiO₄、BeO₄ 四面體共用。鍵結方式不同 → 晶體場強弱不同（**祖母綠中較弱**）→ 3d 軌道分裂的能量差不同 → 吸收不同的波長。

**② 分子間電荷轉移**：價電子不再固定在一個離子上，而是在相鄰的離子間移動，例如 Fe²⁺(A) + Fe³⁺(B) ⇄ Fe³⁺(A) + Fe²⁺(B)。這是許多**藍色礦物**的成因：藍閃石、藍晶石、藍寶石（Fe²⁺–Ti⁴⁺ 也是這種）。

**③ 色心**：和晶格缺陷有關（取代性雜原子、間隙原子、空位）。缺陷可以抓住電子（負電荷）或電子空洞（相當正電荷），被抓住的電子或空洞會吸收光。
- **電子色心**：紫色螢石。
- **洞色心**：**煙水晶**。石英中 Al³⁺ 取代 Si⁴⁺，少的價數由 Na⁺ 或 H⁺ 補足；受放射線照射（常和鈾礦共存）時，Al³⁺ 旁邊的氧被打出一個電子，留下未成對電子的空洞。
- 藍色岩鹽也是長期受微量放射線照射產生的色心，不是雜質。

**④ 雜質**：無色或白色礦物混入極少量其他礦物就會變色：綠色石英（綠泥石）、黑色方解石（MnO、碳）、紅色長石、方解石、石英、碧玉（赤鐵礦）。

<ColorCausesFig />

### 顏色怎麼用

- **金屬光澤的礦物通常顏色單一；非金屬光澤的礦物顏色多變**，所以顏色常常不可靠。
- 例外：有些非金屬礦物顏色很特別、很固定：**孔雀石（綠）、藍銅礦（藍）、薔薇輝石（玫瑰紅到粉紅）、綠松石（綠藍）**。
- 顏色要看**新鮮面**；風化面、聚片雙晶的反光是假色。
- 命名法：標準單色（加淺、深、翠、墨修飾）、二名法（黃綠色 = 黃過渡到綠，主色在後）、類比法（黃銅色、淺黃銅色、鉛灰色、橘紅、檸檬黃、孔雀綠；金屬和金屬比、非金屬和非金屬比）。

### 光澤

旋轉礦物時，表面或解理面對光的反應（相當主觀）。分成**金屬光澤**和**非金屬光澤**兩大類，四個層級：金屬光澤（刺眼）> 半金屬光澤 > **金剛光澤**（比金屬弱、比玻璃強）> 玻璃光澤（柔和）。

| 光澤 | 例子 |
|---|---|
| 金屬 | 黃鐵礦、方鉛礦 |
| 金剛 | 鑽石 |
| 玻璃 | 石英、螢石、方解石 |
| 松脂 | 閃鋅礦、蛇紋石 |
| 油脂 | 石鹽、硫磺 |
| 珍珠 | 白雲母、滑石 |
| 絲絹 | 石棉、石膏（纖維狀） |
| 土狀 | 高嶺土、褐鐵礦 |

（硫磺在投影片中同時出現在油脂光澤，L07 寫松脂光澤；兩者本來就接近。）

### 條痕 ★

把礦物在條痕板（素燒瓷板）上畫，看粉末的顏色。條痕不受假色和反光影響，比顏色可靠，缺點是要破壞礦物；**硬度大於 6 左右的礦物比條痕板硬，畫不出條痕**。

- 大部分非金屬礦物顏色多變，但**條痕是白色**。
- 金屬礦物有特定的條痕：

| 礦物 | 顏色 | 條痕 |
|---|---|---|
| 赤鐵礦 | 紅、鋼灰到黑 | **紅** |
| 金 | 黃 | 金黃 |
| 黃鐵礦 | 黃 | **綠黑** |
| 黃銅礦 | 黃 | **綠黑** |
| 閃鋅礦 | 各種棕色 | 淺黃 |
| 雌黃 | 檸檬黃 | 金黃 |
| 辰砂 | 朱紅 | 紅 |
| 輝鉬礦 | 灰 | 灰 |

<strong>金、黃鐵礦、黃銅礦都是黃色，怎麼分？</strong>條痕：金是金黃、另外兩個綠黑。硬度：黃鐵礦（6–6.5）比小刀硬、黃銅礦（3.5–4）比小刀軟、金（2.5–3）軟而有延展性。

### 螢光與磷光

## 3. 解理、斷口與硬度 ★

礦物對外力的反應取決於兩件事：**鍵結**和**結構缺陷**。

### 解理

**解理**是礦物沿著原子平面裂開的傾向。裂開的面是**鍵結較弱**的面，而鍵結弱通常伴隨**面間距大**（吸引力不夠把兩層拉近）。所以解理的方向和組數直接反映結構。

依好壞分：**極完全**（雲母，一撕就開）、**完全**（平整但還是有台階）、**中等**（平台很窄）、**不完全**（很少看到平台）。

<CleavageTypesFig />

先預測：輝石和角閃石都是兩組柱狀解理，夾角哪個比較接近 90°？為什麼？

<PyxAmphFig />

輝石是**單鏈**矽酸鹽，鏈很窄，解理沿鏈和鏈之間的弱面，兩組幾乎垂直（**87°／93°**）；角閃石是**雙鏈**，比較寬，兩組解理交成 **124°／56°**。這是手標本和薄片下區分兩者最快的方法（L05 矽酸鹽結構、L06 顯微鏡下）。

### 裂理和斷口

- **裂理（parting）**：沿結構中因雜質、包裹體、固溶體離溶等造成的弱面裂開。看起來像解理，但**不連續、不平整**，也**不是晶體固有的性質**，不嚴格遵守晶體對稱。例：輝石、剛玉。
- **斷口（fracture）**：結構中沒有特定的弱面，破裂沒有固定方向。四種：**貝殼狀**（黑曜岩、石英）、**纖維狀／針狀**（針鈉鈣石）、**鋸齒狀**（自然銅、金）、**不規則**。

### 硬度

<MohsDemo />

**摩氏硬度**用十種礦物排順序：1 滑石、2 石膏、3 方解石、4 螢石、5 磷灰石、6 正長石、7 石英、8 黃玉、9 剛玉、10 金剛石。它是**相對**的（誰刮得動誰），不是等距的；絕對硬度從 9 到 10 跳了好幾倍。

【例題 ★ 完整解】一顆無色、玻璃光澤的礦物，小刀刮得動、銅幣刮不動，滴稀鹽酸冒泡，有三組不互相垂直的解理。是什麼？

**解**：小刀（~5.1）刮得動 → H \< 5；銅幣（~3.2）刮不動 → H ≥ 3；所以 H ≈ 3–5。滴酸冒泡 → 碳酸鹽。三組不垂直的解理 → 菱面體解理。答案是**方解石**（H 3）。如果冷鹽酸反應很弱、要磨粉才冒泡，則是白雲石（H 3.5–4）。

【換你算】一顆黃色金屬光澤的礦物，條痕綠黑，小刀刮不動，常呈立方體。是什麼？（答案：黃鐵礦。若小刀刮得動、條痕也綠黑，則是黃銅礦。）

### 韌性

礦物抵抗破裂、變形的性質，和內部鍵結有關：**脆性**（敲就碎，大部分離子鍵礦物）、**延展性**（可以打成薄片，金、銀、銅）、**可切性**（小刀可切成薄片）、**塑性**（彎了不會回復）、**撓曲性**（可彎曲但不回彈，如綠泥石、滑石）、**彈性**（彎了會彈回，雲母）。

## 4. 比重

**密度** ρ = 質量／體積；**比重** = 和同體積水的比值（沒有單位）。結晶物質的比重取決於兩件事：

1. **原子種類**：結構一樣、陽離子不同時，陽離子原子量越大比重越大。例如同結構的碳酸鹽：霰石（Ca）\< 菱鍶礦（Sr）\< 碳鋇礦（Ba）\< 白鉛礦（Pb）。同樣的，角閃石中 Mg（24.3）換成 Fe（55.8）比重就變大。
2. **原子的堆疊方式**：同樣成分，堆得越緊密比重越大（例如霰石 2.9 > 方解石 2.71；藍晶石 3.6 > 紅柱石 3.15）。

**Jolly 天平**量比重：先量在空氣中的重量 W<sub>a</sub>，再量浸在水中的重量 W<sub>w</sub>。水中變輕的量 W<sub>a</sub> − W<sub>w</sub> 就是排開的水重（阿基米德原理），也就是「同體積的水重」，所以

$$G = \frac{W_a}{W_a - W_w}$$

【例題 ★ 完整解】一顆礦物在空氣中重 15.0 g，浸在水中重 12.0 g，比重多少？可能是什麼？

**解**：G = 15.0 ／（15.0 − 12.0）= 15.0 ／ 3.0 = **5.0**。比重 5 左右的常見礦物有黃鐵礦（5.02）、磁鐵礦（5.18）、赤鐵礦（5.26）。再用顏色、條痕、磁性區分。

【換你算】空氣中 10.0 g、水中 6.3 g → G = ？（答案：10.0 ／ 3.7 ≈ 2.70，可能是方解石或石英。）

## 5. 磁性、放射性與電性

<MagnetismFig />

| 磁性 | 微觀原因 | 例子 |
|---|---|---|
| **反磁性** | 同一軌道的兩個電子自旋相反、全部成對，互相抵消；外加磁場時（冷次定律）產生微弱的反向磁性，被磁鐵輕微排斥 | **大部分礦物**：石英、方解石、石墨、石膏、石鹽、方鉛礦（磁感率為負） |
| **順磁性** | 有不成對電子，但磁偶極亂排互相抵消；外加磁場時順著排列，被磁鐵微弱吸引 | 黑雲母、石榴子石、菱鐵礦、橄欖石、輝石、伊萊石（磁感率為正，數百到數萬 × 10⁻⁶） |
| **鐵磁性** | 磁矩自發排列（磁區）；外加磁場後一致，移除仍保有磁性，直到溫度超過**居禮點** | **磁鐵礦**（強磁，居禮點 580 °C）、磁黃鐵礦（弱磁） |

**放射性**：含 U、Th 的礦物會衰變，放出 α、β、γ 粒子和中子，用**蓋格計數器**偵測。（鋯石含微量 U、Th，所以會有輻射變晶；北投石含鐳。）

**電性**：
- **壓電性**：對特定礦物施加有方向的壓力，兩端會產生等量的正負電荷。例：**電氣石、石英**（石英錶就是利用它）。
- **熱電性**：受熱時產生電荷。例：**電氣石**。

## 容易混淆

| 這個 | 那個 | 差別 |
|---|---|---|
| 晶形 | 晶癖 | 晶形是幾何形狀（立方體、八面體）；晶癖是一般外觀（柱狀、葡萄狀） |
| 自色 | 他色 | 本身成分致色（橄欖石）／雜質致色（紅寶石、祖母綠） |
| 晶體場 | 電荷轉移 | 單一離子的 d 軌道分裂／電子在兩個離子之間跳 |
| 顏色 | 條痕 | 塊體顏色常不可靠；粉末顏色較穩定 |
| 解理 | 裂理 | 結構固有、連續平整／缺陷造成、不連續 |
| 螢光 | 磷光 | 停止照射就停／停止後仍發光 |
| 硬度 | 韌性 | 抗刮／抗破裂（鑽石很硬但脆；閃玉不算最硬但極韌） |
| 順磁性 | 鐵磁性 | 移除磁場後磁性消失／保留到居禮點 |
| 黃鐵礦 | 黃銅礦 | 都綠黑條痕；黃鐵礦比小刀硬、常立方體，黃銅礦比小刀軟、顏色較深 |
