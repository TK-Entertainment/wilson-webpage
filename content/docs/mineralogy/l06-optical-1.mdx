**這講在回答**：為什麼偏光顯微鏡是鑑定礦物最好的工具？光通過礦物時發生什麼事？偏光顯微鏡的構造是什麼、怎麼用？只放下偏光鏡（開放偏光）時，可以看到礦物的哪些特徵、怎麼判讀？

**考前 30 秒**

1. 光是**橫波**：振動方向垂直前進方向。進入礦物會變慢、折射（Snell：n₁ sin i = n₂ sin r）；不同礦物的**折射率**不同，可以用來鑑定。
2. **下偏光鏡**（起偏器）只讓**南北向**振動的光通過；**上偏光鏡**（檢偏器）只讓**東西向**通過。兩片都用 = **正交偏光**，什麼都不放時全黑。
3. 開放偏光看五件事：**晶形**（自形／半自形／他形）、**顏色**、**解理**（無／1 組／2 組）、**浮影**（高／中／低）、**多色性**（有／無）。
4. **浮影**來自礦物和周圍（環氧樹脂 n ≈ 1.537）的折射率差；鐵鎂礦物（橄欖石、輝石、角閃石、黑雲母）浮影中到高，長英質礦物（斜長石、正長石、石英、白雲母、方解石）浮影低。
5. **貝克線**：提升鏡筒，亮線往**折射率高**的一側移動。
6. **多色性**：旋轉載物台顏色改變（黑雲母、角閃石、電氣石、綠泥石）；等軸晶系和玻璃沒有。

### 先認識的名詞

| 名詞 | English | 一句話 |
|---|---|---|
| 折射率 n | refractive index | 光在真空中的速度 ÷ 在礦物中的速度；越大光越慢 |
| 色散 | dispersion | 不同波長的光折射率不同，白光被分成光譜 |
| 未偏振光／偏振光 | unpolarized / polarized light | 在垂直前進方向的平面上各方向都在振動／只在一個平面振動 |
| 開放偏光（單偏光） | open nicol; plane-polarized light (PPL) | 只用下偏光鏡 |
| 正交偏光 | crossed nicols; cross-polarized light (XPL) | 上、下偏光鏡都用，振動方向互相垂直 |
| 浮影 | relief | 礦物和周圍物質因折射率差而顯出的邊緣對比 |
| 貝克線 | Becke line | 顆粒邊緣的亮線，對焦改變時會移動 |
| 閃突起 | twinkling (change of relief on rotation) | 旋轉載物台時浮影明顯改變（白雲母、方解石） |
| 多色性 | pleochroism | 不同方向吸收不同波長的光，旋轉時顏色改變 |
| 吸光性 | absorption | 不同方向吸收相近波長但強弱不同，旋轉時深淺改變 |
| 等向性／非等向性 | isotropic / anisotropic | 各方向光學性質相同（等軸晶系、玻璃）／不同（其他晶系） |

## 1. 光的性質

<strong>為什麼用偏光顯微鏡？</strong>1850 年代 Sorby 開始用偏光顯微鏡看岩石薄片，到今天仍是鑑定礦物和岩石組織最有用的方法：不同礦物的光學性質不同，可以在岩石中認出它們；再依礦物的種類和含量把岩石分類。樣本要先做成**薄片**（L02）或把顆粒用膠埋起來。

**光是電磁波**，速度約 30 萬 km／s，可見光只是連續光譜的一小部分。光是**橫波**：電場的振動方向**垂直**於前進方向。

**反射和折射**：反射角 = 入射角，且在同一平面上。光穿過礦物時速度變慢（波長也變短），偏折的程度由折射率決定：

$$n_1 \sin i = n_2 \sin r \qquad\text{或}\qquad n_1 v_1 = n_2 v_2$$

每種礦物讓光變慢的程度不同，這個「遲滯」就是礦物的折射率，可以幫助鑑定。

**色散**：折射率會隨波長改變，所以不同顏色的光折射角度不同，白光被稜鏡分成光譜。榍石色散很高，所以有七彩霓光（L05）。

**偏振**：太陽、燈泡、燭光發出的光，在垂直前進方向的平面上**各個方向都在振動**，叫未偏振光；如果光被限制在**一個平面上振動**，就是偏振光。把未偏振光變成偏振光的過程叫偏振化。偏光顯微鏡的關鍵就是兩片偏振片。

## 2. 偏光顯微鏡 ★

<MicroscopeFig />

課堂的十三個部位：1 目鏡、2 檢偏器（上偏光鏡）、3 附加板插槽、4 物鏡轉盤、5 物鏡、6 旋轉載物台、7 聚光鏡、8 下偏光鏡（可旋轉）、9 垂直調節、10 光圈、11 照明、12 光源控制、13 開關。

光從底座往上，經過下偏光鏡、聚光鏡、載物台上的薄片、物鏡、上偏光鏡，到目鏡。

- **下偏光鏡**（起偏器）：通常只讓**南北向**（前後）振動的光通過。
- **上偏光鏡**（檢偏器）：只讓**東西向**振動的光通過。兩片都用時稱為「正交」（crossed），載物台上沒東西時**全黑**，因為南北向的光完全沒有東西向的分量。

<PolarizerFig />

先預測：正交偏光下放一片玻璃（非晶質），轉動載物台會看到什麼？（答案：一直全黑。玻璃是等向性的，不會改變光的振動方向。）

### 使用注意

- 物鏡的軸要和鏡筒、載物台的軸一致（載物台和鏡筒已對準，只需調整物鏡）。
- 搬顯微鏡時一手拿鏡臂、一手托底座，鏡臂貼著肚子，避免震動光學部件。
- 避免陽光直射、高熱、濕氣、腐蝕。
- **換物鏡或換薄片前，先把載物台降下**。
- 對焦：先從側面看，把載物台調到接近物鏡，再從目鏡看、**往遠離的方向**調焦（避免物鏡撞破薄片）。
- 雙眼觀察；只碰可以碰的部位；不用時放回箱子防塵。

### 顯微鏡的四項調整

1. **十字絲就定位**：十字絲要和上、下偏光鏡的振動方向平行。
2. **校正旋轉中心**：讓載物台的旋轉中心和十字絲交點重合，轉動時顆粒不會跑出視野。
3. **下偏光鏡就定位**：確認上、下偏光鏡互相垂直（正交時全黑）。
4. **清潔鏡片**。

## 3. 開放偏光：晶形、顏色、解理

開放偏光（只用下偏光鏡）看五件事：**外型、顏色、解理、浮影、多色性**。

**外型**：自形（看得到完整晶面）、半自形（部分晶面）、他形（沒有晶面）。觀念和 L04 相同：早結晶、有空間的長成自形；最後填空隙的是他形。

**顏色**：開放偏光下的顏色是礦物吸收後剩下的光，很直觀。大部分長英質礦物無色；黑雲母綠褐、角閃石綠色。

**解理**：在薄片中，解理是一組組平行的細線。看有沒有、有幾組：石英**沒有**解理；黑雲母**一組**；普通輝石**兩組**。解理的成因和手標本一樣：結構中鍵結較弱、面間距較大的面（L04）。輝石兩組解理近直角、角閃石 124°／56°，在橫切面上看得最清楚。

## 4. 浮影與貝克線 ★

**浮影**是礦物和周圍物質因為**折射率差異**而顯出的邊緣。折射率差越大，邊緣越明顯、顆粒看起來越「浮起來」。礦物折射率比周圍高叫**正浮影**，比周圍低叫**負浮影**。

薄片用加拿大膠或環氧樹脂黏貼，折射率約 **1.537**（投影片也寫 1.54）。

| 浮影 | 礦物 | 折射率 |
|---|---|---|
| 中到高（正） | 鐵鎂礦物：橄欖石、紫蘇輝石、普通輝石、角閃石、黑雲母 | 橄欖石 1.64–1.88 |
| 低（正或負） | 長英質礦物：斜長石、正長石、石英、白雲母、方解石 | 斜長石 1.53–1.57 |

例子：橄欖石和輝石共存時，**橄欖石的浮影比輝石高**；高折射率的磷灰石（1.65）被低折射率的石英或鹼性長石（1.55）包圍時，磷灰石浮影明顯。

**閃突起**：白雲母在解理平行東西向時浮影比南北向時強烈，旋轉時浮影會一閃一閃（方解石也很明顯）。原因是這些礦物不同方向的折射率差很大（雙折射大，L08）。

**貝克線測試**：判斷兩個相鄰物質誰的折射率大。

<BeckeDemo />

- **提升鏡筒，貝克線往折射率高的介質移動**。所以亮線往顆粒裡面跑 → 顆粒折射率較高；往外跑 → 顆粒折射率較低。
- 為了看清楚，要**縮小光圈**，並把界面移到視野中央。
- 投影片英文寫「when the stage is raised: moves in → N<sub>grain</sub> > N<sub>surroundings</sub>」。注意：提升**載物台**和提升**鏡筒**是相反的對焦方向，一般教科書的規則是「**拉開**物鏡和薄片的距離（提升鏡筒或降下載物台），亮線往高折射率移動」。考試照中文口訣「提升鏡筒，往高折射率移動」，實驗時先用已知礦物（例如石英邊緣接觸樹脂）確認一次。

【例題 ★ 完整解】薄片中一顆無色顆粒和環氧樹脂接觸，提升鏡筒時亮線往樹脂方向移動。這顆礦物可能是石英（n ≈ 1.54–1.55）還是正長石（n ≈ 1.52）？

**解**：亮線往樹脂移動 → 樹脂的折射率較高 → 顆粒的 n \< 1.537。石英比 1.537 稍高（亮線會往石英移動），正長石較低，所以是**正長石**。

## 5. 多色性與吸光性 ★

**等向性**物質（等軸晶系礦物和玻璃）各方向光學性質相同；**非等向性**（雙折射性）物質各方向的折射率不同。最大和最小折射率的差叫**雙折射率**，例如方解石最高 1.66、最低 1.49，雙折射率 0.17（L08 詳述）。

光進入非等向性的有色礦物時，不同振動方向的光被吸收的程度不同：

- **多色性**：不同方向吸收**不同波長**的光 → 旋轉載物台時**色調**改變（例如綠色變褐色）。紅簾石、電氣石明顯。
- **吸光性**：不同方向吸收**相近波長**但**強弱不同** → 旋轉時**深淺**改變。

典型礦物：黑雲母、角閃石、電氣石、綠泥石；小顆粒的鋯石、綠簾石周圍有時也有。

| 礦物 | 多色性的規則（課堂寫法） |
|---|---|
| 黑雲母 | 要有解理的切面才明顯；**解理東西向時顏色最深**；沒有解理的切面（垂直 c 軸）幾乎不變色 |
| 角閃石 | 只有一組解理的切面：解理東西向最深（墨綠），南北向最淺（淺黃綠）；兩組斜交解理的切面：**銳角平分線**東西向最深 |
| 紫蘇輝石 | 偶有多色性：解理東西向淺綠，南北向淺粉紅 |
| 斜長石 | 無色，無多色性 |

> **原理**：黑雲母在光的振動方向**平行解理**時吸收最強。所以「解理在哪個方向最深」取決於下偏光鏡的振動方向；課堂的寫法是解理東西向最深。實習時以你用的顯微鏡實際看到的為準，考試照課堂寫法。

| 微斜長石 | 半自形 | 無色 | 無 | 低 | 有 |
| 正長石 Or | 半自形 | 無色（常混濁） | 無 | 低 | 有 |

| 下偏光鏡 | 上偏光鏡 | 起偏器、南北向、在載物台下／檢偏器、東西向、在鏡筒中 |

| 浮影 | 閃突起 | 折射率差造成的邊緣／旋轉時浮影變化 |
| 多色性 | 吸光性 | 色調改變／深淺改變 |
| 正浮影 | 負浮影 | 礦物 n 比周圍高／低 |
| 提升鏡筒 | 提升載物台 | 對焦方向相反，貝克線移動方向也相反 |
