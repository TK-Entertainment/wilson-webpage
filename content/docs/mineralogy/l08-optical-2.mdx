**這講在回答**：加上上偏光鏡（正交偏光）之後，礦物為什麼會變黑（消光）或出現顏色（干涉色）？干涉色由什麼決定、怎麼用它鑑定礦物或檢查薄片厚度？最後怎麼把開放偏光和正交偏光的觀察合起來，認出十一種常見造岩礦物？

**考前 30 秒**

1. 正交偏光看四件事：**雙晶、環帶、消光、干涉色**。
2. 非等向性礦物把光拆成兩道**振動方向互相垂直、速度不同**的光；轉一圈**消光 4 次**（振動方向和偏光鏡平行時）。等向性礦物、不透明礦物、玻璃**全消光**。
3. 消光三型：**平行**（解理 ∥ 十字絲）、**對稱**（十字絲平分兩組解理）、**斜**（夾消光角）。
4. **雙折射率 = 最大 − 最小折射率**（方解石 1.66 − 1.49 = 0.17）。沿**光軸**入射不發生雙折射。
5. **一軸晶**（六方、正方）一個光軸；**二軸晶**（斜方、單斜、三斜）兩個光軸；等軸晶系等向性。一軸晶 **ε > ω 正光性（石英）**、**ε \< ω 負光性（方解石）**。
6. **光程差 Δ = 厚度 d × 雙折射率**；干涉色只由 Δ 決定，每 ~550 nm 一階。干涉色受**光性方位、薄片厚度、雙折射率**影響。
7. 標準 30 μm 薄片：石英（0.009）一階灰白；若石英一階黃 → 太厚（~0.04 mm）。

### 先認識的名詞

| 名詞 | 一句話 |
|---|---|
| 雙晶（twinning） | 兩個以上同種晶體依規則（非平行）連生，消光位置不同 |
| 聚片雙晶 | 很多薄片狀雙晶交替排列（斜長石） |
| 環帶（zoning） | 晶體不同生長階段的成分不同，一圈一圈 |
| 消光（extinction） | 正交偏光下顆粒變黑 |
| 消光角 | 解理（或晶體長邊）和消光位置之間的夾角 |
| 波狀消光 | 轉動時黑影像波浪一樣掃過顆粒（石英，晶格受應變） |
| 雙折射（double refraction） | 光進入非等向性礦物後分成兩道 |
| 雙折射率（birefringence） | 最大與最小折射率的差 |
| 光軸（optic axis） | 光沿這個方向前進時不發生雙折射 |
| o 光／e 光 | 正常光（折射率 ω、No 不變）／異常光（折射率 ε、Ne 隨方向變） |
| 光率體（indicatrix） | 以各振動方向的折射率為半徑畫出的立體 |
| 光程差（retardation, Δ） | 兩道光穿過薄片後的路程差 = d × 雙折射率 |
| 干涉色 | 兩道光在上偏光鏡干涉後的顏色，依 Δ 分成一階、二階、三階… |

## 1. 雙晶與環帶

課堂把觀察整理成兩組：**開放偏光**看 Form（自／半自／他形）、Color、Pleochroism（有／無）、Relief（高／中／低）、Cleavage（無／幾組）；**正交偏光**看 Twinning（有／無）、Zoning（有／無）、Extinction（平行／斜）、Interference color（高／中／低）。

<TwinZoningFig />

**雙晶**：兩個或以上同種晶體依一定規律（但不平行）連生在一起。在薄片中，同一顆礦物的不同部分**消光位置不同**或**干涉色不同**，所以看起來一塊亮一塊暗。常見於**斜長石**（聚片雙晶，黑白條紋）、正長石（簡單雙晶）、角閃石、輝石。微斜長石有**聚片雙晶加上交叉的格子雙晶**。

**環帶**：晶體不同的生長區域有不同成分，環帶描出晶體生長時的外形。只會出現在**固溶體**礦物中：在不同溫度（或壓力）下結晶出的成分不同，或結晶時化學不平衡。所以環帶可以推晶體的生長過程。

## 2. 消光 ★

**全消光**：等向性礦物（如石榴子石）、不透明的金屬礦物（如鈦鐵氧化物）、非晶質的玻璃，在正交偏光下**一直是黑的**，怎麼轉都一樣（「旋轉白搭」）。

**非等向性礦物**：每轉 90° 消光一次，**轉一圈消光 4 次**（振動方向平行上、下偏光鏡各兩次）。

為什麼？非等向性礦物把南北向的偏振光拆成兩道振動方向互相垂直的光。當這兩個振動方向**剛好一個南北、一個東西**時，南北向的入射光完全走「南北那一道」，出來仍是南北向，到上偏光鏡（只收東西向）就被擋掉 → 黑。其他角度時，兩道光都有東西向的分量 → 有光。亮度 ∝ sin²2θ（θ 是振動方向和偏光鏡的夾角），所以每 90° 一次全黑、45° 時最亮。

**消光角的量法**：先把解理（或晶體長邊）對齊十字絲的一個方向，再轉動載物台直到消光，轉過的角度就是**消光角**。

<ExtinctionFig />

| 消光型式 | 定義 | 礦物 |
|---|---|---|
| **平行消光** | 消光位和晶稜、解理平行 | 黑雲母（0–3°）、白雲母（0–3°）、正長石、紫蘇輝石、橄欖石 |
| **對稱消光** | 消光位在兩組解理夾角的對角線（十字絲平分解理） | 方解石 |
| **斜消光** | 消光位和解理斜交；在定向切片中，一定的礦物消光角一定 → 可以鑑定 | 普通輝石（36–45°）、角閃石、微斜長石、斜長石（0–70°） |
| **波狀消光** | 黑影像波浪掃過 | 石英 |
| **全消光** | 永遠黑 | 石榴子石、玻璃、不透明礦物 |

**斜方輝石（Opx）平行消光、單斜輝石（Cpx）斜消光**：這是區分兩種輝石最重要的特徵（快速分類表的最後一步）。

## 3. 雙折射與光率體 ★

光進入非等向性礦物時，會產生**兩個不同的折射率**（兩道光）。透過方解石看字會看到兩個影像，就是**雙折射**。最大和最小折射率的差叫**雙折射率**：方解石 1.66 − 1.49 = **0.17**（非常大，所以閃突起和雙影都很明顯）。

**光軸**：光沿著某個方向進入晶體時，**不會發生雙折射**，這個方向就是光軸。依光軸的數目，非等向性晶體分兩類：

| 類型 | 光軸數 | 晶系 |
|---|---|---|
| 等向性 | —（各方向都一樣） | **等軸** |
| **一軸晶** uniaxial | 1 | **六方、正方**（三方） |
| **二軸晶** biaxial | 2 | **斜方、單斜、三斜** |

**一軸晶的兩道光**：
- 振動方向<strong>垂直光軸（c 軸）</strong>的光，折射率不隨方向改變，叫**正常光（o 光）**，折射率 **ω（No）**。
- 振動方向**含有光軸分量**的光，折射率隨方向改變，叫**異常光（e 光）**；振動方向平行光軸時是 **ε（Ne）**。

**光率體**：從晶體中心沿每個振動方向畫一段線，長度等於那個方向的折射率，端點連起來的立體就是光率體。推導（投影片 p.19–20）：

- 光從**沿光軸**的 A 點入射：所有可能的振動方向都垂直光軸，折射率都是 ω，集合起來是一個**半徑 ω 的圓**。
- 光從**垂直光軸**的 B 點入射：分成振動垂直光軸的 o 光（ω）和振動平行光軸的 e 光（ε），這兩個半徑構成一個**橢圓**。
- 把所有方向的圓和橢圓組合起來，得到一個**旋轉橢球**，以光軸為旋轉軸。

<IndicatrixFig />

- **ε > ω**：沿光軸拉長（以長軸為旋轉軸）→ **正光性**，例：**石英**。
- **ε \< ω**：沿光軸壓扁（以短軸為旋轉軸）→ **負光性**，例：**方解石**（ε = 1.49 \< ω = 1.66）。

二軸晶有兩個光軸，光率體是三個軸都不相等的橢球（細節在期末範圍）。

## 4. 干涉色 ★

**干涉色怎麼來**（投影片 p.24）：下偏光鏡的光 → 進入石英 → 分成 o 光和 e 光：

- (a)(b) 偏光鏡的方向剛好和 o 光或 e 光的振動方向一致 → 只有一道光，到上偏光鏡被擋 → **消光**。
- (c)(d)(e) 其他方向 → 兩道光以**不同速度**穿過晶體，出來時一道落後另一道；到上偏光鏡時兩道光的東西向分量**干涉** → **干涉色**。

落後的距離叫**光程差**：

$$\Delta = d \times (n_1 - n_2)$$

d 是薄片厚度（約 0.03 mm = 30 000 nm），n₁ − n₂ 是這個方向上的雙折射。光程差讓某些波長互相抵消、某些加強，白光扣掉被抵消的顏色，就是干涉色。干涉色依光程差分階：**一階**（0–550 nm）、**二階**（550–1100 nm）、**三階**……

所以干涉色受三個因素影響：**① 光性方位**（切面方向，沿光軸切時雙折射為 0，看起來是黑的）、**② 薄片厚度**、**③ 雙折射率**。

<InterferenceDemo />

先預測：標準厚度下，石英（0.009）、普通輝石（0.025）、方解石（0.17）的光程差各是多少？各落在哪一階？

【例題 ★ 完整解】（投影片 p.29–30）
(1) 石英的雙折射率 0.009。某薄片中石英呈一階黃白，薄片多厚？
(2) 標準薄片中某礦物最高干涉色是二階綠（Δ ≈ 720 nm），雙折射率多少？

**解**：
(1) 一階黃白約 Δ ≈ 360 nm（投影片的讀圖結果）。d = Δ ／ δ = 360 ／ 0.009 = 40 000 nm = **0.04 mm**，比標準厚。如果看到的是一階灰白，表示已經磨到標準的 0.03 mm（Δ = 30 000 × 0.009 = 270 nm）。
(2) δ = Δ ／ d = 720 ／ 30 000 = **0.024**，接近普通輝石（0.025）。

【換你算】標準薄片中，黑雲母（δ ≈ 0.05）的最高光程差？（答案：30 000 × 0.05 = 1500 nm，三階。課堂把黑雲母寫成「干涉色中」，因為黑雲母本身的顏色會遮掩干涉色，而且常見切面不在最大雙折射方向。）

> **易錯**：同一種礦物在同一張薄片中，不同顆粒的干涉色可以不同，因為切面方向（光性方位）不同。鑑定時要找**最高**的干涉色。

例子（投影片 p.26）：玄武岩柱狀節理的薄片中，斜長石（0.012）是灰白，單斜輝石（0.025）是黃、紅、藍。

### 常見礦物光性表

| 礦物 | 開放偏光 | 正交偏光 |
|---|---|---|
| 橄欖石 Ol | 自形、無色、無多色性、浮影高、**無解理** | 少見雙晶、干涉色**高**、平行消光 |
| 普通輝石 Cpx | 自形 4–8 邊、無色、無多色性、浮影高、解理 2 組 | 有時有雙晶、干涉色中到高、**斜消光 36–45°** |

| 普通角閃石 Hb | 自形到半自形、**綠色、多色性淡綠到淡褐**、浮影高、解理 2 組 | 有時雙晶、干涉色中到高、斜消光 |
| 黑雲母 Bi | 半自形、**綠褐、多色性綠到深褐**、浮影中、解理 1 組 | 無雙晶、干涉色中、平行消光 0–3° |
| 斜長石 Pl | 半自形、無色、浮影低、解理好 | **聚片雙晶**、干涉色灰白、消光 0–70° |
| 微斜長石 | 同上 | **聚片雙晶 + 格子雙晶**、灰白、斜消光 |
| 正長石 Or | 半自形、無色、浮影低、解理好 | 可見雙晶（簡單雙晶）、灰白、平行消光 |
| 白雲母 Mus | 半自形、無色、有時多色性、浮影低、解理 1 組 | 常見雙晶、干涉色**高**、平行消光 0–3° |
| 石英 Qz | 半自形、無色、浮影低、**無解理** | 少見雙晶、**灰白到黃**、**波狀消光** |
| 方解石 Cal | 他形、無色、浮影中、解理好 | 常見雙晶、干涉色**高（高階白）**、**對稱消光** |
| 石榴子石 | 半自形、無色、浮影高、無解理 | **全消光** |

## 容易混淆

| 這個 | 那個 | 差別 |
|---|---|---|
| 消光 | 全消光 | 每 90° 黑一次（非等向性）／永遠黑（等向性、不透明、玻璃） |
| 平行消光 | 斜消光 | 解理 ∥ 十字絲時黑／解理和十字絲夾一個角時黑 |
| Opx | Cpx | 平行消光、干涉色低／斜消光、干涉色中高 |
| 一軸晶 | 二軸晶 | 一個光軸（六方、正方）／兩個（斜方、單斜、三斜） |
| 正光性 | 負光性 | ε > ω 長橢球（石英）／ε \< ω 扁橢球（方解石） |
| 雙折射率 | 光程差 | 礦物性質（無單位）／× 厚度後的距離（nm） |
