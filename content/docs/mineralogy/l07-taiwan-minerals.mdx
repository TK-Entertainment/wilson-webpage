**這講在回答**：台灣有哪些礦物？它們分布在哪裡？為什麼某些礦物只出現在某些地方？（期末主題礦物報告就從這 60 種中抽。）

**考前 30 秒**

1. 台灣礦物調查：**1911 岡本要八郎 51 種**（含石油和煤）→ 1938 小笠原美津雄 84 → 1959 顏滄波 117 → 1974 林朝棨、周瑞燉 157 → **2004 陳培源等 252 種**。
2. 礦物跟著**地質環境**走：**熱液礦床**（金瓜石、九份）→ 金、銅、硫化物；**火山與地熱**（大屯、北投）→ 硫黃、北投石、蛋白石、黏土；**東部變質帶**（大南澳片岩、豐田蛇紋岩）→ 藍閃石、閃玉、硬綠泥石、石榴子石、石墨；**火山弧與玄武岩**（海岸山脈、綠島、蘭嶼、澎湖）→ 輝石、角閃石、橄欖石；**沉積岩與海濱**→ 方解石、石鹽、重砂礦物。
3. **北投石**：1906 年岡本要八郎在北投溪發現，含**鐳**的放射性含鉛重晶石 (Ba,Pb)SO₄；全世界只有北投和日本秋田玉川溫泉；**唯一以台灣地名命名的礦物**。
4. **金瓜石有硫砷銅礦（高溫熱液）、九份沒有（低溫）**。
5. 採**硫、煤、金**是台灣三大古老礦業。
6. **豐田閃玉**（台灣玉）：蛇紋岩體中熱水作用形成，曾占世界產量一半。

### 先認識的名詞

| 名詞 | English | 一句話 |
|---|---|---|
| 山金／砂金 | lode gold / placer gold | 原生在岩石裂隙、礦脈中的金／原生金風化後被河流搬運堆積的金 |
| 熱液礦脈 | hydrothermal vein | 熱水在裂隙中沉澱礦物形成的脈 |
| 硫氣孔 | solfatara (fumarole) | 火山噴出含硫氣體的孔，周圍沉積硫黃 |
| 換質（蝕變） | alteration | 熱液或風化讓岩石原有礦物變成其他礦物 |
| 捕獲岩 | xenolith | 岩漿帶上來的其他岩石碎塊 |
| 重砂 | heavy minerals (heavy sand) | 河流或海濱沉積物中比重大的礦物（鋯石、磁鐵礦、石榴子石…） |
| 蛇紋岩 | serpentinite | 富鎂的超基性岩經熱液蝕變，主要由蛇紋石組成 |
| 混同層 | mélange | 板塊隱沒帶中各種岩塊混雜的地層（利吉混同層） |

## 1. 台灣礦物調查史

| 年代 | 調查者 | 種數 |
|---|---|---|
| 1911 | 台灣總督府礦物課，**岡本要八郎**《台灣礦物調查報告》 | 51（含石油和煤） |
| 1938 | 殖產局，小笠原美津雄《台灣產礦物一覽》 | 84 |
| 1959 | 地質調查所，**顏滄波**《台灣之礦物》 | 117（不含石油和煤） |
| 1974 | **林朝棨**、周瑞燉《台灣地質》 | 157 |
| 2004 | **陳培源**、劉德慶、黃怡禎《台灣之礦物》 | **252** |

課堂的分類順序：自然元素 → 硫化物、砷化物、硫鹽 → 氧化物、氫氧化物 → 碳酸鹽、鹵化物、磷酸鹽、硫酸鹽 → 矽酸鹽（島、對、環 → 單雙鏈 → 層 → 架）。

## 2. 熱液礦床：金瓜石、九份 ★

新北市瑞芳的**金瓜石、九份、武丹坑**是台灣最重要的金屬礦區。岩漿活動帶來的熱水沿著安山岩的裂隙上升、冷卻，沉澱出金、銅和各種硫化物。

<strong>為什麼金瓜石和九份不一樣？</strong>兩者都是熱液礦床，但溫度不同：

- **金瓜石**：較高溫的熱液，是**金銅礦**；最主要的銅礦物是**硫砷銅礦**（需要高溫熱液）。淺層調查約仍有至少 52 公噸黃金藏量。
- **九份**：較**低溫**的熱液礦脈，以金為主，可見大金塊；**沒有硫砷銅礦**。

| 礦物 | 這裡的產狀 |
|---|---|
| **自然金** | 山金：裂隙充填或蝕變岩中的細脈；九份、金瓜石低溫熱液礦脈。砂金：基隆河（建鐵路的工人先發現，後來才追到金瓜石）、立霧溪（中央山脈兩側河川） |
| 自然銀 | 罕見，只在金瓜石八坑脈石中呈微點狀 |
| 自然汞 | 金瓜石地表的水銀點滴 |
| 自然銅 | 附在金瓜石的脈石上 |
| **硫砷銅礦** | 金瓜石最主要的含銅礦物 |
| 黃銅礦、黃鐵礦 | 金瓜石金銅礦中伴生；黃鐵礦在台灣非常普遍 |
| 方鉛礦、閃鋅礦 | 九份、武丹坑礦床，常共生 |
| 辰砂 | 金瓜石、雙溪平林汞礦 |
| 輝銻礦、雌黃 | 金瓜石、九份脈石中，少見 |
| 赤鐵礦 | 金瓜石 |
| **孔雀石** | 含銅礦物露頭**風化**後形成的綠色薄膜 |
| 石英 | 金瓜石矽化安山岩 |

## 3. 火山與地熱：大屯火山群、北投 ★

大屯火山群（陽明山）至今仍有**硫氣孔**和溫泉。火山氣體和酸性熱水造成獨特的礦物：

| 礦物 | 產狀與重點 |
|---|---|
| **硫黃** | 陽明山大、小油坑、北投大磺嘴的**硫氣孔**周圍；昇華、礦染、沉澱三種產狀。手握放在耳邊會脆裂（手熱使晶體膨脹） |
| **北投石** | 北投溪中安山岩礫的表面；含**鐳**的放射性含鉛重晶石；1906 年岡本要八郎發現 |
| 雄黃、雌黃 | 北投地熱谷 |
| 辰砂 | 北投福興寮、七星山與小觀音山交界 |
| **蛋白石** | 安山岩被硫氣酸性熱液分解，暗色礦物溶掉後留下的矽質殘餘（礦業稱「白土」） |
| 高嶺石、蒙脫石 | 熱液使岩石**黏土化** |
| 石膏 | 北投地熱谷 |
| 紅柱石、矽線石、堇青石 | 七星山、竹子湖、小油坑噴氣口的安山岩**捕獲岩**（岩漿把地殼岩石帶上來加熱變質） |
| 鋯石、黑雲母 | 安山岩中 |

**北投石為什麼特別**：它是重晶石（BaSO₄）和硫酸鉛礦（PbSO₄）的混合，結晶過程中包住微量的放射性元素鐳。全世界只在北投和日本秋田縣玉川溫泉產出，是**唯一以台灣地名命名的礦物**。

## 4. 東部變質帶：大南澳片岩、豐田蛇紋岩 ★

中央山脈東翼是台灣最古老的岩石（大南澳片岩），經歷過區域變質；花東縱谷西側有很多**蛇紋岩體**。

| 礦物 | 產狀與重點 |
|---|---|
| **閃玉**（台灣玉） | **花蓮豐田**蛇紋岩體；熱水和蛇紋石反應形成透閃石。閃玉舊稱「軟玉」，其實比輝玉還韌；豐田曾占世界產量一半 |
| 陽起石 | 南澳、豐田、萬榮、瑞穗、玉里清水溪的蛇紋岩體；透閃石的 Mg 被 Fe²⁺ 取代 2% 以上 |
| **石棉** | 角閃石或蛇紋石的纖維狀變種；豐田曾開採，因為會造成呼吸系統疾病已禁用 |
| 蛇紋石 | 海岸山脈南段利吉混同層、花東縱谷西邊、脊梁山脈東面 |
| **藍閃石** | **瑞穗**打馬燕山的藍閃石片岩、玉里清水溪；**低溫高壓**變質（藍片岩相）的指標 |
| 滑石 | 打馬燕山，和陽起石共生 |
| 石榴子石 | 花蓮打馬燕片岩；記錄變質溫壓 |
| **硬綠泥石** | 大南澳片岩；沙卡礑溪大理岩、太魯閣西段、慈母橋 |
| 石墨 | 大南澳片岩中，土狀夾層或透鏡狀 |
| 白雲石 | 大南澳群大理岩（方解石被富鎂流體取代） |
| 白雲母 | 東澳粉鳥林、源頭山；南橫向陽的絹雲母 |
| 綠簾石 | 綠色片岩、綠色岩 |
| 電氣石 | 花蓮源頭山、荖腦山的偉晶花崗岩 |
| 矽線石 | 南澳源頭山混合片麻岩 |
| 剛玉 | 花蓮沙卡礑溪的硬綠泥石岩體中 |

## 5. 火山弧與玄武岩：海岸山脈、綠島、蘭嶼、澎湖

海岸山脈、綠島、蘭嶼是**呂宋火山弧**的一部分，以安山岩為主；**澎湖**是玄武岩台地。這些火成岩含有典型的鐵鎂礦物：

| 礦物 | 產狀 |
|---|---|
| 紫蘇輝石、普通輝石 | 海岸山脈南部輝長岩、北部和綠島安山岩、**澎湖**與西北部玄武岩 |
| 普通角閃石 | 海岸山脈南部輝長岩、北部與綠島安山岩、東北部角閃岩 |
| **橄欖石** | 澎湖玄武岩 |
| **磁鐵礦** | 安山岩、玄武岩的副礦物；風化後集中成海濱的**磁鐵砂**（金山萬里到富貴角、成功海岸） |
| 霰石、方解石 | 澎湖、蘭嶼玄武岩的**氣孔**中；澎湖**文石**的主要成分是霰石 |
| 蒙脫石 | 澎湖玄武岩熱水蝕變、海岸山脈都巒山層集塊岩 |
| 堇青石 | 綠島、蘭嶼捕獲岩（綠島的堇青石代表大陸地殼的混染） |
| 自然銅 | 台東水母丁蛇紋岩、都蘭山銅礦 |

## 6. 沉積岩、海濱與金門

| 礦物 | 產狀 |
|---|---|
| **方解石** | 西部石灰岩（水泥原料）、高雄半屏山、大小崗山；溫泉石灰華 |
| **石鹽** | 台灣**沒有岩鹽層**；西南沿海布袋到安平曬鹽、澎湖桶盤嶼岩面 |

| 伊萊石 | 各沉積岩層 |

## 容易混淆

| 這個 | 那個 | 差別 |
|---|---|---|
| 金瓜石 | 九份 | 高溫、金銅礦、有硫砷銅礦／低溫、金礦脈 |
| 北投石 | 重晶石 | 北投石含 Pb 和鐳／重晶石 BaSO₄ |
| 閃玉 | 輝玉（翡翠） | 角閃石、台灣豐田／輝石、緬甸 |
| 綠泥石 | 硬綠泥石 | H 2–3／H 6.5，大南澳片岩 |
| 霰石 | 方解石 | 澎湖文石是霰石，會慢慢變成方解石 |
| 山金 | 砂金 | 原生礦脈／河流搬運堆積 |
| 原生 | 重砂 | 黃玉、藍晶石在台灣只見於重砂 |
