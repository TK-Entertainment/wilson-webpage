## 最常考的比較

| 比較 | 怎麼分 |
|---|---|
| 輝石 vs 角閃石 | 解理角 87°／93° vs 124°／56°；角閃石綠色有多色性 |
| Opx vs Cpx | 平行消光 vs 斜消光 |
| 黑雲母 vs 白雲母 | 綠褐、多色性、干涉色中 vs 無色、干涉色高；都 1 組解理、平行消光 |
| 石英 vs 斜長石 vs 正長石 | 石英無解理、乾淨、波狀消光；斜長石聚片雙晶；正長石混濁、簡單雙晶 |
| 橄欖石 vs 石榴子石 | 都浮影高、無解理；石榴子石全消光，橄欖石干涉色高 |
| 方解石 vs 白雲母 | 都干涉色高；方解石對稱消光、菱面解理、閃突起；白雲母平行消光、1 組 |
| 方解石 vs 白雲石 vs 霰石 | 冷鹽酸劇烈／弱（要磨粉或加熱）；霰石斜方、比重大 |
| 黃鐵礦 vs 黃銅礦 vs 金 | 比小刀硬 vs 軟；條痕綠黑 vs 綠黑 vs 金黃；金有延展性 |
| 磁鐵礦 vs 赤鐵礦 | 條痕黑、強磁 vs 條痕紅 |
| 紅寶石 vs 祖母綠 | 都是 Cr³⁺；剛玉晶體場強 vs 綠柱石晶體場弱 |
| 螢光 vs 磷光 | 停止照射就停 vs 繼續發光 |
| 解理 vs 裂理 vs 斷口 | 結構固有弱面 vs 缺陷造成 vs 無方向 |
| 一軸晶 vs 二軸晶 | 六方、正方 vs 斜方、單斜、三斜 |
| 正光性 vs 負光性 | 石英 ε > ω vs 方解石 ε \< ω |

## 練習題

**一、是非與判斷**

1. 人造紅寶石和天然紅寶石成分結構相同，所以都是礦物。
2. 冰是礦物。
3. 煤是礦物，因為它是天然的固體。
4. 面角守恆是說同一種礦物的晶面大小相同。
5. 白雲母和白雲石都是層狀矽酸鹽。
6. 正交偏光下，等向性礦物轉一圈會消光四次。
7. 提升鏡筒，貝克線往折射率低的介質移動。
8. 鑽石是捕獲晶。

<details>
<summary>答案</summary>

1. ✗，人造的不是天然產出。
2. ✓。
3. ✗，有機作用形成、沒有固定成分。
4. ✗，是晶面夾角相同。
5. ✗，白雲母是層狀矽酸鹽，白雲石是碳酸鹽。
6. ✗，等向性礦物全消光；非等向性才是四次。
7. ✗，往折射率高的移動。
8. ✓，只在地函高溫高壓下穩定，由岩漿帶上來。

</details>

**二、簡答**

1. 為什麼說顏色是不可靠的鑑定特徵？什麼性質比較可靠？
2. 說明晶體場轉變如何讓礦物有顏色。
3. 輝石和角閃石的解理夾角為什麼不同？
4. 寫出 Jolly 天平的比重公式，並計算：空氣中 26.0 g、水中 16.0 g。
5. 比較反磁性、順磁性、鐵磁性。
6. 寫出矽酸鹽七種結構類型，各舉一例。
7. 說出火山產生寶石的三種途徑，各舉兩例。
8. 正交偏光下什麼是消光？三種消光型式各舉一例。
9. 石英的雙折射率 0.009，在 0.03 mm 的薄片中光程差是多少？呈現什麼干涉色？
10. 某礦物在標準薄片中最高干涉色是二階綠（約 720 nm），雙折射率是多少？可能是哪種礦物？

<details>
<summary>答案</summary>

1. 非金屬礦物常因雜質、色心、風化面、反光而顏色多變；條痕（粉末顏色）較可靠，再加上硬度、解理、比重等組合判斷。
2. 過渡金屬的 3d 軌道在礦物的多面體位置中因電場不對稱而分裂，能階差相當於可見光的能量，吸收特定波長，看到的是補色。
3. 輝石是單鏈、鏈窄，解理沿鏈間弱面，兩組近直交（87°／93°）；角閃石是雙鏈、較寬，兩組交成 124°／56°。
4. G = W<sub>a</sub>／(W<sub>a</sub> − W<sub>w</sub>) = 26.0／10.0 = 2.6（可能是石英或長石）。
5. 反磁性：電子全成對，外加磁場時微弱反向（石英、方解石）；順磁性：有不成對電子但亂排，外加磁場時順向、移除就消失（黑雲母、石榴子石）；鐵磁性：自發排列，移除磁場仍保有，超過居禮點消失（磁鐵礦 580 °C）。
6. 島（橄欖石）、對（綠簾石）、環（電氣石）、單鏈（輝石）、雙鏈（角閃石）、層（雲母）、架（石英、長石）。
7. 斑晶（月光石、鋯石）、捕獲晶（鑽石、尖晶石）、熱液（祖母綠、綠松石）。
8. 正交偏光下顆粒變黑。平行消光（黑雲母）、對稱消光（方解石）、斜消光（普通輝石）。
9. Δ = 30 000 nm × 0.009 = 270 nm，一階灰白。
10. δ = 720／30 000 = 0.024，可能是普通輝石（0.025）。

</details>

**三、看描述說礦物**

1. 開放偏光：綠色、多色性淡綠到淡褐、浮影高、兩組斜交解理。正交偏光：斜消光。
2. 開放偏光：無色、浮影低、有解理。正交偏光：黑白相間的條紋、一階灰白。
3. 開放偏光：無色、浮影高、無解理。正交偏光：干涉色鮮豔（二階以上）、平行消光。
4. 開放偏光：無色、浮影中、解理好、轉動時浮影一閃一閃。正交偏光：高階白、對稱消光。
5. 手標本：淺黃銅色、金屬光澤、條痕綠黑、小刀刮不動、立方體晶形。
6. 手標本：藍紫色、針狀晶簇，產在花蓮瑞穗的片岩中。
7. 手標本：黃色、放射性，長在北投溪的安山岩礫表面。

<details>
<summary>答案</summary>

1. 普通角閃石。
2. 斜長石（聚片雙晶）。
3. 橄欖石。
4. 方解石。
5. 黃鐵礦。
6. 藍閃石。
7. 北投石。

</details>
