## 第一份作業（L2：REE 與批次熔融）

### 1-1　描述 MORB（紅）與 OIB（黑）的 REE 型態，並提出解釋

<details>
<summary>解題流程</summary>

**思路**：先「描述」再「解釋」，兩部分都要寫。解釋要用到三個觀念：LREE 比 HREE 不相容、熔融程度 F、石榴子石留住 HREE。

**描述**

- **OIB（黑）**：強烈 **LREE 富集**，La 約 100–400 倍球粒隕石，Lu 約 8–10 倍，整條往右下斜。
- **MORB（紅）**：**LREE 虧損**，La 只有約 3–20 倍、往左下彎；HREE 平坦，約 10–20 倍。

**解釋（可以寫多個假說）**

1. **熔融程度不同**：LREE 比 HREE 更不相容（La 半徑大，離 cpx 晶格位置遠）。熔融程度 F 越低，不相容元素富集越多（C<sub>L</sub>/C₀ 趨近 1/D）。OIB 來自熱點、F 低 → LREE 富集很多；MORB 的 F 較高 → 富集較少。
2. **石榴子石殘留**：OIB 熔融深度深，殘留物中有石榴子石。石榴子石的 D<sub>Yb</sub> ≈ 4，會把 HREE 留在固體裡 → 熔體的 HREE 低，斜率更陡。
3. **來源不同**：MORB 來自**已經被抽取過不相容元素的虧損上部地函**，所以 LREE 本來就少，形成虧損型態；OIB 來自較深、未虧損（或富集）的地函柱。

</details>

### 1-2　用礦物比例算 Ce、Yb 的 bulk D，哪個比較適合拿來模擬地函熔融？

地函：60% ol、25% opx、10% cpx、5% garnet

| | D<sub>Ce</sub> | D<sub>Yb</sub> |
|---|---|---|
| olivine | 0.001 | 0.002 |
| opx | 0.003 | 0.05 |
| cpx | 0.1 | 0.28 |
| garnet | 0.02 | 4.0 |

<details>
<summary>解題流程</summary>

**思路**：bulk D = 各礦物的 D 乘上它的比例，全部加起來。

**步驟**

$$
\bar D = \sum_i x_i D_i
$$

- D<sub>Ce</sub> = 0.6(0.001) + 0.25(0.003) + 0.1(0.1) + 0.05(0.02) = 0.0006 + 0.00075 + 0.01 + 0.001 = **0.012**
- D<sub>Yb</sub> = 0.6(0.002) + 0.25(0.05) + 0.1(0.28) + 0.05(4.0) = 0.0012 + 0.0125 + 0.028 + 0.2 = **0.24**

**哪個比較好：Ce**

1. D<sub>Ce</sub> ≪ 1，高度不相容 → C<sub>L</sub>/C₀ ≈ 1/F，濃度直接反映熔融程度 F，模型簡單。
2. D<sub>Yb</sub> 有 0.2 來自石榴子石（5% × 4.0），占了八成。熔融過程中石榴子石的比例會改變，D<sub>Yb</sub> 跟著變，模型不穩定。

**陷阱**：比例要用小數（60% → 0.6）；石榴子石只占 5%，但對 Yb 的貢獻最大。

</details>

### 1-3　沒有 Th 的 D，但夏威夷玄武岩的 Th 和 Ce 成正比（圖中 Ce/Th 約 15），估計 D<sub>Th</sub>

<details>
<summary>解題流程</summary>

**思路**：同一個地函來源、不同熔融程度 F 的岩漿，如果兩個元素的**比值不變**，表示它們在熔融時行為一樣 → D 一樣。

**步驟**

1. 對 Ce 和 Th 各寫一次批次熔融：

$$
\frac{C_L^{Ce}}{C_L^{Th}} = \frac{C_0^{Ce}}{C_0^{Th}} \times \frac{D_{Th}(1-F) + F}{D_{Ce}(1-F) + F}
$$

2. 圖上所有岩漿的 Ce/Th 都差不多（資料落在同一條過原點附近的直線上），表示這個比值**不隨 F 改變**。
3. 右邊那個分數要不隨 F 改變，只能是 **D<sub>Th</sub> = D<sub>Ce</sub>**。
4. 所以 **D<sub>Th</sub> ≈ D<sub>Ce</sub> ≈ 0.012**。

**陷阱**：題目問的是「估計」，關鍵是寫出「比值固定 → D 相同」的推理，不是讀圖算斜率。

</details>

### 1-4　兩個夏威夷岩漿 [Th]<sub>A</sub> = 12 ppm、[Th]<sub>B</sub> = 2.4 ppm，比較熔融程度

<details>
<summary>解題流程</summary>

**思路**：同一個地函來源（C₀ 相同），把兩個岩漿的批次熔融式相除，C₀ 就消掉了。

**步驟**

1. 相除：

$$
\frac{C_A}{C_B} = \frac{D(1-F_B) + F_B}{D(1-F_A) + F_A} = \frac{12}{2.4} = 5
$$

2. **近似 D ≈ 0**（Th 高度不相容）：F<sub>B</sub>/F<sub>A</sub> = 5 → **F<sub>B</sub> = 5 F<sub>A</sub>**
3. **用 D = 0.012 精確算**：5[D + F<sub>A</sub>(1−D)] = D + F<sub>B</sub>(1−D)
   → F<sub>B</sub> = 5F<sub>A</sub> + 4D/(1−D) ≈ **5F<sub>A</sub> + 0.05**

**結論**：A 的 Th 濃度是 B 的 5 倍 → **A 的熔融程度比 B 低很多**（大約只有 B 的 1/5）。不相容元素越濃，表示熔融程度越低。

例：若 F<sub>A</sub> = 2%，則 F<sub>B</sub> ≈ 15%。

**陷阱**：濃度高 ≠ 熔得多。不相容元素在**低 F** 時最濃。

</details>

## 第二份作業（L3：熱力學）

### 2-1　求 Mg₂SiO₄ + SiO₂ ⇌ 2 MgSiO₃ 的 ΔH（以 J 表示）

- Mg + 3/2 O₂ + Si → MgSiO₃　ΔH = −1497.4 kJ/mol
- Si + O₂ → SiO₂　ΔH = −859.4 kJ/mol
- 2Mg + 2O₂ + Si → Mg₂SiO₄　ΔH = −2042.6 kJ/mol

<details>
<summary>解題流程</summary>

**思路**：Hess's law。把已知的生成反應「翻面、乘倍數」，加起來要剛好等於目標反應，元素全部消掉。能這樣加，是因為 H 是狀態函數。

**步驟**

1. 目標反應的反應物是 Mg₂SiO₄、SiO₂ → 它們的生成式要**反過來**，ΔH 變號：
   - Mg₂SiO₄ → 2Mg + 2O₂ + Si　**+2042.6**
   - SiO₂ → Si + O₂　**+859.4**
2. 產物是 2 MgSiO₃ → 生成式**乘 2**：
   - 2Mg + 3O₂ + 2Si → 2MgSiO₃　**2 × (−1497.4) = −2994.8**
3. 三式相加，左右的 Mg、Si、O₂ 剛好消掉。
4. ΔH = 2042.6 + 859.4 − 2994.8 = **−92.8 kJ = −92,800 J**

**快速版**：ΔH = Σ產物 − Σ反應物 = 2(−1497.4) − [(−2042.6) + (−859.4)] = −92.8 kJ

**陷阱**：題目要 **J**；係數 2 要乘進去；反過來的式子要變號。

</details>

### 2-2　CaAl₂Si₂O₈ + 2Mg₂SiO₄ = CaMgSi₂O₆ + MgAl₂O₄ + 2MgSiO₃：算 298 K 的 ΔG，判斷穩定性、加壓與升溫的影響

| | ΔH°f (kJ/mol) | S° (J/K·mol) | V (cm³/mol) |
|---|---|---|---|
| Anorthite | −4214.60 | 205.43 | 100.79 |
| Forsterite | −2175.68 | 95.19 | 43.79 |
| Diopside | −3202.34 | 143.09 | 66.09 |
| Spinel | −2288.01 | 80.63 | 39.71 |
| Enstatite | −1546.77 | 67.86 | 31.28 |

<details>
<summary>解題流程</summary>

**思路**：ΔH、ΔS、ΔV 都是「產物 − 反應物」，記得乘係數。ΔG = ΔH − TΔS 判斷方向；加壓看 ΔV、升溫看 ΔS（來自 dG = V dP − S dT）。

**步驟**

1. **ΔH** = [−3202.34 + (−2288.01) + 2(−1546.77)] − [−4214.60 + 2(−2175.68)]
   = −8583.89 − (−8565.96) = **−17.93 kJ**
2. **ΔS** = [143.09 + 80.63 + 2(67.86)] − [205.43 + 2(95.19)]
   = 359.44 − 395.81 = **−36.37 J/K**
3. **ΔV** = [66.09 + 39.71 + 2(31.28)] − [100.79 + 2(43.79)]
   = 168.36 − 188.37 = **−20.01 cm³**
4. **ΔG** = ΔH − TΔS = −17,930 − 298.15 × (−36.37) = −17,930 + 10,844 = **−7.09 kJ**

**判斷**

| 問題 | 依據 | 答案 |
|---|---|---|
| 298 K 哪邊穩定？ | ΔG \< 0 | 往右，**產物**（透輝石 + 尖晶石 + 頑火輝石）穩定 |
| 加壓往哪邊？ | ΔV \< 0 | 加壓有利體積小的一邊 → **產物** |
| 升溫往哪邊？ | ΔS \< 0 | 升溫時 −TΔS 變成更大的正值，ΔG 往正走 → **反應物**（鈣長石 + 鎂橄欖石） |

**地質意義**：左邊是斜長石橄欖岩（淺），右邊是尖晶石橄欖岩（深）。

**陷阱**：ΔH 是 kJ、ΔS 是 J/K，代入 ΔG 前要統一成 J；T 用 K；兩個負號相乘變正。

</details>

## 第三份作業（L5：碳酸系統）

常數：K<sub>CO₂</sub> = 10⁻¹·⁴⁷、K₁ = 10⁻⁶·³⁵、K₂ = 10⁻¹⁰·³³、K<sub>w</sub> = 10⁻¹⁴

### 3-1　與大氣 CO₂（P<sub>CO₂</sub> = 3.7×10⁻⁴ atm）平衡的純水 pH

<details>
<summary>解題流程</summary>

**思路**：開放系統，H₂CO₃ 由 P<sub>CO₂</sub> 決定；電荷平衡只剩 H⁺ 和 HCO₃⁻（酸性時 CO₃²⁻、OH⁻ 可忽略）。

**步驟**

1. \[H₂CO₃\] = K<sub>CO₂</sub> × P<sub>CO₂</sub> = 10⁻¹·⁴⁷ × 10⁻³·⁴³ = **10⁻⁴·⁹⁰ M**
2. 電荷平衡：\[H⁺\] = \[HCO₃⁻\] + 2\[CO₃²⁻\] + \[OH⁻\] ≈ \[HCO₃⁻\]
3. 代入 K₁ = \[H⁺\]\[HCO₃⁻\] / \[H₂CO₃\] → \[H⁺\]² = K₁\[H₂CO₃\] = 10⁻⁶·³⁵ × 10⁻⁴·⁹⁰ = 10⁻¹¹·²⁵
4. \[H⁺\] = 10⁻⁵·⁶² → **pH ≈ 5.6**

**陷阱**：log 相加時指數直接相加；開根號是指數除以 2。

</details>

### 3-2　C<sub>T</sub> = 10⁻² M，求三個當量點的 pH

<details>
<summary>解題流程</summary>

**思路**：每個當量點就是「把某種純物質溶進水」，寫出那個溶液的電荷平衡，只留主要項。

| 當量點 | 等於什麼溶液 | 條件 | 解法 | pH |
|---|---|---|---|---|
| **CO₂ EP** | 純 H₂CO₃ | \[H⁺\] = \[HCO₃⁻\] | \[H⁺\]² + K₁\[H⁺\] − K₁C<sub>T</sub> = 0；近似 \[H⁺\]² ≈ K₁C<sub>T</sub> = 10⁻⁸·³⁵ | **4.18** |
| **HCO₃⁻ EP** | 純 NaHCO₃ | \[H₂CO₃\] = \[CO₃²⁻\] | \[H⁺\] = √[K₁(K₂C<sub>T</sub> + K<sub>w</sub>)/(K₁ + C<sub>T</sub>)]；近似 pH ≈ (pK₁ + pK₂)/2 | **8.34** |
| **CO₃²⁻ EP** | 純 Na₂CO₃ | \[HCO₃⁻\] = \[OH⁻\] | 當成弱鹼：K<sub>b</sub> = K<sub>w</sub>/K₂ = 10⁻³·⁶⁷；\[OH⁻\]² + K<sub>b</sub>\[OH⁻\] − K<sub>b</sub>C<sub>T</sub> = 0 | **11.13** |

**最快的近似（考試先寫這個）**

- CO₂ EP：pH ≈ ½(pK₁ − log C<sub>T</sub>) = ½(6.35 + 2) ≈ 4.2
- HCO₃⁻ EP：pH ≈ ½(pK₁ + pK₂) = ½(6.35 + 10.33) ≈ 8.3
- CO₃²⁻ EP：pOH ≈ ½(pK<sub>b</sub> − log C<sub>T</sub>) = ½(3.67 + 2) ≈ 2.8 → pH ≈ 11.2（精確解 11.13）

**陷阱**：CO₃²⁻ EP 要先換成 K<sub>b</sub> 算 OH⁻，最後用 pH = 14 − pOH。

</details>

### 3-3　寫出含 H₃SiO₄⁻、H₄SiO₄、B(OH)₃、B(OH)₄⁻、H₂S、HS⁻、H₂PO₄⁻、HPO₄²⁻、H₂CO₃、HCO₃⁻、CO₃²⁻、OH⁻、H⁺ 的鹼度式

<details>
<summary>解題流程</summary>

**思路**：鹼度 = 以 CO₂ 當量點的主要物種為「零點」，每個物種比零點**少了幾個 H⁺**，就記幾倍正；比零點多的記負。

**步驟**

1. 零點（題目提示）：H₄SiO₄、B(OH)₃、H₂S、H₂PO₄⁻、H₂CO₃ → 它們在式子裡係數為 0，不出現。
2. 逐一比較：

| 物種 | 比零點少幾個 H⁺ | 係數 |
|---|---|---|
| HCO₃⁻（比 H₂CO₃ 少 1 個） | 1 | +1 |
| CO₃²⁻（少 2 個） | 2 | **+2** |
| H₃SiO₄⁻ | 1 | +1 |
| B(OH)₄⁻（= B(OH)₃ + OH⁻，等於少 1 個 H⁺） | 1 | +1 |
| HS⁻ | 1 | +1 |
| HPO₄²⁻（比 H₂PO₄⁻ 少 1 個） | 1 | +1 |
| OH⁻ | 1 | +1 |
| H⁺ | 多 1 個 | **−1** |

3. 答案：

**Alk = \[HCO₃⁻\] + 2\[CO₃²⁻\] + \[H₃SiO₄⁻\] + \[B(OH)₄⁻\] + \[HS⁻\] + \[HPO₄²⁻\] + \[OH⁻\] − \[H⁺\]**

**陷阱**：HPO₄²⁻ 的係數是 1 不是 2，因為零點是 H₂PO₄⁻，不是 H₃PO₄。

</details>

### 3-4　與大氣平衡的純水加 NaOH，pH 怎麼變？算緩衝強度並作圖

<details>
<summary>解題流程</summary>

**思路**：開放系統，P<sub>CO₂</sub> 固定 → \[H₂CO₃\] 固定 = 10⁻⁴·⁹⁰。加 NaOH 後 pH 上升，HCO₃⁻、CO₃²⁻ 跟著變多。用電荷平衡寫出加了多少鹼 C<sub>B</sub>，再對 pH 微分。

**步驟**

1. 各物種用 \[H⁺\] 表示：
   - \[HCO₃⁻\] = K₁\[H₂CO₃\] / \[H⁺\]
   - \[CO₃²⁻\] = K₂\[HCO₃⁻\] / \[H⁺\]
2. 電荷平衡（Na⁺ = C<sub>B</sub>）：**C<sub>B</sub> = \[HCO₃⁻\] + 2\[CO₃²⁻\] + \[OH⁻\] − \[H⁺\]**
3. 對 pH 微分：每個跟 1/\[H⁺\] 成正比的項，微分後乘 2.303；CO₃²⁻ 跟 1/\[H⁺\]² 成正比，再多乘 2：

$$
\beta = \frac{dC_B}{d\mathrm{pH}} = 2.303\left([\mathrm{H^+}] + [\mathrm{OH^-}] + [\mathrm{HCO_3^-}] + 4[\mathrm{CO_3^{2-}}]\right)
$$

4. 代數字：

| pH | \[HCO₃⁻\] (M) | 需加的 NaOH C<sub>B</sub> (M) | β (M/pH) |
|---|---|---|---|
| 5.6 | 2.2×10⁻⁶ | 0（純水） | 1.1×10⁻⁵ |
| 7 | 5.6×10⁻⁵ | 5.6×10⁻⁵ | 1.3×10⁻⁴ |
| 8 | 5.6×10⁻⁴ | 5.7×10⁻⁴ | 1.3×10⁻³ |
| 9 | 5.6×10⁻³ | 6.1×10⁻³ | 1.5×10⁻² |
| 10 | 5.6×10⁻² | 1.1×10⁻¹ | 3.7×10⁻¹ |

**結論**：開放系統中，pH 每升一單位，HCO₃⁻ 大約多 10 倍 → **β 隨 pH 一直增加**（對數圖上幾乎是斜率 1 的直線）。一開始加一點 NaOH，pH 就升很多；pH 越高，要加越多鹼才推得動。這跟封閉系統不同：封閉系統的 β 在 pK₁、pK₂ 最大，在當量點最小。

**陷阱**：開放系統 \[H₂CO₃\] 是固定的，不是 C<sub>T</sub> 固定。

</details>

### 3-5　Pb 總量 10⁻⁸ M，Pb²⁺ + H₂O ⇌ PbOH⁺ + H⁺（K = 10⁻⁷·⁷），算 pH 6–9 的 PbOH⁺ 分率並作圖

<details>
<summary>解題流程</summary>

**思路**：分率只跟 K 和 \[H⁺\] 有關，總濃度會消掉。

**步驟**

1. K = \[PbOH⁺\]\[H⁺\] / \[Pb²⁺\] → \[PbOH⁺\]/\[Pb²⁺\] = K/\[H⁺\]
2. 分率 α = \[PbOH⁺\] / (\[Pb²⁺\] + \[PbOH⁺\]) = **K / (K + \[H⁺\])**

| pH | 6 | 6.5 | 7 | 7.5 | 7.7 | 8 | 8.5 | 9 |
|---|---|---|---|---|---|---|---|---|
| α<sub>PbOH⁺</sub> | 0.02 | 0.06 | 0.17 | 0.39 | **0.50** | 0.67 | 0.86 | 0.95 |

**規律**：S 形曲線，**pH = pK = 7.7 時剛好各一半**。跟碳酸系統的交叉點（pH = pK₁、pK₂）是同一個道理。

**陷阱**：總 Pb 10⁻⁸ M 是干擾資訊，算分率用不到。

</details>

### 4-1　三核種衰變鏈 N₁ → N₂ → N₃ 的方程式推導

題目要你推出：

$$
N_2(t) = \frac{\lambda_1}{\lambda_2 - \lambda_1}N_1^0\left(e^{-\lambda_1 t} - e^{-\lambda_2 t}\right) + N_2^0 e^{-\lambda_2 t}
$$

$$
N_3(t) = N_1^0\left[1 + \frac{1}{\lambda_2 - \lambda_1}\left(\lambda_1 e^{-\lambda_2 t} - \lambda_2 e^{-\lambda_1 t}\right)\right] + N_2^0\left(1 - e^{-\lambda_2 t}\right) + N_3^0
$$

<details>
<summary>解題流程</summary>

**思路**：每個核種都寫「增加 − 減少」。N₁ 只會減少；N₂ 從 N₁ 來、自己也衰變；N₃ 穩定，只會增加。N₂ 那條是一階線性微分方程，用積分因子 e^(λ₂t) 解。N₃ 不用解微分方程，用「原子總數守恆」就好。

**步驟**

1. 三條速率式：

$$
\frac{dN_1}{dt} = -\lambda_1 N_1,\qquad \frac{dN_2}{dt} = \lambda_1 N_1 - \lambda_2 N_2,\qquad \frac{dN_3}{dt} = \lambda_2 N_2
$$

2. 第一條直接積分：N₁ = N₁⁰e^(−λ₁t)。
3. 代進第二條，移項：dN₂/dt + λ₂N₂ = λ₁N₁⁰e^(−λ₁t)。兩邊乘 e^(λ₂t)，左邊變成一個乘積的微分：

$$
\frac{d}{dt}\left(N_2 e^{\lambda_2 t}\right) = \lambda_1 N_1^0 e^{(\lambda_2 - \lambda_1)t}
$$

4. 從 0 積到 t：

$$
N_2 e^{\lambda_2 t} - N_2^0 = \frac{\lambda_1}{\lambda_2 - \lambda_1}N_1^0\left(e^{(\lambda_2-\lambda_1)t} - 1\right)
$$

   兩邊乘 e^(−λ₂t)，就是 N₂(t) 的式子。
5. **N₃ 用守恆**：衰變不會讓原子消失，N₁ + N₂ + N₃ = N₁⁰ + N₂⁰ + N₃⁰，所以 N₃ = N₁⁰ + N₂⁰ + N₃⁰ − N₁ − N₂。
6. 代入 N₁、N₂，把 N₁⁰ 的項整理在一起：

$$
N_1^0\left[1 - e^{-\lambda_1 t} - \frac{\lambda_1}{\lambda_2-\lambda_1}\left(e^{-\lambda_1 t} - e^{-\lambda_2 t}\right)\right]
$$

   中括號裡 e^(−λ₁t) 的係數是 −1 − λ₁/(λ₂−λ₁) = −λ₂/(λ₂−λ₁)，e^(−λ₂t) 的係數是 λ₁/(λ₂−λ₁)，所以等於 1 + (λ₁e^(−λ₂t) − λ₂e^(−λ₁t))/(λ₂−λ₁)。N₂⁰ 的項是 N₂⁰ − N₂⁰e^(−λ₂t) = N₂⁰(1 − e^(−λ₂t))，加上 N₃⁰，就是題目的式子。

**檢查**：t = 0 時中括號 = 1 + (λ₁ − λ₂)/(λ₂ − λ₁) = 0，N₃ = N₃⁰ ✓；t → ∞ 時 N₃ = N₁⁰ + N₂⁰ + N₃⁰，全部變成穩定子核 ✓。

**陷阱**：N₃ 硬解微分方程很容易算錯，用守恆最快也最不會錯。分母是 λ₂ − λ₁，不要寫反。

</details>

### 4-2　t₁/₂ = 2.0×10⁶ 年，現在 D\*/N = 1.5，分別在 (a) D₀/N = 0、(b) D₀/N = 1.0 時求年齡

<details>
<summary>解題流程</summary>

**思路**：定年方程式 D = D₀ + N(e^(λt) − 1)，其中 D\* = N(e^(λt) − 1) 是放射成因的部分。先看清楚 1.5 指的是 D\* 還是總 D。

**步驟**

1. λ = ln2 ÷ 2.0×10⁶ = 3.466×10⁻⁷ yr⁻¹
2. **(a) D₀/N = 0**：D\*/N = e^(λt) − 1 = 1.5 → t = ln(2.5)/λ = 0.9163 ÷ 3.466×10⁻⁷ = **2.64×10⁶ 年**
3. **(b) D₀/N = 1.0**，分兩種解讀：
   - 照字面，1.5 是**放射成因的 D\***（投影片 D\* 的定義就是放射成因子核）：D₀ 不影響 D\* 和時間的關係，年齡一樣是 **2.64×10⁶ 年**。
   - 如果 1.5 是**量到的總 D/N**：D\*/N = 1.5 − 1.0 = 0.5 → t = ln(1.5)/λ = 0.4055 ÷ 3.466×10⁻⁷ = **1.17×10⁶ 年**。

**結論**：題目給兩種 D₀，就是要你發現「沒扣掉 D₀ 會把年齡算老」：(a) 和 (b) 第二種解讀差了一倍多。這也是為什麼要用等時線法同時求 D₀ 和 t。

**陷阱**：兩種解讀都寫出來、說明你採用哪一種最安全。半衰期要先換成 λ，不能直接拿 t₁/₂ 去除。

</details>

### 4-3　從 −dN/dt = λN 推導長期平衡時 λ₁N₁ = λ₂N₂（N₁ → N₂ → N₃）

<details>
<summary>解題流程</summary>

**思路**：長期平衡的意思是 N₂ 的數量不再改變，也就是 dN₂/dt = 0。可以直接從速率式寫，也可以從 4-1 的 N₂(t) 取極限，兩種都寫最完整。

**步驟**

1. N₂ 的變化 = 從 N₁ 衰變來的 − 自己衰變掉的：dN₂/dt = λ₁N₁ − λ₂N₂。
2. 平衡時 dN₂/dt = 0 → **λ₁N₁ = λ₂N₂**。
3. **為什麼會達到平衡**（從 4-1 的解）：令 N₂⁰ = 0，母核半衰期遠大於子核（λ₁ ≪ λ₂），t 夠大時 e^(−λ₂t) → 0，而 e^(−λ₁t) 幾乎不變：

$$
N_2 \approx \frac{\lambda_1}{\lambda_2 - \lambda_1}N_1^0 e^{-\lambda_1 t} = \frac{\lambda_1}{\lambda_2 - \lambda_1}N_1 \approx \frac{\lambda_1}{\lambda_2}N_1
$$

   所以 λ₂N₂ = λ₁N₁。
4. 同理對下一個子核，整條鏈都成立：λ₁N₁ = λ₂N₂ = λ₃N₃ = …

**物理意義**：λN 就是活度，長期平衡是**活度相等**，不是原子數相等。半衰期越短的核種，平衡時原子數越少。大約經過中間子核的 5–10 個半衰期就會平衡。

**陷阱**：一定要寫出 λ₁ ≪ λ₂ 這個前提。如果 λ₁ 和 λ₂ 差不多（暫時平衡），比值會是 λ₁/(λ₂ − λ₁)，不是 λ₁/λ₂；如果 λ₁ > λ₂，永遠不會平衡。

</details>

### 4-4　讀 Rutherford（1900）〈A radioactive substance emitted from thorium compounds〉，設計一個新實驗回答一個未知問題

<details>
<summary>解題流程</summary>

**思路**：這題沒有標準答案，分數在「讀懂論文」和「實驗設計有沒有對照組、能不能被證偽」。照三段寫。

**第一段：論文做了什麼**（我讀到的重點）

- 釷化合物會放出一種會隨氣流移動的放射性物質，Rutherford 叫它 emanation（後來知道是氣體 ²²⁰Rn，當時叫 thoron）。
- 用游離室量電流，發現它的活度隨時間**等比例下降**，大約 1 分鐘減半（²²⁰Rn 的半衰期現在測到約 55.6 秒）。這是第一次清楚量到單一放射性物質的指數衰減。
- 碰過 emanation 的物體表面會帶「感應放射性」（excited radioactivity），衰減得慢很多；後來知道是 ²²⁰Rn 的子核（²¹²Pb，半衰期約 10.6 小時）。

**第二段：提出一個未知問題**，例：

> 台灣活動斷層附近，土壤氣體中的 ²²²Rn 和 ²²⁰Rn 比值，能不能分辨氣體是從深處沿斷層上來，還是只是淺層土壤自己放出來的？

為什麼用兩種 Rn：²²⁰Rn 半衰期不到 1 分鐘，只能走幾公分就衰變光，所以只代表**就地**來源；²²²Rn 半衰期 3.8 天，可以從深處移上來。比值變化就是氣體來源深度的指標。

**第三段：實驗設計**

1. **測站**：斷層線上 3 站、離斷層 500 m 外的對照站 3 站，同樣岩性。
2. **量測**：每小時用 α 能譜分開量 ²²²Rn、²²⁰Rn；同時記氣壓、雨量、土壤含水量。
3. **對照**：氣壓和雨量會改變土壤透氣度；用對照站扣掉共同的氣象訊號。
4. **預期結果**：如果斷層是氣體通道，斷層站的 ²²²Rn/²²⁰Rn 會比對照站高，而且變化和氣象無關；如果兩邊一樣，就表示斷層沒有特別的氣體通道。
5. **限制**：岩性差異也會讓 Ra 含量不同，所以每站還要採土壤量 ²²⁶Ra、²²⁴Ra 校正。

**陷阱**：只寫「我想研究 XX」沒有對照組和預期結果，會被扣分。換成你自己感興趣的問題也可以，結構照這三段。

**注意**：題目寫 Philosophical Magazine 47，正確出處是 Phil. Mag. Series 5, **49**, 1–14（1900 年 1 月）；同一卷 p.161 還有第二篇續作。引用時寫 49。

</details>

### 5-1　年齡小於 5 萬年的樣品，把 Equation 1 簡化成 Equation 2

Equation 1：

$$
\left[\frac{^{230}\mathrm{Th}}{^{238}\mathrm{U}}\right] = 1 + \left(\left[\frac{^{232}\mathrm{Th}}{^{238}\mathrm{U}}\right]\left[\frac{^{230}\mathrm{Th}}{^{232}\mathrm{Th}}\right]_0 - 1\right)e^{-\lambda_{230}t} + \frac{\lambda_{230}}{\lambda_{230}-\lambda_{234}}\left(\left[\frac{^{234}\mathrm{U}}{^{238}\mathrm{U}}\right] - 1\right)\left(1 - e^{-(\lambda_{230}-\lambda_{234})t}\right)
$$

Equation 2：

$$
\left[\frac{^{230}\mathrm{Th}}{^{232}\mathrm{Th}}\right]_m \approx \left[\frac{^{238}\mathrm{U}}{^{232}\mathrm{Th}}\right]_m\left[\frac{^{234}\mathrm{U}}{^{238}\mathrm{U}}\right]_m\lambda_{230}t + \left[\frac{^{230}\mathrm{Th}}{^{232}\mathrm{Th}}\right]_0
$$

<details>
<summary>解題流程</summary>

**思路**：Equation 2 是一條直線（對 t 線性），所以一定用了**泰勒展開** e^(−x) ≈ 1 − x。再把兩邊除以 ²³²Th 換成以 ²³²Th 為分母。

**假設**

1. **t 很短**：λ₂₃₀t ≪ 1、λ₂₃₄t ≪ 1，所以 e^(−λ₂₃₀t) ≈ 1 − λ₂₃₀t，1 − e^(−(λ₂₃₀−λ₂₃₄)t) ≈ (λ₂₃₀ − λ₂₃₄)t。
2. **²³²Th 和 ²³⁸U 的衰變忽略**（半衰期 140 億年、45 億年，5 萬年內不變），所以量到的 ²³²Th/²³⁸U 就是當初的值。
3. **初始 ²³⁰Th 這幾萬年的衰變忽略**（只保留一階小量的主項）。

**步驟**

1. 第二項代入假設 1：

$$
\left(\left[\tfrac{^{232}\mathrm{Th}}{^{238}\mathrm{U}}\right]\left[\tfrac{^{230}\mathrm{Th}}{^{232}\mathrm{Th}}\right]_0 - 1\right)(1 - \lambda_{230}t)
$$

2. 第三項：分母的 λ₂₃₀ − λ₂₃₄ 和展開出來的 (λ₂₃₀ − λ₂₃₄)t 約掉，剩 **λ₂₃₀t([²³⁴U/²³⁸U] − 1)**。
3. 全部加起來，展開後 1 和 −1 抵消、+λ₂₃₀t 和 −λ₂₃₀t 抵消：

$$
\left[\frac{^{230}\mathrm{Th}}{^{238}\mathrm{U}}\right] \approx \left[\frac{^{232}\mathrm{Th}}{^{238}\mathrm{U}}\right]\left[\frac{^{230}\mathrm{Th}}{^{232}\mathrm{Th}}\right]_0(1 - \lambda_{230}t) + \left[\frac{^{234}\mathrm{U}}{^{238}\mathrm{U}}\right]\lambda_{230}t
$$

4. 兩邊乘 [²³⁸U/²³²Th]：

$$
\left[\frac{^{230}\mathrm{Th}}{^{232}\mathrm{Th}}\right] \approx \left[\frac{^{230}\mathrm{Th}}{^{232}\mathrm{Th}}\right]_0(1 - \lambda_{230}t) + \left[\frac{^{238}\mathrm{U}}{^{232}\mathrm{Th}}\right]\left[\frac{^{234}\mathrm{U}}{^{238}\mathrm{U}}\right]\lambda_{230}t
$$

5. 用假設 3，把 [²³⁰Th/²³²Th]₀ · λ₂₃₀t 這個「小量 × 小量」丟掉，就是 Equation 2。

**物理意義**：Equation 2 是一條**等時線**。同一層的幾個子樣品，橫軸放 [²³⁸U/²³²Th]·[²³⁴U/²³⁸U]，縱軸放 [²³⁰Th/²³²Th]，**截距 = 初始 [²³⁰Th/²³²Th]₀，斜率 = λ₂₃₀t**。這樣不必假設初始 Th 是多少，碎屑汙染比較多的年輕樣品特別有用。

### 5-2　挑一篇科學人文章，提出一個相關的未知問題或爭議，以及可能的解法

投影片上標了科學人的主題（2009–2025 年各期）：石筍紋層不一定一年一層、西班牙「骨坑」人骨（約 43 萬年）、甘肅夏河丹尼索瓦人下顎骨（16 萬年）、石筍記錄的百年尺度地磁變化、密克羅尼西亞南馬都爾的珊瑚石建築、微環礁珊瑚記錄蘇門答臘超級地震週期。哪一期對哪篇，請對照投影片 U-Th 那份的後半。

<details>
<summary>解題流程</summary>

**思路**：沒有標準答案。照「文章一句話 → 還不知道什麼 → 怎麼查 → 預期結果」四步寫，每步兩三句就夠。

**示範（石筍紋層）**

1. **文章重點**：大家常把石筍的紋層當成一年一層來數年份，但沈川洲老師團隊用單一紋層的 ²³⁰Th 定年發現，有一段石筍數出 36.9 層、定年只過了 27.1 年（紋層數多了），另一段數出 22.7 層、其實過了 25.5 年（紋層數少了）。
2. **未知**：多出來的「假紋層」和少掉的紋層是什麼造成的？是某些年份雨季下兩次、某些年份乾到不長？
3. **解法**：在同一個洞穴放監測儀，連續幾年記錄滴水速率、滴水的 Mg/Ca、洞內 CO₂；在石筍頂端放玻璃片收集新長出來的碳酸鈣，看一年長出幾層。再拿現代的石筍頂部和當地雨量紀錄比對。
4. **預期**：如果假紋層對應「一年兩次雨季」，就可以用微量元素（例如 Mg/Ca、P 的季節變化）分辨真假紋層，讓老石筍不必每層都定年也能數年份。

**另一個方向（微環礁）**：超級地震的週期（1797、1833、2007）是規律的，還是會隨機成群出現？解法：在明打威群島沿線多採幾個微環礁做 U-Th 定年，把紀錄延長到幾千年，再和 GNSS 量到的現今累積速率比對。

**陷阱**：問題要小到「做得出來」，解法要寫出量什麼、在哪裡量、怎麼判讀。示範只是格式，最好換成你自己真的好奇的問題。

</details>

### 5-3　沉積岩芯裡的 ²¹⁰Pb 也可以由就地的 ²²⁶Ra 產生（supported ²¹⁰Pb），²¹⁰Pb 定年公式要不要修正？怎樣得到準確又精確的年齡？

<details>
<summary>解題流程</summary>

**思路**：要修正。原本的公式假設**所有** ²¹⁰Pb 都是從大氣落下來、埋了之後只會衰變。實際上沉積物裡的 ²²⁶Ra 一直在就地產生 ²¹⁰Pb，這部分和 ²²⁶Ra 平衡，不會隨深度減少。

**步驟（修正公式）**

1. 原本的公式（沉積速率 a 固定、深度 z 的年齡 t = z/a）：

$$
A(z) = A_0\, e^{-\lambda z / a}
$$

2. 實際量到的總活度 = 過剩 + supported：

$$
A_{\text{total}}(z) = A_{\text{ex},0}\, e^{-\lambda z / a} + A_{\text{sup}},\qquad A_{\text{sup}} \approx A(^{226}\mathrm{Ra})
$$

3. 所以要先扣掉 supported 再取對數：

$$
\ln\left(A_{\text{total}} - A_{\text{sup}}\right) = \ln A_{\text{ex},0} - \frac{\lambda}{a}z
$$

   斜率 = −λ/a，λ = ln2/22.3 yr = 0.0311 yr⁻¹。
4. **不扣會怎樣**：深處的總活度被 supported 墊高，ln A 對深度的線會變彎、變平；硬配一條直線，斜率太平，**沉積速率高估、年齡偏年輕**。

[L9 的 ²¹⁰Pb 圖](/docs/geochemistry/l9-u-series)有畫總活度和過剩活度的差別。

**怎樣準確（accurate，不偏）**

1. **直接量 ²²⁶Ra**：用 γ 能譜量 ²²⁶Ra 的子核 ²¹⁴Pb（352 keV）、²¹⁴Bi（609 keV）。樣品要**密封約 3 週**，讓 ²²²Rn 不逃掉、和 ²²⁶Ra 達到平衡，否則 ²²⁶Ra 會被低估。
2. **用背景值交叉檢查**：岩芯深處 ²¹⁰Pb 不再下降的平台值應該等於 ²²⁶Ra；兩者不一樣，表示某處有問題（例如 Rn 逸散）。
3. **深度改成質量深度（g/cm²）**：上層含水多、下層被壓密，用 cm 會讓沉積速率看起來往下變慢。
4. **選對模式**：沉積速率和 ²¹⁰Pb 通量都固定才能用上面的直線（CF:CS 模式）；通量固定但沉積速率會變，要用 **CRS 模式**（用剩下的累積量算每層年齡）；表層被生物擾動混合的部分要排除。
5. **獨立年代驗證**：¹³⁷Cs 的 1963 年核試高峰、Pu 同位素，對照 ²¹⁰Pb 算出的年代。

**怎樣精確（precise，誤差小）**

1. **計數時間夠長**：計數誤差 ∝ 1/√N，深處過剩活度很小（總活度減一個差不多大的數），相對誤差會暴增，要計更久或用更多樣品。
2. **取樣夠密**：每 0.5–1 cm 一層，迴歸點多、斜率誤差小。
3. **α 能譜法**：用 ²¹⁰Po（和 ²¹⁰Pb 平衡）加 ²⁰⁹Po 示蹤劑做化學回收率校正，靈敏度比 γ 法高，適合樣品量少的情況。
4. **誤差傳遞**：過剩活度的誤差要同時包含總活度和 ²²⁶Ra 兩者的誤差。

**陷阱**：「準確」和「精確」是兩件事，題目兩個都問，要分開答。準確 = 系統誤差（有沒有扣對、模式對不對），精確 = 隨機誤差（計數統計、取樣密度）。

</details>

2. 吸的熱 = 熱容 × 升溫 = 20,917 × 9.9 = 207.08 kJ
3. **算生成了幾莫耳產物**：1 mol Na → 0.5 mol Na₂O
4. 每莫耳：207.08 ÷ 0.5 = 414.16 kJ；水溫上升 = 放熱 → **ΔH°f = −414.16 kJ/mol**

</details>

### L3　Cp 積分求 ΔH（例：石英 25 → 300 °C，Cp = a + bT − c/T²）

<details>
<summary>解題流程</summary>

1. **T 換成 K**：298.15、573.15
2. ΔH = a(T₂ − T₁) + (b/2)(T₂² − T₁²) + c(1/T₂ − 1/T₁)（−c/T² 積分變 **+c/T**）
3. = 12,908.5 + 4,109.3 − 1,818.0 ≈ **15.2 kJ/mol**
4. ΔS 同理，每項多除一個 T：a ln(T₂/T₁) + b(T₂ − T₁) + (c/2)(1/T₂² − 1/T₁²) ≈ 35.5 J/K·mol

</details>

### L3　相界壓力與 Clapeyron（例：石墨 → 鑽石）

<details>
<summary>解題流程</summary>

1. 查表：ΔH = 1860 J、ΔS = 2.37 − 5.74 = −3.37 J/K、ΔV = 3.417 − 5.298 = −1.881 cm³ = −1.881 J/MPa
2. 地表 ΔG = ΔH − TΔS = 1860 + 298.15 × 3.37 = **+2865 J** → 往右不自發，石墨穩定
3. 加壓讓 ΔG 降到 0：2865 + ΔV·ΔP = 0 → ΔP = 2865/1.881 ≈ **1.5 GPa**
4. 相界斜率：dP/dT = ΔS/ΔV = (−3.37)/(−1.881) ≈ **1.79 MPa/K**

</details>

### L4　K<sub>sp</sub>（例：CaF₂，K<sub>sp</sub> = 3.9×10⁻¹¹）

<details>
<summary>解題流程</summary>

- **給定 \[F⁻\] = 10⁻⁴ M**：\[Ca²⁺\] = K<sub>sp</sub>/\[F⁻\]² = 3.9×10⁻¹¹/10⁻⁸ = **3.9×10⁻³ M**（F⁻ 要平方）
- **純水中溶解度**：設 \[Ca²⁺\] = x、\[F⁻\] = 2x → K<sub>sp</sub> = 4x³ → x = (K<sub>sp</sub>/4)^(1/3) = **2.1×10⁻⁴ M**

</details>

### L4　van't Hoff、溫度計

<details>
<summary>解題流程</summary>

1. ΔG° = −RT ln K → ln K = −(ΔH°/R)(1/T) + ΔS°/R
2. ln K 對 1/T：**斜率 = −ΔH°/R、截距 = ΔS°/R**
3. 好溫度計：ΔH 大、ΔV 小；好壓力計：ΔV 大
4. 例：橄欖石–熔體 K<sub>D</sub>：log K<sub>D</sub> = 171/T − 0.63，1473 K 時 K<sub>D</sub> ≈ 0.31；171/T 很小 → 對溫度不敏感

</details>

### L4　一階反應半衰期（例：CO₂ 水合，k = 0.014 s⁻¹）

<details>
<summary>解題流程</summary>

1. \[A\] = \[A\]₀e^(−kt)
2. t½ = ln2/k = 0.693/0.014 ≈ **50 s**；每過一個半衰期剩一半

</details>

### L6　滯留時間

<details>
<summary>解題流程</summary>

1. 先確認穩態：流入總和 = 流出總和
2. τ = 儲庫大小 ÷ 通量（例：湖 1000 ÷ 60 ≈ 16.7 yr）
3. 反過來求通量：F = M/τ（例：深海 38,000 PgC ÷ 380 yr = 100 PgC/yr）

</details>

### L7　E 不能直接相加（例：Fe³⁺ + 3e⁻ → Fe）

<details>
<summary>解題流程</summary>

1. 每一步換成 ΔG = −zFE：Fe³⁺/Fe²⁺：−1·F·0.77 = −0.77F；Fe²⁺/Fe：−2·F·(−0.44) = +0.88F
2. ΔG 相加：+0.11F
3. 換回 E：E = −ΔG/(zF) = −0.11/3 ≈ **−0.037 V**

</details>

### L7　pε 與 pε–pH 邊界（例：SO₄²⁻/HS⁻）

<details>
<summary>解題流程</summary>

1. pε = E/0.0592；pε° = (1/n)log K
2. 寫出半反應：SO₄²⁻ + 9H⁺ + 8e⁻ ⇌ HS⁻ + 4H₂O，log K = 33.64
3. log K = log(a<sub>HS⁻</sub>/a<sub>SO₄</sub>) + 9pH + 8pε；邊界上兩者相等，第一項 = 0
4. **pε = 4.21 − 1.125 pH**（斜率 = −H⁺ 數/電子數 = −9/8）；pH 7 時 pε ≈ −3.7
5. 水的範圍：上界 pε = 20.75 − pH、下界 pε = −pH

</details>
