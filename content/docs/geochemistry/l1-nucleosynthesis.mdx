**這講在回答**：地球上的元素從哪裡來？為什麼有些多、有些少？為什麼內行星是岩石、外行星是氣體？

**考前 30 秒**

1. 大霹靂只做出 **H、He**（和一點 Li），其他元素都是恆星做的。
2. 恆星融合做到 **Fe** 就停（Fe 結合能最大）；比 Fe 重的元素靠**中子捕獲**：s 慢（紅巨星）、r 快（超新星）。
3. 太陽星雲依**凝結溫度**分成內側岩石行星、外側氣體和冰的巨行星。

**主線**：大霹靂 → 只有 H、He → 恆星把它們融合到 Fe → 超過 Fe 改靠中子捕獲 → 這些過程留下的「指紋」就是太陽系的元素豐度 → 太陽星雲冷卻時依溫度凝結出不同的行星。下面照這個順序走。

★ = 考試重點。

## 1. 大霹靂：起點，但只做出 H 和 He

**證據（三個）**

- **紅移與 Hubble plot**：距離越遠的星系後退速度越快 → 宇宙在膨脹，`v = H₀·d`。
- **宇宙微波背景（CMB）**：宇宙約 38 萬歲時留下的最古老的光。
- **輕元素豐度**：He/H 在空間和時間上都很均勻 → 來自大霹靂；Fe/H 不均勻 → 是恆星後來加工的。

既然 v = H₀·d，倒推回所有星系擠在一起的時間，就是宇宙年齡：

$$
t \approx \frac{d}{v} = \frac{1}{H_0}
$$

<details>
<summary>【例題 ★】用 Hubble 常數估算宇宙年齡</summary>

換算：1 yr ≈ 3.16×10⁷ s，1 Mpc = 3.08×10¹⁹ km。先把單位統一成 km 和 s，再算 d/v。

- 現代 H₀ ≈ 70 km/s/Mpc（Type Ia 超新星，~430 Mpc 處約 3×10⁴ km/s）：
  t = 3.08×10¹⁹ km ÷ 70 km/s = 4.4×10¹⁷ s ÷ 3.16×10⁷ s/yr ≈ **1.4×10¹⁰ yr（約 140 億年）**
- Hubble 1929 的原始值 ≈ 500 km/s/Mpc（2×10⁶ pc 處約 1000 km/s）→ t ≈ **2×10⁹ yr**，比地球年齡還小，所以原始值高估了。

</details>

**為什麼大霹靂只做到 He（加微量 ⁶Li、⁷Li）？**

1. **Deuterium bottleneck**：要做 He 得先做出 ²H，但 ²H 在高溫下不穩定，會分解回 p + n。
2. **質量數 5 和 8 沒有穩定核**：要跳過去需要三個粒子同時碰撞，但等溫度降下來，宇宙已經膨脹到密度太低。

所以 C、O、Fe 一定是之後在恆星裡做的。

<details>
<summary>核反應的基本寫法（寫反應式會用到）</summary>

- 粒子：質子（~1 amu, +1）、中子（~1 amu, 0）、電子（0.0005 amu, −1）、正子（0.0005 amu, +1）。1 amu = ¹²C 質量 / 12。
- 寫法：左上是質量數 A = p + n，左下是質子數 Z，例如 ⁴₂He。
- 反應前後**電荷守恆**、**核子數（p + n）守恆**。

</details>

## 2. 恆星：把 H 融合到 Fe ★

**B²FH（1957）理論**之所以被接受，是因為它以已知的核反應速率為定量基礎，而且同時解釋了兩件事：恆星在 HR 圖上的分群，以及元素豐度。

<img src="/img/notes/geochemistry/l1-nucleosynthesis/01.png" alt="元素是怎麼做出來的" width="748" height="281" />

上排是恆星內部的融合鏈：越往右，需要的溫度越高、恆星質量越大。下排是過了 Fe 之後的兩條中子捕獲路線（第 3 節）。

| 過程 | 反應 | 產物 | 場所 |
|---|---|---|---|
| H burning | 4 ¹H → ⁴He | He | 主序星 |
| He burning | 3 ⁴He → ¹²C（triple-alpha） | C | 紅巨星 |
| α process | ¹²C + ⁴He → ¹⁶O → ²⁰Ne → ²⁴Mg → ²⁸Si …；另有 C、Ne、O burning | 偶-偶核（A 為 4 的倍數） | 大質量星核心 |
| e process | ²⁸Si + ²⁸Si → ⁵⁶Fe + 2e⁺，高溫下核種互相轉換達到統計平衡 | Fe 附近（Fe peak） | 大質量星末期 |
| 奇數 Z 元素 | 融合時丟掉一個質子（¹²C + ¹²C → ²³Na + p）；spallation（散裂） | Na、Al、P | — |

注意 He burning 直接從 He 跳到 C，**跳過了 Li、Be、B**，所以這三個元素在宇宙中特別少（第 4 節豐度圖上的深谷）。

### 為什麼停在 Fe：結合能 ★

<img src="/img/notes/geochemistry/l1-nucleosynthesis/02.png" alt="結合能曲線：為什麼停在 Fe" width="733" height="385" />

每核子結合能越大，原子核越穩定。曲線最高點在 **⁵⁶Fe**：

- 比 Fe 輕的核**融合**時往曲線高處走 → 放出能量，恆星靠它發光。
- 再融合到比 Fe 重 → 往低處走，要**吸收**能量，恆星做不下去。
- He-4 特別穩定，所以突出一個尖峰。

結合能就是「核子分開放」和「組成原子核後」的質量差：

$$
\mathrm{BE} = N m_n + Z m_p + Z m_e - M_{\text{atom}}, \qquad \text{BE/nucleon} = \frac{\mathrm{BE}}{A}
$$

mₙ = 1.00866、mₚ = 1.00728、mₑ = 0.00055 amu；1 amu = 1.66054×10⁻²⁴ g ≈ 931.5 MeV

<details>
<summary>【例題 ★】³⁶S（20 n, 16 p, 16 e⁻, M = 35.96708 amu）的結合能</summary>

BE = 20(1.00866) + 16(1.00728) + 16(0.00055) − 35.96708 = 36.29848 − 35.96708 = **0.3314 amu**

BE/nucleon = 0.3314 / 36 = **0.00920 amu**（約 8.57 MeV）

</details>

## 3. 比 Fe 重的元素：中子捕獲 ★

融合做不出比 Fe 重的元素，那 Sr、Ba、Pb、U 從哪來？答案是**捕獲中子**：中子不帶電，不用克服電荷排斥就能進入原子核。吃了中子之後有三種結果：

- 還是穩定的 → 可以繼續吃中子；
- β⁻ 衰變（n → p + e⁻）→ 變成原子序 **Z+1** 的元素；
- β⁺ 衰變（p → n + e⁺）→ 變成原子序 **Z−1** 的元素。

依「吃中子」和「β 衰變」哪個比較快，分成兩條路：

| | s process（慢） | r process（快） |
|---|---|---|
| 速度 | β 衰變比下一次捕獲快 | 一下子吃很多中子，來不及衰變 |
| 核種表上的路徑 | 吃一個中子往右一格，不穩定就 β⁻ 往左上一格，**貼著穩定谷走** | 先衝進很富中子的區域，再沿等質量數（isobar）的對角線 β⁻ 衰變回來，停在第一個穩定 isobar |
| 產物 | 比 Fe 重的元素 | 比 Fe 重、富中子的核種（例如 ⁷⁰Zn、⁷⁶Ge） |
| 場所 | 紅巨星（AGB） | 超新星 |

另有 p process 產生稀少的富質子核種，投影片沒有細講。

**超新星（提供大量中子）**

- **Type Ia**：雙星系統中的白矮星吸積物質，到 1.4 M☉ 時塌縮。
- **Type II**：大質量星燒到 e process、核燃料用完後自身塌縮。

## 4. 結果：太陽系的元素豐度 ★

上面這些過程的特性，全都留在今天的元素豐度裡。

<img src="/img/notes/geochemistry/l1-nucleosynthesis/slide-p28.webp" alt="太陽系元素豐度（Si = 10⁶），可見 Li–Be–B 谷、Fe 峰與奇偶鋸齒" width="640" height="289" />

*圖：太陽系元素豐度，以 Si = 10⁶ 標準化（H ≈ 10¹⁰·⁵、He ≈ 10⁹·⁵）。來源：Abby Ren〈地球化學〉課程投影片 L1 p.28。*

**六個特徵**，每一個都對應到前面的某個過程：

| 特徵 | 原因 |
|---|---|
| 1. 所有穩定核種在自然界都存在 | — |
| 2. H、He 最多；Li、Be、B 有很深的谷（\< 10²） | 大霹靂只做 H、He；Li–Be–B 在恆星中被破壞，He burning 又跳過它們 |
| 3. 偶-偶核（even Z, even N）最豐富 | α process 一次加一個 ⁴He；配對比較穩定 |
| 4. Fe 附近有豐度峰 | e process，結合能最大 |
| 5. 比 Fe 重的元素豐度遞減（比輕元素少約 10⁶ 倍），且偶數原子序比奇數多（Oddo–Harkins 鋸齒） | 只能靠中子捕獲，產量少 |
| 6. Pb 附近有次峰 | 中子 magic number，s／r process 堆積 |

<strong>這些豐度怎麼量出來？</strong>兩個來源互相印證：

1. **天文光譜**：太陽光球的光譜是吸收譜（連續光譜上的暗線），從暗線位置知道有哪些元素。
2. **CI 碳質球粒隕石**：沒經過高溫分餾的星雲塵。

<img src="/img/notes/geochemistry/l1-nucleosynthesis/slide-p27.webp" alt="CI 球粒隕石與太陽光球的元素豐度幾乎落在 1:1 線上" width="640" height="576" />

*圖：CI 球粒隕石對太陽光球的豐度。來源：Abby Ren〈地球化學〉課程投影片 L1 p.27。*

兩者幾乎都落在 1:1 線上，所以 CI 隕石可以代表太陽系的平均組成。例外：

- **H、He、C、N、O、惰性氣體**在太陽中較多 → 揮發性高，沒凝結進隕石。
- **Li** 在太陽中較少 → 在恆星內部被燒掉。

## 5. 太陽系的形成：溫度決定行星 ★

### 時序

| 事件 | 年齡（Myr 前） |
|---|---|
| 氣體收縮成盤、加熱氣化，再冷卻凝結 | 4,567 |
| CAI（Ca-Al inclusions，最老的固體）、chondrules 形成 | 4,565–4,566 |
| 隕石母體在小行星帶形成 | 4,563 |
| 地球吸積 | 4,565–4,515 |
| 火星大小的天體撞地球，形成月球 | ~4,535 |
| 月球高地最老的岩石 | ~4,515 |

T-Tauri 太陽風把行星際空間的氣體吹走。內行星約 5,000 萬年內形成，外行星花得更久。

### 凝結序列：離太陽越遠越冷，凝結的東西越多

<img src="/img/notes/geochemistry/l1-nucleosynthesis/slide-p44.webp" alt="吸積時的溫度隨離太陽距離下降，決定各處凝結出的物質" width="640" height="516" />

*圖：吸積時的溫度隨離太陽的距離下降。來源：Abby Ren〈地球化學〉課程投影片 L1 p.44。*

| 凝結溫度 (K) | 凝結出什麼 | 形成哪些天體 |
|---|---|---|
| 1800–1500 | Ca、Al 氧化物 | 水星、金星、地球 |
| 1500–1000 | 金屬 Fe；Ca、Mg 矽酸鹽 | 水星、金星、地球 |
| 1000–500 | Mg、Fe 矽酸鹽 | 火星、小行星（多數隕石） |
| 500–200 | 磁鐵礦 Fe₃O₄、硫酸鹽、碳酸鹽、有機物 | 火星、小行星 |
| 200–20 | H₂O、NH₃、CH₄ 冰 | 巨行星 |
| \< 20 | Ne、H₂、He | 巨行星 |

地球軌道附近約 2000 K，只有金屬和矽酸鹽能凝結 → 內行星小、密度高（約 4–5.5 g/cm³）。木星以外冷到水冰、氨冰都能凝結 → 外行星大，重力大到能抓住氣體，密度低（約 0.7–1.8 g/cm³）。

### 行星的其他特徵

| 觀察 | 解釋 |
|---|---|
| 所有行星同方向公轉、都在黃道面上 | 反映原始盤的旋轉 |
| 自轉方向有正有逆（金星、天王星逆轉） | 撞擊效應的總和 |
| 行星間距大約 ×1.6 遞增 | 重力吸引範圍的掃掠 |
| 小行星帶沒有行星 | 木星重力干擾 |

> **易錯**：大霹靂只產生 H、He 和一點 Li，**C、O、Fe 都是恆星做的**。比 Fe 重的元素**不是靠融合**，而是靠中子捕獲（s／r process）。
