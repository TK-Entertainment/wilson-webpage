**本章重點**

1. 大霹靂只做出 **H、He**（和一點 Li），其他元素都是恆星做的。
2. 恆星融合做到 **Fe** 就停（Fe 結合能最大）；比 Fe 重的元素靠**中子捕獲**：s 慢（紅巨星）、r 快（超新星）。
3. 太陽星雲依**凝結溫度**分成內側岩石行星、外側氣體和冰的巨行星。

每核子結合能（MeV）對質量數作圖，曲線最高點在 ⁵⁶Fe。比 Fe 輕的元素融合時往高處走，會放出能量；比 Fe 重的元素分裂時也往高處走。He-4 特別穩定，所以突出一個尖峰。

## 地球化學的兩個問題

- **What is there?** 定量地球及可到達空間的組成
- **Why is it there?** 找出控制元素分布的定律

## 大霹靂（Big Bang）的證據

- **紅移與 Hubble plot**：距離越遠的星系後退速度越快 → 宇宙在膨脹。`v = H₀·d`
- **宇宙微波背景（CMB）**：宇宙約 38 萬歲時留下的最古老的光。
- **輕元素豐度**：He/H 在空間和時間上都很均勻，所以來自大霹靂；Fe/H 則不均勻，是恆星後來逐漸加工出來的。

$$
t \approx \frac{d}{v} = \frac{1}{H_0}
$$

換算：1 yr ≈ 3.16×10⁷ s，1 pc ≈ 3.08×10¹³ km（1 Mpc = 3.08×10¹⁹ km）

<details>
<summary>【例題】用 Hubble 常數估算宇宙年齡</summary>

現代 H₀ ≈ 70 km/s/Mpc：t = 3.08×10¹⁹ km ÷ 70 km/s = 4.4×10¹⁷ s ÷ 3.16×10⁷ s/yr ≈ **1.4×10¹⁰ yr（約 140 億年）**。

Hubble 1929 的原始值 ≈ 500 km/s/Mpc → t ≈ **2×10⁹ yr**，比地球年齡還小，這個矛盾說明原始值高估了。

做法：先把 v 換成 km/yr、d 換成 km，再算 d/v。

</details>

## 原始核合成（Primordial nucleosynthesis）

- 粒子：質子（~1 amu, +1）、中子（~1 amu, 0）、電子（0.0005 amu, −1）、正子（0.0005 amu, +1）。1 amu = ¹²C 質量 / 12
- 寫法：左上是質量數 A = p + n，左下是質子數 Z，例如 ⁴₂He。
- 核反應規則：**電荷守恆**（p + e⁺ − e⁻ 兩邊相等），**核子數守恆**（p + n 兩邊相等）。
- 大霹靂只產生 **H、He，以及微量 ⁶Li、⁷Li**，原因：
  1. **Deuterium bottleneck**：²H 在高溫下不穩定，會分解回 p + n
  2. **沒有穩定的質量數 5 和 8**，要跳過去需要三體反應，但那時物質密度已經太低

## 恆星核合成（B²FH, 1957）

B²FH 理論有說服力的三個原因：以已知核反應速率為定量基礎、能解釋恆星光度–表面溫度的分群（HR 圖）、能解釋元素豐度。

| 過程 | 內容 | 產物 | 場所 |
|---|---|---|---|
| H burning | 4 ¹H → ⁴He | He | 主序星 |
| He burning | 3 ⁴He → ¹²C（triple-alpha） | C | 紅巨星 |
| α process | ¹²C + ⁴He → ¹⁶O → ²⁰Ne → ²⁴Mg → ²⁸Si … → ⁵⁶Fe；另有 C、Ne、O burning | 偶-偶核（A 為 4 的倍數） | 大質量星核心 |
| e process | ²⁸Si + ²⁸Si → ⁵⁶Fe + 2e⁺；高溫下核種互相轉換，達到統計平衡 | Fe 附近（Fe peak） | 大質量星末期 |
| 奇數 Z 元素 | 融合時失去一個質子（¹²C + ¹²C → ²³Na + p）；spallation（散裂） | Na, Al, P | — |
| **s process** | 慢速捕獲中子；β 衰變比下一次捕獲更快，所以沿著穩定谷前進 | 比 Fe 重的元素 | 紅巨星（AGB） |
| **r process** | 快速捕獲中子，先形成富中子的不穩定核，再 β 衰變到第一個穩定 isobar | 比 Fe 重、富中子的核種 | 超新星 |
| p process | 複雜過程 | 富質子核種（稀少） | — |

- 中子捕獲後的三種結果：`ᵃ⁺¹X` 穩定 → 可以繼續吃中子；n → p + e⁻（β⁻）→ `ᵃ⁺¹(Z+1)Y`；p → n + e⁺ → `ᵃ⁺¹(Z−1)`。
- 超新星：**Type Ia**：約一個太陽質量的白矮星吸積物質，到 1.4 M☉ 時塌縮；**Type II**：大質量星燒完核燃料到 e-process 後自身塌縮。兩者都會釋放大量中子。

## 結合能（Binding energy）

$$
\mathrm{BE} = N m_n + Z m_p + Z m_e - M_{\text{atom}}, \qquad \text{BE/nucleon} = \frac{\mathrm{BE}}{A}
$$

mₙ = 1.00866、mₚ = 1.00728、mₑ = 0.00055 amu；1 amu = 1.66054×10⁻²⁴ g ≈ 931.5 MeV

<details>
<summary>【例題】³⁶S（20 n, 16 p, 16 e⁻, M = 35.96708 amu）</summary>

BE = 20(1.00866) + 16(1.00728) + 16(0.00055) − 35.96708 = 36.29848 − 35.96708 = **0.3314 amu**

BE/nucleon = 0.3314 / 36 = **0.00920 amu**（約 8.57 MeV）

</details>

- 曲線峰值在 **⁵⁶Fe**（每核子結合能最大，最穩定）。比 Fe 輕的元素融合（fusion）放出大量能量；比 Fe 重的元素分裂（fission）放出的能量較少。所以恆星燃燒到 Fe 就停了。

## 太陽系元素豐度的六個特徵（必考）

1. 所有穩定核種在自然界都存在
2. 偶-偶核（even Z, even N）最豐富（α process、配對穩定）
3. Fe 附近有豐度峰（e process，結合能最大）
4. 比 Fe 重的元素豐度遞減，重的難熔元素比輕元素少約 10⁶ 倍
5. 重核中偶數原子序的比奇數多（Oddo–Harkins 鋸齒）
6. Pb 附近有次峰（中子 magic number，s/r process 堆積）

- 怎麼知道宇宙的組成：**天文光譜**（發射譜、吸收譜，太陽光球的吸收線）+ **CI 碳質球粒隕石**（沒經過高溫分餾的星雲塵，組成和太陽光球最接近，揮發性元素除外）。

### 行星性質及其解釋

| 觀察 | 解釋 |
|---|---|
| 所有行星同方向公轉、都在黃道面上 | 反映原始盤的旋轉 |
| 自轉方向有正有逆（retrograde） | 撞擊效應的總和 |
| 行星間距大約 ×1.6 遞增 | 重力吸引範圍的掃掠 |
| 小行星帶沒有行星 | 木星重力干擾 |
| 內行星小、密度高；外行星大、密度低 | 離太陽越遠越冷，凝結的氣體越多；大行星重力也越大 |

#### 核種表：s 與 r process （p.37, p.38）

- 圖是 Z = 28–34（Ni 到 Se）的核種表，橫軸中子數、縱軸質子數。**s process** 吃一個中子就往右一格，遇到不穩定核就 β⁻ 衰變往左上一格（Z + 1），所以路徑貼著穩定核前進。**r process** 一下子往右走很遠，進入富中子區，之後沿著等質量數（isobar）的對角線 β⁻ 衰變回來，停在第一個穩定的 isobar（例如 ⁶⁸Zn、⁷⁰Zn、⁷⁴Ge、⁷⁶Ge）。
- 投影片中正子衰變寫成 `ᵃ⁺¹ᵦX → ᵃ⁺²ᵦ₋₁Z + e⁺`，質量數應該仍是 **a+1**（β⁺ 衰變不改變質量數），應該是筆誤。
