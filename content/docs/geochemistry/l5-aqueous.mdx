### 先認識的名詞

| 名詞 | 一句話 |
|---|---|
| master variable | 幾乎所有反應都和它有關、決定系統狀態的變數（pH、redox） |
| component／species | 用來「組出」所有物種的基本單位／溶液裡實際存在的分子或離子 |
| TOTH | component H⁺ 的總量（不是 H⁺ 離子的濃度） |
| 當量（equivalent） | 莫耳數 × 電荷 |
| 當量點 | 把某個純物質溶進水會到達的 pH |
| 鹼度（alkalinity） | 中和酸的能力 |
| 保守離子 | 濃度不受 pH、T、P 影響的離子（Na⁺、Cl⁻、Ca²⁺…） |
| 緩衝強度 β | 加多少酸或鹼才能讓 pH 變 1 |
| 錯合物、配位基 | 中心金屬離子和周圍的配位基（ligand）結合的物種 |
| 一致／不一致溶解 | 全部溶掉／溶掉一部分、留下新的固體 |

## 1. 水中的四類反應，pH 是主控變數

水裡發生的反應大致分成四類：

| 類型 | 例子 |
|---|---|
| 酸鹼 | H₂CO₃ = H⁺ + HCO₃⁻ |
| 溶解／沉澱 | KAlSi₃O₈ + H⁺ + 7H₂O = Al(OH)₃ + K⁺ + 3H₄SiO₄ |
| 錯合 | Hg²⁺ + H₂O = Hg(OH)⁺ + H⁺ |
| 吸附／脫附 | ≡S + Mn²⁺ = ≡S–Mn（Mn 吸附在黏土表面） |

仔細看，前三類的反應式裡都有 H⁺。所以 pH 一變，這些反應的方向全部跟著變：一杯水能溶多少 CaCO₃、金屬離子以什麼形式存在、Mn 是哪個價數，第一步都要先知道 pH。放大到地表尺度，岩石風化和沉積物沉澱也都由 pH 控制。因此 pH 被稱為水溶液系統的 **master variable**（L7 會講另一個：氧化還原）。

酸鹼採用 Brønsted 的定義：**酸是質子（H⁺）提供者，鹼是質子接受者**。強弱看它多想給或拿質子，用解離常數衡量：強酸幾乎完全解離（HCl，K ≈ 10³），弱酸只解離一點（H₂S，K = 10⁻⁷·¹）。能給也能拿的叫**兩性**（amphoteric），例如 HCO₃⁻ 和 Al(OH)₂⁺。

## 2. 解題工具：三個平衡式 + K ★

要算一杯水的 pH 和各物種濃度，其實就是解聯立方程式：每個物種是一個未知數，需要一樣多的方程式。方程式有四個來源。

**第一，Proton balance（TOTH）**。這是 Morel & Hering 的記帳方法，用來追蹤 H⁺ 跑到哪裡。先選 **component**（組成所有物種的基本單位）：H⁺ 和 H₂O 一定是 component，OH⁻ 不是，因為 OH⁻ = H₂O − H⁺。接著每個物種寫成 component 的組合：由 component **加上** H⁺ 形成的物種，對 TOTH 貢獻正值；由 component **扣掉** H⁺ 形成的物種，貢獻負值。純水只有 H⁺ 和 OH⁻，所以 TOTH = \[H⁺\] − \[OH⁻\]。

Component 的選法會改變 TOTH 的寫法。以 CO₂ 為碳的 component：H₂CO₃ = H₂O + CO₂（沒有加減 H⁺，貢獻 0）、HCO₃⁻ = H₂O + CO₂ − H⁺（−1）、CO₃²⁻ = H₂O + CO₂ − 2H⁺（−2）：

$$
\mathrm{TOTH} = [\mathrm{H^+}] - [\mathrm{HCO_3^-}] - 2[\mathrm{CO_3^{2-}}] - [\mathrm{OH^-}]
$$

如果改選 CO₃²⁻ 為 component，HCO₃⁻ = CO₃²⁻ + H⁺ 就變成貢獻 +1。選哪個都對，只要前後一致；通常選「那個 pH 下的主要物種」，算起來最簡單。

**第二，電荷平衡**：溶液是電中性的，陽離子的總當量 = 陰離子的總當量。這條**永遠成立**。

**第三，質量守恆**：酸鹼反應不會改變某個東西的總量，例如總碳 C<sub>T</sub> = \[H₂CO₃\] + \[HCO₃⁻\] + \[CO₃²⁻\]。但沉澱、氧化還原、吸附會改變物種的量，所以比較保險的做法是寫**元素**的總量（元素不會被氧化還原改變），而且要把含這個元素的物種全部列進來，例如有 PbS<sub>aq</sub> 時，ΣS = \[H₂S\] + \[HS⁻\] + \[S²⁻\] + \[PbS<sub>aq</sub>\] + …

**第四，每個反應的平衡常數 K**（L4）。

數一數未知數和方程式，一樣多就能解。實際的天然水物種很多，解起來很麻煩，關鍵的一步是**判斷哪些物種量太少、可以忽略**，下一節的例題就是這樣做。

<details>
<summary>【例題 ★ 完整解】把 Na₂CO₃ 溶進水（完全解離、封閉系統），寫出 TOTH、電荷平衡、碳守恆。還能寫什麼方程式？夠不夠解？</summary>

**第一步：選 component。** 配方裡放的是 Na₂CO₃，所以選 Na⁺、CO₃²⁻、H⁺、H₂O。

**第二步：TOTH。** 配方沒有加任何 H⁺，所以 TOTH = 0。相對於 CO₃²⁻，HCO₃⁻ 多一個 H⁺（+1）、H₂CO₃ 多兩個（+2）、OH⁻ 少一個（−1）：

$$
\mathrm{TOTH} = [\mathrm{H^+}] + [\mathrm{HCO_3^-}] + 2[\mathrm{H_2CO_3}] - [\mathrm{OH^-}] = 0
$$

**第三步：電荷平衡。** CO₃²⁻ 帶兩個電荷，乘 2：

$$
[\mathrm{Na^+}] + [\mathrm{H^+}] = [\mathrm{HCO_3^-}] + 2[\mathrm{CO_3^{2-}}] + [\mathrm{OH^-}]
$$

**第四步：質量守恆。** 每 1 mol Na₂CO₃ 給 2 mol Na⁺ 和 1 mol 碳：$C_T = [\mathrm{H_2CO_3}] + [\mathrm{HCO_3^-}] + [\mathrm{CO_3^{2-}}] = [\mathrm{Na^+}]/2$。

**第五步：還能寫什麼？** 三個平衡常數式 K₁、K₂、K<sub>w</sub>。未知數 6 個（H⁺、OH⁻、H₂CO₃、HCO₃⁻、CO₃²⁻、Na⁺），方程式也是 6 個（給定 Na₂CO₃ 的量時：TOTH 或電荷平衡擇一，因為兩者等價；碳守恆；Na 的量；三個 K），可以解。

</details>

<summary>【換你算】把純 CO₂ 溶進水，以 CO₂ 為 component 寫 TOTH。它和電荷平衡有什麼關係？</summary>

**答案**：TOTH = \[H⁺\] − \[HCO₃⁻\] − 2\[CO₃²⁻\] − \[OH⁻\] = 0，移項就是電荷平衡 \[H⁺\] = \[HCO₃⁻\] + 2\[CO₃²⁻\] + \[OH⁻\]。沒有其他離子時，兩條式子是同一件事。

## 3. 碳酸系統 ★

碳酸系統之所以最重要，是因為它會解離放出 H⁺、也會結合 H⁺，**控制了大部分天然水的 pH**。CO₂ 從大氣溶進水，形成碳酸，再分兩步解離：

$$
\begin{aligned}
\mathrm{CO_2(g) + H_2O \rightleftharpoons H_2CO_3} \quad & K_{\mathrm{CO_2}} = a_{\mathrm{H_2CO_3}}/P_{\mathrm{CO_2}} = 10^{-1.47} \\
\mathrm{H_2CO_3 \rightleftharpoons H^+ + HCO_3^-} \quad & K_1 = 10^{-6.35} \\
\mathrm{HCO_3^- \rightleftharpoons H^+ + CO_3^{2-}} \quad & K_2 = 10^{-10.33} \\
\mathrm{H_2O \rightleftharpoons H^+ + OH^-} \quad & K_w = 10^{-14}
\end{aligned}
$$

這些是 25 °C 的值（White 教科書）；考卷若有給數值，以考卷為準。

<details>
<summary>【例題 I ★ 完整解】與大氣平衡的純水，pH 是多少？（25 °C、理想行為、P<sub>CO₂</sub> = 3.7×10⁻⁴ atm）</summary>

**第一步：先求 H₂CO₃。** 和大氣平衡，P<sub>CO₂</sub> 固定：\[H₂CO₃\] = K<sub>CO₂</sub> · P<sub>CO₂</sub> = 10⁻¹·⁴⁷ × 10⁻³·⁴³ = 10⁻⁴·⁹⁰ M。

**第二步：電荷平衡，再簡化。** \[H⁺\] = \[HCO₃⁻\] + 2\[CO₃²⁻\] + \[OH⁻\]。預期是酸性（溶了 CO₂），酸性時 CO₃²⁻ 和 OH⁻ 都極少，可以忽略 → \[H⁺\] ≈ \[HCO₃⁻\]。

**第三步：代入 K₁。** K₁ = \[H⁺\]\[HCO₃⁻\]/\[H₂CO₃\] = \[H⁺\]²/\[H₂CO₃\]，所以 \[H⁺\]² = K₁\[H₂CO₃\] = 10⁻⁶·³⁵ × 10⁻⁴·⁹⁰ = 10⁻¹¹·²⁵。

**第四步：** \[H⁺\] = 10⁻⁵·⁶³，**pH ≈ 5.6**。

**檢查簡化**：pH 5.6 時 \[OH⁻\] = 10⁻⁸·⁴，遠小於 \[H⁺\]，忽略合理。所以就算沒有污染，雨水也是微酸的；「酸雨」定義為 pH \< 5.6，就是從這裡來。

</details>

<details>
<summary>【換你算】如果大氣 CO₂ 變成兩倍，雨水 pH 變多少？</summary>

**提示**：\[H⁺\]² ∝ \[H₂CO₃\] ∝ P<sub>CO₂</sub>。

**答案**：\[H⁺\] 變成 √2 倍，pH 下降 log√2 = 0.15，從 5.63 變成 **約 5.48**。

</details>

**封閉系統：各物種隨 pH 怎麼分配？** 如果水不和大氣交換，總碳 C<sub>T</sub> 固定，只問它在三個物種之間怎麼分。把 K₁、K₂ 代進碳守恆，每個物種占的比例（分率 α）只跟 \[H⁺\] 有關：

$$
\alpha_0 = \frac{[\mathrm{H^+}]^2}{D},\quad \alpha_1 = \frac{K_1[\mathrm{H^+}]}{D},\quad \alpha_2 = \frac{K_1K_2}{D},\qquad D = [\mathrm{H^+}]^2 + K_1[\mathrm{H^+}] + K_1K_2
$$

α₀、α₁、α₂ 分別是 H₂CO₃、HCO₃⁻、CO₃²⁻ 的比例。由 K₁ 的定義，$[\mathrm{HCO_3^-}]/[\mathrm{H_2CO_3}] = K_1/[\mathrm{H^+}]$，所以 **pH = pK₁ 時兩者剛好一樣多**；pH 每高 1，HCO₃⁻/H₂CO₃ 就大 10 倍。

## 4. 當量點：把純物質溶進水的 pH ★

**當量點**就是「把某一種純物質溶進水，系統會到的 pH」。碳酸系統有三個：

| 名稱 | 條件 | 等於什麼溶液 | pH（C<sub>T</sub> = 10 mM） |
|---|---|---|---|
| CO₂ 當量點 | \[H⁺\] = \[HCO₃⁻\] | 純 CO₂（H₂CO₃）溶液 | ≈ 4.2 |
| HCO₃⁻ 當量點 | \[H₂CO₃\] = \[CO₃²⁻\] | 純 NaHCO₃ 溶液 | ≈ 8.3 |
| CO₃²⁻ 當量點 | \[HCO₃⁻\] = \[OH⁻\] | 純 Na₂CO₃ 溶液 | ≈ 10–11 |

條件從電荷平衡（或 TOTH）來，以 CO₂ 當量點為例：純 CO₂ 溶液的電荷平衡是 \[H⁺\] = \[HCO₃⁻\] + 2\[CO₃²⁻\] + \[OH⁻\]，在酸性條件下後兩項很小，剩 \[H⁺\] = \[HCO₃⁻\]。代入 K₁，而 H₂CO₃ 幾乎就是全部碳：

$$
[\mathrm{H^+}]^2 = K_1 C_T \;\Rightarrow\; \mathrm{pH} = \tfrac12(\mathrm{p}K_1 - \log C_T) = \tfrac12(6.35 + 2) \approx 4.2
$$

HCO₃⁻ 當量點的 pH 與 C<sub>T</sub> 無關：\[H₂CO₃\] = \[CO₃²⁻\] 時，K₁K₂ = \[H⁺\]²\[CO₃²⁻\]/\[H₂CO₃\] = \[H⁺\]²，所以 **pH = (pK₁ + pK₂)/2 ≈ 8.3**。

在上面的互動圖裡，CO₂ 當量點就是 H⁺ 虛線碰到 HCO₃⁻ 線的黑點。下一節的鹼度就是用這個點定義的。

**答案**：(1) \[H⁺\] = \[HCO₃⁻\]；\[H₂CO₃\] = \[CO₃²⁻\]；\[HCO₃⁻\] = \[OH⁻\]。(2) K₁K₂ = \[H⁺\]²\[CO₃²⁻\]/\[H₂CO₃\]，兩者相等時 \[H⁺\]² = K₁K₂。(3) ½(6.35 + 3) ≈ 4.7。

## 5. 鹼度：一個不受 CO₂ 影響的量 ★

**鹼度**（alkalinity）是溶液**中和酸的能力**，也就是溶液裡能被強酸滴定的鹼，以當量計。它有三種等價的定義：

- **分析上**：把溶液滴定到 CO₂ 當量點需要加的酸量。
- **數學上**：以 CO₂ 當量點的主要物種（H₂O、H⁺、CO₂…）為 component 時的 **−TOTH**。把第 2 節以 CO₂ 為 component 的 TOTH 加個負號：

$$
\text{碳酸鹼度} = [\mathrm{HCO_3^-}] + 2[\mathrm{CO_3^{2-}}] + [\mathrm{OH^-}] - [\mathrm{H^+}]
$$

- **電荷平衡上**：Σ保守陽離子 − Σ保守陰離子。這是最有用的一個，下面推導。

**一個當量 = 莫耳數 × 電荷**。所以 1 當量的 CO₃²⁻ 是 0.5 mol，1 當量的 Cl⁻ 是 1 mol。

**把離子分成兩類**。**保守離子**在天然水的 pH 範圍內完全解離，濃度不受 pH、T、P 影響（沒有沉澱溶解時）：Na⁺、K⁺、Ca²⁺、Mg²⁺、Cl⁻、SO₄²⁻、NO₃⁻。**非保守離子**會在這個 pH 範圍內結合或解離 H⁺：H⁺、OH⁻、碳酸物種、B(OH)₄⁻、H₃SiO₄⁻、HS⁻、磷酸、有機酸根等，除了 H⁺ 和 NH₄⁺，幾乎都是陰離子。

**推導**：電荷平衡寫成兩類分開：

$$
\textstyle\sum \text{保守陽} - \sum \text{保守陰} + \sum \text{非保守陽} - \sum \text{非保守陰} = 0
$$

移項：

$$
\text{Alk} = \textstyle\sum \text{保守陽} - \sum \text{保守陰} = \sum \text{非保守陰} - \sum \text{非保守陽}
$$

右邊只有碳酸時，就是上面的碳酸鹼度。左邊只有保守離子，**不隨 pH 和 CO₂ 改變**，所以鹼度是保守的，即使組成它的個別物種一直在變。

**先預測**：往海水裡多溶一些 CO₂，pH、HCO₃⁻、CO₃²⁻、鹼度各會怎麼變？

<AlkalinityDemo />

保守陽離子比保守陰離子多出一塊「缺口」，必須由非保守陰離子補上，這個缺口就是鹼度。CO₂ 進出只改變缺口裡 HCO₃⁻ 和 CO₃²⁻ 的比例（和 pH），缺口大小不變。要改變鹼度，必須改變保守離子：CaCO₃ 沉澱帶走 Ca²⁺ 讓鹼度下降，矽酸鹽風化釋出 Ca²⁺、Na⁺ 讓鹼度上升（L6 的長期碳循環會用到）。

<details>
<summary>【例題 ★ 完整解】某河水（mM）：Ca²⁺ 0.50、Mg²⁺ 0.20、Na⁺ 0.30、K⁺ 0.05、Cl⁻ 0.25、SO₄²⁻ 0.15。鹼度是多少？</summary>

**第一步：都換成當量（乘電荷）。** 陽離子：Ca 1.00 + Mg 0.40 + Na 0.30 + K 0.05 = 1.75 meq/L。陰離子：Cl 0.25 + SO₄ 0.30 = 0.55 meq/L。

**第二步：相減。** Alk = 1.75 − 0.55 = **1.20 meq/L**。

**第三步：解讀。** 這條河 pH 約 7 到 8，碳酸物種主要是 HCO₃⁻，所以 \[HCO₃⁻\] ≈ 1.2 mM。不需要量 pH 或 CO₂ 就能算出鹼度，這就是保守量的好處。

</details>

<details>
<summary>【換你算】(a) 同一條河流進湖裡，吸收了一些 CO₂，鹼度變多少？(b) 湖裡沉澱了 0.10 mM 的 CaCO₃，鹼度變多少？</summary>

**提示**：只有保守離子的改變會影響鹼度；Ca²⁺ 是 2 價。

**答案**：(a) **不變，1.20 meq/L**（pH 下降，但缺口大小不變）。(b) Ca²⁺ 少了 0.10 mM = 0.20 meq/L，鹼度變成 **1.00 meq/L**。

</details>

**用滴定量鹼度：Na₂CO₃ 加 HCl 的例子**。假設理想行為、封閉系統（只有加進去的 H⁺ 和 Cl⁻ 會變）、不稀釋、完全解離。滴定前 TOTH = −\[Na⁺\]，所以 Alk = \[Na⁺\]；滴定中電荷平衡多了 \[Cl⁻\]：\[Na⁺\] + \[H⁺\] = \[Cl⁻\] + \[HCO₃⁻\] + 2\[CO₃²⁻\] + \[OH⁻\]；到達終點（CO₂ 當量點）時，碳幾乎都變成 H₂CO₃，右邊只剩 Cl⁻，所以 **\[Na⁺\] = \[Cl⁻\]**：加進去的酸剛好等於鹼度。

**Tableau 法**（Morel & Hering）：把 component 列在表格上方、物種列在左邊，每格填「這個物種含幾個這種 component」，TOTH 就是 H⁺ 那一欄的加總。在 CO₂ 當量點選 H₄SiO₄、B(OH)₃、H₂S、H₂PO₄⁻、CO₂ 為 component；不選 H₂CO₃，因為它含 H₂O，不獨立。

<summary>自我檢測 5</summary>

**答案**：(1) 滴定到 CO₂ 當量點所需的酸；CO₂ 當量點 component 下的 −TOTH；Σ保守陽 − Σ保守陰。(2) 電荷平衡分成保守、非保守兩類後移項。(3) CO₂ 只改變非保守物種之間的比例，保守離子不變；改變保守離子的過程（CaCO₃ 沉澱、風化）會改變鹼度。(4) 2 meq。

## 6. 緩衝強度：pH 有多難被改變

鹼度說的是「總共能中和多少酸」，**緩衝強度**說的是「此刻 pH 有多難推動」：

$$
\beta = \frac{dC_B}{d\,\mathrm{pH}} = -\frac{dC_A}{d\,\mathrm{pH}}
$$

C<sub>B</sub>、C<sub>A</sub> 是加入的強鹼、強酸（當量）。β 越大，加同樣的酸鹼，pH 變得越少。

<BufferFig />

直覺上，緩衝靠的是「一對酸和鹼同時存在」：加酸時有鹼接住 H⁺，加鹼時有酸補出 H⁺。兩者一樣多時（pH = pK）緩衝最好；只剩一種時（當量點）最差。這就是為什麼 pH 約 8 的海水，靠 HCO₃⁻/CO₃²⁻（加上硼酸）撐住 pH。

開放系統（和大氣交換、P<sub>CO₂</sub> 固定，投影片 p.28 的例子）的緩衝強度是 $\beta = 2.303([\mathrm{H^+}] + [\mathrm{OH^-}] + [\mathrm{HCO_3^-}] + 4[\mathrm{CO_3^{2-}}])$，pH 越高 β 越大，因為大氣會一直補 CO₂ 進來。

<details>
<summary>自我檢測 6</summary>

1. 鹼度和緩衝強度差在哪？
2. 封閉碳酸系統的 β 在哪裡最大、哪裡最小？為什麼？

**答案**：(1) 鹼度是能中和的酸的總量；緩衝強度是此刻 pH 對加酸鹼的敏感度。(2) pH = pK₁、pK₂ 最大（酸鹼兩種物種一樣多），當量點最小（幾乎只有一種物種）。

</details>

## 7. 錯合：金屬離子在水中的樣子

金屬離子在水裡很少是「裸」的，常常和周圍的分子或離子結合成**錯合物**（complex）：中心通常是金屬離子，周圍的叫**配位基**（ligand）。這種結合比真正的化學鍵弱，但強到足以形成可以辨認的物種。錯合很重要，因為它改變離子的溶解度和反應性：有時是沉澱的中間步驟，有時形成很穩定、可溶的錯合物，**大幅增加溶解度**。

最常見的配位基就是水本身。Fe³⁺ 在水中是 Fe(H₂O)₆³⁺，中心的正電荷排斥水分子上的 H，讓這些水比一般的水更容易放出 H⁺。所以水合金屬離子本身就是弱酸，會一步一步水解：

$$
\mathrm{Fe(H_2O)_6^{3+}} \rightleftharpoons \mathrm{Fe(H_2O)_5(OH)^{2+} + H^+} \rightleftharpoons \mathrm{Fe(H_2O)_4(OH)_2^{+} + 2H^+} \rightleftharpoons \cdots
$$

電荷越高、半徑越小，排斥越強，越容易水解；這就是下一節「離子勢」的伏筆。

<details>
<summary>【例題 ★ 完整解】Pb²⁺ + H₂O = PbOH⁺ + H⁺，K = 10⁻⁷·⁷，總 Pb = 10⁻⁸ M。求 pH 6 到 9 時 PbOH⁺ 占多少。</summary>

**第一步：寫分率。** α = \[PbOH⁺\]/(\[Pb²⁺\] + \[PbOH⁺\])。

**第二步：用 K 消去。** \[PbOH⁺\] = K\[Pb²⁺\]/\[H⁺\]，代入後 \[Pb²⁺\] 約掉：α = K/(K + \[H⁺\])。總 Pb 濃度不影響分率。

**第三步：代 pH。**

| pH | 6 | 7 | 7.7 | 8 | 9 |
|---|---|---|---|---|---|
| α | 0.02 | 0.17 | 0.50 | 0.67 | 0.95 |

**規律**：pH = pK（7.7）時剛好各占一半，和碳酸系統的交叉點是同一個道理。pH 越高，越多 Pb 被水解。

</details>

**穩定常數**：錯合物一步一步形成，每一步有自己的 K（逐步常數），從頭到某一步的總常數叫 β（累積常數），等於各步 K 相乘：

$$
\begin{aligned}
\mathrm{Zn^{2+} + OH^- \rightleftharpoons ZnOH^+} \quad & \beta_1 = K_1 \\
\mathrm{ZnOH^+ + OH^- \rightleftharpoons Zn(OH)_2} \quad & K_2 \\
\mathrm{Zn^{2+} + 2OH^- \rightleftharpoons Zn(OH)_2} \quad & \beta_2 = K_1K_2
\end{aligned}
$$

<details>
<summary>自我檢測 7</summary>

1. 為什麼 Fe(H₂O)₆³⁺ 是弱酸？
2. 錯合一定會讓金屬沉澱嗎？
3. β₃ 和 K₁、K₂、K₃ 的關係？

**答案**：(1) 中心 Fe³⁺ 的正電荷排斥水分子的 H，容易放出 H⁺。(2) 不一定，穩定的可溶錯合物反而會增加溶解度。(3) β₃ = K₁K₂K₃。

</details>

## 8. 溶解與沉澱 ★

**哪些元素容易溶？看離子勢**。上一節說中心離子的電荷越高、半徑越小，越會影響周圍的水。把這兩個量合成**離子勢 Z/r**，就能預測元素在水中的命運：

<IonicPotentialFig />

推理是這樣的。**離子勢低**的離子（K⁺、Na⁺、Ca²⁺）對水的影響小，只是被水分子圍著，以水合陽離子溶在水中，所以易溶。**離子勢中等**的（Fe³⁺、Al³⁺、Ti⁴⁺、Zr⁴⁺）會把水分子的 H⁺ 擠掉，形成氫氧化物，而氫氧化物是電中性的固體，所以最難溶。**離子勢高**的（C⁴⁺、N⁵⁺、S⁶⁺、P⁵⁺）更進一步，和 O 形成共價鍵，氧給出的電子比原本的正電荷還多，變成含氧陰離子（CO₃²⁻、NO₃⁻、SO₄²⁻、PO₄³⁻），又變得易溶。

| 離子勢 | 例子 | 在水中 | 溶解度 |
|---|---|---|---|
| **低**（≲ 3） | Cs⁺、K⁺、Na⁺、Ca²⁺、Mg²⁺、Fe²⁺ | 水合陽離子 | **易溶** |
| **中**（≈ 3–9） | Fe³⁺ 4.7、Zr⁴⁺ 5.1、Al³⁺ 5.9、Ti⁴⁺ 5.9 | 水解成氫氧化物 | **最難溶** |
| **高**（≳ 9） | Si⁴⁺ 9.5、B³⁺ 13、P⁵⁺ 14、S⁶⁺ 20、C⁴⁺ 25、N⁵⁺ 38 | 和 O 共價鍵結成含氧陰離子 | **易溶** |

週期表上，左邊是低離子勢、右上是高離子勢，所以**純水中週期表兩側的元素易溶、中間的難溶**。海水組成在週期表上就呈現 U 形：

<SeawaterTableFig />

中間的元素在純水裡溶解度低，但在成分複雜的天然水裡，可以靠錯合（第 7 節）提高溶解度，例如 U⁶⁺ 和碳酸形成錯合物。

**溶解度怎麼算：先寫反應，再用 x 表示每個離子**。溶解度的定義是「每單位體積能溶掉多少 mol 的固體」，所以用「1 mol 固體產生 1 mol」的那個溶質來定義 x 最方便：

$$
\begin{aligned}
\mathrm{NaCl}:&\quad x = [\mathrm{Na^+}] = [\mathrm{Cl^-}], \quad K_{sp} = x^2 \;\Rightarrow\; x = \sqrt{K_{sp}} \\
\mathrm{CaF_2}:&\quad x = [\mathrm{Ca^{2+}}], \quad [\mathrm{F^-}] = 2x, \quad K_{sp} = x(2x)^2 = 4x^3 \;\Rightarrow\; x = (K_{sp}/4)^{1/3}
\end{aligned}
$$

<details>
<summary>【例題 ★ 完整解】純水中螢石的溶解度（K<sub>sp</sub> = 3.9×10⁻¹¹）</summary>

**第一步：寫反應並定義 x。** CaF₂ ⇌ Ca²⁺ + 2F⁻，1 mol 螢石給 1 mol Ca²⁺，所以 x = \[Ca²⁺\]，\[F⁻\] = 2x。

**第二步：代入 K<sub>sp</sub>。** K<sub>sp</sub> = x(2x)² = 4x³。

**第三步：解。** x = (3.9×10⁻¹¹/4)<sup>1/3</sup> = (9.75×10⁻¹²)<sup>1/3</sup> ≈ **2.1×10⁻⁴ M**。

**比較 L4 的例題**：那裡 \[F⁻\] 固定在 0.1 mM，\[Ca²⁺\] 可以到 3.9 mM；這裡 F⁻ 全部來自螢石本身（4.2×10⁻⁴ M），Ca²⁺ 反而只有 0.21 mM。F⁻ 越多，Ca 溶得越少（共同離子效應）。

</details>

<details>
<summary>【換你算】頑輝石 MgSiO₃ + 3H₂O ⇌ Mg²⁺ + H₄SiO₄ + 2OH⁻，若 K = 4×10⁻¹⁶，溶解度是多少？</summary>

**提示**：x = \[Mg²⁺\] = \[H₄SiO₄\]，\[OH⁻\] = 2x，K = 4x⁴。

**答案**：x⁴ = 10⁻¹⁶，x = **10⁻⁴ M**。（K 是為了好算而假設的值。）

</details>

**三類溶解**

| 類型 | 例子 | 溶解度 |
|---|---|---|
| 共價固體直接溶解 | 葡萄糖：C₆H₁₂O₆(s) ⇌ C₆H₁₂O₆(aq) | x = K |
| 一致溶解（congruent，全部溶掉） | NaCl、CaF₂；頑輝石 MgSiO₃ | 用 1:1 的溶質定義 x |
| 不一致溶解（incongruent，留下新固體） | K-長石 → 高嶺石：2KAlSi₃O₈ + 2H⁺ + 9H₂O ⇌ Al₂Si₂O₅(OH)₄ + 2K⁺ + 4H₄SiO₄ | 用能對應回原礦物的溶質：x = \[K⁺\]（= ½\[H₄SiO₄\]） |

**TDS**（total dissolved solids）是每公升溶液中所有溶質的乾重，包含離子和共價溶質。海水平均密度 1.034 kg/L，可以看成約 1 kg 水加上 34 g 溶質。TDS 影響密度、溶解度和用途（TDS 高的水會在管線裡沉澱結垢），它反映的是降水與蒸發、風化（溶解沉澱、淋溶、離子交換）、溫度、pH、氣體溶解度和生物作用。

<details>
<summary>自我檢測 8</summary>

1. 用離子勢解釋為什麼 Al、Fe³⁺ 留在土壤，而 Na、Cl 進入海洋。
2. 為什麼 S⁶⁺ 電荷那麼高卻易溶？
3. CaF₂ 的 K<sub>sp</sub> 為什麼是 4x³？
4. 一致和不一致溶解差在哪？

**答案**：(1) Al³⁺、Fe³⁺ 離子勢中等，水解成難溶的氫氧化物留在原地；Na⁺ 離子勢低（水合陽離子），Cl⁻ 是陰離子，都易溶，被河流帶到海洋。(2) 離子勢很高，和 O 共價鍵結成 SO₄²⁻ 陰離子，易溶。(3) \[F⁻\] = 2x，x·(2x)² = 4x³。(4) 一致溶解全部溶掉；不一致溶解留下新的固體（例如長石留下高嶺石）。

</details>

## 9. 礦物穩定圖：風化會變成什麼 ★

K-長石在地表風化成高嶺石，是一個不一致溶解。這個反應會不會發生，要看水的組成。把它的 K 寫出來（固體和水的活度 = 1）：

$$
\begin{aligned}
& \mathrm{2KAlSi_3O_8 + 2H^+ + 9H_2O = Al_2Si_2O_5(OH)_4 + 2K^+ + 4H_4SiO_4} \\
& K = \frac{a_{\mathrm{K^+}}^2\,a_{\mathrm{H_4SiO_4}}^4}{a_{\mathrm{H^+}}^2} \;\Rightarrow\; \log K = 2\log\frac{a_{\mathrm{K^+}}}{a_{\mathrm{H^+}}} + 4\log a_{\mathrm{H_4SiO_4}}
\end{aligned}
$$

整理成直線的形式：

$$
\underbrace{\log\frac{a_{\mathrm{K^+}}}{a_{\mathrm{H^+}}}}_{y} = -2\,\underbrace{\log a_{\mathrm{H_4SiO_4}}}_{x} + \underbrace{\tfrac12\log K}_{b}
$$

在 y 對 x 的圖上，這是一條斜率 −2 的直線，線上兩種礦物平衡。**線的上方**（K⁺ 多、H⁺ 少、矽多）表示產物太多、Q \> K，反應往左，**K-長石穩定**；**線的下方**反應往右，長石風化成**高嶺石**。x 也有上限：非晶質矽的溶解 SiO₂(am) + 2H₂O ⇌ H₄SiO₄，K = 10⁻²·⁷⁴（25 °C），所以 log\[H₄SiO₄\] 超過 −2.74 時矽會沉澱。

**先預測**：多雨的熱帶（雨水把 K⁺ 和矽帶走、pH 偏低），點會往哪個方向移動？

<MineralStabilityDemo />

降低 pH、帶走 K⁺ 和矽，都讓點往下、往左移，進入高嶺石區，所以強烈風化的地區土壤富含高嶺石（再更強會變成 gibbsite，鋁的氫氧化物，對應第 8 節 Al 的低溶解度）。

<details>
<summary>【例題 ★ 完整解】地下水 pH 6、\[K⁺\] = 10⁻⁴ M、log\[H₄SiO₄\] = −4，若 ½ log K = −2，哪個礦物穩定？</summary>

**第一步：算實際的 y。** y = log(\[K⁺\]/\[H⁺\]) = log\[K⁺\] + pH = −4 + 6 = 2。

**第二步：算直線在這個 x 的高度。** y<sub>線</sub> = −2(−4) + (−2) = 6。

**第三步：比較。** 2 \< 6，落在直線**下方 → 高嶺石穩定**，K-長石會被風化成高嶺石。

</details>

<details>
<summary>【換你算】同一個地下水，pH 要升到多少，K-長石才會穩定？</summary>

**提示**：要 y \> 6，而 y = −4 + pH。

**答案**：pH \> **10**。天然地下水幾乎達不到，所以在這種 K⁺ 和矽濃度下，長石一定會風化。

</details>

<details>
<summary>自我檢測 9</summary>

2. 線的上方、下方各是什麼礦物穩定？為什麼？
3. 為什麼 x 軸有上限？

**答案**：(1) log K = 2 log(a<sub>K</sub>/a<sub>H</sub>) + 4 log a<sub>Si</sub>，移項除以 2。(2) 上方 K-長石（產物太多，Q \> K，往左），下方高嶺石。(3) log\[H₄SiO₄\] \> −2.74 時非晶質矽會沉澱。

</details>

## 容易混淆的地方

| 容易搞混 | 正確理解 |
|---|---|
| TOTH 就是 \[H⁺\]？ | TOTH 是 component H⁺ 的**總量**，包含所有含 H⁺ 的物種，扣掉少 H⁺ 的物種 |
| 加 CO₂ 會降低鹼度？ | **不會**；pH 下降，但鹼度不變。改變保守離子（CaCO₃ 沉澱）才會 |
| 鹼度大 = 緩衝強度大？ | 不一樣：鹼度是總量，β 是此刻 pH 的敏感度；β 在 pH = pK 最大 |
| 當量 = 莫耳？ | 當量 = 莫耳 × 電荷；1 mmol CO₃²⁻ = 2 meq |
| 電荷越高越難溶？ | 不是單調的：離子勢中等最難溶，高的反而形成含氧陰離子易溶 |
| K<sub>sp</sub> = x² 通用？ | 只適用 1:1 的鹽；CaF₂ 是 4x³ |
| 線的上方是高嶺石？ | 上方（K⁺/H⁺ 高）是 **K-長石**；往下（酸、淋溶）才是高嶺石 |

## 章末綜合題

<details>
<summary>1.（觀念）用「碳酸系統 → 當量點 → 鹼度 → 緩衝」這條鏈，解釋為什麼海水 pH 長期維持在約 8.2，即使大氣 CO₂ 會變。</summary>

海水中碳主要以 HCO₃⁻ 存在（pH 介於 pK₁ 和 pK₂ 之間）。鹼度由保守離子決定（Σ保守陽 − Σ保守陰），CO₂ 進出不改變它；CO₂ 增加時只是把 CO₃²⁻ 轉成 HCO₃⁻，pH 只降一點。而且 HCO₃⁻ 和 CO₃²⁻ 同時存在，有緩衝能力。長期來說，pH 由鹼度控制，而鹼度要靠風化（加 Ca²⁺、Na⁺）和 CaCO₃ 沉澱（帶走 Ca²⁺）來改變，這些過程很慢，所以 pH 很穩定。

</details>

<details>
<summary>2.（計算）C<sub>T</sub> = 2 mM 的封閉系統，pH = 7.35。HCO₃⁻ 和 H₂CO₃ 各是多少？</summary>

pH − pK₁ = 1，所以 \[HCO₃⁻\]/\[H₂CO₃\] = 10。CO₃²⁻ 可忽略（pH 比 pK₂ 低 3）。H₂CO₃ = 2/11 = **0.18 mM**，HCO₃⁻ = 20/11 = **1.82 mM**。

</details>

<details>
<summary>3.（計算）某湖水 Ca²⁺ 1.0、Na⁺ 0.5、Cl⁻ 0.4、SO₄²⁻ 0.3（mM）。(a) 鹼度？(b) 假設碳酸物種都是 HCO₃⁻，\[HCO₃⁻\] 多少？(c) 酸雨加入 0.1 mM 的 H₂SO₄（全部解離），鹼度變多少？</summary>

(a) 陽 2.0 + 0.5 = 2.5 meq/L；陰 0.4 + 0.6 = 1.0 meq/L；Alk = **1.5 meq/L**。(b) **1.5 mM**。(c) SO₄²⁻ 是保守陰離子，多了 0.2 meq/L，Alk = **1.3 meq/L**（加進來的 H⁺ 被 HCO₃⁻ 中和掉，鹼度因此減少）。

</details>

<details>
<summary>4.（應用）用離子勢解釋：為什麼紅土（強烈風化的土壤）富含 Fe、Al，而海水富含 Na、Cl、SO₄²⁻？</summary>

風化時，離子勢低的 Na⁺、K⁺、Ca²⁺ 以水合陽離子溶走，離子勢高的 S、C 形成含氧陰離子溶走，Cl⁻ 本身就是易溶陰離子，它們都被河流帶進海洋。離子勢中等的 Fe³⁺、Al³⁺ 水解成難溶的氫氧化物，留在原地，越風化越富集，形成紅土（礦物穩定圖上也是往高嶺石、gibbsite 方向走）。

</details>

**水的特殊性質（p.2）**：除了氨以外，固體和液體中熱容最高；汽化潛熱最高；液體中表面張力最高；密度最大值在 4 °C；冰比水輕；是已知溶解力最強的溶劑。

**TDS 分類（p.40）**

| 水的類型 | TDS (mg/L) | 例子 |
|---|---|---|
| Fresh | \< 1,000 | 雨水、河水、大部分湖泊 |
| Brackish | 1,000–10,000 | 河口、潟湖、近岸含水層 |
| Saline | 10,000–100,000 | 海洋（~35,000）、部分地熱水 |
| Brine | \> 100,000 | 淺潮間盆地、地熱水 |

**元素分類（p.36）**：A-metals（鹼金屬、鹼土、REE 等）、transition metals、B metals（Cu、Zn、Ag、Cd、Hg、Pb 等）、ligand formers（B、C、N、O、F、P、S、Cl、As、Se、Br、I 等）。

**完整離子勢表（White Table 6.3）**

- 低：Cs⁺ 0.60、Rb⁺ 0.68、K⁺ 0.75、Na⁺ 1.0、Li⁺ 1.5、Ba²⁺ 1.5、Sr²⁺ 1.8、Ca²⁺ 2.0、Mn²⁺ 2.5、La³⁺ 2.6、Fe²⁺ 2.7、Co²⁺ 2.8、Mg²⁺ 3.0
- 中：Y³⁺ 3.3、Lu³⁺ 3.5、Sc³⁺ 3.7、Th⁴⁺ 3.9、Ce⁴⁺ 4.3、Fe³⁺ 4.7、Zr⁴⁺ 5.1、Be²⁺ 5.7、Al³⁺ 5.9、Ti⁴⁺ 5.9、Mn⁴⁺ 6.7、Nb⁵⁺ 7.5
- 高：Si⁴⁺ 9.5、Mo⁶⁺ 9.7、B³⁺ 13、P⁵⁺ 14、S⁶⁺ 20、C⁴⁺ 25、N⁵⁺ 38

**溶解度、飽和、濃度（p.41）**：solubility 是平衡時能溶解的量；saturation 是溶液能容納的最大溶質濃度。濃度單位有 molarity（mol/L）、molality（mol/kg）、ppm（mg/kg = μg/g）。
