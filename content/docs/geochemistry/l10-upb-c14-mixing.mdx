**這講在回答**：L8 給了定年方程式 D = D₀ + N(e^(λt) − 1)，這講把它用到三個最常用的系統上，並且每個系統都碰到一個「理想假設不成立」的問題：U-Pb 的岩石常常丟過 Pb，¹⁴C 的初始值會隨時間變，Rb-Sr 的資料可能根本是兩種東西混出來的。這講的每一節都在處理「假設壞掉時怎麼辦」，最後的二成分混合則是一套通用的數學，任何「兩種來源混在一起」的問題（岩漿、河水、湖水、汙染）都能用。

River 老師重視推導，這講每條公式都從衰變定律或質量守恆一步一步推出來，**近似是在哪一步做的、為什麼可以做**都寫清楚。推導的段落請自己拿紙跟著推一次。

**考前 30 秒**

1. **U-Pb**：²⁰⁴Pb 不是衰變來的，數量固定，當分母。$\dfrac{^{206}\mathrm{Pb}}{^{204}\mathrm{Pb}} = \left(\dfrac{^{206}\mathrm{Pb}}{^{204}\mathrm{Pb}}\right)_0 + \dfrac{^{238}\mathrm{U}}{^{204}\mathrm{Pb}}(e^{\lambda_{238}t}-1)$，²⁰⁷Pb／²³⁵U 同理。
2. **Pb-Pb**：兩式扣掉初始值再相除，U 含量消掉，只剩 ²³⁵U/²³⁸U = 1/137.818 和 t。鋯石幾乎沒有初始 Pb，直接用 ²⁰⁷Pb\*/²⁰⁶Pb\* 求年齡。
3. **鋯石**：U⁴⁺ 替代 Zr⁴⁺，Pb²⁺ 進不去 → 初始 Pb ≈ 0 → $t = \frac{1}{\lambda_{238}}\ln\left(1 + \frac{^{206}\mathrm{Pb}^*}{^{238}\mathrm{U}}\right)$。
4. **¹⁴C**：$F = \dfrac{(^{14}\mathrm{C}/^{12}\mathrm{C})_{\text{樣品}}}{(^{14}\mathrm{C}/^{12}\mathrm{C})_{\text{標準,1950}}} = e^{-\lambda t}$ → **年齡（BP）= −8033 ln F**（慣例用 Libby 半衰期 5568 年）。¹⁴C 年不等於日曆年，要用校正曲線；海洋樣品還要扣海洋庫效應（Marine20 ＋ ΔR）。
5. **Rb-Sr**：$\dfrac{^{87}\mathrm{Sr}}{^{86}\mathrm{Sr}} = \left(\dfrac{^{87}\mathrm{Sr}}{^{86}\mathrm{Sr}}\right)_0 + \dfrac{^{87}\mathrm{Rb}}{^{86}\mathrm{Sr}}(e^{\lambda t}-1)$；λt ≪ 1 時斜率 ≈ λt，高估約 λt/2。
6. **二成分混合**：$X_M = fX_A + (1-f)X_B$（直線）；同位素比值是用**濃度加權**的平均 → $\left(\dfrac{^{87}\mathrm{Sr}}{^{86}\mathrm{Sr}}\right)_M = \dfrac{a}{\mathrm{Sr}_M} + b$（雙曲線），對 1/Sr 作圖變直線。**兩個比值共用分母 → 直線；分母不同 → 雙曲線。**

### 先認識的名詞

| 名詞 | 一句話 |
|---|---|
| 放射成因（radiogenic） | 由衰變產生的，例如 ²⁰⁶Pb\*、⁸⁷Sr\*；星號表示「衰變長出來的那部分」 |
| 非放射成因 | 不是衰變來的穩定同位素（²⁰⁴Pb、⁸⁶Sr、¹²C），數量不隨時間變，拿來當分母 |
| 諧和（concordant） | ²⁰⁶Pb/²³⁸U 和 ²⁰⁷Pb/²³⁵U 兩個時鐘給出一樣的年齡 |
| 碎屑鋯石 | 從老岩石侵蝕下來、搬到沉積物裡的鋯石，記錄來源區的年齡 |
| BP | Before Present，「現在」固定是西元 **1950** 年 |
| F（fraction modern） | 樣品的 ¹⁴C/¹²C 除以 1950 年標準的值；現代 = 1 |
| 校正曲線 | ¹⁴C 年齡對日曆年的對照表（樹輪、珊瑚、石筍定出來的） |
| 海洋庫年齡 R | 海洋生物的 ¹⁴C 年齡比同時的陸地生物老的部分，全球平均約 400 年 |
| ΔR | 某地的海洋庫年齡和全球模式（Marine20）的差 |
| 端元（end member） | 混合的兩個來源 A、B |
| f | 混合物中 A 的**重量**（或體積）比例 = A/(A+B) |

## 1. U-Th-Pb：三個時鐘、一個參考 ★

投影片 p.2 列出三個衰變：

| 衰變 | 半衰期 | 衰變常數 |
|---|---|---|
| ²³⁸U → ²⁰⁶Pb | 4.468 Ga | λ₂₃₈ = 1.551×10⁻¹⁰ yr⁻¹ |
| ²³⁵U → ²⁰⁷Pb | 0.704 Ga | λ₂₃₅ = 9.846×10⁻¹⁰ yr⁻¹ |
| ²³²Th → ²⁰⁸Pb | 14.01 Ga | λ₂₃₂ = 4.948×10⁻¹¹ yr⁻¹ |

（λ = ln 2 / t₁/₂，自己按一次計算機確認。）中間經過的衰變鏈（L9）在幾百萬年內就達到長期平衡，所以在十億年的尺度上可以把它看成一步：母核 → 最後的 Pb。

**推導：為什麼分母是 ²⁰⁴Pb**

從 L8 的出發點開始。母核衰變 $N = N_0 e^{-\lambda t}$，衰變掉的數量就是長出來的子核：

$$
D^* = N_0 - N = Ne^{\lambda t} - N = N(e^{\lambda t}-1)
$$

注意這裡把 N₀ 換成 **現在量得到的 N** 乘 e^(λt)，因為 N₀ 量不到。加上一開始就有的子核 D₀：

$$
^{206}\mathrm{Pb} = {}^{206}\mathrm{Pb}_0 + {}^{238}\mathrm{U}\,(e^{\lambda_{238}t}-1)
$$

質譜儀量**比值**比量絕對數量準得多，所以要除以一個同位素。選 ²⁰⁴Pb 的理由：它**不是任何衰變的產物**，從岩石形成到現在數量不變。除以一個不隨時間變的數，不會在方程式裡多加一個時間項：

$$
\frac{^{206}\mathrm{Pb}}{^{204}\mathrm{Pb}} = \left(\frac{^{206}\mathrm{Pb}}{^{204}\mathrm{Pb}}\right)_0 + \frac{^{238}\mathrm{U}}{^{204}\mathrm{Pb}}\left(e^{\lambda_{238}t}-1\right)
\qquad
\frac{^{207}\mathrm{Pb}}{^{204}\mathrm{Pb}} = \left(\frac{^{207}\mathrm{Pb}}{^{204}\mathrm{Pb}}\right)_0 + \frac{^{235}\mathrm{U}}{^{204}\mathrm{Pb}}\left(e^{\lambda_{235}t}-1\right)
$$

²⁰⁸Pb/²⁰⁴Pb 對 ²³²Th/²⁰⁴Pb 同理。三條方程式都是 y = b + mx 的等時線形式（L8 §4）。

**U-Pb 系統的特別之處**：同一個元素（U）有兩個母核，長出同一個元素（Pb）的兩個子核。兩個時鐘的化學行為完全一樣，但走的速度不同，這讓我們可以**互相檢查**，也可以**相除把未知數消掉**（下一節）。

<summary>自我檢測 1</summary>

1. 為什麼定年方程式裡用「現在的 N」而不是 N₀？寫出 D\* = N(e^(λt) − 1) 的推導。
2. 為什麼 U-Pb 系統選 ²⁰⁴Pb 當分母，不選 ²⁰⁶Pb？

**答案**：(1) N₀ 量不到，只能量現在的 N。由 N = N₀e^(−λt) 得 N₀ = Ne^(λt)，長出來的子核 = N₀ − N = N(e^(λt) − 1)。(2) ²⁰⁴Pb 不是衰變產物，數量固定；²⁰⁶Pb 會一直長，當分母會讓式子多一個時間項。(3) 兩個時鐘化學行為相同、速度不同，可以互相檢查是否封閉（諧和），也可以相除消掉 U 的含量。

## 2. Pb-Pb 法與 ²⁰⁷Pb/²⁰⁶Pb 年齡 ★

**問題**：岩石形成後如果丟了 U 或 Pb（開放系統），上面任一條方程式的 U/²⁰⁴Pb 就不是原本的值，年齡會錯。能不能把 U 的含量從方程式裡拿掉？

**推導**（投影片 p.4）

第 1 步，兩條方程式都把初始值移到左邊：

$$
\left(\frac{^{206}\mathrm{Pb}}{^{204}\mathrm{Pb}}\right)_t - \left(\frac{^{206}\mathrm{Pb}}{^{204}\mathrm{Pb}}\right)_0 = \frac{^{238}\mathrm{U}}{^{204}\mathrm{Pb}}\left(e^{\lambda_{238}t}-1\right)
\qquad
\left(\frac{^{207}\mathrm{Pb}}{^{204}\mathrm{Pb}}\right)_t - \left(\frac{^{207}\mathrm{Pb}}{^{204}\mathrm{Pb}}\right)_0 = \frac{^{235}\mathrm{U}}{^{204}\mathrm{Pb}}\left(e^{\lambda_{235}t}-1\right)
$$

第 2 步，第二式除以第一式。右邊的 ²⁰⁴Pb 約掉，剩下 ²³⁵U/²³⁸U：

$$
\frac{\left(\frac{^{207}\mathrm{Pb}}{^{204}\mathrm{Pb}}\right)_t - \left(\frac{^{207}\mathrm{Pb}}{^{204}\mathrm{Pb}}\right)_0}{\left(\frac{^{206}\mathrm{Pb}}{^{204}\mathrm{Pb}}\right)_t - \left(\frac{^{206}\mathrm{Pb}}{^{204}\mathrm{Pb}}\right)_0}
= \frac{^{235}\mathrm{U}}{^{238}\mathrm{U}}\cdot\frac{e^{\lambda_{235}t}-1}{e^{\lambda_{238}t}-1}
$$

第 3 步，²³⁵U/²³⁸U 不用量。兩個是同一個元素，化學反應分不開它們，所以**現在**地球上所有樣品的比值都一樣（第 4 節會看到其實有極小的差異）。投影片用 Hiess et al. (2012) 量到的值：

$$
\frac{^{235}\mathrm{U}}{^{238}\mathrm{U}} = \frac{1}{137.818}
$$

右邊只剩 t。**U 的含量完全消失了**，這就是 Pb-Pb 法能減少開放系統影響的原因：

- 最近丟了 U（或得到 U）：不影響已經長出來的 Pb 的同位素比值。
- 丟了 Pb：²⁰⁶Pb 和 ²⁰⁷Pb 是同一個元素，按同樣比例丟，比值不變。

**怎麼用**：同時形成、初始 Pb 相同、但 U/Pb 不同的一組樣品，在 ²⁰⁷Pb/²⁰⁴Pb 對 ²⁰⁶Pb/²⁰⁴Pb 圖上排成直線（**Pb-Pb 等時線**），斜率就是左邊那個比值，只跟 t 有關，直線通過初始比值那一點。

**只有一顆鋯石的時候**：鋯石幾乎沒有初始 Pb（第 3 節），左邊的初始值 ≈ 0，²⁰⁴Pb 也約掉，直接變成放射成因 Pb 的比值：

$$
\boxed{\ \frac{^{207}\mathrm{Pb}^*}{^{206}\mathrm{Pb}^*} = \frac{1}{137.818}\cdot\frac{e^{\lambda_{235}t}-1}{e^{\lambda_{238}t}-1}\ }
$$

這叫 **²⁰⁷Pb/²⁰⁶Pb 年齡**。這條式子沒辦法把 t 移到一邊（超越方程式），要用試誤法或查表：

| t | 0.5 Ga | 1 Ga | 1.849 Ga | 2 Ga | 3 Ga | 4.404 Ga |
|---|---|---|---|---|---|---|
| ²⁰⁷Pb\*/²⁰⁶Pb\* | 0.0572 | 0.0725 | 0.1131 | 0.1230 | 0.2226 | 0.5582 |

比值隨 t 單調增加（²³⁵U 衰變比 ²³⁸U 快 6 倍，越老 ²⁰⁷Pb 佔的比例越高），所以一個比值對應唯一的年齡。

<details>
<summary>【例題 ★ 完整解】Sudbury 撞擊熔岩的鋯石（投影片 p.6；Davis, 2008）：t = 1849.5 Ma 時 ²⁰⁷Pb\*/²⁰⁶Pb\* 應該是多少？如果改用舊的 137.88，同一個比值會算出幾歲？</summary>

**思路**：代進 boxed 式子。先算兩個指數。

**步驟**

1. λ₂₃₅t = 9.8458×10⁻¹⁰ × 1.8495×10⁹ = 1.8210 → e^(1.8210) − 1 = 6.1777 − 1 = **5.1777**
2. λ₂₃₈t = 1.5514×10⁻¹⁰ × 1.8495×10⁹ = 0.28692 → e^(0.28692) − 1 = **0.33232**
3. 比值 = 5.1777 ÷ 0.33232 ÷ 137.818 = 15.580 ÷ 137.818 = **0.11306**

**換成 137.88**：同一個量到的 0.11306，要用試誤法找 t，會得到 **1850.3 Ma**，比正確值老了 **0.8 Ma**。

**為什麼重要**：Davis (2008) 量到兩種正輝長岩的年齡是 1849.53 ± 0.21 Ma 和 1849.11 ± 0.19 Ma，兩者差 0.4 Ma，靠的就是 ±0.2 Ma 的精度。如果常數錯了 0.8 Ma，**系統誤差比量測誤差還大四倍**，再精確也不準確。這就是 Hiess et al. (2012) 重新量 ²³⁸U/²³⁵U 的意義。

</details>

## 3. 鋯石：為什麼是最好的 U-Pb 時鐘 ★

**晶體化學**（投影片 p.5、p.12）：鋯石 ZrSiO₄，Zr⁴⁺ 被 8 個 O 包圍，和 SiO₄ 四面體連成緊密的三維骨架，沒有弱面、沒有好的解理，硬度 7.5，熔點 2550 °C。

**為什麼初始 Pb ≈ 0**（投影片 p.5 筆記：「用 ²³⁸U-²⁰⁶Pb 即可」）：這是 L2 的離子替代規則。

| 離子 | 電荷 | 8 配位半徑（補充¹） | 能不能進 Zr 的位置 |
|---|---|---|---|
| Zr⁴⁺ | +4 | 0.84 Å | 本來就在 |
| U⁴⁺ | +4 | 1.00 Å | 電荷相同、半徑接近 → **可以** |
| Th⁴⁺ | +4 | 1.05 Å | 可以，但比 U 少 |
| Pb²⁺ | +2 | 1.29 Å | 電荷差 2、半徑大太多 → **幾乎進不去** |

所以鋯石結晶時吃進 U、排除 Pb，**現在裡面的 Pb 幾乎全是 U 衰變長出來的**。D₀ = 0，定年方程式最簡單：

$$
^{206}\mathrm{Pb}^* = {}^{238}\mathrm{U}\left(e^{\lambda_{238}t}-1\right)
\;\Longrightarrow\;
\boxed{\ t = \frac{1}{\lambda_{238}}\ln\left(1+\frac{^{206}\mathrm{Pb}^*}{^{238}\mathrm{U}}\right)\ }
$$

**為什麼能保存幾十億年**：骨架緊密、硬、耐風化、耐搬運，Pb 在裡面擴散極慢（封閉溫度超過 900 °C，補充²）。一顆鋯石可以從岩漿裡長出來、被侵蝕、搬到河裡、沉積、再被埋到下一個岩漿裡，年齡都還留著（投影片 p.7「Zircon is FOREVER」）。

**三種鋯石**（投影片 p.14）

| 種類 | 怎麼來的 | 記錄什麼 |
|---|---|---|
| 岩漿鋯石（magmatic） | 從正在結晶的岩漿直接長出來 | 岩漿結晶的年齡 |
| 繼承鋯石（inherited） | 岩漿同化了更老的地殼，老鋯石沒熔掉 | 更老的地殼碎片；常是鋯石的核心，外面再包一圈新長的 |
| 碎屑鋯石（detrital） | 老岩石被侵蝕，鋯石顆粒搬到沉積物裡 | 沉積物的**來源區**有哪些年齡的岩石 |

**碎屑鋯石的用法**（投影片 p.13，從源到匯）：一層砂岩裡量幾十到上百顆鋯石，年齡畫成機率分布，每個峰對應來源區的一次岩漿事件。和可能的來源區比對，就知道砂是從哪裡搬來的、當時的河流系統長什麼樣子。

**例子**

- **Jack Hills（西澳）**：碎屑鋯石最老 **4404 ± 8 Ma**（Wilde et al., 2001），是地球上最老的物質。它的 δ¹⁸O 比地函的值高，代表形成它的岩漿裡有曾在低溫和液態水反應過的物質，表示 **44 億年前已經有大陸地殼和海洋**（投影片 p.7–9）。鋯石裡還找到冥古宙的鑽石包裹體（Menneken et al., 2007；投影片 p.12）。
- **大屯火山群**（投影片 p.11；Chu et al.，Journal of Asian Earth Sciences）：22 個熔岩樣品和基隆嶼 2 個安山岩的鋯石 U-Pb 年齡顯示，大屯火山群約 **3 Ma 開始**，主要在 **≤ 0.8 Ma** 活動，**≤ 0.35 Ma** 有一次爆發高峰；基隆嶼約 0.41 Ma，Hf 同位素和大屯一樣，所以屬於大屯火山群的一部分。

### 補充：諧和曲線與不諧和線（投影片沒有，但鋯石 U-Pb 一定會碰到）

鋯石有兩個 U-Pb 時鐘，各自寫成「子核/母核」：

$$
x = \frac{^{207}\mathrm{Pb}^*}{^{235}\mathrm{U}} = e^{\lambda_{235}t}-1 \qquad y = \frac{^{206}\mathrm{Pb}^*}{^{238}\mathrm{U}} = e^{\lambda_{238}t}-1
$$

t 從 0 開始增加，(x, y) 在圖上畫出一條曲線，叫**諧和曲線（concordia）**。封閉系統的鋯石一定落在這條線上。

**推導：丟過 Pb 的鋯石落在哪裡？** 假設鋯石 t₁ 前結晶，t₂ 前（t₂ \< t₁）發生一次事件（變質、熱液），丟掉比例 φ 的放射成因 Pb，之後又恢復封閉。用**現在的** U 當分母：

- t₁ 到 t₂ 之間長出來的 Pb：$U(e^{\lambda t_1} - e^{\lambda t_2})$，事件後剩下 $(1-\varphi)$ 倍。
- t₂ 到現在長出來的 Pb：$U(e^{\lambda t_2} - 1)$，沒有被丟。

$$
\frac{\mathrm{Pb}^*}{\mathrm{U}} = (1-\varphi)\left(e^{\lambda t_1}-e^{\lambda t_2}\right) + \left(e^{\lambda t_2}-1\right)
$$

這條式子對 ²³⁵U 和 ²³⁸U 都成立（各自代入自己的 λ），而且**兩個座標用的是同一個 φ**（Pb 是同一個元素，丟的比例一樣）。x 和 y 都是 φ 的一次函數，所以 φ 從 0 變到 1 時，點沿著**直線**移動：

- φ = 0（沒丟）：$(e^{\lambda_{235}t_1}-1,\ e^{\lambda_{238}t_1}-1)$，就是諧和曲線上 t₁ 那一點。
- φ = 1（全丟）：$(e^{\lambda_{235}t_2}-1,\ e^{\lambda_{238}t_2}-1)$，諧和曲線上 t₂ 那一點。

這條直線叫**不諧和線（discordia）**。同一個岩體的鋯石丟的比例不同，會散布在這條弦上。**上交點 = 結晶年齡 t₁，下交點 = 丟 Pb 事件的年齡 t₂**。例：t₁ = 2000 Ma、t₂ = 500 Ma：

| φ | ²⁰⁷Pb\*/²³⁵U | ²⁰⁶Pb\*/²³⁸U |
|---|---|---|
| 0 | 6.165 | 0.3638 |
| 0.3 | 4.506 | 0.2789 |
| 0.6 | 2.848 | 0.1939 |
| 1 | 0.636 | 0.0807 |

每一列 x、y 的變化量和 φ 成正比（x 每 0.3 少 1.659、y 每 0.3 少 0.0849），所以是直線。

## 4. ²³⁸U/²³⁵U 不是常數

**Hiess et al. (2012)**（投影片 p.15）量了大量含 U 礦物，發現 ²³⁸U/²³⁵U 並不完全一樣，鋯石的平均值是 **137.818 ± 0.045**，而過去幾十年大家用的是 **137.88**（Steiger & Jäger, 1977，補充³）。差 0.045%，看起來很小，但第 2 節算過，它會讓 1.85 Ga 的 ²⁰⁷Pb/²⁰⁶Pb 年齡差 0.8 Ma。

**為什麼會變：氧化還原**（投影片 p.16）

| 性質 | UO₂（晶質鈾礦） | UO₂(CO₃)₂²⁻（鈾醯碳酸根） |
|---|---|---|
| U 的價數 | +4 | +6 |
| 配位數 | 8 | 6（2 個軸向 O ＋ 4 個赤道 O） |
| 溶解度 | 不溶（還原的 U(IV)） | 很容易溶（氧化的 U(VI)） |
| 環境 | 缺氧沉積物 | 有氧海水 |
| δ²³⁸U | 0.0 到 +0.8‰ | −0.39‰ |

這就是 L7、L9 講過的：U 在氧化的水裡以 U(VI) 溶解，碰到缺氧環境被還原成 U(IV) 沉澱。**還原的時候 ²³⁸U 比較容易被拿走**，兩者的差 Δ²³⁸U(UO₂ − 海水) ≈ **+0.6‰**。一般的質量分餾是輕的同位素反應比較快，這裡反而是重的 ²³⁸U 進還原相，原因是 U 原子核很大，原子核體積的差異（nuclear field shift）壓過了質量效應（補充⁴）。

**δ 的定義**（和 δ¹⁸O、δ¹³C 一樣，都是相對標準的千分差）：

$$
\delta^{238}\mathrm{U} = \left(\frac{(^{238}\mathrm{U}/^{235}\mathrm{U})_{\text{樣品}}}{(^{238}\mathrm{U}/^{235}\mathrm{U})_{\text{CRM-112a}}} - 1\right)\times 1000
$$

> 投影片 p.16 的方框寫 (137.77/137.88 − 1) × 1000 ≈ −0.39‰，但這兩個數相除其實是 **−0.80‰**。標準品 CRM-112a 的 ²³⁸U/²³⁵U 約 **137.837**（Richter et al., 2010，補充⁵），海水約 137.783，代進去 (137.783/137.837 − 1) × 1000 = −0.39‰ 才對得上。考試如果要你代數字，請先跟老師確認用哪個標準值。

**推導：為什麼海水的 δ²³⁸U 能記錄全球缺氧程度**（質量平衡，補充⁶）

穩定狀態下，海水的 U 進來多少就出去多少。進來的主要是河流，同位素組成 δ_in；出去分成缺氧沉積（比例 f_anox，分餾 Δ_anox ≈ +0.6‰）和其他出口（比例 1 − f_anox，假設分餾很小 ≈ 0）。每個出口帶走的 δ = 海水的 δ ＋ 它的分餾。同位素也要守恆：

$$
\delta_{\text{in}} = f_{\text{anox}}\left(\delta_{\text{sw}} + \Delta_{\text{anox}}\right) + (1-f_{\text{anox}})\,\delta_{\text{sw}}
\;\Longrightarrow\;
\boxed{\ \delta_{\text{sw}} = \delta_{\text{in}} - f_{\text{anox}}\,\Delta_{\text{anox}}\ }
$$

**缺氧的海底面積變大 → f_anox 變大 → 更多 ²³⁸U 被埋掉 → 剩下的海水 δ²³⁸U 變低**。在缺氧海水底下形成的黑色頁岩，δ²³⁸U = 當時海水 ＋ 0.6‰，也跟著變低。用示意數字：δ_in = −0.3‰、Δ = 0.6‰ 時，f_anox = 0.15 得 δ_sw = −0.39‰（接近今天）；f_anox 變成 0.5，δ_sw 降到 −0.6‰。

**應用**

- **大洋缺氧事件 OAE2（93 Ma）**（投影片 p.16；Montoya-Pino et al., 2010）：大西洋 Demerara Rise（IODP 1261A）的黑色頁岩，在 OAE2 層段 δ²³⁸U 明顯比上下的層低，表示當時**全球**缺氧範圍擴大，不只是局部。
- **鐵錳結殼**（投影片 p.17；Wang 王相力等）：結殼長得極慢、一層層吸附當時海水的 U，可以回推新生代海水 δ²³⁸U 的變化。
- **人造 ²³⁶U**（投影片 p.18–19）：²³⁶U 在自然界幾乎不存在，主要是核反應爐和核試爆中 ²³⁵U 捕獲中子產生的（補充⁷）。台大團隊（林卉婷、沈川洲等，2021，*Analytical Chemistry*）用 MC-ICPMS 量到飛克（10⁻¹⁵ g）等級的 ²³⁶U。珊瑚裡的 ²³⁶U/²³⁸U 和核爆 Δ¹⁴C 同時在 1950–60 年代上升，可以當成追蹤海洋環流的人造示蹤劑。

## 5. ¹⁴C：從產生到年齡公式 ★

**¹⁴C 從哪來**（投影片 p.25–26）：絕大部分是宇宙射線產生的中子撞擊大氣中的 ¹⁴N：

$$
^{14}_{\ 7}\mathrm{N} + n \rightarrow {}^{14}_{\ 6}\mathrm{C} + p \qquad \text{寫成 } {}^{14}\mathrm{N}(n,p)\,{}^{14}\mathrm{C}
$$

一小部分在岩石圈裡產生（例如 ²⁸Si(n,x)¹⁴C、¹⁶O(μ⁻,2p)¹⁴C），岩石圈和大氣的產量比只有約 3.4×10⁻⁵，可以忽略。碳的三個同位素：¹²C 98.89%、¹³C 1.11%、¹⁴C 只有約 10⁻¹⁰ %（¹⁴C/¹²C ≈ 10⁻¹²）。

¹⁴C 很快氧化成 CO₂、混入大氣，被植物和生物利用、溶進水裡。活著的時候不斷和環境交換；**死掉或碳酸鹽沉澱之後停止交換，時鐘開始走**。

**推導：年齡公式**（投影片 p.27–28，每一步都要會）

1. 衰變定律：$\dfrac{dN}{dt} = -\lambda N$，移項 $\dfrac{dN}{N} = -\lambda\,dt$，兩邊從 0 積到 t：$\ln\dfrac{N}{N_0} = -\lambda t$，所以 $N = N_0e^{-\lambda t}$。
2. ¹²C 是穩定的，數量不變。兩邊同除以 ¹²C：$\dfrac{^{14}\mathrm{C}}{^{12}\mathrm{C}} = \left(\dfrac{^{14}\mathrm{C}}{^{12}\mathrm{C}}\right)_0 e^{-\lambda t}$。用比值的理由和 U-Pb 一樣：質譜儀量比值最準，而且不用知道樣品總共有多少碳。
3. 關鍵假設：**樣品死掉時的 (¹⁴C/¹²C)₀ 等於 1950 年標準的值**。定義

$$
F = \frac{(^{14}\mathrm{C}/^{12}\mathrm{C})_{\text{樣品}}}{(^{14}\mathrm{C}/^{12}\mathrm{C})_{\text{標準,1950}}} = e^{-\lambda t}
$$

4. 取對數：$\ln F = -\lambda t$，$t = -\dfrac{\ln F}{\lambda} = -\dfrac{t_{1/2}}{\ln 2}\ln F$。
5. 代入 Libby 半衰期 5568 年：$t_{1/2}/\ln 2 = 5568/0.6931 = 8033$ 年（這個數叫平均壽命）：

$$
\boxed{\ \text{年齡（BP）} = -8033\,\ln F\ }
$$

投影片寫 −8034，是用 0.693 代 ln 2 的四捨五入結果（5568/0.693 = 8034.6）。

**為什麼標準定在 1950 年**：1950 年代開始的核試爆讓大氣 ¹⁴C 大增（核爆碳），之前的工業革命又用沒有 ¹⁴C 的化石燃料稀釋大氣（Suess 效應）。把「現在」固定在 1950 年，所有實驗室的年齡都相對同一個起點，BP 的意思就是「1950 年之前幾年」。

**半衰期到底是多少？**（投影片 p.29）

| 半衰期 | 出處 | 公式 |
|---|---|---|
| 5568 年 | Libby, 1952 | −8033 ln F |
| 5730 年 | Godwin, 1962（劍橋值） | −8267 ln F |
| 5700 年 | Kutschera, 2019 | −8223 ln F |

5730 年比較接近真實值，但**國際慣例的「傳統 ¹⁴C 年齡」一律用 Libby 的 5568 年**。投影片上的筆記「半衰期不同但不管用什麼系統都會一樣」就是這個意思：校正曲線本身也是用 5568 年的慣例建的，量到的 F 經過同一套慣例換成 ¹⁴C 年、再查同一套曲線，得到的日曆年一樣。真實半衰期的誤差已經被校正曲線吸收了。

> L8 的例題用 5730 年，F = 0.25 得 11,460 年；用慣例的 5568 年是 **11,136 BP**。兩個都是對的算法，但只有後者能拿去查校正曲線。考試看題目給哪個半衰期。

### 補充：δ¹³C 正規化（為什麼投影片 p.38 特別標出 δ¹³C = −25.3‰）

光合作用、碳酸鹽沉澱都會分餾碳同位素。分餾的大小大致和**質量差**成正比：¹⁴C 和 ¹²C 差 2，¹³C 和 ¹²C 差 1，所以 **¹⁴C/¹²C 被分餾的程度約是 ¹³C/¹²C 的兩倍**。量 δ¹³C 就知道 ¹⁴C 被分餾了多少，把所有樣品換算成同一個 δ¹³C（慣例 −25‰，木頭的典型值）（Stuiver & Polach, 1977，補充⁸）：

$$
F_N = F\left(\frac{1 - 25/1000}{1 + \delta^{13}\mathrm{C}/1000}\right)^2
$$

平方就是「兩倍」的那一步。例：海洋碳酸鹽 δ¹³C ≈ 0‰，括號 = 0.975，平方 = 0.9506，年齡要**加約 410 年**（−8033 ln 0.9506）。碳酸鹽比木頭富含重同位素，等於多吃了一點 ¹⁴C，看起來偏年輕，正規化把它拉回來。七星山的木炭 −25.3‰ 和樹完全一樣，修正可以忽略，也證明它真的是燒過的樹。

### 補充：Δ¹⁴C（投影片 p.19、p.33、p.42 的縱軸）

研究大氣、海水的 ¹⁴C 變化時，不是要算年齡，而是要知道**某一年的 ¹⁴C/¹²C 比 1950 年標準高或低多少**。樣品是 y 年形成的，從 y 年到量測時的衰變要先補回來（Stuiver & Polach, 1977）：

$$
\Delta^{14}\mathrm{C} = \left(F_N\,e^{(1950-y)/8267} - 1\right)\times 1000\ \text{‰}
$$

指數用 8267 年（真實半衰期 5730 年的平均壽命），因為這裡要的是真正的衰變量。Δ¹⁴C = 0 代表和 1950 年標準一樣；核試爆高峰（1960 年代）大氣 Δ¹⁴C 接近 +1000‰（¹⁴C 幾乎翻倍）；深層海水是 −100 到 −250‰（第 7 節）。

**AMS：直接數原子**（投影片 p.22–24、p.30–31）

| | β 衰變計數（傳統） | AMS 加速器質譜 |
|---|---|---|
| 量什麼 | 等 ¹⁴C 衰變放出的 β | 直接數 ¹⁴C 原子 |
| 樣品量 | > 0.5 g 碳 | **約 1 mg 碳** |
| 時間 | 超過 1 天 | 約 1 小時 |
| 精度 | 一般達不到 1% | 約 0.3% |
| 範圍 | 百年到約 4 萬年 | 10 年到約 5 萬年 |

**推導：為什麼數衰變這麼慢**（補充）：1 mg 現代碳有多少 ¹⁴C？

- 碳原子數 = (1×10⁻³ g ÷ 12 g/mol) × 6.022×10²³ = 5.0×10¹⁹ 個。
- ¹⁴C 原子數 = 5.0×10¹⁹ × 1.2×10⁻¹² ≈ **6×10⁷ 個**。
- λ = ln 2 ÷ (5730 × 3.156×10⁷ s) = 3.83×10⁻¹² s⁻¹。
- 每秒衰變數 A = λN = 3.83×10⁻¹² × 6×10⁷ ≈ 2.3×10⁻⁴ 次/秒 = **每小時不到 1 次**。

要 1% 的統計精度需要約 10⁴ 個計數（相對誤差 ≈ 1/√N），用衰變計數根本不可能；但這 6×10⁷ 個原子都還在，AMS 直接數它們就好。換成 1 g 碳，每分鐘約 14 次衰變（現代碳的比活度約 13.6 dpm/g），這就是傳統法要用到 0.5 g 以上、量一天以上的原因。

AMS 能在千億個原子中找出一個 ¹⁴C（豐度靈敏度 10⁻¹² 到 10⁻¹⁵）。第一次 AMS 量測是 Alvarez 和 Cornog（1939）在柏克萊的迴旋加速器上，還順便發現了氚 ³H 的放射性。台大 NTUAMS（李紅春）用的是 1 MV Tandetron，可以量 ¹⁴C、¹⁰Be、²⁶Al。製樣要把 1 mg 碳變成石墨靶：木頭或木炭約 2 mg、貝殼 12 mg、水 1 公升。

**杜林裹屍布**（投影片 p.20–21）：傳說包過耶穌的亞麻布。1988 年取下小塊樣品，交給 Arizona、Oxford、Zurich 三間 AMS 實驗室**各自獨立**量測，結果是 **AD 1260–1390**（95% 信心；Damon et al., 1989），是中世紀的織物。這件事能做，靠的就是 AMS 只需要很少的樣品。

**上限與汙染**（投影片 p.27、p.32）：約 10 個半衰期後，剩下 2⁻¹⁰ ≈ 0.1%，太少量不到，**上限約 5 萬年**（L8 說 3.5–4.5 萬年是傳統計數法的上限）。越老的樣品越怕汙染。

**推導：汙染讓年齡偏多少**（補充）。樣品混了比例 c 的現代碳（F = 1）：

$$
F_{\text{量到}} = (1-c)\,F_{\text{真}} + c
$$

| 真實年齡 | 混 0.1% 現代碳 | 混 0.5% | 混 1% |
|---|---|---|---|
| 1 萬年 | 9,980 | 9,900 | 9,800 |
| 3 萬年 | 29,680 | 28,510 | 27,250 |
| 5 萬年 | 46,720 | 39,890 | **35,560** |

5 萬年的樣品 F_真 只有 0.002，混 1% 的現代碳就讓 F 變成約 0.012，**年輕了 1.4 萬年**；同樣的汙染對 1 萬年的樣品只差 200 年。反過來，混了不含 ¹⁴C 的**老碳**（比例 c），F 乘上 (1 − c)，不論真實年齡多少都老了固定的 −8033 ln(1 − c)：1% 是 81 年、5% 是 412 年。

## 6. 校正：¹⁴C 年不等於日曆年 ★

第 5 節的關鍵假設「初始 ¹⁴C/¹²C = 1950 年的值」其實不成立（投影片 p.27、p.32–33）：

1. **產率會變**：宇宙射線通量、地磁場強弱改變 ¹⁴C 的產量。地磁場強的時候擋掉較多宇宙射線，產量低。
2. **化學、物理分餾**：見上一節的 δ¹³C 正規化。
3. **化石燃料稀釋**（Suess, 1954）：化石燃料的碳早就沒有 ¹⁴C，工業革命以後讓大氣 ¹⁴C 變低，最近幾百年的 ¹⁴C 年齡因此出現一段平台（投影片 p.33）。
4. **核爆碳**：1950–60 年代的核試爆讓大氣 ¹⁴C 幾乎翻倍。

**解法：建一張對照表**。找有**獨立**絕對年代的材料，同時量它的 ¹⁴C 年齡：

| 材料 | 獨立年代怎麼來 | 投影片 |
|---|---|---|
| 樹輪 | 一年一輪；不同樹的寬窄紋路交叉比對（dendrochronology），接成上萬年的連續序列，例如狐尾松 | p.34 |
| 珊瑚 | ²³⁰Th/²³⁴U/²³⁸U 定年（L9），涵蓋 0–5 萬年（Fairbanks et al., 2005） | p.35 |
| 石筍 | U-Th 定年；葫蘆洞石筍記錄末次冰期的大氣 ¹⁴C（Cheng et al., 2018） | p.37 |

把每個樣品的（日曆年，¹⁴C 年）畫出來，連成**校正曲線**。它不是一條 45° 直線，而是有起伏、有**平台**的曲線。

**校正的步驟**：量到的 ¹⁴C 年齡帶有誤差（常態分布），從縱軸往右碰到校正曲線，再往下投影到日曆年。曲線陡的地方，誤差投影下去還是很窄；**曲線平的地方（平台），同一個 ¹⁴C 年齡對應一大段日曆年**，機率分布會變寬、分成好幾個峰（投影片 p.36）。所以校正後的年代是一個**範圍**，通常報 2σ（95%）。

<C14CalibFig />

**例：七星山（大屯火山群）的爆發年代**（投影片 p.38；Chen, Burr & Lin, 2010）：台北盆地關渡井（KT-1）松山層裡的木炭火山灰，¹⁴C 年齡 **16,950 ± 150 BP（1σ）**，校正後 **19,814–20,431 cal BP（2σ）**，δ¹³C = −25.3‰（典型的樹）。注意校正後比 ¹⁴C 年老了約 3,000 年：末次冰期時大氣 ¹⁴C 比 1950 年高，樣品一開始就比假設的多吃了 ¹⁴C，看起來偏年輕。

## 7. 海洋庫效應 ★

**現象**（投影片 p.39–40）：大氣的 ¹⁴C/¹²C 和海洋不一樣。海水下沉之後要上千年才會從湧升回到表面；在深海的這段時間，¹⁴C 一直衰變、沒有補充。表層海水又會混到湧升上來的老水，所以**同一時間活著的海洋生物，¹⁴C 年齡比陸地生物老**，這個差叫**海洋庫年齡 R**。

<ReservoirFig />

**推導**：假設表層海水的 ¹⁴C/¹²C 一直是大氣的 e^(−R/τ) 倍（τ = 8033 年）。一個 t 年前死掉的貝殼：

$$
F_{\text{貝殼}} = F_{\text{大氣}}(t)\cdot e^{-R/\tau}
\;\Longrightarrow\;
-\tau\ln F_{\text{貝殼}} = \underbrace{-\tau\ln F_{\text{大氣}}(t)}_{\text{陸地樣品會量到的 }^{14}\mathrm{C}\text{ 年}} + R
$$

所以海洋樣品量到的 ¹⁴C 年齡 = 同時期陸地樣品的 ¹⁴C 年齡 **＋ R**。全球平均 R ≈ 400 年，代表表層海水的 ¹⁴C 比大氣少 1 − e^(−400/8033) ≈ 5%。投影片 p.40「在海裡待了 2000 年的水，¹⁴C 比大氣少約 20%」也可以自己驗算：1 − e^(−2000/8267) = 21%。

**怎麼修正**（投影片 p.39–41）

1. 舊做法：全球統一用 R = 400 年（Marine13 校正曲線）。
2. 新做法：**Marine20 校正曲線 ＋ 當地的 ΔR**。Marine20 是全球海洋模式算出的海洋 ¹⁴C 曲線；各地因為湧升、洋流不同，和模式有差，這個差就是 ΔR（負值代表當地表層水比模式「年輕」）。
3. **台灣海峽澎湖**（Wang et al., 2025, *Radiocarbon*）：50–5500 cal BP 的加權平均 **ΔR = −155 ± 59** 年，5500–9000 cal BP 為 **−107 ± 96** 年，約 5500–6700 cal BP 有較大的變動（約 400 年）。文章認為台灣周圍的 ΔR 繼承自上游北赤道洋流的值。

**WOCE 深層水 ¹⁴C**（投影片 p.42；Key et al., 2002）：世界大洋環流實驗量了全球底層水的 Δ¹⁴C（約 −240 到 −120‰），北太平洋最低，代表那裡的水離開表面最久。投影片的評語是「資料很多、代價很高，但仍然缺少時間控制」：WOCE 只是一張快照，要知道過去環流怎麼變，還是要靠有年代的紀錄（例如深海珊瑚、有孔蟲）。

## 8. Rb-Sr 等時線與海水的 Sr ★

**衰變**（投影片 p.43）：⁸⁷Rb → ⁸⁷Sr + β⁻，λ = 1.42×10⁻¹¹ yr⁻¹，t₁/₂ = 48.8 Ga（比宇宙年齡還長三倍）。

**推導：等時線方程式**。和第 1 節完全一樣的三步：

1. 長出來的子核 = 現在的母核 × (e^(λt) − 1)：$^{87}\mathrm{Sr} = {}^{87}\mathrm{Sr}_0 + {}^{87}\mathrm{Rb}\left(e^{\lambda t}-1\right)$
2. 選一個**不是衰變產物、數量固定**的同位素當分母：⁸⁶Sr。
3. 同除以 ⁸⁶Sr：

$$
\frac{^{87}\mathrm{Sr}}{^{86}\mathrm{Sr}} = \left(\frac{^{87}\mathrm{Sr}}{^{86}\mathrm{Sr}}\right)_0 + \frac{^{87}\mathrm{Rb}}{^{86}\mathrm{Sr}}\left(e^{\lambda t}-1\right)
\qquad\Longleftrightarrow\qquad y = b + m\,x
$$

**為什麼一組樣品會排成直線**：同一次岩漿事件形成的礦物（或岩石），結晶時 Sr 同位素已經均勻（Sr 同位素化學上分不開），所以**初始 ⁸⁷Sr/⁸⁶Sr 相同 = 同一個截距 b**；但不同礦物吃 Rb 的多寡不同（雲母、鉀長石 Rb 多，斜長石 Rb 少），x 不同。經過時間 t，每個點都往上長 x(e^(λt) − 1)，Rb 越多長越多，原本的水平線轉成一條斜率 e^(λt) − 1 的直線。

$$
t = \frac{\ln(1+m)}{\lambda}
$$

投影片 p.44 的隕石：斜率 0.04855 → t = ln(1.04855)/1.42×10⁻¹¹ = 0.04741/1.42×10⁻¹¹ = **3.34 Ga**，截距 0.7042。

**推導：λt ≪ 1 的近似和它的誤差**（投影片 p.45）。泰勒展開：

$$
e^{\lambda t} = 1 + \lambda t + \frac{(\lambda t)^2}{2!} + \frac{(\lambda t)^3}{3!} + \cdots
\quad\Longrightarrow\quad
e^{\lambda t} - 1 \approx \lambda t
\quad\Longrightarrow\quad
\frac{^{87}\mathrm{Sr}}{^{86}\mathrm{Sr}} \approx \left(\frac{^{87}\mathrm{Sr}}{^{86}\mathrm{Sr}}\right)_0 + \frac{^{87}\mathrm{Rb}}{^{86}\mathrm{Sr}}\,\lambda t
$$

斜率直接 = λt，t = m/λ。被丟掉的第一項是 (λt)²/2，所以 $e^{\lambda t}-1 = \lambda t\,(1 + \lambda t/2 + \cdots)$：**用近似算出來的年齡會偏老，相對誤差約 λt/2**。

| 年齡 | λt | 近似高估 |
|---|---|---|
| 0.1 Ga | 0.0014 | 0.07% |
| 1 Ga | 0.0142 | 0.7% |
| 4.5 Ga | 0.0639 | **3.3%** |

**海水的 Sr 同位素**（投影片 p.46；Peucker-Ehrenbrink & Fiske, 2019）

- Sr 在海水的**滯留時間（百萬年量級）遠大於海洋混合時間（約一千年）**（L6 的滯留時間觀念），所以全世界海水的 ⁸⁷Sr/⁸⁶Sr 在任何時刻都一樣（現代 0.70917，補充¹⁰）。
- Sr 容易替代碳酸鈣裡的 Ca，**海洋碳酸鹽忠實記錄沉澱當時的海水比值**。
- 海水的比值由兩個來源決定，就是一個**二成分混合**（下一節）：大陸風化的河水（老的花崗質地殼，Rb/Sr 高，⁸⁷Sr/⁸⁶Sr 約 0.711–0.712）和中洋脊熱液、地函物質（約 0.703）。穩定狀態下用通量加權：

$$
\left(\frac{^{87}\mathrm{Sr}}{^{86}\mathrm{Sr}}\right)_{\text{海水}} = \frac{J_{\text{河}}\,R_{\text{河}} + J_{\text{熱液}}\,R_{\text{熱液}}}{J_{\text{河}} + J_{\text{熱液}}}
$$

（J 是 Sr 的通量。）造山、大陸風化增強 → 海水比值上升；海底擴張、熱液增強 → 下降。投影片 p.46 的曲線就是過去 8.5 億年海水比值的起伏，有了這條曲線，**量一個海相碳酸鹽的 ⁸⁷Sr/⁸⁶Sr，就能對照出它的沉積年代**（鍶同位素地層學）。

**Sm-Nd**（投影片 p.51）：¹⁴⁷Sm → ¹⁴³Nd ＋ α，t₁/₂ = 1.06×10¹¹ 年，等時線用 ¹⁴⁴Nd 當分母，形式和 Rb-Sr 一樣。來源意義見 L8：地函 Sm/Nd 高、¹⁴³Nd/¹⁴⁴Nd 高；地殼相反。下一節的 Sr-Nd 混合就會用到這個對比。

## 9. 二成分混合：完整推導 ★

投影片 p.47–52 取自 Faure《Principles of Isotope Geology》第 9 章。這節是整講推導最多的部分，也是 Week 11 作業後三題的基礎。**目標：兩個端元 A、B 混合，混合物 M 的濃度和同位素比值在圖上長什麼樣子？**

### 9-1　一個元素的濃度：直線（槓桿法則）

定義 f = **A 在混合物中的重量比例**：

$$
f = \frac{A}{A+B}
$$

A、B 是兩個端元的重量。元素 X 的總量守恆：混合物裡 X 的量 = 從 A 來的 ＋ 從 B 來的：

$$
X_M\,(A+B) = X_A\,A + X_B\,B
\quad\xrightarrow{\ \div (A+B)\ }\quad
\boxed{\ X_M = X_A f + X_B(1-f)\ } \quad (9.2)
$$

反過來解 f：

$$
f = \frac{X_M - X_B}{X_A - X_B} \quad (9.3)
$$

這就是**槓桿法則**：混合物離 B 多遠，就有多少比例的 A。只要知道兩個端元和混合物的濃度，就能算出混合比例。

### 9-2　兩個元素：還是直線

另一個元素 Y 也一樣：Y_M = Y_A f + Y_B(1 − f)。把 (9.3) 的 f 代進去消掉 f：

$$
Y_M = Y_B + (Y_A - Y_B)\,\frac{X_M - X_B}{X_A - X_B}
= X_M\,\frac{Y_A - Y_B}{X_A - X_B} + \frac{X_A Y_B - X_B Y_A}{X_A - X_B} \quad (9.4)
$$

（第二個等號：展開後把常數項通分，$Y_B - \frac{(Y_A - Y_B)X_B}{X_A - X_B} = \frac{Y_B X_A - Y_B X_B - Y_A X_B + Y_B X_B}{X_A - X_B} = \frac{X_A Y_B - X_B Y_A}{X_A - X_B}$。）

**兩個元素的濃度互相作圖是直線**，斜率 $m = \frac{Y_A - Y_B}{X_A - X_B}$，兩個端元都在線上，混合物落在它們之間。投影片 p.48：Huron 湖北水道的水樣 **Ca = 0.178 Sr + 9.81**（r² = 0.989），就是 Superior 湖水和 Huron 湖水的混合線。

### 9-3　同位素比值：雙曲線

這是本節的核心。比值不能直接用 (9.2) 加權，要回到**原子數**。

**第 1 步：數 ⁸⁷Sr 原子**（投影片 p.49，式 9.5）。A 端元貢獻的 Sr 重量 = Sr_A × f（每單位混合物），除以 Sr 的原子量 W_A 變成莫耳數，乘亞佛加厥數 N 變成原子數，再乘 ⁸⁷Sr 的豐度 Ab⁸⁷_A：

$$
^{87}\mathrm{Sr}_M = \frac{\mathrm{Sr}_A\,Ab^{87}_A\,N f}{W_A} + \frac{\mathrm{Sr}_B\,Ab^{87}_B\,N(1-f)}{W_B} \quad (9.5)
$$

**第 2 步**：⁸⁶Sr 照抄（把 87 換成 86），兩式相除，N 約掉（9.6）。

**第 3 步：兩個近似**（9.7）：兩個端元 Sr 的原子量相同（W_A = W_B），⁸⁶Sr 的豐度相同（Ab⁸⁶_A = Ab⁸⁶_B）。為什麼可以：⁸⁷Sr/⁸⁶Sr 在自然界只差幾 %（0.70 到 0.74），造成的原子量和 ⁸⁶Sr 豐度差異都極小。W 約掉，Ab⁸⁶ 提出來：

$$
\left(\frac{^{87}\mathrm{Sr}}{^{86}\mathrm{Sr}}\right)_M = \frac{\mathrm{Sr}_A Ab^{87}_A f + \mathrm{Sr}_B Ab^{87}_B (1-f)}{Ab^{86}\left[\mathrm{Sr}_A f + \mathrm{Sr}_B(1-f)\right]} \quad (9.8)
$$

**第 4 步**：Ab⁸⁷_A/Ab⁸⁶ 就是 A 的比值 R_A（R 代表 ⁸⁷Sr/⁸⁶Sr），分母的方括號就是 Sr_M（式 9.2）：

$$
\boxed{\ R_M = R_A\,\frac{\mathrm{Sr}_A f}{\mathrm{Sr}_M} + R_B\,\frac{\mathrm{Sr}_B(1-f)}{\mathrm{Sr}_M}\ } \quad (9.9)
$$

**讀這條式子**：混合物的比值是兩端元比值的加權平均，但權重是「**混合物的 Sr 有多少比例來自 A**」（Sr_A f/Sr_M），不是 f。Sr 濃度高的端元拉得比較用力。

**第 5 步：消掉 f**。由 (9.2) 解出 $f = \frac{\mathrm{Sr}_M - \mathrm{Sr}_B}{\mathrm{Sr}_A - \mathrm{Sr}_B}$、$1 - f = \frac{\mathrm{Sr}_A - \mathrm{Sr}_M}{\mathrm{Sr}_A - \mathrm{Sr}_B}$，代入 (9.9) 兩邊乘 Sr_M：

$$
R_M\,\mathrm{Sr}_M = \frac{R_A\mathrm{Sr}_A(\mathrm{Sr}_M - \mathrm{Sr}_B) + R_B\mathrm{Sr}_B(\mathrm{Sr}_A - \mathrm{Sr}_M)}{\mathrm{Sr}_A - \mathrm{Sr}_B}
= \frac{\mathrm{Sr}_M(R_A\mathrm{Sr}_A - R_B\mathrm{Sr}_B) + \mathrm{Sr}_A\mathrm{Sr}_B(R_B - R_A)}{\mathrm{Sr}_A - \mathrm{Sr}_B}
$$

兩邊除以 Sr_M：

$$
R_M = \frac{\mathrm{Sr}_A\mathrm{Sr}_B(R_B - R_A)}{\mathrm{Sr}_M(\mathrm{Sr}_A - \mathrm{Sr}_B)} + \frac{R_A\mathrm{Sr}_A - R_B\mathrm{Sr}_B}{\mathrm{Sr}_A - \mathrm{Sr}_B} \quad (9.10)
$$

$$
\boxed{\ R_M = \frac{a}{\mathrm{Sr}_M} + b\ } \quad (9.11)
\qquad a = \frac{\mathrm{Sr}_A\mathrm{Sr}_B(R_B - R_A)}{\mathrm{Sr}_A - \mathrm{Sr}_B},\quad b = \frac{R_A\mathrm{Sr}_A - R_B\mathrm{Sr}_B}{\mathrm{Sr}_A - \mathrm{Sr}_B}
$$

**結論**

1. 比值對濃度作圖是**雙曲線**（投影片 p.50 圖 a）。
2. 比值對 **1/Sr** 作圖是**直線**，斜率 a、截距 b（圖 b）。這就是擬合資料時的線性化：先求 a、b，再用端元比值反推端元濃度。
3. a 的正負看「Sr 高的那端比值低不低」：Sr_A > Sr_B 且 R_A \< R_B 時 a > 0。b 是 Sr_M → ∞ 時的極限，**不是**任何真實端元的比值。
4. 投影片 p.50 的 Huron 北水道：**(⁸⁷Sr/⁸⁶Sr)_M = 0.1996/Sr_M + 0.7086**。

**先預測**：A 有 600 ppm Sr、比值 0.709；B 有 100 ppm、比值 0.725。各一半混合（f = 0.5），比值會是兩者的平均 0.717 嗎？比較靠近哪一端？

<MixingDemo />

（答案：Sr_M = 350 ppm，比值 = (0.5×600×0.709 + 0.5×100×0.725)/350 = **0.7113**，不是 0.717，靠近 Sr 多的 A。混合物的 Sr 有 600×0.5/350 = 86% 來自 A。）

### 9-4　反過來：從量到的比值求 f

把 (9.9) 寫成 $R_M[\mathrm{Sr}_A f + \mathrm{Sr}_B(1-f)] = R_A\mathrm{Sr}_A f + R_B\mathrm{Sr}_B(1-f)$，把含 f 的項移到一邊：

$$
f\left[R_M(\mathrm{Sr}_A - \mathrm{Sr}_B) - R_A\mathrm{Sr}_A + R_B\mathrm{Sr}_B\right] = \mathrm{Sr}_B(R_B - R_M)
$$

$$
\boxed{\ f = \frac{\mathrm{Sr}_B\,(R_B - R_M)}{R_M(\mathrm{Sr}_A - \mathrm{Sr}_B) - R_A\mathrm{Sr}_A + R_B\mathrm{Sr}_B}\ } \quad (9.30)
$$

只要知道兩個端元的 Sr 和比值，**一個比值**就能求出混合比例，不需要量混合物的濃度。

### 9-5　兩個元素、兩個比值：Sr-Nd 雙曲線

投影片 p.52：花崗岩（A）和玄武岩（B）混合，同時看 Sr 和 Nd 的同位素：

| | A 花崗岩 | B 玄武岩 |
|---|---|---|
| Sr | 160 ppm | 318 ppm |
| ⁸⁷Sr/⁸⁶Sr（X） | 0.73691 | 0.70362 |
| Nd | 31 ppm | 18 ppm |
| ¹⁴³Nd/¹⁴⁴Nd（Y） | 0.51212 | 0.51300 |

每個比值各自照 (9.9) 寫：X 的權重是 Sr，Y 的權重是 Nd。對同一個 f：

| f | Sr（ppm） | ⁸⁷Sr/⁸⁶Sr | Nd（ppm） | ¹⁴³Nd/¹⁴⁴Nd |
|---|---|---|---|---|
| 0.2 | 286.4 | 0.70734 | 20.6 | 0.51274 |
| 0.4 | 254.8 | 0.71198 | 23.2 | 0.51253 |
| 0.6 | 223.2 | 0.71794 | 25.8 | 0.51237 |
| 0.8 | 191.6 | 0.72586 | 28.4 | 0.51223 |

兩個比值互相作圖是**雙曲線**。原因：X 用 Sr 加權、Y 用 Nd 加權，兩個權重隨 f 變的方式不同。只有當兩個端元的 **Sr/Nd 相同**時，兩組權重一樣，曲線才退化成直線；Sr/Nd 差越多，彎得越厲害。這個例子 A 的 Sr/Nd = 5.2、B 的 = 17.7，B 的 Sr 相對多：f = 0.2 時，⁸⁷Sr/⁸⁶Sr 只從 B 往 A 移動了全程的 11%（Sr 還被 B 主導），¹⁴³Nd/¹⁴⁴Nd 卻已經移動了 30%（Nd 兩端差不多多）。兩個比值「走的速度」不同，點就不會在直線上。

**例**（投影片 p.52 最後一行）：量到 (⁸⁷Sr/⁸⁶Sr)_M = 0.71200，用 (9.30)：

$$
f = \frac{318\,(0.70362 - 0.71200)}{0.71200(160-318) - 0.73691\times160 + 0.70362\times318}
= \frac{-2.6648}{-112.496 - 117.906 + 223.751} = \frac{-2.6648}{-6.6504} = 0.40
$$

再預測 Nd：$(^{143}\mathrm{Nd}/^{144}\mathrm{Nd})_M$ = (0.4×31×0.51212 + 0.6×18×0.51300)/23.2 = 0.51253。量到的值如果不在這附近，就表示不是單純的兩端元混合（例如還有第三個來源，或混合時同時在結晶分異）。

### 9-6　統一的規則：共用分母 → 直線

回頭看 9-2 和 9-3，有一條通用的規則（補充，可以自己證明）：

> **兩個比值的分母是同一個量時，混合物在圖上落在直線上；分母不同時是雙曲線。**

證明的想法：比值 = 分子/分母，分子和分母各自都按 (9.2) 線性混合。如果 x 軸和 y 軸的分母是同一個（例如都是 ⁸⁶Sr），兩者都等於「分子的線性混合 ÷ 同一個分母」，消掉分母後 y 是 x 的一次式。

- 濃度 vs 濃度（分母都是「樣品重量」）→ 直線（9-2）。
- ⁸⁷Sr/⁸⁶Sr vs 1/Sr：1/Sr 可以看成「1/⁸⁶Sr」，分母都是 ⁸⁶Sr → 直線（9-3 的線性化）。
- ⁸⁷Sr/⁸⁶Sr vs ¹⁴³Nd/¹⁴⁴Nd：分母一個 ⁸⁶Sr、一個 ¹⁴⁴Nd → 雙曲線（9-5）。
- ²⁰⁶Pb/²⁰⁷Pb vs ²⁰⁸Pb/²⁰⁷Pb：分母都是 ²⁰⁷Pb → 直線。投影片 p.53 的**鉛同位素汙染鑑識**就是用這個：人為汙染和自然背景的 Pb 同位素組成不同，土壤樣品落在兩者的連線上，在線上的位置（槓桿法則）就是汙染的貢獻比例，可以當成環境訴訟的科學證據。

### 9-7　假等時線

這條規則有一個重要的後果。Rb-Sr 等時線圖的兩個軸是 ⁸⁷Rb/⁸⁶Sr 和 ⁸⁷Sr/⁸⁶Sr，**分母都是 ⁸⁶Sr**。所以兩個端元混出來的一組樣品，**不用經過任何時間**，在等時線圖上就已經排成一條直線。照斜率算出來的「年齡」沒有意義，這叫**假等時線**（fictitious isochron，Faure 第 9 章第 4 節）。

**怎麼分辨**：混合物同時會在 ⁸⁷Sr/⁸⁶Sr 對 1/Sr 的圖上也排成直線（9-3）。如果一組「等時線」資料對 1/Sr 也呈現很好的直線，就要懷疑它是混合線。反過來不一定成立：真的等時線資料也可能剛好和 1/Sr 相關，所以這只是警訊，還要配合地質判斷。

<details>
<summary>自我檢測 9</summary>

1. 從質量守恆推出 X_M = X_A f + X_B(1 − f) 和槓桿法則。
2. 推導 (⁸⁷Sr/⁸⁶Sr)_M = a/Sr_M + b，說明用了哪兩個近似、為什麼可以用。
3. 為什麼混合物的比值不是用 f 加權平均？
4. 什麼時候兩個同位素比值的混合是直線、什麼時候是雙曲線？
5. 什麼是假等時線？怎麼檢查？

**答案**：(1) X 總量守恆：X_M(A + B) = X_A A + X_B B，除以 A + B；f = (X_M − X_B)/(X_A − X_B)。(2) 數 ⁸⁷Sr、⁸⁶Sr 原子相除，近似：兩端元 Sr 原子量相同、⁸⁶Sr 豐度相同（自然界 ⁸⁷Sr/⁸⁶Sr 只差幾 %）；得到 R_M = R_A Sr_A f/Sr_M + R_B Sr_B(1 − f)/Sr_M，再用 (9.2) 消掉 f。(3) 比值是原子數的比，Sr 濃度高的端元貢獻的原子多，權重是 Sr_A f/Sr_M。(4) 分母相同（或兩端元的分母元素比例相同，例如 Sr/Nd 相同）是直線，否則是雙曲線。(5) 兩端元混合的樣品在 ⁸⁷Sr/⁸⁶Sr 對 ⁸⁷Rb/⁸⁶Sr 圖上排成直線（分母都是 ⁸⁶Sr），斜率不代表年齡；檢查 ⁸⁷Sr/⁸⁶Sr 對 1/Sr 是否也成直線。

</details>

## 容易混淆的地方

| 容易搞混 | 正確理解 |
|---|---|
| ²⁰⁴Pb、⁸⁶Sr、¹²C 是「母核」？ | 都是**非放射成因的穩定同位素**，只是拿來當分母 |
| Pb-Pb 法量的是 U/Pb？ | **不用 U 的含量**，只要 Pb 的同位素比值；U 被相除消掉 |
| ²³⁵U/²³⁸U 用 137.88 | 新值 **137.818**（Hiess et al., 2012）；差 0.8 Ma／1.85 Ga |
| 傳統 ¹⁴C 年齡用 5730 年 | 慣例用 **5568 年**（−8033 ln F）；真實半衰期的差被校正曲線吸收 |
| BP 是「今年之前」 | BP 的「現在」固定是 **1950 年** |
| ¹⁴C 年 = 日曆年 | 要查**校正曲線**；平台上範圍會變很寬 |
| 海洋樣品直接用大氣曲線 | 要扣海洋庫效應：**Marine20 ＋ ΔR** |
| ¹⁴C 上限 4 萬年 vs 5 萬年 | 傳統衰變計數約 4 萬年；AMS 約 5 萬年；越老越怕現代碳汙染 |
| λt ≪ 1 近似什麼時候都能用 | 年齡偏老約 λt/2；4.5 Ga 的隕石已經差 3% |
| 混合比值 = f 加權平均 | 是**濃度加權**：權重是 Sr_A f/Sr_M |
| 雙曲線截距 b 是端元的比值 | b 是 Sr → ∞ 的數學極限，不是真實端元 |
| f 是 Sr 的比例 | f 是 A 的**重量（或體積）**比例；Sr 來自 A 的比例是 Sr_A f/Sr_M |
| 等時線圖上的直線一定是年齡 | 兩端元混合也會排成直線（**假等時線**） |
