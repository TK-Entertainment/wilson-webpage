**本章重點**

1. **τ = 儲庫大小 / 通量**（穩態時流入 = 流出）。
2. 人為 CO₂ 的緩衝由快到慢：**溶解碳酸鹽 → 海床 CaCO₃ → 矽酸鹽風化**。
3. 瓶頸是**海洋環流（數百年）**，不是海氣交換（約半年）。

**簡化碳循環（L6 p.7，PgC）**

<img src="/img/notes/geochemistry/l6-carbon-cycle/01.png" alt="簡化碳循環（L6 p.7，PgC）" width="693" height="368" />

τ = 儲庫 ÷ 通量。大氣和海洋、陸地之間交換很快（數年），但深海很大、換一次要數百年，地殼的碳更是要上億年。所以要問的是「人為 CO₂ 多久能進到深海和沉積物」，而不是單一分子在大氣中停留多久。

**人為 CO₂ 的去處：各過程的時間尺度**

<img src="/img/notes/geochemistry/l6-carbon-cycle/02.png" alt="人為 CO₂ 的去處：各過程的時間尺度" width="683" height="303" />

對數時間軸，每一格是 10 倍。越往右的過程越慢，但最終能吸收的量越徹底；4 萬年後大氣中仍殘留約 7%，要靠矽酸鹽風化慢慢移除。

這講的三個核心問題：人為 CO₂ 有多少會留在大氣？留多久？其餘的去哪裡？

## 滯留時間（Residence time）

> **τ = \[A\]<sub>reservoir</sub> / Flux(A)<sub>in or out</sub>**  
> 嚴格來說只適用於穩態（流入 = 流出，儲庫大小固定），但在非穩態下也很有用。

<details>
<summary>【例題】Lake Clearandfresh（體積 1000 M-L）</summary>

流入：降雨 10 + 河流 50 = 60 M-L/yr；流出：蒸發 30 + 河流 20 + 地下水 10 = 60 M-L/yr → **穩態**。

τ = 1000 / 60 ≈ **16.7 年**。

延伸：如果蒸發量增加，湖會縮小（非穩態），但仍可以用 τ 估算時間尺度。

</details>

## 全球碳循環（IPCC 圖，單位 PgC、PgC/yr）

| 儲庫 | 大小 (PgC) |
|---|---|
| 大氣 | 589 + 240（人為），每年增加 ~4 |
| 表層海洋 / 中深層海洋 / DOC | 900 / 37,100 / 700 |
| 植被 / 土壤 / 永凍土 | 450–650 / 1500–2400 / ~1700 |
| 化石燃料蘊藏 | ~1000–1900 |

主要通量（p.4）：光合作用約 123、海–氣交換約 80；化石燃料約 7.8、土地利用約 1.1。**大氣中單一 CO₂ 分子的滯留時間大約只有幾年**（p.7 的簡化碳循環圖：τ(大氣→表層海洋) = 7 yr、τ(大氣→陸地) = 12 yr），但人為擾動要恢復需要數百到數萬年。這兩個時間尺度不一樣，是常見的觀念題。

## 平衡考量：三種緩衝（由快到慢）

1. **溶解碳酸鹽緩衝**：`CO₂ + H₂O + CO₃²⁻ ⇌ 2HCO₃⁻`。海水的 CO₃²⁻ 會被消耗，所以吸收能力會隨著 CO₂ 增加而**下降**（非線性；圖中 nonlinear 的曲線比 linear 低）。如果整個海洋都和大氣平衡，海洋最多能吸收約 80% 的增量。
2. **沉積物 CaCO₃ 緩衝**（seafloor neutralization）：`CaCO₃ + CO₂ + H₂O → Ca²⁺ + 2HCO₃⁻`。海水酸化 → 溶躍面（lysocline）變淺 → 海底 CaCO₃ 溶解，補充 CO₃²⁻ 和鹼度。時間尺度約數千年。
3. **風化緩衝**：岩石礦物 + CO₂ + H₂O → 陽離子 + HCO₃⁻ + SiO₂ + 貧陽離子的鋁矽酸鹽。 CaCO₃ + CO₂ + H₂O → Ca²⁺ + 2HCO₃⁻ CaSiO₃ (wollastonite) + 2CO₂ + H₂O → Ca²⁺ + SiO₂ + 2HCO₃⁻ 2KAlSi₃O₈ + 2CO₂ + 3H₂O → 2K⁺ + 2HCO₃⁻ + 4SiO₂ + Al₂Si₂O₅(OH)₄ 碳酸鹽風化吸收的 CO₂，在海洋沉澱 CaCO₃ 時又釋放回去；**矽酸鹽風化才是長期淨移除 CO₂** 的機制（~10⁴–10⁵ 年）。

- 風化產物取決於原岩、T、P、水的組成、有機質、pH。**Bowen 反應系列**：形成時 T、P 越高（pE 越低）的礦物越容易風化（橄欖石最容易，石英最穩定）。

## 動力學考量

- 速率限制步驟：**海–氣交換約 6 個月**就能平衡表層；**海洋環流需要數百年**（這是真正的瓶頸）。
- 人為 CO₂ 主要在上層海洋；北大西洋和南大洋的柱積量（column inventory）最高，因為那裡有深層水形成，把 CO₂ 帶到深處。
- 長期吸收（脈衝響應圖）：ocean invasion（數百年）→ seafloor CaCO₃ neutralization（峰值約數千年）→ terrestrial CaCO₃ → silicate weathering（數萬年以上）。4 萬年後大氣中仍殘留約 7%。
- 生物圈：陸地碳匯（CO₂ fertilization）。回饋與不確定性：暖化降低 CO₂ 溶解度、海洋分層、永凍土釋碳。（這一點的細節是補充）

- NASA 影片：大氣 CO₂ 從 1979 年 1 月的 336 ppm 上升到 400 ppm 以上；北半球季節振幅較大（陸地植物多）。

#### 海洋中的 CaCO₃ 溶解度 （p.11–14）

> CO₂\* + CaCO₃ + H₂O ⇌ Ca²⁺ + 2HCO₃⁻  
> CaCO₃(s) ⇌ Ca²⁺ + CO₃²⁻

- p.11 圖：浮游生物的 CaCO₃ 殼（球石藻、有孔蟲）。生物產生 CaCO₃ 會降低海水的 ΣCO₂。
- **K<sub>sp</sub>(CaCO₃) 隨溫度降低而增加、隨壓力升高而增加**，這跟大多數離子固體**相反**。深海又冷、壓力又大 → **CaCO₃ 越深越容易溶解**。

| T (°C) | P (atm) | 飽和 CO₃²⁻：calcite (10⁻⁶ mol/L) | aragonite |
|---|---|---|---|
| 24 | 1 | 53 | 90 |
| 2 | 1 | 72 | 110 |
| 2 | 250 | 97 | 144 |
| 2 | 500 | 130 | 190 |

Broecker Table 2-2；100 atm 約等於 1000 m 水深。aragonite 每一列都比 calcite 高 → aragonite 比 calcite 更容易溶解。

- **Lysocline（溶躍面）**：在這個深度以下，CaCO₃ 溶解速率迅速增加，脆弱的有孔蟲殼先溶掉、物種多樣性下降，只剩堅固的種類。**CCD（carbonate compensation depth，碳酸鹽補償深度）**：在這個深度以下幾乎沒有 CaCO₃。（Peterson 1966 的實驗：把方解石球掛在不同深度，約 3,700 m 的 critical level 以下重量損失急增。）
- 海床 CaCO₃ 含量圖：中洋脊和較淺的海底 CaCO₃ 含量高；深海盆，特別是北太平洋，含量很低。

#### Bowen 反應系列 （p.17）

不連續系列：olivine → pyroxene → amphibole → biotite；連續系列：Ca 斜長石（anorthite）→ Na 斜長石（oligoclase）；最後結晶的殘餘相：K-spar、muscovite、quartz。從超基性、基性、中性到長英質，SiO₂、Na、Al、K 增加，Fe、Mg、Ca 減少。**越早（越高溫）結晶的礦物越容易風化**（橄欖石最不穩定，石英最穩定）。

#### 人為碳匯的分配 （p.24）

| 碳匯 | 時間尺度 | 分擔（隨化石燃料釋放量 1000–4500 PgC 變化） |
|---|---|---|
| Ocean invasion | ~300 yr | 最大：~80% → ~70%（釋放越多，比例越低，因為 CO₃²⁻ 被消耗） |
| Sea-floor CaCO₃ | ~4 kyr | ~10–20% |
| Terrestrial CaCO₃ | ~10 kyr | 幾 % |
| Igneous (silicate) weathering | ~200 kyr | 剩下的 ~7–8% |
