考前最後 30 分鐘看這一節就好。

| 主題 | 公式 |
|---|---|
| Hubble 年齡 | $t = 1/H_0 = d/v$ |
| 結合能 | $\mathrm{BE} = N m_n + Z m_p + Z m_e - M$；每核子 $\mathrm{BE}/A$ |
| 分配係數 | $D = C_s/C_L$；$\bar D = \sum x_i D_i$ |
| Batch melting | $C_L/C_0 = 1/[D(1-F)+F]$；$F \to 0$ 時為 $1/D$ |
| 第一定律 | $dU = dQ + dW = T\,dS - P\,dV$ |
| 熵 | $dS = dQ_{\text{rev}}/T$；$S = k\ln\Omega$ |
| 焓 | $H = U + PV$；$\Delta H = \int C_P\,dT$；$\Delta S = \int (C_P/T)\,dT$ |
| Gibbs | $G = H - TS$；$dG = V\,dP - S\,dT$ |
| G 對 P、T | $(\partial \Delta G/\partial P)_T = \Delta V$；$(\partial \Delta G/\partial T)_P = -\Delta S$ |
| Clapeyron | $dP/dT = \Delta S/\Delta V = \Delta H/(T\Delta V)$ |
| 相律 | $f = c - \varphi + 2$；$c = n - r$ |
| 化學勢 | $\mu_i = \mu_i^\circ + RT\ln a_i$ |
| 平衡常數 | $\Delta G^\circ = -RT\ln K$；$\Delta G = \Delta G^\circ + RT\ln Q$ |
| van't Hoff | $\ln K = -\Delta H^\circ/RT + \Delta S^\circ/R$ |
| 一階動力學 | $[\mathrm{A}] = [\mathrm{A}]_0 e^{-kt}$；$t_{1/2} = \ln 2/k$ |
| Arrhenius | $k = A\,e^{-E_a/RT}$ |
| 碳酸常數（25 °C） | $K_{\mathrm{CO_2}} = 10^{-1.47}$；$K_1 = 10^{-6.35}$；$K_2 = 10^{-10.33}$；$K_w = 10^{-14}$ |
| 鹼度 | $\text{Alk} = [\mathrm{HCO_3^-}] + 2[\mathrm{CO_3^{2-}}] + [\mathrm{OH^-}] - [\mathrm{H^+}]$ |
| 緩衝強度 | $\beta = dC_B/d\,\mathrm{pH}$ |
| $K_{sp}$ 溶解度 | AB：$x = \sqrt{K_{sp}}$；AB₂：$x = (K_{sp}/4)^{1/3}$ |
| 滯留時間 | $\tau = M/F$ |
| Nernst | $E = E^\circ - (0.0592/z)\log Q$；$\Delta G = -zFE$ |
| $E^\circ$ 與 $K$ | $E^\circ = (0.0592/z)\log K$ |
| pε | $p\varepsilon = -\log a_{e^-} = E/0.0592$；$p\varepsilon^\circ = (1/n)\log K$ |
| 水的穩定範圍 | 上界 $p\varepsilon = 20.75 - \mathrm{pH}$；下界 $p\varepsilon = -\mathrm{pH}$ |
| 常數 | $R = 8.314\ \mathrm{J/(mol\cdot K)}$；$F = 96{,}485\ \mathrm{C/mol}$ |
| 換算 | $1\ \mathrm{cm^3} = 1\ \mathrm{J/MPa}$；$2.303RT/F = 0.0592\ \mathrm{V}$（25 °C） |
