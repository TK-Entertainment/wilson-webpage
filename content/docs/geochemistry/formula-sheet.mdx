| 主題 | 公式 |
|---|---|
| Hubble 年齡 | t = 1/H₀ = d/v |
| 結合能 | BE = N·mₙ + Z·mₚ + Z·mₑ − M；BE/A |
| 分配係數 | D = Cs/CL；bulk D = Σ xᵢDᵢ |
| Batch melting | CL/C₀ = 1/\[D(1−F)+F\]；F→0 時為 1/D |
| 第一定律 | dU = dQ + dW = TdS − PdV |
| 熵 | dS = dQrev/T；S = k ln Ω |
| 焓 | H = U + PV；ΔH = ∫Cp dT；ΔS = ∫(Cp/T)dT |
| Gibbs | G = H − TS；dG = VdP − SdT |
| G 對 P、T | (∂ΔG/∂P)T = ΔV；(∂ΔG/∂T)P = −ΔS |
| Clapeyron | dP/dT = ΔS/ΔV = ΔH/(TΔV) |
| 相律 | f = c − φ + 2；c = n − r |
| 化學勢 | μᵢ = μᵢ° + RT ln aᵢ |
| 平衡常數 | ΔG° = −RT ln K；ΔG = ΔG° + RT ln Q |
| van't Hoff | ln K = −ΔH°/RT + ΔS°/R |
| 一階動力學 | \[A\] = \[A\]₀e^(−kt)；t½ = ln2/k |
| Arrhenius | k = A·e^(−Ea/RT) |
| 碳酸常數 25 °C | K\_CO₂ = 10^−1.47；K₁ = 10^−6.35；K₂ = 10^−10.33；Kw = 10^−14 |
| 鹼度 | Alk = \[HCO₃⁻\] + 2\[CO₃²⁻\] + \[OH⁻\] − \[H⁺\] |
| 緩衝強度 | β = dC\_B/dpH |
| Ksp 溶解度 | AB: x = √Ksp；AB₂: x = (Ksp/4)^(1/3) |
| 滯留時間 | τ = M / F |
| Nernst | E = E° − (0.0592/z)·log Q；ΔG = −zFE |
| E° 與 K | E° = (0.0592/z)·log K |
| pε | pε = −log a\_e = E/0.0592；pε° = (1/n) log K |
| 水的穩定 | 上界 pε = 20.75 − pH；下界 pε = −pH |
| 常數 | R = 8.314 J/mol·K；F = 96,485 C/mol；1 cm³ = 1 J/MPa；2.303RT/F = 0.0592 V（25 °C） |
