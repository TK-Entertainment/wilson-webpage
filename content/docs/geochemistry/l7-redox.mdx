**本章重點**

1. **pε = −log a<sub>e⁻</sub> = E/0.0592**，數值越大越氧化。
2. 水的穩定範圍：**pε = 20.75 − pH**（上界）到 **pε = −pH**（下界）。
3. 缺氧時微生物依能量高低輪流用：**O₂ → NO₃⁻ → MnO₂ → Fe(III) → SO₄²⁻ → CH₄**。

**pε–pH 圖：水的穩定範圍 ＋ 硫系統**

**Redox ladder：有機物越多，pε 一階一階往下走**

依 L7 p.26 的圖重畫（pH 7）。每一階都是一種電子接受者被用完，才換下一種。MnO₂、Fe(III) 是**不溶的固體**，被還原成可溶的 Mn²⁺、Fe²⁺，所以孔隙水中的 Mn、Fe 會在對應深度突然增加。SO₄²⁻ 那一階的 −3.7 就是下面例題算出來的邊界。

水的兩個 master variables：**pH** 與 **redox state**。

## 氧化數規則（a–f）

1. 化合物中各原子氧化數總和 = 該化合物的電荷（SO₄²⁻：O = −2，S = +6）
2. 只和自己鍵結（純共價）的原子 = 0（O₂、N₂、H₂）
3. O 一律 −2，過氧化物（H₂O₂、Na₂O₂）例外，為 −1
4. H 一律 +1；例外：H₂ 為 0、金屬氫化物為 −1
5. 鹵素 −1；例外：跟自己鍵結、跟 O 鍵結時
6. 鹼金屬 +1、鹼土金屬 +2

|---|---|---|---|---|---|---|---|---|---|---|
| 氧化數 | S −2 | S +6 | N +5 | N −3 | C −4 | C 0 | C +4 | Mn +4 | Fe +8/3 | Fe +2, S −1 |

氧化數只是電荷分布的近似：離子鍵（NaCl）接近真實，共價鍵（N–O：N = +2）不真實，但用來平衡電子流很有用。

## 半反應

每個氧化還原反應 = 一個氧化半反應 + 一個還原半反應。平衡步驟：電子 → O（加 H₂O）→ H（加 H⁺）。

> NO + ClO⁻ ⇌ NO₂ + Cl⁻  
> = NO + H₂O ⇌ NO₂ + 2e⁻ + 2H⁺ ＋ ClO⁻ + 2H⁺ + 2e⁻ ⇌ Cl⁻ + H₂O

## 電位 E<sub>H</sub> 與 Nernst 方程式

- 標準氫電極：½H₂(g) ⇌ H⁺ + e⁻，定義 E = 0。
- 符號規則：**E<sub>H</sub> \> 0** → 金屬離子會被 H₂ 還原成金屬（強氧化劑，例如 Au³⁺、O₂）；**E<sub>H</sub> \< 0** → 金屬被氧化成離子、H⁺ 被還原（例如 Zn²⁺/Zn = −0.763 V）。

> **ΔG = −zFE** ΔG = ΔG° + RT ln Πaᵢ^νᵢ  
> **E = E° − (RT/zF)·ln Πaᵢ^νᵢ** 25 °C：E = E° − (0.0592/z)·log Πaᵢ^νᵢ  
> 平衡時：E° = (RT/zF)·ln K = **(0.0592/z)·log K**  
> ⚠ 投影片寫「E° = 0.0592/z × lnK」，0.0592 已經包含 ln10 的換算，所以應該配 **log K**。F = 96,485 C/mol。

<details>
<summary>【例題】求 Fe³⁺ + 3e⁻ ⇌ Fe 的 E<sub>H</sub>（已知 Fe³⁺/Fe²⁺ = 0.77 V，Fe²⁺/Fe = −0.44 V）</summary>

**E 不能直接相加**，要先換成 ΔG（ΔG 才是可以相加的狀態函數）：

ΔG₁ = −1·F·(0.77)；ΔG₂ = −2·F·(−0.44) = +0.88F → ΔG = −0.77F + 0.88F = +0.11F

E = −ΔG/(3F) = −0.11/3 ≈ **−0.037 V**

</details>

## pε（電子活度）

> **pε ≡ −log a<sub>e⁻</sub>** **pε = F·E / (2.303RT) = E / 0.0592**（25 °C）  
> pε° = (1/n)·log K  
> Fe³⁺ + e⁻ ⇌ Fe²⁺：K = a<sub>Fe²⁺</sub>/(a<sub>Fe³⁺</sub>·a<sub>e⁻</sub>) → **pε = log K − log(a<sub>Fe²⁺</sub>/a<sub>Fe³⁺</sub>)**，pε° = 0.77/0.0592 ≈ 13.0

- **pε 越高 → 越氧化**（電子越少）；−pε 可以看成電子的可得性。pε 是一個為了方便放進平衡常數框架而定義的「假想單位」，天然系統中很難直接測量。

## pε–pH 圖

> 水的上界（氧化）：2H₂O → O₂ + 4H⁺ + 4e⁻，E° = 1.23 V → **pε = 20.75 − pH**（P<sub>O₂</sub> = 1 atm）  
> 水的下界（還原）：2H⁺ + 2e⁻ → H₂，E° = 0 → **pε = −pH**（P<sub>H₂</sub> = 1 atm）  
> 用 E 表示：E = 1.23 − 0.059pH；E = −0.059pH

- 邊界線的形狀：純酸鹼反應 → **垂直線**（pH = pK）；氧化還原反應不含 H⁺ → **水平線**；氧化還原反應含 H⁺ → **斜線**（斜率 = −m/n，m 是 H⁺ 數，n 是電子數）。
- Fe 圖：Fe³⁺ 在低 pH、高 pε；Fe²⁺ 的範圍很大；Fe(OH)₃ 在中高 pH；強還原、高 pH 時出現 Fe(OH)⁺ 等。

<details>
<summary>【例題】推導 SO₄²⁻ / HS⁻ 邊界（7 \< pH \< 12.9）</summary>

已知：SO₄²⁻ + 8H⁺ + 8e⁻ ⇌ S²⁻ + 4H₂O（log K = 20.74）；HS⁻ ⇌ S²⁻ + H⁺（log K = −12.9）

相加：SO₄²⁻ + 9H⁺ + 8e⁻ ⇌ HS⁻ + 4H₂O，log K = 20.74 + 12.9 = 33.64

log K = log a<sub>HS⁻</sub> − log a<sub>SO₄</sub> + 9pH + 8pε；邊界上 a<sub>HS⁻</sub> = a<sub>SO₄</sub>：

**pε = 4.21 − 1.125 pH** → pH 7 時 pε ≈ −3.7（跟 redox ladder 中 SO₄²⁻ → H₂S 那一階吻合）

pH \< 7 時改用 H₂S（再加 H₂S ⇌ HS⁻ + H⁺，log K = −7）：log K = 40.64 → pε = 5.08 − 1.25 pH

</details>

## 生物控制與 Redox ladder

> H₂O + CO₂ ⇌ \{CH₂O\} + O₂ （光合 →，呼吸 ←）

- 光合作用旺盛 → O₂ 累積、pε 上升（較氧化），而且消耗 CO₂ 使 pH 上升。呼吸作用旺盛則相反。**植物是碳的主要「還原者」，呼吸的生物是「氧化者」**。
- 在缺氧（suboxic／anoxic）環境中，微生物依照**能量產率由高到低**的順序使用電子接受者：

| 順序 | 反應 | 溶解度變化 | pε (pH 7) 約 （補充） |
|---|---|---|---|
| 1 | O₂ → H₂O（有氧呼吸） | — | +13.8 |
| 2 | NO₃⁻ → N₂ / NO₂⁻（脫氮） | 可溶 → 可溶 | +12.6 |
| 3 | MnO₂ → Mn²⁺ | **不溶 → 可溶** | ~+8 |
| 4 | Fe₂O₃ / Fe(OH)₃ → Fe²⁺ | **不溶 → 可溶** | ~−1 |
| 5 | SO₄²⁻ → H₂S | 可溶 → 可溶 | ~−3.5 |
| 6 | CH₂O → CH₃OH（發酵）；CO₂ / CH₂O → CH₄（產甲烷） | — | ~−4 |

- 沉積物孔隙水剖面：往深處 O₂ 先耗盡 → NO₃⁻ 下降 → Mn²⁺ 上升 → Fe²⁺ 上升 → SO₄²⁻ 下降 → CH₄ 出現。
- 其他例子：淹水的土壤（孔隙被水填滿，O₂ 被高 BOD 消耗）；垃圾掩埋場或有機污染物下游的地下水（污染源附近 pE 最低，往下游逐漸恢復）。
- Redox ladder 對 pH 的影響：O₂ 呼吸產生 CO₂ → pH 下降；脫氮、Mn、Fe 還原**消耗 H⁺ → pH 上升**。

### 酸性礦山排水（AMD）

> 4FeS₂ + 14O₂ + 4H₂O → 4Fe²⁺ + 8SO₄²⁻ + 8H⁺ （Thiobacillus ferrooxidans 催化；無機反應很慢）  
> 4Fe²⁺ + O₂ + 4H⁺ → 4Fe³⁺ + 2H₂O （Gallionella 從中獲取能量）  
> 4Fe³⁺ + 12H₂O → 4Fe(OH)₃(s) + 12H⁺ （更多酸；鐵鏽色沉澱）

低 pH 使水具有腐蝕性，整治的目標就是消除這一點。

#### 電化學電池 （p.9）

Zn 片（anode，陽極，−）：Zn → Zn²⁺ + 2e⁻（氧化）；Cu 片（cathode，陰極，+）：Cu²⁺ + 2e⁻ → Cu（還原）。電子經外電路從 Zn 流到 Cu，多孔隔板讓離子流動。量測方法是施加剛好能讓電子停止流動的電壓，這就是電極電位 E。

#### 水的 pε–pH 圖 （p.20）

兩條平行斜線（斜率 −1）把圖分成三區：上方「對水來說太氧化」（水會被氧化成 O₂）、中間「水穩定」、下方「對水來說太還原」（水會被還原成 H₂）。

#### 硫系統 pε–pH 圖的組合方式 （p.22）

(A) 水的穩定區 ＋ (B) 酸鹼平衡（垂直線 pH = 1.98、7、12.9，來自下面的 α 分率曲線：HSO₄⁻/SO₄²⁻、H₂S/HS⁻、HS⁻/S²⁻ 的交叉點）＋ 氧化還原邊界（**非垂直線**）＝ (C) 完整的硫 pε–pH 圖：上方 SO₄²⁻（及低 pH 的 HSO₄⁻），下方 H₂S、HS⁻、S²⁻。

#### 光合–呼吸反應的寫法 （p.23）

> \[H⁺\] + H₂O + CO₂ ⇌ \{CH₂O\} + O₂  
> 酸 + 「還原態」O + 「氧化態」C ⇌ 「還原態」C + 「氧化態」O （往右 = 光合作用，往左 = 呼吸作用）

#### Redox ladder 的 E<sub>h</sub> 尺度（pH 7） （p.25）

O₂/H₂O 約 +0.8 V → NO₃⁻/NO₂⁻、NO₂⁻/NH₄⁺、Mn⁴⁺/Mn²⁺ 約 +0.4–0.5 V → FeOOH/Fe²⁺ 約 0 V → SO₄²⁻/HS⁻、CO₂/CH₄ 約 −0.2 V → H⁺/H₂、HCOO⁻/CH₂O 約 −0.4 V。（÷ 0.0592 就可以換算成 pε。）

#### 沉積物、土壤、地下水的例子 （p.27–30）

- **沉積物**（p.27）：落下的有機物提供還原力，驅動一系列微生物媒介的氧化還原反應 → 孔隙水組成隨深度改變，常常造成**顏色分層**（上層棕色，往下變成橄欖綠、灰色）和氣味變化。p.28：往深處 NO₃⁻（~40 μM）在 ~40 cm 內耗盡，Mn²⁺ 從 ~20 cm 開始上升，Fe²⁺ 在更深處上升。
- **淹水的土壤**（p.29，Sposito 1989）：O₂ 在約 1 天內耗盡 → NO₃⁻ 約 2.5 天耗盡 → Mn(IV) 固體逐漸減少 → Fe²⁺ 在約 4 天後開始大量出現；pE 從約 +7 一路降到約 −2。
- **垃圾掩埋場下游的地下水**（p.30）：從污染源往下游，依序出現 **methanogenic → sulfate-reducing → Fe(III)-reducing → nitrate- and Mn(IV)-reducing → oxic** 帶。污染源附近 pE 最低；剖面中可以看到 CH₄、NH₄⁺、HS⁻、Fe²⁺、Mn²⁺ 的分布。
- **Redox ladder 對 pH 的影響**（p.31，Langmuir 的模擬滴定）：初始條件 8 mg/L DO、0.1 mM NO₃⁻、0.1 mM SO₄²⁻、0.1 mM Fe(OH)₃、0.1 mM MnO₂、Alk 0.83 mM。依序還原 (1) O₂ (2) NO₃⁻ (3) MnO₂ (4) Fe(OH)₃ (5) SO₄²⁻；pH 先從約 7.0 降到約 6.6（O₂ 呼吸產生 CO₂），再升到約 7.4（Mn、Fe 還原消耗 H⁺）。

#### Gallionella 與鐵管腐蝕 （p.33, p.34）

Gallionella 是能催化 Fe²⁺ 氧化來取得能量的微生物。它分泌 Fe(OH)₃ 細絲（stalk）來排除廢棄的 Fe(III)，細絲上可以長出赤鐵礦結晶。鐵管上的「瘤」（tubercle）：外層好氧區由 Gallionella 把 Fe²⁺ 氧化成 Fe(OH)₃；內層厭氧區中 Fe(s) + 2H⁺ → Fe²⁺ + H₂，鐵持續被腐蝕。
