## 1. 熱力學的基本語言

- 熱力學只能用在**平衡系統**。它能預測新的平衡狀態，但**不能**告訴你反應怎麼發生、多快、會不會真的達到平衡（那是 L4 動力學的範圍）。
- 兩個用途：(1) 預測給定 P、T、組成下的穩定狀態；(2) 從保存下來的礦物組合反推形成條件。

**系統的四種類型**

<img src="/img/notes/geochemistry/l3-thermodynamics-1/slide-p4.webp" alt="孤立、絕熱、封閉、開放系統" width="640" height="676" />

*圖：孤立、絕熱、封閉、開放系統。來源：White, W. M. (2013) *Geochemistry*, Wiley-Blackwell Fig. 2.1；Abby Ren〈地球化學〉課程投影片 L3 p.4。*

| 類型 | 質量交換 | 能量交換 |
|---|---|---|
| Isolated（孤立） | ✗ | ✗ |
| Adiabatic（絕熱） | ✗ | 不能傳熱，但可以作功 |
| Closed（封閉） | ✗ | ✓ |
| Open（開放） | ✓ | ✓ |

**平衡、介穩、不穩定**

<img src="/img/notes/geochemistry/l3-thermodynamics-1/slide-p5.webp" alt="平衡、介穩與不穩定狀態" width="640" height="477" />

*圖：山谷中的球。來源：White, W. M. (2013) *Geochemistry*, Wiley-Blackwell Fig. 2.2；Abby Ren〈地球化學〉課程投影片 L3 p.5。*

- **Equilibrium**：最低點，不隨時間變化。
- **Metastable**：較高的小凹槽，也不隨時間變化，但不是能量最低。例如地表的鑽石、貝殼的 aragonite。
- **Unstable**：在斜坡上，會自發改變。

平衡的三種說法：宏觀上不隨時間變化；正、逆反應速率相等；系統沒有限制時會趨向的狀態。

**可逆 vs 不可逆**：可逆過程是理想化的，每一小步都處於平衡，慢到隨時可以倒回去；自然界的過程都以有限速率進行，全部不可逆。後面公式裡的下標 rev 就是 reversible（可逆），不是「逆反應」。

### 狀態函數 ★

**狀態函數只看「你現在在哪裡」，不管「你怎麼走過來」**：U、H、S、G、V、T、P 都是。熱 Q 和功 W 不是，它們是「路徑函數」。

用存錢來想：帳戶從 1000 元變成 1500 元，可以存現金，也可以轉帳，比例隨你；但帳戶餘額的變化一定是 +500。餘額就是 U（狀態函數），現金和轉帳就是 Q 和 W。

| 路徑 | 存現金（Q） | 轉帳（W） | 餘額變化（ΔU） |
|---|---|---|---|
| A | +500 | 0 | **+500** |
| B | +300 | +200 | **+500** |
| C | +800 | −300 | **+500** |

這就是投影片 p.11 那句：**熱和功「加起來」跟路徑無關，雖然它們各自跟路徑有關**。下面的互動圖用一團氣體實際走三條路給你看：

**為什麼這很重要**：因為只看起點和終點，算的時候可以自己挑一條好算的路。Hess's law（查表相減）、把 E 換成 ΔG 再相加（L7）、從 25 °C、1 bar 的數據推到任意 P、T（第 5 節），全都靠這個性質。

**其他用語**：Intensive（強度性質，跟量無關）：T、P、密度；extensive（廣度性質，跟量有關）：質量、體積、能量。

### 溫度、絕對零度與第零定律（p.10）

- **溫度**是分子平均動能的量度：分子動得越快，溫度越高。
- **用理想氣體定溫標**：壓力固定時 PV = NRT → **V ∝ T**。量氣體體積就能當溫度計（U 形管）。把 V 對 T 的直線往低溫外推，在 **−273.15 °C** 碰到 V = 0，這一點定為**絕對零度（0 K）**。所以 T(K) = T(°C) + 273.15，熱力學公式裡的 T 一律用 K。
- 真實氣體的分子本身有體積，到了絕對零度體積也不會真的變成 0。V = 0 只是理想氣體外推的結果。
- **第零定律**：兩個物體熱平衡 → 溫度相同；A、B 各自和 C 熱平衡 → A、B 互相熱平衡。它保證「溫度」可以拿來比較，溫度計才有意義。

## 2. 為什麼需要 H 和 S：自然界的兩個傾向

投影片 p.29 的直覺說明，是理解這一講的關鍵：要預測反應往哪裡走，得同時考慮兩件事。

| 傾向 | 例子 | 用什麼量描述 | 從哪條定律來 |
|---|---|---|---|
| **能量想變低** | 球往山下滾 | **H**（焓） | 第一定律（第 3 節） |
| **亂度想變大** | 杯子摔碎不會自己拼回去 | **S**（熵） | 第二定律（第 4 節） |

兩個傾向有時候方向相反（例如冰融化：要吸熱、能量上「不想」，但會變亂、亂度上「想」），所以需要一個量把兩邊合起來比：**G = H − TS**（第 5 節）。

接下來三節就照這個順序：先講能量那一邊（H），再講亂度那一邊（S），最後合成 G。

## 3. 能量那一邊：第一定律與焓 H ★

**第一定律：能量守恆**

$$
dU = dQ + dW, \qquad dW = -P\,dV
$$

**U 是內能**：系統內部所有粒子的能量總和，包括原子振動、轉動、移動的動能，以及原子之間（化學鍵）的位能。整塊東西被舉高的重力位能、整體移動的動能不算在 U 裡。可以直接把 U 想成「系統裡裝了多少能量」。

- 能量只會從外面進來（吸熱 Q、外界作功 W）或出去，不會憑空產生。
- dW = −P dV 的負號：體積變大時，系統推開周圍、對外作功，自己的能量變少。

**為什麼要定義 H**：地質過程大多在**定壓**下發生。反應時體積如果變大，系統要推開周圍才有空間，這要花能量（P dV）。所以卡計量到的熱不是 ΔU，而是「ΔU + 推開周圍花的能量」。為了方便，直接定義：

$$
H = U + PV
$$

推導一步一步來（關鍵是 d(PV) 要用乘積法則）：

1. d(PV) = P dV + V dP（寬 P、高 V 的長方形，兩邊都變大，面積多出兩條）
2. dH = dU + P dV + V dP
3. 代入 dU = dQ − P dV：dH = (dQ − P dV) + P dV + V dP
4. −P dV 和 +P dV 抵銷：**dH = dQ + V dP**
5. 可逆時 dQ = T dS：**dH = T dS + V dP**
6. **定壓**時 dP = 0：**dH = dQ<sub>P</sub>**，也就是 ΔH 剛好等於定壓下吸收的熱

**H 怎麼量出數字（p.18–20）**

- 絕對的 H 量不到，只能量**變化量** ΔH。就像海拔要先選海平面當基準。
- 基準：**純元素在 25 °C、1 bar（標準狀態）的 H = 0**。碳的標準狀態是石墨，所以石墨 H = 0、鑽石 +1.86 kJ。
- 化合物的 **ΔH°<sub>f</sub>（生成焓）**：用元素做出它時放出或吸收的熱。例：H₂ + ½O₂ → H₂O(l)，ΔH° = −285.83 kJ/mol。
- **ΔH \< 0 是放熱**：產物能量比較低，多出來的能量以熱跑出去。
- 反應的 ΔH = Σ ΔH°<sub>f</sub>(產物) − Σ ΔH°<sub>f</sub>(反應物)（Hess's law，查 Table 2.2）。

**熱容 C**：讓 1 莫耳物質升高 1 K 需要的熱。熱容反映原子的內部運動：原子能動的方式越多，越難加熱。定壓下 Cp = H 隨溫度變化的速率，所以：

$$
\Delta H = \int C_P\,dT, \qquad C_P = a + bT - cT^{-2}\ \text{（Maier–Kelley）}
$$

熱容固定時就是 Cp × ΔT；礦物的熱容會隨溫度變，所以要積分。

<details>
<summary>【例題 ★】卡計測 Na₂O 的 ΔH<sub>f</sub></summary>

23 g Na 在相當於 5 kg 水的卡計中反應，溫度從 20 °C 升到 29.9 °C（C<sub>p,water</sub> = 75.3 J/mol·K）。

**因果順序**：Na 和 O₂ 反應 → 反應放熱 → 熱被水吸收 → 水溫上升。解題時倒推：水溫上升 → 反應放熱 → ΔH 是負的。

1. 卡計熱容 = 75.3 × (5000 / 18) = 20,917 J/K（整桶水每升高 1 K 要吸多少熱）
2. 放出的熱 = 9.9 × 20,917 = 207.08 kJ
3. 23 g Na = 1 mol Na；一個 Na₂O 有 2 個 Na → 只生成 **0.5 mol** Na₂O
4. 每莫耳：207.08 ÷ 0.5 = 414.16 kJ；放熱加負號 → ΔH<sub>f</sub> = **−414.2 kJ/mol**

水溫下降的話，反應就是吸熱，ΔH 是正的。

</details>

<details>
<summary>【例題 ★】1 mol 石英從 25 °C 加熱到 300 °C 的 ΔH（a = 46.94, b = 0.0343, c = 1,129,680）</summary>

$$
\Delta H = \int (a + bT - cT^{-2})\,dT = a(T_2-T_1) + \frac{b}{2}(T_2^2-T_1^2) + c\left(\frac{1}{T_2}-\frac{1}{T_1}\right)
$$

T₁ = 298.15 K，T₂ = 573.15 K（**一定要換成 K**）

= 46.94(275) + 0.01715(573.15² − 298.15²) + 1,129,680(1/573.15 − 1/298.15)  
= 12,908.5 + 4,109.3 − 1,818.0 = **≈ 15.2 kJ/mol**

陷阱：c 前面是負號，積分 −cT⁻² 得到 +cT⁻¹，所以是 **+c(1/T₂ − 1/T₁)**。

延伸：ΔS = a ln(T₂/T₁) + b(T₂ − T₁) + (c/2)(1/T₂² − 1/T₁²) ≈ **35.5 J/K·mol**

</details>

## 4. 亂度那一邊：第二、三定律與熵 S

**先分清楚第一定律和第二定律**

| | 在講什麼 | 一句話 |
|---|---|---|
| **第一定律** | 能量的**量** | 能量守恆，不會憑空產生或消失 |
| **第二定律** | 變化的**方向** | 宇宙的熵總是增加；熱不能自發從冷流向熱（冷氣不是免費的）；熱不能百分之百轉成功（引擎效率不可能 100%） |

第二定律說的「流失」，意思是能量變得**比較沒用**：集中、可以作功的能量，變成分散的熱，收不回來。能量本身沒有消失。

**熵是什麼（p.13）：排列方式的數量**

$$
S = k\ln\Omega \quad (\Omega = \text{可能的微觀排列數})
$$

投影片 p.13 的圖：兩塊溫度不同的金屬中間有隔熱板，或兩種氣體中間有隔板。拿掉之後，系統會跑到「平均分配」的狀態。不是有什麼力推它，而是平均分配的排法最多、機率最大。右邊的長條圖就是這個意思：中間（平均）的機率最高，兩端（全擠在一邊）幾乎是 0。

**p.14 的三個重點**

1. **熵 ≈ 亂度**：加上限制（隔板），排法變少；拿掉限制，排法變多，看起來就亂。
2. **熵增加 = 我們對系統知道得更少**：排法越多，越無法確定實際是哪一種。
3. **系統的熵可以減少**（例如生命、冷氣房），但周遭的熵必須增加更多，宇宙的總熵仍然增加。

**熵的變化怎麼算**

$$
dS = \frac{dQ_{\text{rev}}}{T}
$$

- rev = **reversible（可逆過程）**，不是逆反應。
- T 是**溫度**，不是時間。同樣吸 100 J 的熱，低溫時造成的「變亂」比高溫時大，所以要除以 T。
- 定壓下 dQ = dH = Cp dT，所以 $\Delta S = \int (C_P/T)\,dT$（p.25）。

**p.15：把熵放進第一定律**

1. 第一定律：dU = dQ + dW
2. 可逆時 dQ = T dS、dW = −P dV
3. 代入：**dU = T dS − P dV**

讀法：體積固定時，熵增加 → 能量增加；熵固定時，體積增加 → 能量減少（對外作功）。這條式子沒有假設定壓；後面的 dH、dG 都是從它推出來的。

**第三定律與絕對熵（p.16–17）**

- 完美晶體在 0 K 時只有一種排法：S = k ln 1 = 0。
- 真實礦物在同一種晶格位置上混了兩種以上的原子（甚至同位素），0 K 時仍有很多排法 → **殘留熵（組態熵）S₀ \> 0**。例：橄欖石 (Mg,Fe)₂SiO₄ 的 M 位置放 Mg 或 Fe；長石、角閃石特別重要。

| 定律 | 一句話 | 管什麼 |
|---|---|---|
| 第零 | 熱平衡可以傳遞 | 定義**溫度** |
| 第一 | 能量守恆，ΔU = Q + W | 定義**內能 U** |
| 第二 | 宇宙的熵只會增加 | 定義**熵 S**，決定方向 |
| 第三 | 完美晶體在 0 K 時 S = 0 | 給熵一個**零點** |

## 5. 兩邊合起來：Gibbs 自由能 G ★

$$
G = H - TS, \qquad \Delta G = \Delta H - T\Delta S\ \text{（定溫）}
$$

- **H 小**（能量低）有利；**S 大**（亂度高）有利；**T** 是亂度的權重，溫度越高，亂度越重要。
- 定溫定壓下，**ΔG \< 0 的方向會自己發生**；**ΔG = 0 是平衡**。

| ΔG（往右） | 意思 | 例子 |
|---|---|---|
| **\< 0** | 往右自發，產物穩定 | 作業：斜長石橄欖岩 → 尖晶石橄欖岩，ΔG = −7.1 kJ |
| **= 0** | 平衡，兩邊一樣穩定（在相界上） | 0 °C 的冰水 |
| **\> 0** | 往右不會發生，**往左**才會；反應物穩定 | 地表石墨 → 鑽石，ΔG = +2865 J |

反應反過來寫，ΔG 變號。所以地表的鑽石「應該」變回石墨，只是反應太慢（介穩態，L4 動力學）。

**熔化：用 G 判斷哪個相穩定**

<MeltingGDemo />

G 對 T 的斜率是 −S。液體的熵比較大，線比較陡，升溫時一定會跑到固體下面。交點就是熔點，那裡 ΔG<sub>m</sub> = 0，所以 **ΔH<sub>m</sub> = T<sub>m</sub>ΔS<sub>m</sub>**，即 T<sub>m</sub> = ΔH<sub>m</sub>/ΔS<sub>m</sub>（p.30）。

**G 怎麼隨溫度、壓力變（p.31）**：跟推 dH 同一招，d(TS) 要用乘積法則。

1. dG = dH − d(TS)
2. d(TS) = T dS + S dT（T 和 S 都可能變）
3. dG = (T dS + V dP) − (T dS + S dT)
4. 負號分配進括號：dG = T dS + V dP − T dS − S dT
5. T dS 抵銷：**dG = V dP − S dT**

$$
\left(\frac{\partial \Delta G}{\partial P}\right)_T = \Delta V, \qquad \left(\frac{\partial \Delta G}{\partial T}\right)_P = -\Delta S
$$

| 改變 | 看什麼 | 有利哪一邊 |
|---|---|---|
| **加壓** | ΔV | 體積**小**的那邊 |
| **升溫** | ΔS | 熵**大**的那邊 |

> **易錯**：dG = dH − T dS 只在**溫度固定**時成立（dT = 0，S dT 那項消失）。ΔG = ΔH − TΔS 就是這個定溫版本，用來判斷「某個溫度下會不會反應」；dG = V dP − S dT 是一般版本，用來判斷「溫度、壓力變了，結果怎麼變」。

**任意 P、T 下的 ΔG（p.32）**：查表只有 25 °C、1 bar 的值。因為 G 是狀態函數，可以從參考狀態出發，先改壓力、再改溫度：

$$
\Delta G_{T,P} = \Delta G_{\text{ref}} + \int \Delta V\,dP - \int \Delta S\,dT \approx \Delta G_{\text{ref}} + \Delta V\,\Delta P - \Delta S\,\Delta T
$$

## 6. 相界與 Clapeyron 方程式 ★

相界就是兩相 ΔG = 0 的線。沿著相界走，ΔG 一直保持 0：

$$
d(\Delta G) = \Delta V\,dP - \Delta S\,dT = 0 \;\Rightarrow\; \frac{dP}{dT} = \frac{\Delta S}{\Delta V} = \frac{\Delta H}{T\,\Delta V}
$$

相界的斜率 = 熵變 ÷ 體積變。大部分相界斜率為正，因為體積大的相通常熵也大（p.45）。

**數據從哪來**：p.26、p.33 的 **Table 2.2**（25 °C、0.1 MPa 的標準數據）。注意兩個單位：ΔH 是 **kJ**、S 是 **J/K**，算 ΔG 前要統一成 J；**V 的單位 cm³/mol = J/MPa**，所以 ΔV × ΔP（MPa）直接得到 J。

| 物質 | ΔH°<sub>f</sub> (kJ) | S° (J/K) | ΔG°<sub>f</sub> (kJ) | V (cm³) |
|---|---|---|---|---|
| graphite | 0 | 5.740 | — | 5.298 |
| diamond | 1.86 | 2.37 | — | 3.417 |
| α-quartz | −910.65 | 41.34 | −856.24 | 22.69 |
| calcite | −1207.30 | 92.68 | −1130.10 | 36.93 |
| aragonite | −1207.21 | 90.21 | −1129.16 | 34.15 |

<details>
<summary>【例題 ★】石墨 → 鑽石的相界</summary>

1. ΔH = 1.86 kJ = **1860 J**；ΔS = 2.37 − 5.74 = **−3.37 J/K**
2. ΔG°(298 K) = ΔH − TΔS = 1860 − 298.15 × (−3.37)。T 是 +298.15 K；兩個負號（公式的減號、ΔS 本身是負的）相乘變正 → 1860 + 1005 = **+2865 J**
3. ΔG \> 0 → 往右不自發，**地表石墨穩定**。
4. ΔV = 3.417 − 5.298 = −1.881 cm³/mol = −1.881 J/MPa。要讓 ΔG 降到 0：2865 + (−1.881) × ΔP = 0 → ΔP ≈ **1,523 MPa ≈ 1.5 GPa**（25 °C）。
5. 斜率 dP/dT = ΔS/ΔV = (−3.37)/(−1.881) ≈ **1.79 MPa/K**，正斜率：溫度越高，需要的壓力越大。

</details>

## 7. 相律：最多幾個相能共存 ★

先分清楚三個詞（用一杯冰紅茶來想）：

| 名詞 | 定義 | 冰紅茶裡 |
|---|---|---|
| **相（phase）** | 均勻、物理上可區分、可以機械分離的物質 | 冰塊、茶水、杯底沒溶掉的糖 → 3 相 |
| **物種（species）** | 實際存在的分子、離子 | H₂O、溶掉的糖分子、各種離子 |
| **成分（component）** | 描述所有相的組成，**最少**需要幾種「原料」；可以自己挑 | 例如 H₂O 和糖 |

- 相 ≠ 化合物：冰和水都是 H₂O，但是兩相；aragonite 和 calcite 都是 CaCO₃，也是兩相。溶進茶裡的糖不是另一相。
- 成分不一定真實存在。同一個化石，只看 aragonite → calcite 用 CaCO₃ 一個成分就夠；要考慮從水中沉澱，就得拆成 Ca²⁺、CO₃²⁻ 兩個。

$$
c = n - r \quad (n = \text{物種數},\ r = \text{獨立反應數})
$$

<details>
<summary>【例題 ★】H₂O、H₂CO₃、HCO₃⁻、CO₃²⁻、H⁺、OH⁻ 系統的 c = ?</summary>

獨立反應：H₂O ⇌ H⁺ + OH⁻；H₂CO₃ ⇌ H⁺ + HCO₃⁻；HCO₃⁻ ⇌ H⁺ + CO₃²⁻ → r = 3

c = 6 − 3 = **3**（例如選 H₂O、H⁺、CO₃²⁻ 當原料，其他三種都能用反應組出來）。再加上電中性條件，有些書會算出 2，**但依投影片的公式答案是 3**。

</details>

<img src="/img/notes/geochemistry/l3-thermodynamics-1/slide-p39.webp" alt="Al₂O₃–H₂O 二元與 Al₂O₃–SiO₂–H₂O 三元系統的成分圖" width="640" height="479" />

*圖：選對成分，就能用最少的成分描述所有相。來源：White, W. M. (2013) *Geochemistry*, Wiley-Blackwell；Abby Ren〈地球化學〉課程投影片 L3 p.39。*

**自由度 f**：可以獨立改變、而不會讓某個相消失的變數數量（通常是 T、P，再加上各相的組成）。

$$
f = c - \varphi + 2 \quad (f = \text{自由度},\ c = \text{成分數},\ \varphi = \text{相數},\ +2 = T \text{ 和 } P)
$$

| 例子 | c | φ | f | 在 P–T 圖上 |
|---|---|---|---|---|
| 純水（一相） | 1 | 1 | 2（divariant） | 一塊面積：T、P 都能自由調 |
| 水 + 蒸氣 | 1 | 2 | 1（univariant） | 一條線：改了 T，P 就被決定 |
| 水的三相點 | 1 | 3 | 0（invariant） | 一個點（273.16 K、0.006 bar） |
| 石墨–鑽石相界 | 1 | 2 | 1 | 一條線 |
| Al₂SiO₅ 三相共存（kyanite 高壓、andalusite 低壓、sillimanite 高溫） | 1 | 3 | 0 | 一個點（約 500 °C、0.4 GPa） |

**相圖**（p.43）：用兩個變數畫圖，標出每個相最穩定的區域。面積內一相（f = 2）、線上兩相共存（f = 1）、點上三相共存（f = 0）。

## 容易混淆的地方

| 容易搞混 | 正確理解 |
|---|---|
| 「能量不能無中生有」是第二定律？ | 是**第一**定律（量）。第二定律講**方向**（熵增加） |
| dS = dQ<sub>rev</sub>/T 的 rev 是逆反應？ | rev = **可逆過程**；分母 T 是**溫度**，不是時間 |
| dG = dH − T dS？ | 只在**定溫**成立；一般情況要用乘積法則，得到 dG = V dP − S dT |
| ΔG \> 0 代表反應不會發生？ | 往右不會，**往左**會；反應物比較穩定 |
| 石墨 → 鑽石 ΔG \> 0，為什麼鑽石還在？ | 熱力學只管方向，不管速度；反應太慢 → 介穩態 |
| U 就是位能？ | U 是**內能**：粒子的動能 + 粒子之間的位能，不含整體的重力位能 |
| 化學勢 μ（L4）是位能？ | 不是。μ 是「多加一點這個成分，G 變多少」；名字有 potential，但跟位能無關 |

<details>
<summary>延伸：看過就好（投影片上的推導）</summary>

**理想氣體的熱膨脹係數（p.8）**

$$
\alpha = \frac{1}{V}\left(\frac{\partial V}{\partial T}\right)_P = \frac{1}{V}\cdot\frac{NR}{P} = \frac{1}{T}
$$

**壓力對 H 的影響（定溫，p.23）**：$\Delta H = \int V(1-\alpha T)\,dP$

**熱容（p.21）**：$C = dQ/dT$，$C_P = (\partial H/\partial T)_P$

</details>
