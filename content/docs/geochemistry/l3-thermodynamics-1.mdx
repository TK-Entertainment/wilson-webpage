**這講在回答**：給定溫度、壓力，哪一個礦物（相）會穩定？一個反應會不會自己發生？

**考前 30 秒**

1. $G = H - TS$；定溫定壓下，反應往 G 降低的方向走，兩邊 G 相等就是平衡。
2. $dG = V\,dP - S\,dT$：加壓有利體積小的相，升溫有利熵大的相。
3. 相律 $f = c - \varphi + 2$；相界斜率 $dP/dT = \Delta S/\Delta V$（Clapeyron）。

**主線**：先定義系統和平衡 → 第一定律管能量（H），第二定律管亂度（S）→ 把兩者合成一個判準 G = H − TS → G 隨 P、T 怎麼變（dG = VdP − SdT）→ 兩個相的 G 相等的地方就是相界，相界的斜率是 Clapeyron → 相律告訴你最多幾個相能共存。

★ = 考試重點。

## 1. 熱力學能回答什麼、不能回答什麼

- 熱力學只能用在**平衡系統**。它能預測新的平衡狀態，但**不能**告訴你反應怎麼發生、多快、會不會真的達到平衡（那是 L4 動力學的範圍）。
- 兩個用途：(1) 預測給定 P、T、組成下的穩定狀態；(2) 從保存下來的礦物組合反推形成條件。

**系統的四種類型**

<img src="/img/notes/geochemistry/l3-thermodynamics-1/slide-p4.webp" alt="孤立、絕熱、封閉、開放系統" width="640" height="676" />

*圖：孤立、絕熱、封閉、開放系統。來源：White, W. M. (2013) *Geochemistry*, Wiley-Blackwell Fig. 2.1；Abby Ren〈地球化學〉課程投影片 L3 p.4。*

| 類型 | 質量交換 | 能量交換 |
|---|---|---|
| Isolated（孤立） | ✗ | ✗ |
| Adiabatic（絕熱） | ✗ | 不能傳熱，但可以作功 |
| Closed（封閉） | ✗ | ✓ |
| Open（開放） | ✓ | ✓ |

**平衡、介穩、不穩定**

<img src="/img/notes/geochemistry/l3-thermodynamics-1/slide-p5.webp" alt="平衡、介穩與不穩定狀態" width="640" height="477" />

*圖：山谷中的球。來源：White, W. M. (2013) *Geochemistry*, Wiley-Blackwell Fig. 2.2；Abby Ren〈地球化學〉課程投影片 L3 p.5。*

- **Equilibrium**：最低點，不隨時間變化。
- **Metastable**：較高的小凹槽，也不隨時間變化，但不是能量最低。例如地表的鑽石、貝殼的 aragonite。
- **Unstable**：在斜坡上，會自發改變。

平衡的三種說法：宏觀上不隨時間變化；正、逆反應速率相等；系統沒有限制時會趨向的狀態。

**幾個用語**

- **狀態函數**只跟目前狀態有關，跟路徑無關：U、H、S、G、V。**熱 Q 和功 W 不是狀態函數**，但兩者的和（ΔU）是。
- Intensive（強度性質，跟量無關）：T、P、密度；extensive（廣度性質，跟量有關）：質量、體積、能量。
- 可逆過程是理想化的（每一步都處於平衡）；自然過程都不可逆。

## 2. 第一定律：能量守恆 → 焓 H ★

$$
dU = dQ + dW, \qquad dW = -P\,dV
$$

地質過程大多在**定壓**下發生，所以改用焓 H，它的變化量就是定壓下吸收或放出的熱：

$$
\begin{aligned}
H &= U + PV, \qquad dH = T\,dS + V\,dP, \qquad dH = dQ_P\ \text{（定壓）} \\
\Delta H &= \int C_P\,dT, \qquad C_P = a + bT - cT^{-2}\ \text{（Maier–Kelley）}
\end{aligned}
$$

- 標準狀態 298.15 K、0.1 MPa（25 °C、1 bar）下，**元素的 H = 0**。化合物的 **ΔH°<sub>f</sub>** 是由元素生成它時的熱。
- **ΔH \< 0 是放熱**，例如 H₂ + ½O₂ → H₂O(l)，ΔH° = −285.83 kJ/mol。
- 反應的 ΔH<sub>r</sub> = Σ ΔH<sub>f</sub>(產物) − Σ ΔH<sub>f</sub>(反應物)（Hess's law，查 Table 2.2）。
- 熱容 C<sub>P</sub> 反映原子的內部運動。

<details>
<summary>【例題 ★】卡計測 Na₂O 的 ΔH<sub>f</sub></summary>

23 g Na 在相當於 5 kg 水的卡計中反應，溫度從 20 °C 升到 29.9 °C（C<sub>p,water</sub> = 75.3 J/mol·K）。

1. 卡計熱容 = 75.3 × (5000 / 18) = 20,917 J/K
2. 放出的熱 = 9.9 × 20,917 = 207.08 kJ
3. 23 g Na = 1 mol Na，只生成 **0.5 mol** Na₂O → ΔH<sub>f</sub> = −207.08 / 0.5 = **−414.2 kJ/mol**（放熱，負號）

</details>

<details>
<summary>【例題 ★】1 mol 石英從 25 °C 加熱到 300 °C 的 ΔH（a = 46.94, b = 0.0343, c = 1,129,680）</summary>

$$
\Delta H = \int (a + bT - cT^{-2})\,dT = a(T_2-T_1) + \frac{b}{2}(T_2^2-T_1^2) + c\left(\frac{1}{T_2}-\frac{1}{T_1}\right)
$$

T₁ = 298.15 K，T₂ = 573.15 K（**一定要換成 K**）

= 46.94(275) + 0.01715(573.15² − 298.15²) + 1,129,680(1/573.15 − 1/298.15)  
= 12,908.5 + 4,109.3 − 1,818.0 = **≈ 15.2 kJ/mol**

陷阱：c 前面是負號，積分 −cT⁻² 得到 +cT⁻¹，所以是 **+c(1/T₂ − 1/T₁)**。

延伸：ΔS = a ln(T₂/T₁) + b(T₂ − T₁) + (c/2)(1/T₂² − 1/T₁²) ≈ **35.5 J/K·mol**

</details>

## 3. 第二、三定律：熵 S

| 定律 | 內容 | 公式 |
|---|---|---|
| 第零定律 | A、B 都和 C 熱平衡，則 A、B 也熱平衡（定義溫度） | — |
| 第一定律 | 能量守恆；熱和功等價 | dU = dQ + dW |
| 第二定律 | 宇宙的熵總是增加；熱不能自發從冷流向熱；引擎效率不可能 100% | dS = dQ<sub>rev</sub>/T |
| 第三定律 | 完美晶體在 0 K 時熵 = 0 | S = k ln 1 = 0 |

- **S = k ln Ω**（Ω 是可能的微觀排列數）。系統自發走向排列方式最多、機率最大的狀態，也就是熵最大。
- 系統本身的熵可以減少（例如生命），但周遭的熵必須增加更多。
- 真實礦物在 0 K 仍有 **configurational（residual）entropy**，來自不同原子混在相同晶格位置，例如長石、角閃石。
- 定壓下 $\Delta S = \int (C_P/T)\,dT$。

## 4. Gibbs 自由能：把 H 和 S 合成一個判準 ★

自然界同時有兩個傾向：能量想降低（H 小），亂度想增加（S 大）。G 把兩者合在一起：

$$
\begin{aligned}
G &= H - TS, \qquad dG = V\,dP - S\,dT \\
\left(\frac{\partial \Delta G}{\partial P}\right)_T &= \Delta V, \qquad \left(\frac{\partial \Delta G}{\partial T}\right)_P = -\Delta S
\end{aligned}
$$

- 定溫定壓下，反應往 **G 降低的方向**進行（**ΔG<sub>r</sub> \< 0 自發**）。
- **平衡時兩邊的 G 相等**（ΔG = 0）。
- **加壓有利體積小的相**（ΔV \< 0 的方向）；**升溫有利熵大的相**。

<img src="/img/notes/geochemistry/l3-thermodynamics-1/01.png" alt="誰穩定？看誰的 G 比較低" width="683" height="386" />

圖的意思：G 對 T 的斜率是 −S。液體熵大，線比較陡，升溫時一定會跑到固體下面。交點是熔點，在那裡 ΔG<sub>m</sub> = 0，所以 **ΔH<sub>m</sub> = T<sub>m</sub>ΔS<sub>m</sub>**，即 T<sub>m</sub> = ΔH<sub>m</sub>/ΔS<sub>m</sub>。

要算任意 P、T 下的 ΔG，從參考狀態積分過去：

$$
\Delta G_{T,P} = \Delta G_{\text{ref}} + \int \Delta V\,dP - \int \Delta S\,dT
$$

## 5. 相界與 Clapeyron 方程式 ★

相界就是兩相 ΔG = 0 的線。沿著相界走，ΔG 一直保持 0：

$$
d(\Delta G) = \Delta V\,dP - \Delta S\,dT = 0 \;\Rightarrow\; \frac{dP}{dT} = \frac{\Delta S}{\Delta V} = \frac{\Delta H}{T\,\Delta V}
$$

大部分相界斜率為正，因為體積大的相通常熵也大。

**算題要查 Table 2.2**（298.15 K、0.1 MPa 的標準數據）。注意 **V 的單位 cm³/mol = J/MPa**，這樣 ΔV·ΔP 直接得到 J。

| 物質 | ΔH°<sub>f</sub> (kJ) | S° (J/K) | ΔG°<sub>f</sub> (kJ) | V (cm³) |
|---|---|---|---|---|
| graphite | 0 | 5.740 | — | 5.298 |
| diamond | 1.86 | 2.37 | — | 3.417 |
| α-quartz | −910.65 | 41.34 | −856.24 | 22.69 |
| calcite | −1207.30 | 92.68 | −1130.10 | 36.93 |
| aragonite | −1207.21 | 90.21 | −1129.16 | 34.15 |

<details>
<summary>【例題 ★】石墨 → 鑽石的相界</summary>

1. ΔG°(298 K) = ΔH − TΔS = 1860 − 298.15(2.37 − 5.74) = **+2865 J/mol** → 地表鑽石不穩定（只是反應很慢）。
2. ΔV = 3.417 − 5.298 = −1.881 cm³/mol = −1.881 J/MPa。
3. 要讓 ΔG 降到 0：ΔG + ΔV·ΔP = 0 → ΔP = 2865 / 1.881 ≈ **1,523 MPa ≈ 1.5 GPa**（25 °C）。
4. 斜率 dP/dT = ΔS/ΔV = (−3.37)/(−1.881) ≈ **1.79 MPa/K**，正斜率。

</details>

<details>
<summary>【例題 補充】25 °C、1 bar 下 calcite 和 aragonite 哪個穩定？升壓呢？</summary>

1. calcite → aragonite：ΔG = −1129.16 − (−1130.10) = +0.94 kJ \> 0 → **地表 calcite 穩定**（貝殼的 aragonite 是介穩態）。
2. ΔV = 34.15 − 36.93 = −2.78 cm³/mol \< 0 → 升壓有利於 aragonite。
3. ΔP ≈ 940 / 2.78 ≈ 338 MPa → **約 0.34 GPa**（25 °C）。aragonite 是高壓相（隱沒帶藍片岩）。

</details>

## 6. 相律：最多幾個相能共存 ★

先分清楚三個詞：

- **Phase（相）**：均勻、物理上可區分、可以機械分離的物質。冰水是兩相；aragonite + calcite 雖然都是 CaCO₃，也是兩相；溶在茶裡的糖不是另一相。
- **Species（物種）**：實際存在的化學實體，例如水中的 H₂O、H₂CO₃、HCO₃⁻、CO₃²⁻、H⁺、OH⁻。
- **Component（成分）**：描述所有相的組成所需的**最少**獨立變數，可以自己選。

$$
c = n - r \quad (n = \text{物種數},\ r = \text{獨立反應數})
$$

<details>
<summary>【例題 ★】H₂O、H₂CO₃、HCO₃⁻、CO₃²⁻、H⁺、OH⁻ 系統的 c = ?</summary>

獨立反應：H₂O ⇌ H⁺ + OH⁻；H₂CO₃ ⇌ H⁺ + HCO₃⁻；HCO₃⁻ ⇌ H⁺ + CO₃²⁻ → r = 3

c = 6 − 3 = **3**（例如選 H₂O、H⁺、CO₃²⁻）。再加上電中性條件，有些書會算出 2，**但依投影片的公式答案是 3**。

</details>

<img src="/img/notes/geochemistry/l3-thermodynamics-1/slide-p39.webp" alt="Al₂O₃–H₂O 二元與 Al₂O₃–SiO₂–H₂O 三元系統的成分圖" width="640" height="479" />

*圖：選對成分，就能用最少的成分描述所有相。來源：White, W. M. (2013) *Geochemistry*, Wiley-Blackwell；Abby Ren〈地球化學〉課程投影片 L3 p.39。*

- 二元 Al₂O₃–H₂O：boehmite／diaspore（AlO(OH)）、gibbsite（Al(OH)₃）都在兩端點的連線上，所以 2 個成分就夠。
- 三元 Al₂O₃–SiO₂–H₂O：Al₂SiO₅ 三相在 Al₂O₃–SiO₂ 邊上；kaolinite、pyrophyllite 在三角形內。

有了 c，就能用相律算自由度：

$$
f = c - \varphi + 2 \quad (f = \text{自由度},\ c = \text{成分數},\ \varphi = \text{相數})
$$

| 例子 | c | φ | f | 在 P–T 圖上 |
|---|---|---|---|---|
| 純水（一相） | 1 | 1 | 2（divariant） | 一塊面積 |
| 水 + 蒸氣 | 1 | 2 | 1（univariant） | 一條線（相界） |
| 水的三相點 | 1 | 3 | 0（invariant） | 一個點（273.16 K、0.006 bar） |
| 石墨–鑽石相界 | 1 | 2 | 1 | 一條線 |
| Al₂SiO₅ 三相共存（kyanite 高壓、andalusite 低壓、sillimanite 高溫） | 1 | 3 | 0 | 一個點（約 500 °C、0.4 GPa） |

<summary>延伸：看過就好（投影片上的推導）</summary>

**理想氣體的熱膨脹係數（p.8）**

$$
\alpha = \frac{1}{V}\left(\frac{\partial V}{\partial T}\right)_P = \frac{1}{V}\cdot\frac{NR}{P} = \frac{1}{T}
$$

**焓的推導（p.19）**

$$
dH = dU + V\,dP + P\,dV, \quad dU = T\,dS - P\,dV \;\Rightarrow\; dH = T\,dS + V\,dP
$$

dU = TdS − PdV 的意思：定容時 U 隨 S 增加而增加；定熵時 U 隨 V 增加而減少。

**壓力對 H 的影響（定溫）**：$\Delta H = \int V(1-\alpha T)\,dP$

**熱容（p.21）**：$C = dQ/dT$，$C_P = (\partial H/\partial T)_P$

**狀態函數圖（p.7）**：從狀態 1 到狀態 2 走路徑 A、B、C，狀態函數的變化量都一樣。

**溫度計（p.10）**：用氣體體積隨溫度變化的原理做溫度計（U 形管）。

**熵的圖（p.13）**：兩塊溫度不同的金屬接觸，或兩種氣體之間的隔板拿掉後，能量和分子平均分布的排列方式最多，所以系統自發走向那裡。

</details>
