**本章重點**

1. $G = H - TS$；定溫定壓下，反應往 G 降低的方向走，兩邊 G 相等就是平衡。
2. $dG = V\,dP - S\,dT$：加壓有利體積小的相，升溫有利熵大的相。
3. 相律 $f = c - \varphi + 2$；相界斜率 $dP/dT = \Delta S/\Delta V$（Clapeyron）。

**誰穩定？看誰的 G 比較低**

<img src="/img/notes/geochemistry/l3-thermodynamics-1/01.png" alt="誰穩定？看誰的 G 比較低" width="683" height="386" />

(∂G/∂T)<sub>P</sub> = −S：熵大的相（液體）線比較陡，所以升溫時一定會超過熵小的相。交點是熔點，那裡 ΔG<sub>m</sub> = 0，所以 ΔH<sub>m</sub> = T<sub>m</sub>ΔS<sub>m</sub>。

## 基本觀念

- 熱力學只能用在**平衡系統**。它能預測新的平衡狀態，但**不能**告訴你反應怎麼發生、多快、會不會真的達到平衡（那是動力學的範圍）。
- 熱力學的兩個用途：預測給定 P、T、組成下的穩定狀態；從保存下來的狀態反推形成條件。
- Intensive（強度性質，跟量無關）：T、P、密度；extensive（廣度性質，跟量有關）：質量、體積、能量。
- 平衡的三種定義：宏觀上不隨時間變化；正、逆反應速率相等；系統在沒有限制時會趨向的狀態。
- 可逆過程是理想化的（每一步都處於平衡）；自然過程以有限速率進行，都不可逆。
- **狀態函數**只跟目前狀態有關，跟路徑無關：U、H、S、G、V。**熱 Q 和功 W 不是狀態函數**，但兩者的和是。
- 理想氣體 `PV = nRT`，熱膨脹係數 α = 1/T。

## 熱力學四大定律

| 定律 | 內容 | 公式 |
|---|---|---|
| 第零定律 | A、B 都和 C 熱平衡，則 A、B 也熱平衡（溫度的定義） | — |
| 第一定律 | 能量守恆；熱和功等價；ΔU 與路徑無關 | dU = dQ + dW, dW = −PdV |
| 第二定律 | 宇宙的熵總是增加；熱不能自發從冷流向熱（冷氣不是免費的）；引擎效率不可能 100% | dS = dQ<sub>rev</sub>/T |
| 第三定律 | 完美晶體在 0 K 時熵 = 0 | S = k ln Ω = k ln 1 = 0 |

- 熵 S = k ln Ω（Ω 是可能的微觀排列數）。熵增加，代表我們對系統的知識減少。系統的熵可以減少（例如生命），但周遭的熵必須增加更多。
- 真實物質在 0 K 仍有 **configurational（residual）entropy**，來自不同原子混在相同晶格位置，例如長石、角閃石。

$$
dU = T\,dS - P\,dV \quad \text{（可逆）}
$$

定容時，U 隨 S 增加而增加；定熵時，U 隨 V 增加而減少。

## 焓 H、熱容 C<sub>p</sub>

$$
\begin{aligned}
H &= U + PV, \qquad dH = T\,dS + V\,dP, \qquad dH = dQ_P\ \text{（定壓）} \\
\Delta H &= \int C_P\,dT, \qquad C_P = a + bT - cT^{-2}\ \text{（Maier–Kelley）} \\
\Delta H\big|_T &= \int V(1-\alpha T)\,dP \\
dS &= \frac{dH}{T}\ \text{（定壓可逆）} \;\Rightarrow\; \Delta S = \int \frac{C_P}{T}\,dT
\end{aligned}
$$

- 元素在 298.15 K、0.1 MPa（25 °C、1 bar）的標準狀態下 H = 0。化合物的 **ΔH°<sub>f</sub>** 是由元素生成它時放出的熱。
- ΔH \< 0 是放熱（exothermic），例如 H₂ + ½O₂ → H₂O(l)，ΔH° = −285.83 kJ/mol。
- 反應的 ΔH<sub>r</sub> = Σ ΔH<sub>f</sub>(產物) − Σ ΔH<sub>f</sub>(反應物)（Hess's law，查 Table 2.2）（補充）
- 熱容反映原子的內部運動。

<details>
<summary>【例題】卡計測 Na₂O 的 ΔH<sub>f</sub></summary>

23 g Na 在相當於 5 kg 水的卡計中反應，溫度從 20 °C 升到 29.9 °C（C<sub>p,water</sub> = 75.3 J/mol·K）。

卡計熱容 = 75.3 × (5000 / 18) = 20,917 J/K；放出的熱 = 9.9 × 20,917 = 207.08 kJ。

23 g Na = 1 mol Na，生成 **0.5 mol** Na₂O → ΔH<sub>f</sub> = −207.08 / 0.5 = **−414.2 kJ/mol**（放熱，所以是負號）。

</details>

<details>
<summary>【例題】1 mol 石英從 25 °C 加熱到 300 °C 的 ΔH（a = 46.94, b = 0.0343, c = 1,129,680）</summary>

$$
\Delta H = \int (a + bT - cT^{-2})\,dT = a(T_2-T_1) + \frac{b}{2}(T_2^2-T_1^2) + c\left(\frac{1}{T_2}-\frac{1}{T_1}\right)
$$

T₁ = 298.15 K，T₂ = 573.15 K（**一定要換成 K**）

= 46.94(275) + 0.01715(573.15² − 298.15²) + 1,129,680(1/573.15 − 1/298.15)  
= 12,908.5 + 4,109.3 − 1,818.0 = **≈ 15.2 kJ/mol**

延伸：ΔS = a ln(T₂/T₁) + b(T₂ − T₁) + (c/2)(1/T₂² − 1/T₁²) ≈ **35.5 J/K·mol**

注意：c 前面是負號，積分 −cT⁻² 得到 +cT⁻¹，所以是 +c(1/T₂ − 1/T₁)。

</details>

## Gibbs 自由能（最重要）

$$
\begin{aligned}
G &= H - TS, \qquad dG = V\,dP - S\,dT \\
\left(\frac{\partial \Delta G}{\partial P}\right)_T &= \Delta V, \qquad \left(\frac{\partial \Delta G}{\partial T}\right)_P = -\Delta S \\
\Delta G_{T,P} &= \Delta G_{\text{ref}} + \int \Delta V\,dP - \int \Delta S\,dT \\
\text{熔點：}\ \Delta G_m &= 0 \;\Rightarrow\; \Delta H_m = T_m \Delta S_m
\end{aligned}
$$

- 定溫定壓下，反應往 **G 降低的方向**進行（ΔG<sub>r</sub> \< 0 自發）。**平衡時產物和反應物的 G 相等**（ΔG = 0）。
- 直覺：G 同時考慮了「能量傾向降低」（H）和「熵傾向增加」（S）。
- 升高壓力，有利於體積較小的相（ΔV \< 0 的方向）；升高溫度，有利於熵較大的相。

## 相、物種、成分

- **Phase（相）**：均勻、物理上可區分、可以機械分離的物質。冰水是兩相；aragonite + calcite 雖然都是 CaCO₃，也是兩相；溶解在茶裡的糖不是另一相。
- **Species（物種）**：實際存在的化學實體，例如水中的 H₂O、H₂CO₃、HCO₃⁻、CO₃²⁻、H⁺、OH⁻。
- **Component（成分）**：描述每個相組成所需的最少獨立變數，是代數上的項，可以自己定義。

$$
c = n - r \quad (n = \text{物種數},\ r = \text{獨立反應數})
$$

<details>
<summary>【例題】H₂O、H₂CO₃、HCO₃⁻、CO₃²⁻、H⁺、OH⁻ 系統的 c = ?</summary>

獨立反應：H₂O ⇌ H⁺ + OH⁻；H₂CO₃ ⇌ H⁺ + HCO₃⁻；HCO₃⁻ ⇌ H⁺ + CO₃²⁻ → r = 3

c = 6 − 3 = **3**（例如選 H₂O、H⁺、CO₃²⁻）。如果再加上電中性條件，有些書會算出 2，**但依投影片的公式，答案是 3**。

</details>

## Gibbs 相律

$$
f = c - \varphi + 2 \quad (f = \text{自由度},\ c = \text{成分數},\ \varphi = \text{相數})
$$

- 純 H₂O：一相 → f = 2（divariant，一塊面積）；水 + 蒸氣兩相 → f = 1（univariant，一條線）；三相點 → f = 0（invariant，273.16 K、0.006 bar）。
- Al₂SiO₅（c = 1）：藍晶石（kyanite，高壓）、紅柱石（andalusite，低壓）、矽線石（sillimanite，高溫）。三相共存 → invariant，P、T 都固定（約 500 °C、0.4 GPa）。

## Clapeyron 方程式

<img src="/img/notes/geochemistry/l3-thermodynamics-1/slide-p44.webp" alt="石墨–鑽石相界" width="640" height="637" />

*圖：石墨–鑽石相界。來源：White, W. M. (2013) *Geochemistry*, Wiley-Blackwell；Abby Ren〈地球化學〉課程投影片 L3 p.44。*


$$
\frac{dP}{dT} = \frac{\Delta S}{\Delta V} = \frac{\Delta H}{T\,\Delta V}
$$

相界線在 P–T 圖上的斜率。大部分斜率為正，代表體積大的相通常熵也大。

<details>
<summary>【例題】石墨 → 鑽石 的相界（Table 2.2 數據）</summary>

石墨：ΔH<sub>f</sub> = 0, S = 5.740 J/K, V = 5.298 cm³；鑽石：ΔH<sub>f</sub> = 1.86 kJ, S = 2.37 J/K, V = 3.417 cm³

ΔG°(298 K) = ΔH − TΔS = 1860 − 298.15(2.37 − 5.74) = **+2865 J/mol** → 地表鑽石不穩定（只是動力學上很慢）

ΔV = −1.881 cm³/mol = −1.881 J/MPa（**1 cm³ = 1 J/MPa**）

平衡壓力：ΔG + ΔV·ΔP = 0 → ΔP = 2865 / 1.881 ≈ **1,523 MPa ≈ 1.5 GPa**（25 °C）

斜率 dP/dT = ΔS/ΔV = (−3.37)/(−1.881) ≈ **1.79 MPa/K**，正斜率，跟投影片圖一致。

</details>

#### 理想氣體的熱膨脹係數推導 （p.8）

$$
\left(\frac{\partial V}{\partial T}\right)_P = \frac{\partial}{\partial T}\left(\frac{NRT}{P}\right) = \frac{NR}{P} \;\Rightarrow\; \alpha = \frac{1}{V}\left(\frac{\partial V}{\partial T}\right)_P = \frac{NR}{PV} = \frac{1}{T}
$$

#### 溫度計與第一定律 （p.10, p.11）

用氣體體積隨溫度變化的原理做溫度計（U 形管）。第一定律寫成 `ΔU = Q + W` 或 `dU = dQ + dW`。

#### 熵的圖 （p.13）

左：兩塊溫度不同的金屬塊接觸，或兩種氣體之間有隔板 → 拿掉隔熱層或隔板後，能量和分子平均分布的排列方式最多。右：能量分布的機率長條圖，中間（平均分配）的機率最高 → 系統自發走向機率最大的狀態，也就是熵最大。

#### 焓、熱容、G、熔點的完整式子 （p.19, p.21, p.28, p.30）

$$
\begin{aligned}
dH &= dU + V\,dP + P\,dV, \quad dU = T\,dS - P\,dV \;\Rightarrow\; dH = T\,dS + V\,dP \\
C &= \frac{dQ}{dT}, \qquad C_P = \left(\frac{\partial H}{\partial T}\right)_P \\
\Delta G &= \Delta H - T\Delta S \\
T_m &= \frac{\Delta H_m}{\Delta S_m}
\end{aligned}
$$

#### Clapeyron 的推導 （p.45）

$$
d(\Delta G_r) = \Delta V_r\,dP - \Delta S_r\,dT = 0 \;\Rightarrow\; \frac{dT}{dP} = \frac{\Delta V_r}{\Delta S_r} \quad \left(\text{即 } \frac{dP}{dT} = \frac{\Delta S}{\Delta V}\right)
$$
