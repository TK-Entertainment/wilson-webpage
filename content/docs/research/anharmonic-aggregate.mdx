## 3. 單晶 vs 岩石：Cij、為什麼要平均、Voigt / Reuss / Hill

### 問題
實驗量的是一顆晶體，但地震波穿過的是由無數顆、方向隨機的晶體組成的岩石。怎麼從單晶的數據得到岩石的 $K$ 和 $G$？

### 邏輯鏈
1. **晶體是異向性（anisotropic）的。** 原子在不同方向排列不同，所以不同方向的硬度不同。兩個數字（$K$、$G$）不夠用。
2. 一般線性彈性：$\sigma_{ij} = C_{ijkl}\,\varepsilon_{kl}$。$C_{ijkl}$ 叫 **彈性常數（elastic constants）**，或「剛度張量」。
3. **Voigt 記號**：把一對指標縮成一個：$11\to1$、$22\to2$、$33\to3$、$23\to4$、$13\to5$、$12\to6$。於是 $C_{ijkl}$ 寫成 $6\times6$ 的 $C_{ij}$ 矩陣。
4. 這個矩陣是對稱的（來自應變能的存在），所以最多 $6\times7/2 =$ **21** 個獨立常數。
5. **橄欖石是正交晶系（orthorhombic）**：有三個互相垂直的鏡面。對稱性讓「正向應力與剪應變的耦合」以及「不同剪切分量之間的耦合」全部為零。剩下：
   - $C_{11}$、$C_{22}$、$C_{33}$（三個軸向的壓縮剛度）
   - $C_{44}$、$C_{55}$、$C_{66}$（三個剪切剛度）
   - $C_{12}$、$C_{13}$、$C_{23}$（軸向之間的耦合）
   - 共 **9 個**。
6. **為什麼要平均：** 岩石裡晶粒方向隨機。整塊岩石在大尺度上變成近似等向，可以用一組 $K$、$G$ 描述。但「怎麼平均」沒有唯一答案，因為每顆晶粒內部的應力和應變分佈未知。
7. 兩個極端假設：
   - **Voigt（等應變）**：假設每顆晶粒的應變都一樣。這樣會讓軟的方向被「硬撐」，高估剛度 → **上限**。
   - **Reuss（等應力）**：假設每顆晶粒的應力都一樣。這樣讓軟的方向「自由變形」，低估剛度 → **下限**。
   - 真實岩石裡應力和應變都不均勻，所以在兩者之間。Hill（1952，doi:10.1088/0370-1298/65/5/307）用能量論證證明 Voigt $\ge$ 真值 $\ge$ Reuss，並建議取平均。
   - **Hill 平均（VRH）** $= (\text{Voigt} + \text{Reuss})/2$。這只是經驗上好用，沒有物理推導。
   - 更緊的界限是 **Hashin–Shtrikman（HS）界限**（Hashin & Shtrikman 1963，doi:10.1016/0022-5096(63)90060-7）。Abramson 1997 報的就是 HS 平均。

### 方程式
Voigt（直接用 $C$）：

$$
K_V = \frac{(C_{11} + C_{22} + C_{33}) + 2\,(C_{12} + C_{13} + C_{23})}{9}
$$

$$
G_V = \frac{(C_{11} + C_{22} + C_{33}) - (C_{12} + C_{13} + C_{23}) + 3\,(C_{44} + C_{55} + C_{66})}{15}
$$

Reuss（用柔度 $S$ = $C$ 的反矩陣）：

$$
\frac{1}{K_R} = (S_{11} + S_{22} + S_{33}) + 2\,(S_{12} + S_{13} + S_{23})
$$

$$
\frac{15}{G_R} = 4\,(S_{11} + S_{22} + S_{33}) - 4\,(S_{12} + S_{13} + S_{23}) + 3\,(S_{44} + S_{55} + S_{66})
$$

注意：Reuss 一定要用矩陣求逆得到 $S$，不能用 $1/C_{11}$ 之類的。

### 數字：用 Abramson 1997 的 San Carlos 橄欖石實際算一次
**數據查證：** Abramson et al. 1997 摘要（從 Crossref API 取得，doi:10.1029/97JB00682）原文：「In the order (c11, c12, c13, c22, c23, c33, c44, c55, c66) the 1 bar intercepts (gigapascal units) are (320.5, 68.1, 71.6, 196.5, 76.8, 233.5, 64.0, 77.0, 78.7)」。

**更正：** 你給的 $C_{12} = 68.2$，論文摘要寫的是 **68.1**。其餘 8 個一致。

樣品：San Carlos 橄欖石，Fo90（90% 鎂橄欖石端元），初始密度 3.355 g/cm³，室溫（摘要）。

計算（自算，MATLAB `inv(C)`）：

| | $C_{12} = 68.1$（論文） | $C_{12} = 68.2$（你的數字） |
|---|---|---|
| $K_V$ | 131.50 | 131.52 |
| $K_R$ | 127.38 | 127.40 |
| **$K_{\mathrm{VRH}}$** | **129.44** | 129.46 |
| $G_V$ | 79.54 | 79.53 |
| $G_R$ | 76.48 | 76.48 |
| **$G_{\mathrm{VRH}}$** | **78.01** | 78.01 |

單位 GPa。0.1 GPa 的 $C_{12}$ 差異對結果的影響 $\lt  0.02$ GPa，可以忽略。

**交叉檢查：** Abramson 摘要的 HS 平均 $K_{\mathrm{HS}} = 129.4$、$G_{\mathrm{HS}} = 78$，和 VRH 一致到 0.1 GPa。Mao et al. 2015（doi:10.1016/j.epsl.2015.06.045，p.207 正文）用 Brillouin 量同種橄欖石，得 $K_{S0} = 129.8(9)$、$G_0 = 77.8(5)$ GPa。三者互相吻合。

**Voigt–Reuss 差距：** $K$ 差 4.1 GPa（3.2%），$G$ 差 3.1 GPa（3.9%）。這個差距就是「不知道晶粒間怎麼分擔應力」造成的不確定性。

### 和 VBRc 預設值比較：81 從哪裡來？
VBRc：`Gu_0_ol = 81`、`Ku_0_ol = 129`（`Params_Elastic.m:29-30`），旁邊只寫「olivine reference shear modulus」，沒有引用。

我查到的事實：
1. **$K = 129$** 和 Abramson 的 129.4（Fo90）一致。Isaak 1992 摘要也說含鐵橄欖石的 $K_S$ 比純鎂橄欖石高約 1–2 GPa。
2. **$G = 81$ 比 Fo90 的實測值（78）高 3 GPa（3.8%）。**
3. **git 歷史**：VBRc 最早的版本（commit `0d56ccc`，`Params_Elastic.m` 中 Cammarano 分支的註解）寫著：「Cammarano has G_0 = 81 - 31*X_Fe, for X = 0.9 (Mg# 91), G_0 = 78.2」。也就是說，81 是 Cammarano et al. 2003（doi:10.1016/S0031-9201(03)00156-0）參數化中 **$X_{\mathrm{Fe}} = 0$（純鎂橄欖石，Fo100）** 的值。這個註解在 commit `d552e56`（2025-05）重寫時被刪掉。**（2026-11-10 已查證）Cammarano 2003 原文 Table A.1（p. 217）寫橄欖石 $G = 81 - 31\,X_{\mathrm{Fe}}$（$\pm 1\%$），$X_{\mathrm{Fe}}$ = 鐵的莫耳分率；見 `papers/Cammarano_2003.pdf`。**
4. **旁證**：Mao et al. 2015 Table 1 給出橄欖石 $G = 81.6 - 0.38\,X_{\mathrm{Fe}}$（$X_{\mathrm{Fe}}$ 用莫耳百分比；代入 $X_{\mathrm{Fe}} = 10$ 得 77.8，等於他們正文報的 Fo90 實測值，所以單位推論是對的）。Fo100 端元 $\approx 81.6$。
5. **VBRc 論文** Havlin et al. 2021（doi:10.1016/j.pepi.2020.106639；我讀的是 EarthArXiv 版本第 360 行）寫「G0 = 80 at standard temperature and pressure」，又寫 Isaak (1992) 的 $dG/dP = 1.8$。但 Isaak 1992 摘要說量測只在常壓（ambient pressure）下做，所以那篇不可能提供 $dG/dP$。論文、現行程式碼（81、1.4）和最早版本（81、1.8）三者不一致，我無法確定 1.8 的來源（未查證）。

**結論（誠實版）：**
- 81 大概是「純鎂橄欖石」的值，不是 San Carlos Fo90 的值。
- 但 VBRc 預設的溫度斜率來自 Isaak 1992 的 Fo90 樣品。所以預設組合是「Fo100 的 $G_0$ + Fo90 的斜率」，不完全自洽。
- **影響有多大（自算）：** $d\ln V_s = \tfrac12 \ln(81/78) = 1.9\%$。在 1300 °C、3 GPa，VBRc 的 $d\ln V_s/dT = -8.55\times10^{-5}\ \mathrm{/K}$（第 8 節），所以 1.9% 相當於約 220 K。**但這是室溫下的比值**：$G_0$ 差的是一個固定的 3 GPa，在 1300 °C、3 GPa 時 $G$ 只剩約 68 GPa，同樣 3 GPa 佔的比例更大，$V_s$ 是 4.558 vs 4.456 km/s，差 2.3%，**約 260 K 的溫度誤差**（VBRc 2.1.1 自算）。如果你要用 $V_s$ 反推溫度，$G_0$ 的選擇本身就是一個 200 多 K 等級的系統誤差。
- `anharmonic.md:129` 明白說 VBRc 不計算組成對模數的影響，$G_0$ 要使用者自己決定。

### 常見誤解
- **誤解：「Hill 平均是物理上正確的值」。** 不是。它只是 Voigt 與 Reuss 的算術平均，剛好常常接近實驗。
- **誤解：「岩石是等向的，所以 $K$、$G$ 就夠了」。** 只有晶粒方向隨機時才成立。地函的橄欖石常有優選方位（LPO），那時波速有方向性。VBRc 只算等向值（Havlin et al. 2021, 第 348-350 行）。
- **誤解：「Reuss 用 $1/C$」。** 要用整個矩陣的反矩陣。
