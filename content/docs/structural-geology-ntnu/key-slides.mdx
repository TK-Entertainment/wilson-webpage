## Lecture 01　Preface and Overview

- **尺度觀**：要了解大陸變形 → 山脈 → 褶皺與斷層 → 原子尺度的韌性與脆性變形機制。地質學是**歷史性**也是**解釋性**的科學。
- 造山理論的演變：岩漿上推、地球冷卻收縮 → James Hall 地槽說 → Wegener 大陸漂移 → Holmes 地函對流 → Hess 海底擴張。
- **地質構造的七種分類**（老師列得很完整，可用在名詞比較）：
  | 分類依據 | 類別 |
  |---|---|
  | I 形狀 | 平面、曲面、線狀 |
  | II 地質意義 | **原生與非構造**（原生、局部重力、局部密度倒轉如鹽丘、液壓）vs **次生（構造）** |
  | III 形成時間 | 同沉積（波痕、交錯層、生長斷層）、半同期（焰狀構造）、成岩後（節理） |
  | IV 變形機制 | 破裂、摩擦滑動、塑性、擴散 |
  | V 內聚程度 | 脆性（節理、斷層）、韌性（褶皺、葉理）、脆韌性（膝折） |
  | VI 應變 | 壓縮、伸張、走滑 |
  | VII 分布 | 連續、均透（penetrative，劈理）、局部（斷層）、孤立 |
- **應力** σ = F／A；σv = ρgh：地下 1000 m 花崗岩（2700 kg/m³）約 **26.5 MPa ≈ 265 bar**。
- **變形** = 剛體平移 + 剛體旋轉 + **扭曲（distortion，形狀變）** + **膨縮（dilation，體積變）**；扭曲 + 膨縮 = **應變**。均勻 vs 非均勻變形 → B 名詞比較。
- 構造解析六層次：形態、應變、運動、動力、力學、大地構造解析。觀察尺度：微、中、巨、宏觀。
- **Steno 法則**：原始水平、上下疊置、原始側向連續、包裹、截切、化石同類同層。**最不嚇人原則**（Occam's razor）；**觀察和解釋要分開**。
- **位態**：面 090°/45°N（走向／傾角）= 000°/45°（傾向／傾角）；線 30°/315°（傾沒／傾沒方向）。→ A 位態換算。HW1：Table 1.2 的名詞（apparent dip、attitude、cross section、dip、foliation、lineation、pitch、plunge、plunge direction、profile plane、rake、strike、trace、trend）。

## Lecture 02　Primary and Nontectonic Structures → C1

- **原生構造**：顆粒集結後、固結前，只受重力作用形成（壓密、滑移）；**次生構造**：集結後受外力。
- 地層單位：超群 > 群 > 層 > 段 > 岩層（bed，最基本）。層面標為 **S₀**；**facing／younging direction**（變年輕的方向）、current direction。
- **Facing indicators**：粒級層理（濁流、Bouma 序列）、交錯層理（offlap、onlap）、表面印痕（動物足跡、礫石覆瓦、槽鑄型、泥裂、雨滴印痕、波痕、牽引線理、蟲孔）、碎屑岩脈、**荷重鑄型（ball-and-pillow）**。Hjulström–Sundborg 圖：流速與沉積構造。
- **接觸面**三種：沉積、斷層、侵入。沉積接觸：整合 vs **不整合**（假整合、交角不整合、非整合），hiatus。
- **壓密與成岩構造**：泥岩 → 頁岩（parting）；不等量壓密 → 縮小膨脹構造（pinch-and-swell）；**壓溶** → 凹坑礫石（pitted pebble）、**縫合線**、鐵鏽紋（Liesegang banding）。
- **半同期構造**：碎屑流（基質支撐、淘選差）、**滑移（slumping）**、層間構造（intraformational）。
- **鹽構造**：鹽密度低（2.2）、不可壓縮、黏度低；鹽枕 → 鹽丘 → 鹽柱 → 鹽篷；鹽丘上方的正斷層群；重力驅動的鏟狀正斷層與滾動背斜。
- **火成構造**：岩脈（斜交層面）、岩脈群（環狀、放射狀）、岩床（平行層面）、岩蓋；混合岩、捕獲岩；繩狀熔岩、塊狀熔岩、**枕狀熔岩**、**柱狀節理**、流動葉理。
- **撞擊構造**：碎裂錐（shatter cone）、震波變質（石英 → 重矽石）、假玄武玻璃（pseudotachylyte，也可由斷層摩擦熔融形成）。

## Lecture 03　Force and Stress → B、C4

- **力**：體力（∝ 質量）vs 面力（∝ 面積）；四種基本力；F = ma（a = 0 靜力學）。→ B Force vs Stress
- **應力橢球**：三個互相垂直的主應力軸與主應力；三種表示法：應力橢球、**莫爾圓**、應力張量（9 個分量）。→ B Stress vs Strain ellipsoid
- **莫爾圓**：σn = (σ1+σ3)/2 + (σ1−σ3)/2·cos2θ，τ = (σ1−σ3)/2·sin2θ；**最大剪應力 = 軸差應力的一半，作用在法線與 σ1 夾 45° 的面上**。→ C4、HW2
- **軸差應力** σ1 − σ3：地殼只有幾百 MPa、地函幾十 MPa（但足以驅動地函流動）。
- **平均應力** σm = (σ1+σ2+σ3)/3 → **改變體積**；**偏差應力** σdev = σ − σm → **改變形狀**。→ B（每年幾乎都考其中一組）
- **靜水應力／靜岩壓**：σ1 = σ2 = σ3；Pl = ρgh；只改變體積。不均勻應力：三個主應力不等。→ B Hydrostatic vs Lithostatic
- 單軸、雙軸、三軸應力狀態；Lithostatic／Hydrostatic state 的莫爾圓是一個點。

## Lecture 04　Deformation and Strain → B、C3、HW3

- 均勻應變的幾何結果：直線仍直、平行仍平行、圓 → 橢圓；**尺度問題**。
- **縱應變**：伸長率 e = (l − l₀)／l₀；**拉長比** s = 1 + e；**二次拉長比** λ = s²；X = s₁、Y = s₂、Z = s₃。→ B Stretch vs Elongation
- 剪應變 γ = tanψ；變形前後保持垂直的兩條物質線 = 主應變軸 → 應變橢球。
- **Flinn 圖**：a = X/Y、b = Y/Z、**k = (a − 1)/(b − 1)**；**體積變化** Δ = (V − V₀)/V₀，Δ + 1 = XYZ；表觀扁平與表觀收縮（體積變化會讓點偏離 k = 1）。**Ramsay 圖**：ln a、ln b，K = ln a／ln b，等量增量走直線。**應變強度 i = [(X/Y − 1)² + (Y/Z − 1)²]^½**。→ C3（每年 20 分以上）
- **pure shear**（共軸，k<sub>x</sub>k<sub>y</sub> = 1）、**simple shear**（非共軸）、**general shear**；**transtension（橫張）／transpression（橫壓）**。→ B
- 流動參數：速度梯度張量 L = S + W；運動渦度數 **Wk = cos α**（α 是兩條流動漸近線夾角）：pure shear 0、simple shear 1。
- 板岩形成實例：天然板岩的扁平應變常需要約 **50 % 體積損失**（假設平面應變 k = 1 時）；剪切帶中 γ 可達 40。
- **HW3**：由應變資料估計 ψ′ 與方位 θ′、解主應變與方位、畫應變莫爾圓、算面積膨脹。

## Lecture 05　Rheology → C2、HW4

- σ<sub>ij</sub> = C<sub>ijkl</sub>ε<sub>kl</sub>：力／應力、變形／應變、流變（兩者的關係）。同一物質在不同時間尺度下可像固體或液體。
- **應變速率** ė = e／t：30 % 應變 1 天 → 3.5 × 10⁻⁶ /s；1 Ma → 9.5 × 10⁻¹⁵ /s；地質應變率 **10⁻¹² – 10⁻¹⁵ /s**；指甲 2 × 10⁻⁸ /s；隕石撞擊、火山爆發 10⁻² – 10⁻⁴ /s。剪應變率 γ̇ = 2ė。
- **理想彈性（彈簧）**：σ = Ee（Hooke），E 約 10² GPa；**可恢復**、**瞬間**、與時間無關（內部應變能）。剪力模數（剛度）τ = Gγ；**波松比 ν = −e⊥／e∥**（−1 到 0.5；岩石 0.25–0.35；軟木塞 0）；體積模數 K = E／3(1 − 2ν)，可壓縮度 = 1/K。→ C2、C4b
- **理想黏性（唧筒）**：σ = ηė，應變**隨時間**累積、**永久**；黏度 Pa·s（1 poise = 0.1 Pa·s）；水 10⁻³、地函 10²⁰–10²² Pa·s。
- **塑性（滑塊）**：超過降伏應力才有永久且連續的變形；微觀機制：差排、擴散、雙晶。理想塑性（St. Venant）、彈–理想塑性、彈塑性加工硬化。
- **應變硬化**（差排纏結）vs **應變軟化**（粒徑變小、再結晶、流體）。→ B Work hardening vs Work softening
- 組合模型（像電路串聯、並聯）：彈塑性、黏塑性（熔岩、油漆）、**Kelvin（並聯，可恢復但延遲）**、**Maxwell（串聯，短期彈性、長期黏性，地函）**、General linear。
- **非線性**：ė ∝ σⁿ（n > 1）；**有效黏度**隨應力或應變速率增加而**減少**（應力相依黏度）。
- **潛變曲線**（定差應力）：初期、穩態、加速三階段。實驗變因：圍壓、溫度、應變率、孔隙壓。
- **HW4**：用 Excel 做岩石圈強度剖面：花崗岩上地殼、輝長岩下地殼、橄欖岩地函；Byerlee τ = C + μσn 與冪律潛變 ė = Aσⁿ exp(−Q/RT) 取小值。

## Lecture 06　Brittle Deformation → C5、破壞準則題

- **脆性變形**：破裂成長、沿破裂或顆粒接觸滑動、顆粒旋轉與破碎。粉碎化（pulverization，> 100 /s）、**碎裂作用**與**碎裂流**（中尺度看起來是韌性）。
- **破裂模式**：Mode I（張開，⊥ σ3）、Mode II（滑動，⊥ 裂隙前鋒）、Mode III（撕裂，∥ 裂隙前鋒）。單軸 vs 三軸實驗的破壞方式。
- **Coulomb**：τ = C + σn tanφ = C + μσn；**Byerlee**：τ = 0.85σn（σn < 200 MPa）、τ = 50 + 0.6σn（> 200 MPa）。**von Mises** 降伏應力；樣本越大強度越低。
- 理論強度約 10 GPa，實際低很多 → **Griffith 裂隙**：材料中既存的微裂隙尖端應力集中；**Griffith 準則** τ² + 4Tσn − 4T² = 0、**C = 2T**；Navier–Coulomb–Griffith 組合準則。→ 2020 期中
- 應力強度因子 K<sub>I</sub> = σ<sub>t</sub>Y(πc)^½；裂隙長度和粒徑有關 → **細粒岩石比粗粒岩石強**。翼裂隙、破裂終止與交互作用。
- **Amonton 摩擦定律**：摩擦力與正向力成正比 → 既存斷層再活動 τ = μσn′。→ C5d、HW5

## Lecture 07　Joints and Veins → 礦脈題

- 節理：天然、未充填、平面或曲面的破裂；羽狀構造、**扭梳紋（twist hackle，主應力方向旋轉時裂成雁行小節理）**、節理間距與應變量（伸張越多節理越多）；野外調查：節理組、節理系、位態。
- **礦脈分類**（→ 2020 期中）：
  - 晶體形狀：自形、**塊狀（blocky）**、拉長、**纖維狀（fibrous）**；纖維脈又分**同向（syntaxial）**與**反向（antiaxial）**。
  - 成因：既存裂隙再活動；**超壓**：P<sub>f</sub> > σ3、> σ2、> σ1 時可以張開不同方位的裂隙；自然水力破裂 τ = C − μ(σn − P<sub>f</sub>)、σ3′ = σ3 − P<sub>f</sub> < 0。
  - **Crack-seal（一破即封）**：裂隙一形成就被礦物充填，反覆形成纖維。纖維長軸 = 最大伸張方向。
  - 排列：平行脈群、網狀脈群（stockwork）、**雁行脈**（剪切帶中，長軸和帶邊界約 45°）、**S 形雁行脈**（中段被旋轉）。

## Lab 01–02

- **Lab01 位態**：走向是面和水平面交線與正北的夾角；象限式 0–90°、方位式 0–360°（三位數、右手法則）；真傾角在唯一的鉛直面上量；線的方位（bearing／trend）與傾沒角；**rake（pitch）在線所在的面上量**；羅盤、磁偏角；定位：卷尺羅盤、步測羅盤、三點交會、三角網。
- **Lab02 等值圖**：等值線間距固定、不交叉、必閉合或被截切、重複等值線代表坡向反轉；V 字法則；構造等高線圖（關鍵層）、斷層在構造等高線圖上的表現（垂直斷層缺失、正斷層斷口、逆斷層重疊）；形態等高線圖；**isopach（真厚度）vs isochore（鉛直視厚度）**：水平層相等、傾斜層 isochore 較大。→ B（2019–2023 每年考）
