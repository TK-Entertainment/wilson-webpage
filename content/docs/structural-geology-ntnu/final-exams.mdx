## 作答要點

<details>
<summary>左移走滑斷層帶伴生構造</summary>

畫一條東西向的左移斷層（北盤往西、南盤往東）。左移時 **σ1 呈東北–西南向**，和主斷層約夾 45°。伴生構造：
- **R（Riedel）剪裂**：同向（左移），和主斷層夾約 15°（從主斷層**逆時針**轉）。
- **R′ 剪裂**：反向（右移），和主斷層夾約 75°。
- **P 剪裂**：同向，在主斷層另一側、和 R 對稱約 15°。
- **T 張裂**（節理、脈）：平行 σ1。
- **雁行褶皺**、**逆斷層**：軸跡 ⊥ σ1（西北–東南向）；**正斷層**：⊥ 伸張方向。
- 躍階：左移斷層**左階**是鬆弛（拉張盆地、正斷層、負花狀構造），**右階**是受阻（擠壓脊、逆斷層、正花狀構造）。
- 參考：台大〈Ch10〉的 Riedel 圖（那張是右移，左移時全部鏡射）。

</details>

<details>
<summary>五種左剪韌性剪動指標</summary>

每一個畫在左移剪切帶中（上盤往左）：
1. **S–C 組構**：S 面（葉理）和 C 面（剪切面）夾銳角，S 面彎進 C 面的方向指示剪動方向；C′（剪切帶劈理）。
2. **σ 型碎斑**（σ-clast）：碎斑兩側的再結晶尾巴不越過參考線，左右尾巴呈階梯狀錯開，尾巴拖曳的方向即剪動方向。
3. **δ 型斑晶尾巴**（δ-clast）：尾巴越過參考線、彎繞回來（旋轉較強）。
4. **雲母魚**（mica fish）：雲母被拉成和 C 面斜交的菱形（魚形），傾斜方向和 S 面一樣，用 S–C 的方式判讀剪動方向。
5. **斜向晶粒形態**（oblique grain-shape foliation）、**骨牌構造／書架構造**（剛性碎片反向旋轉）、**不對稱褶皺**（S／Z 形）、**剪切帶中的雁行脈**。

</details>

<details>
<summary>變形機制圖</summary>

橫軸同系溫度 T/T<sub>m</sub>、縱軸差應力（正規化），等應變率線。各區：
- **低溫高應力**：脆性破裂／**碎裂流**（cataclasis）。
- **中低溫**：**壓溶**（溶解–沉澱潛變、擴散在流體膜）；**低溫塑性（差排滑移、機械雙晶）**。
- **中高溫中應力**：**差排潛變**（dislocation creep：差排滑移 + 爬移、動態再結晶、晶格優選方位、冪律 ė ∝ σⁿ，n ≈ 3）。
- **高溫低應力、細粒**：**擴散潛變**（Nabarro–Herring 晶內擴散、Coble 晶界擴散，牛頓流 ė ∝ σ／d²），超塑性（晶界滑移）。
- 粒徑越小，擴散潛變區越大。**Pressure solution vs Dislocation creep**：前者靠流體輔助的溶解–沉澱、低溫、物質轉移、形成縫合線與劈理；後者靠晶格內差排移動、較高溫、形成晶格優選方位與動態再結晶。

</details>

<details>
<summary>Anderson 斷層理論</summary>

地表是自由面（不能有剪應力），所以三個主應力之一必為鉛直：
- **σv = σ1 → 正斷層**，傾角約 60°。
- **σv = σ2 → 平移斷層**，鉛直。
- **σv = σ3 → 逆斷層**，傾角約 30°。

莫爾空間：同一個 Coulomb 包絡線，圓碰到包絡線的點 2θ = 90° + φ，斷層面和 σ1 夾約 30°，共軛斷層夾 60°、σ1 平分銳角、交線 ∥ σ2。正斷層時 σv 固定、σh 減少（圓往左擴大）；逆斷層時 σv 固定為 σ3、σH 增加（圓往右擴大）。限制：既存弱面會先再活動、斷層會隨變形旋轉、應力軌跡會偏轉。參考台大〈Ch1〉的 Anderson 圖與〈Ch7〉。

</details>

<details>
<summary>曲滑／曲流褶皺 vs 中立面褶皺</summary>

- **曲滑（flexural slip）**：層與層之間沿層面滑動（像彎一疊紙），各層**平行褶皺**、厚度不變；層面上有**垂直褶皺軸的擦痕**，滑動量在翼部最大、樞紐為 0；伴生層間剪切、楔形逆斷層。**曲流（flexural flow）**：層內流動代替層間滑動，弱層中有剪切、層面劈理。
- **中立面褶皺（neutral-surface／tangential longitudinal strain）**：單一強硬層彎曲，**外弧伸張、內弧縮短**，中間有一個應變為 0 的中立面；外弧有張裂（平行褶皺軸的節理、正斷層、楔形脈），內弧有縮短構造（逆斷層、小褶皺、壓溶劈理）。
- 應變分布：曲滑在翼部集中、樞紐少；中立面在樞紐集中、翼部少。

</details>

<details>
<summary>Pseudotachylyte vs Mylonite、兩種線理、斷層相關褶皺</summary>

- **假玄武玻璃**：斷層快速滑動（地震）時摩擦熱讓岩石局部熔融、急冷形成的玻璃質斷層岩，深色脈、可注入圍岩，代表**脆性、高應變率**；**糜稜岩**：韌性剪切帶中**晶體塑性**（動態再結晶）使粒徑變小、有葉理與線理的斷層岩，代表**較深、較高溫、慢速**。相同：都是斷層帶產物；兩者可以共存（震間韌性、同震脆性）。
- **伸張線理（stretching lineation）**：顆粒或礦物集合體被拉長排列，平行最大伸張 X，代表**運動方向**；**皺紋線理（crenulation lineation）**：早期葉理被後期褶皺成小皺紋，皺紋的樞紐線，代表**兩期變形面的交線**，平行褶皺軸。
- **斷層轉折褶皺**（fault-bend）：上盤越過斷坡–斷坪轉折時被動彎曲，前翼角度由斷坡決定；**斷層擴展褶皺**（fault-propagation）：斷層尖端往前擴展時前方岩層褶皺吸收位移，前翼陡甚至倒轉，向上收斂（三角剪切）；**滑脫褶皺**（detachment）：在弱的滑脫層（鹽、頁岩）上方褶皺，下方沒有斷坡。
- **薄皮 vs 厚皮**：薄皮只在基底滑脫面以上的沉積蓋層變形（台灣西部麓山帶）；厚皮連基盤一起變形。

</details>

<details>
<summary>加分題：視傾角</summary>

公式 tan(視傾角) = tan(真傾角) × sin β，β 是剖面方向和走向的夾角。
- 2023：岩脈走向 255°、崖壁走向 210° → β = 45°；tan δ = tan30° ／ sin45° = 0.816 → **真傾角 ≈ 39.2°**。
- 2024：視傾角 90° → 真傾角就是 **90°**（直立岩脈在任何鉛直剖面上都是 90°）。

</details>

<details>
<summary>期末計算題（2024 期末 B8）</summary>

ρ = 2.5（中文題）、地下水面 100 m、2 km、破壞準則 τ = 0.7σn + 10（φ = 35°、C = 10 MPa）：σv = 49.0、P<sub>f</sub> = 18.6、σ3′ = 30.4 MPa；σ1′ = σ3′(1 + sinφ)／(1 − sinφ) + 2C cosφ／(1 − sinφ) = 3.69 × 30.4 + 38.4 ≈ **150.5 MPa**，總水平最大應力 ≈ **169 MPa**（英文題 ρ = 2.65 時 ≈ 180 MPa）。CCUS 摩擦律 τ = 0.5σn′：莫爾圓超出摩擦線的範圍 2θ ≈ 69°–164°，換成逆斷層的裂隙傾角 **約 8°–56° 不應有既存裂隙**，否則灌注提高孔隙壓時會被活化。

</details>
