## A. 位態換算（16 分，每年必考）

三種寫法：
- **象限式**：走向用 N／S 起算偏 E／W（0–90°），再寫傾角與傾向象限，例：N32°W, 41°NE。
- **方位式**：走向用三位數方位角（0–360°），依**右手法則**（傾向在走向順時針 90° 那一側），例：328°/41°。
- **傾沒式（傾角／傾向）**：例：41°, 058° (dd)。

**換算三步**：(1) 找傾向 dd；(2) 右手法則走向 = dd − 90°；(3) 走向換成象限式（例：122° = S58°E，也就是 N58°W 那條線）。

<summary>逐步詳解（十題）</summary>

**規則**：右手法則走向 = 傾向 − 90°（小於 0 就加 360°）；象限式走向：方位 0–90 → N□E、90–180 → S(180−□)E、180–270 → S(□−180)W、270–360 → N(360−□)W；一條走向線兩端互為反向，例如 S58°E 和 N58°W 是同一條線，習慣寫成 N 開頭。

1. **63°, 212° (dd)**：傾向 212°（SW 象限）→ 右手走向 212 − 90 = **122°** → 方位式 **122°/63°**；122° = S58°E = N58°W → 象限式 **N58°W, 63°SW**。
2. **N32°W, 41°NE**：走向線 N32°W = 328°（另一端 148°）；傾向要在 NE → 和走向垂直的兩個方向是 328 + 90 = 058° 與 238°，取 NE 的 **058°** → 傾沒式 **41°, 058°**；右手走向 058 − 90 = **328°** → **328°/41°**。
3. **36°, 222°**：222 − 90 = **132°** → **132°/36°**；132° = S48°E = N48°W → **N48°W, 36°SW**。
4. **N42°W, 59°NE**：N42°W = 318°；垂直方向 048° 或 228°，取 NE → **59°, 048°**；048 − 90 + 360 = **318°** → **318°/59°**。
5. **73°, 261°**：261 − 90 = **171°** → **171°/73°**；171° = S9°E = N9°W，傾向 261° 在西南側 → **N9°W, 73°SW**。
6. **N75°W, 43°NE**：N75°W = 285°；垂直方向 015° 或 195°，取 NE → **43°, 015°**；015 − 90 + 360 = **285°** → **285°/43°**。
7. **72°, 252°**：252 − 90 = **162°** → **162°/72°**；162° = S18°E = N18°W → **N18°W, 72°SW**。
8. **N73°W, 47°NE**：N73°W = 287°；取 NE 的 **017°** → **47°, 017°**；017 − 90 + 360 = **287°** → **287°/47°**。
9. **S73°E, 71°NE**：S73°E = 107°（另一端 287°）；垂直方向 017° 或 197°，取 NE → **71°, 017°**；右手走向 017 − 90 + 360 = **287°** → **287°/71°**；象限式改寫成 N 開頭：**N73°W, 71°NE**。

## B. 名詞比較（20–28 分，每年 4–7 組）

**作答模板**：① 各自定義（一句）；② 相同處；③ 相異處；④ 關連（公式或圖）。每組 4 分，最好附一個小圖或式子。

<details>
<summary>Isopach vs Isochore（2019–2023）</summary>

都是表示某一岩層**厚度**的等值線圖。**Isopach（等厚線圖）**：垂直層面量的**真厚度**；**isochore（等垂厚線圖）**：沿**鉛直方向**量的**視厚度**。水平岩層兩者相等；傾斜岩層 isochore > isopach（isochore = isopach／cos 傾角）；褶皺岩層的 isochore 會反映傾角變化。isopach 反映原始沉積厚度與變形造成的厚度變化，可用來看沉積盆地形狀、古河道、古地形、不整合、斷層、地層封閉；較好但較難畫（要知道傾角）。

</details>

<details>
<summary>Primary vs Secondary Structures（2022–2024）</summary>

**原生構造**：組成岩石的顆粒集結之後、固結之前，尚未受外力作用、只受重力作用形成的構造（交錯層理、粒級層理、波痕、泥裂、荷重鑄型、枕狀熔岩、柱狀節理、流動構造）。**次生構造**：岩石形成後受外力（構造力）作用形成（節理、斷層、褶皺、葉理）。相同：都是岩體中可描述的幾何現象。相異：形成時間與驅動力（重力／沉積、火成過程 vs 板塊構造力）。關連：原生構造是判斷地層上下與變形前狀態的**參考**（S₀ 層面原始水平），次生構造疊加在上面；有些非構造成因（重力滑動、鹽丘）介於兩者之間。

</details>

<details>
<summary>Stress ellipsoid vs Strain ellipsoid（2019）</summary>

**應力橢球**：描述一點的應力狀態，三個互相垂直的主應力軸 σ1 ≥ σ2 ≥ σ3，各方向的牽引力向量端點構成橢球；是瞬間的「力」。**應變橢球**：單位球均質變形後的形狀，主應變軸 X ≥ Y ≥ Z（= s₁、s₂、s₃）；是累積的「變形結果」。相同：都用三個互相垂直的主軸描述。相異：一個是原因（力／面積）、一個是結果（形狀改變）；應力可以是靜水的（球），應變橢球記錄整個變形歷史。關連：兩者經流變學（σ = Cε）連結；在均向、共軸、小應變時 σ1 ∥ Z（最大壓縮 ↔ 最大縮短），非共軸（simple shear）時應變軸會旋轉，兩者不一定平行。

</details>

<details>
<summary>Mean vs Deviatoric Stress（2019、2023、2024）</summary>

**平均應力** σm = (σ1 + σ2 + σ3)／3，是等向分量，**只改變體積**；**偏差應力** σdev = σ − σm（σ1dev = σ1 − σm…），是非等向分量，**改變形狀**（造成變形、斷層、褶皺）。總應力 = 平均應力 + 偏差應力。靜水（靜岩）狀態下偏差應力為 0。

</details>

<details>
<summary>Differential vs Deviatoric Stress（2021、2022）</summary>

**軸差應力**：σ1 − σ3，是一個**純量**，等於莫爾圓直徑，也等於最大剪應力的兩倍（作用在法線與 σ1 夾 45° 的面上）；地殼中只有幾百 MPa，地函只有幾十 MPa，但足以驅動地函緩慢流動。**偏差應力**：總應力減掉平均應力的**張量**（三個分量）。相同：都描述應力的「不均等」部分，靜水狀態下兩者皆為 0。相異：純量 vs 張量；偏差應力的 σ3dev 可以是負的（看起來像張應力），但總應力仍可全為壓應力。

</details>

<details>
<summary>Hydrostatic vs Lithostatic（2021）</summary>

兩者都是 σ1 = σ2 = σ3 的等向應力狀態，只改變體積不改變形狀。**靜水壓**：靜止液體中任一點的壓力，P = ρ<sub>w</sub>gh（約 10 MPa/km）；**靜岩壓**：靜止岩體中上覆岩石重量造成的壓力，P = ρgh（約 26–27 MPa/km；地下 1 km 花崗岩約 26.5 MPa）。差別在密度（水 1 vs 岩石 2.7 g/cm³）。關連：孔隙水壓通常為靜水壓，有效應力 = 靜岩應力 − 孔隙水壓；被不透水層封住時孔隙壓可超過靜水壓（超壓），接近靜岩壓時岩石容易水力破裂。

</details>

<details>
<summary>Force vs Stress（2022）</summary>

**力**：使物體改變運動狀態的作用，F = ma，向量，單位 N；分**體力**（與質量成正比，如重力）和**面力**（與面積成正比）。**應力**：單位面積上的力（牽引力）σ = F／A，單位 Pa；在一點上要用二階張量（9 個分量）描述，取決於面的方位。同樣的力作用在較小面積上應力較大。地質上看不到應力，只看到應力造成的結果（變形）。

</details>

<details>
<summary>Stretch vs Elongation（2021–2024）</summary>

**伸長率 e** = (l − l₀)／l₀（長度變化量對原長，伸長為正、縮短為負）；**拉長比 s** = l／l₀ = 1 + e。另有**二次拉長比** λ = s² 。s 直接給出應變橢球的半軸長 X = s₁、Y = s₂、Z = s₃，所以比 e 好用。例：10 cm 拉到 15 cm，e = 0.5、s = 1.5。

</details>

<details>
<summary>Pure vs Simple Shear（2022–2024）</summary>

都是**平面應變**（Y 不變）、通常體積不變（k = 1）。**純剪**：**共軸**變形，主應變軸方位不旋轉，沒有內部旋轉（運動渦度數 Wk = 0），兩條流動漸近線互相垂直。**簡單剪**：**非共軸**，平行剪動面的線不變長也不旋轉，主應變軸逐漸旋轉趨近剪動面（Wk = 1），只有一條流動漸近線。兩者之間的叫 general（subsimple）shear（0 < Wk < 1）。

<ShearDemo />

</details>

<details>
<summary>Transpression vs Transtension（2021–2024）</summary>

都是 **general shear**：simple shear（平行剪動帶的走滑）加上 pure shear 分量。**橫壓（transpression）**：走滑 + **垂直剪動帶的縮短**（剪動帶增厚、抬升，伴生逆斷層、褶皺、花狀構造正向，例：受阻躍階、聚合斜向板塊邊界）；**橫張（transtension）**：走滑 + **垂直剪動帶的伸張**（剪動帶變薄、沉陷，伴生正斷層、拉張盆地、負花狀構造，例：鬆弛躍階）。

</details>

<details>
<summary>Strain Softening vs Strain (Work) Hardening（2019、2023、2024）</summary>

都是超過降伏點之後的塑性變形行為。**應變硬化**：持續變形需要**更大**的應力，因為差排互相纏結（dislocation tangle）、堆積，阻礙滑移；應力–應變曲線往上翹。**應變軟化**：持續變形需要的應力**變小**，原因有粒徑變小、動態再結晶、流體加入、礦物相變（糜稜岩化）；常讓變形集中成剪切帶。介於兩者之間是完全塑性（stress 不變）或穩態潛變。

</details>

<details>
<summary>Homogeneous vs Heterogeneous Deformation（2020）</summary>

**均勻變形**：物體每一部分的應變都相同；直線變形後仍是直線、平行線仍平行、圓變成橢圓。**非均勻變形**：各部分應變不同，直線會彎曲、平行線不再平行。是否均勻取決於**觀察尺度**：大尺度非均勻的變形，切成小區域後可當成均勻處理。

</details>

<details>
<summary>Trend vs Strike（2020）、Rake vs Plunge（2024）</summary>

- **Strike（走向）**：**面**和水平面交線的方位（0–360°或象限式）。**Trend（方位、bearing）**：**線**投影到水平面的方位，指向線傾沒的方向。相同：都是水平方向的方位角；相異：一個描述面、一個描述線；面上的走向線本身 plunge 為 0。
- **Plunge（傾沒角）**：線和水平面的夾角，在**鉛直面**上量。**Rake（pitch，側伏角）**：線和水平線（走向線）的夾角，在**該線所在的面**上量。關連：**sin(plunge) = sin(rake) × sin(dip)**；面是鉛直時 rake = plunge，線沿走向時兩者都是 0。

</details>

<details>
<summary>Brittle vs Ductile Behavior（2020）</summary>

**脆性**：變形時岩體內某些面**失去內聚力**，形成破裂並沿破裂滑動（節理、斷層），通常在低溫低圍壓、高應變率；應力–應變曲線在破壞點後應力急降。**韌性**：變形時岩體**沒有失去內聚力**，在中尺度上連續流動（褶皺、葉理），通常在高溫高圍壓、低應變率。兩者是**尺度相關**的「變形樣式」；機制上，碎裂流在中尺度可以是韌性的，所以韌性 ≠ 塑性（晶體塑性機制）。之間有脆韌性轉換（kink）。

</details>

<details>
<summary>Mean vs Deviatoric Strain（2020）</summary>

類似應力的分解：**平均（體積）應變** = 三個主應變的平均，代表體積變化（膨縮 dilation）；**偏差應變** = 總應變減平均應變，代表形狀改變（扭曲 distortion）。應變 = 扭曲 + 膨縮。

</details>

<details>
<summary>Ideal Elastic vs Ideal Viscous Material（2020）</summary>

見 C2：彈性（彈簧）σ = Ee，瞬間反應、可完全恢復、和時間無關；黏性（唧筒）σ = ηė，應變隨時間累積、不可恢復，應力和**應變速率**成正比。

</details>

## C3. 板岩形成的應變路徑（20–28 分）

**公式**（投影片）：X ≥ Y ≥ Z 是三軸長度（由 a、b、c 排序）

$$\text{Flinn } a = X/Y,\quad b = Y/Z,\quad k = \frac{a-1}{b-1},\quad i = \sqrt{(X/Y-1)^2 + (Y/Z-1)^2},\quad V = XYZ$$

- k = 0：單軸扁平（oblate）；0 < k < 1：扁平；k = 1：平面應變；k > 1：雪茄狀（prolate、constriction）；k = ∞：單軸伸長。
- 題目設定：a 向上、b 向南、c 向東；原本是壓密的沉積岩（**層面 bc**，水平），最後變成板岩（**板劈理 ab**，直立）。

<FlinnDemo />

6. **換成傾角**：逆斷層 σ1 水平，平面法線與水平夾 θ，所以平面傾角 = 90° − θ → **16°–39°**。
7. **結論**：傾角約 16°–39°（走向 ⊥ σ1）的既存裂隙在達到新斷層的破壞應力之前就會先沿摩擦面滑動，所以要讓「產生新逆斷層」成立，這個範圍內不能有不連續面。新斷層本身傾角 31°，正好落在這範圍內。
8. **2024 的數字**：c = 134.9、r = 75.9 → sin(2θ − 35°) ≥ 0.7 × 134.9／(75.9 × 1.221) = 94.4／92.7 = 1.02 > 1，**無解** → 用課本 σ1 數據算時，沒有任何角度的既存裂隙會先滑動（圓剛好差一點碰到摩擦線，最接近的是傾角約 28° 的裂隙）。考場若給的 σ1 不同，代同樣步驟。

</details>

<summary>Griffith、Coulomb、von Mises 破壞準則與破裂模式（15 分）</summary>

<FigSource s="Fossen (2016)；課堂投影片 Lecture06"><GriffithFig /></FigSource>

在莫爾圖上畫一條組合包絡線：
- **Griffith**（張力區，σn < 0）：拋物線 τ² + 4Tσn − 4T² = 0（張為負時寫 τ² = 4T(σn + T)）；截距 τ = 2T，所以 **C = 2T**。來自微裂隙尖端的應力集中。
- **Coulomb**（壓力區）：直線 τ = C + μσn。
- **von Mises**（高圍壓、韌性）：**水平線** τ = 常數（降伏應力），和正應力無關。

四種破裂模式（依莫爾圓碰到包絡線的位置）：
1. **張力破裂**（tensile，Mode I）：小圓（差應力 < 4T）碰到包絡線和 σn 軸交點 −T，破裂面 ⊥ σ3（節理、脈）。
2. **混合破裂**（hybrid）：圓碰到拋物線段（σn < 0），破裂面和 σ1 夾 0–30°，有張開也有剪動。
3. **剪動破裂**（shear）：圓碰到 Coulomb 直線，破裂面和 σ1 夾約 30°（共軛）。
4. **韌性破壞**（ductile）：大圓碰到 von Mises 水平線，在最大剪應力面（45°）上發生塑性流動、剪切帶，沒有失去內聚力。

</details>

<details>
<summary>依充填生長方式分類礦脈（10 分）</summary>

<FigSource s="Fossen (2016)；課堂投影片 Lecture07"><VeinTypesFig /></FigSource>

- **依晶體形狀**：自形（euhedral，空腔中自由生長）、**塊狀**（blocky，等軸粒狀，裂隙一次張開後才充填）、拉長狀（elongate）、**纖維狀**（fibrous，crack-seal 反覆破裂、立刻封填）。
- **纖維脈依生長方向**：**同向脈（syntaxial）**：從脈壁往中間長，礦物和圍岩相同（石灰岩中的方解石脈），中線是最後的生長面；**反向脈（antiaxial）**：從中線往兩壁長，礦物和圍岩不同（例：頁岩中的纖維狀方解石），中線常有包裹物；另有伸展型（stretched）、複合型。纖維長軸 = 最大伸張方向。
- **依液壓**：既存裂隙再張開（P<sub>f</sub> > σ3）、超壓（P<sub>f</sub> > σ3 + T，自然水力破裂）；液壓越高，越能在不同方位的裂隙中形成脈。
- **依排列**：平行脈群、網狀脈群（stockwork）、雁行脈（剪切帶中、長軸與帶邊界約 45°）、S 形雁行脈。

</details>

<summary>以有效應力莫爾圓說明降雨會不會引發地震（10 分）</summary>

會，在條件適合時。畫圖：一個在包絡線下方、接近但未觸碰的莫爾圓（斷層臨界應力狀態）。降雨入滲使地下水面上升、孔隙水壓 P<sub>f</sub> 增加 → 有效應力 σ′ = σ − P<sub>f</sub> 降低 → **莫爾圓向左平移、半徑（差應力）不變** → 碰到破壞包絡線（或既存斷層的摩擦線 τ = μσn′）→ 斷層滑動 → 地震。條件：斷層原本就接近臨界、岩體滲透率夠讓水壓傳到震源深度（通常延遲數天到數月），所以多半是小規模的誘發地震（例：大雨後、水庫蓄水、廢水灌注誘發地震）。如果斷層離臨界很遠，降雨造成的水壓變化（幾十 kPa 到 MPa）不足以觸發。
