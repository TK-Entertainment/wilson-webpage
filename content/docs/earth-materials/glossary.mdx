## 考古題名詞（★ 先背這些）

| 名詞 | 中文 | 定義 | 出現 |
|---|---|---|---|
| Minerals | 礦物 | 天然形成、通常由無機作用生成的固體，具規則原子排列，以及一定（可在固溶範圍內變化）且均勻的化學成分 | 2021、2022、2024、2025 |
| Silica tetrahedron | 矽氧四面體 | Si⁴⁺ 居中、四個 O²⁻ 在頂點的 SiO₄⁴⁻；Si–O 鍵強為 O²⁻ 電價一半，氧可再接 Si 或其他陽離子，聚合成各種矽酸鹽結構 | 2025 |
| Polymorph | 同質異形體 | 化學成分相同、因溫壓不同而結構不同的礦物（鑽石／石墨、方解石／霰石） | 2025 |
| Paramagnetic mineral | 順磁性礦物 | 含不成對電子，在外加磁場中順向排列而被微弱吸引，移除後磁性消失（黑雲母、橄欖石） | 2025 |
| Omission solid solution | 缺位固溶體 | 結構中部分原子位置留空而非被取代，電荷由價數變化平衡（磁黃鐵礦 Fe₁₋ₓS） | 2025 |
| Cleavage | 解理 | 沿結構中鍵結弱或面間距大的原子面平整裂開的性質 | 2025 |
| Solid solution | 固溶體 | 晶格中某原子被尺寸、電價相近的原子替換，成分連續變化而結構不變（(Mg,Fe)₂SiO₄） | 2021 |
| Curie temperature | 居禮溫度 | 鐵磁性物質失去自發磁化、變成順磁性的溫度（磁鐵礦約 580 °C）；冷卻通過時記錄地磁場 | 2024 |
| Amorphous solid | 非晶質固體 | 原子沒有長程規則週期排列的固體（黑曜岩、玻璃） | 2024 |
| Secondary twins | 次生雙晶 | 晶體形成後因機械變形或位移型相變產生的雙晶（方解石變形雙晶、石英道芬雙晶） | 2024 |
| Enantiomorph | 對映異構物 | 互為鏡像、無法旋轉疊合的一對晶體或結構（左旋、右旋石英） | 2022 |
| Optic axis | 光軸 | 非均向晶體中光傳播不發生雙折射的方向；一軸晶一條、二軸晶兩條 | 2021 |
| Becke line | 貝克線 | PPL 下兩折射率不同物質交界的亮線，提升鏡筒時往折射率高的一側移動 | 2021、2022 |
| Eutectic point | 共晶點 | 兩種以上固體同時從液體結晶的特定成分與最低溫度；等壓下三相共存、F = 0 | 2024 |
| Concordia age | 諧和年齡 | ²⁰⁶Pb/²³⁸U 與 ²⁰⁷Pb/²³⁵U 兩系統年齡一致、落在諧和曲線上的年齡 | 2021 |
| Sorting | 分選 | 沉積物粒徑分布的集中程度；分選好大小一致 | 2025 |
| Imbrication | 覆瓦狀構造 | 扁平礫石被水流排成同方向傾斜疊靠，可指示古水流 | 2025 |
| Graded bedding | 粒級層理 | 一層之內底粗頂細，多由濁流減速沉降形成，可判上下 | 2024、2025 |
| Saltation | 跳躍 | 顆粒被流體舉起（Bernoulli）再落下的一連串短跳，底負載搬運方式 | 2024 |
| Hummocky cross-stratification | 丘狀交錯層理 | 風暴浪造成的低角度（< 15°）交錯層理，有上凸丘與下凹窪、底部侵蝕面 | 2024 |

## Ch3　如何識別礦物

| 名詞 | English | 定義 |
|---|---|---|
| 晶癖 | crystal habit | 礦物的一般外形，包括生長環境限制造成的不規則面 |
| 晶形 | crystal form | 呈現規則幾何形狀的外觀 |
| 晶簇產狀 | state of aggregation | 細顆粒集合體的形態（顆粒狀、葡萄狀、鮞狀） |
| 光澤 | luster | 礦物表面在反射光下的外觀特性 |
| 條痕 | streak | 礦物粉末的顏色 |
| 晶場理論 | crystal field theory | 過渡金屬 d 軌域被周圍陰離子靜電場分裂成不同能階，吸收特定波長 |
| 分子軌域轉換 | molecular orbital transition | 價電子在相鄰陽離子間轉移造成吸收（藍寶石 Fe²⁺–Ti⁴⁺） |
| 色心 | color center | 晶體缺陷（陰離子空位）困住電子而吸收特定波長（紫螢石、煙水晶） |
| 變彩 | play of color | 不同角度看到不同顏色，蛋白石中 SiO₂ 小球繞射 |
| 貓眼效應 | chatoyancy | 平行纖維或針狀包裹體反射形成一條亮帶 |
| 暈彩 | labradorescence | 拉長石內部層狀結構干涉造成的虹彩 |
| 星光效應 | asterism | 定向針狀包裹體反射散射形成星形光芒 |
| 斷口 | fracture | 沒有特定方向的破裂面 |
| 裂理 | parting | 沿雙晶面、離溶片層等缺陷裂開，非結構固有 |
| 比重 | specific gravity | 物質密度與同體積水的比；取決於原子量與堆積密度 |
| 反磁性 | diamagnetism | 電子全部成對，外加磁場時被微弱排斥（大多數礦物） |
| 鐵磁性 | ferromagnetism | 磁矩在磁區內自發平行排列，移除外場仍保有磁性（磁鐵礦） |
| X 光繞射 | XRD | X 光在原子層間繞射，nλ = 2d sinθ，測晶面間距 |
| 電子探針 | EPMA | 電子束激發特徵 X 光做微區定量成分分析 |
| 高解析穿透式電子顯微鏡 | HRTEM | 電子穿透超薄樣品，看原子尺度晶格影像 |

## Ch4　基礎結晶構造

| 名詞 | English | 定義 |
|---|---|---|
| 元素 | element | 原子核質子數相同、無法用化學方法分解的物質 |
| 離子半徑 | ionic radius | XRD 量陰陽離子最短距離，扣除已知 O²⁻ 半徑求得 |
| 配位數 | coordination number | 中心陽離子周圍配位陰離子的數目 |
| 配位多面體 | coordination polyhedron | 以陽離子為中心、配位陰離子為頂點的多面體 |
| 六方最密堆積 | HCP | ABAB 疊法，配位數 12，填充率 74 % |
| 立方最密堆積 | CCP（FCC） | ABCABC 疊法，配位數 12，填充率 74 % |
| Pauling 法則 | Pauling's rules | 配位、靜電價數、共用 I、共用 II、極度儉省五原則 |
| 靜電價數 | electrostatic valency | 鍵強 = 陽離子電價 ÷ 配位數 |
| 等價鍵結構 | isodesmic | 所有鍵強相等且小於陰離子電價一半（鉻鐵礦） |
| 異價鍵結構 | anisodesmic | 鍵強差異大，部分大於陰離子電價一半（方解石） |
| 中價鍵結構 | mesodesmic | 鍵強等於陰離子電價一半（SiO₄） |
| 共價鍵 | covalent bond | 原子共用電子；硬、熔點高、不導電（鑽石） |
| 離子鍵 | ionic bond | 電子轉移，正負離子吸引（岩鹽） |
| 金屬鍵 | metallic bond | 外層電子自由流動；導電、延展（銅） |
| 凡得瓦力 | van der Waals force | 電荷分布不均的弱吸引；軟（石墨層間、高嶺土） |
| 替換固溶體 | substitutional solid solution | 原子被尺寸相近的原子替換（橄欖石） |
| 間隙固溶體 | interstitial solid solution | 小原子進入結構間隙（綠柱石孔洞中的 Na⁺） |
| 端成分 | end member | 固溶體系列兩端的純成分 |

## Ch5　結晶學

| 名詞 | English | 定義 |
|---|---|---|
| 基元 | motif | 晶體結構中規律重複排列的基本單位 |
| 鏡面 | mirror plane | 對一平面鏡射後重合的對稱要素（m） |
| 旋轉軸 | rotation axis | 繞軸旋轉 360°/n 後重合（n = 1、2、3、4、6） |
| 反演中心 | center of inversion | 每點經中心反演後重合（i = 1̄） |
| 旋轉反演軸 | rotoinversion axis | 旋轉後再反演（n̄） |
| 國際符號 | Hermann–Mauguin notation | 用 n、n̄、m、n/m 表示對稱要素組合的符號 |
| 晶族／點群 | crystal class / point group | 通過晶體中心的對稱要素組合，32 種 |
| 晶系 | crystal system | 依晶軸長度與夾角分的六大類 |
| 單位晶胞 | unit cell | 可無限重複生成整個結構的最小結構單元 |
| 空間格子 | lattice | 每個點的環境都完全相同的假想點陣（14 種 Bravais 晶格） |
| Miller 指數 | Miller index | 晶面在三晶軸截距的倒數化成最小整數 |
| 晶面族 | form | 對稱等價的一組晶面 `{hkl}` |
| 赤平投影 | stereographic projection | 球面極點投影到赤道面的方法 |
| 雙晶 | twin | 同種晶體依對稱關係共生，多出單晶沒有的雙晶要素 |
| 原生（生長）雙晶 | growth (primary) twin | 晶體自由生長時成核錯誤造成的雙晶 |
| 聚片雙晶 | polysynthetic twin | 多個個體依同一雙晶律重複、組成面都平行（斜長石） |
| 輪式雙晶 | cyclic twin | 三個以上個體重複、雙晶軸或雙晶面不平行 |
| 螺旋軸 | screw axis | 旋轉加上平行軸的平移 |
| 滑移面 | glide plane | 鏡射加上平行鏡面的平移 |
| 空間群 | space group | 32 點群加平移要素，共 230 種 |
| 重建型同質異像 | reconstructive polymorphism | 斷鍵重組、活化能高、通常不可逆 |
| 位移型同質異像 | displacive polymorphism | 原子微小位移、不斷鍵、可逆、幾乎瞬間 |
| 有序–無序型 | order–disorder polymorphism | 原子在位置上從有序變無序（鉀長石） |
| 疊型 | polytypism | 相同二維層、不同堆疊方式（雲母、石墨） |

## Ch8　熱力學與動力學

| 名詞 | English | 定義 |
|---|---|---|
| 熱力學 | thermodynamics | 研究能量及其轉換的科學 |

| 相律 | phase rule | P + F = C + 2 |
| Clapeyron 方程式 | Clapeyron equation | 相界斜率 dP/dT = ΔS／ΔV |
| 液相線 | liquidus | 高於此溫度全為液體 |
| 固相線 | solidus | 低於此溫度全為固體 |
| 固溶線 | solvus | 分隔單一固溶體與兩固相共存區 |
| 槓桿定律 | lever rule | 由連結線長度比算兩相比例 |

| 離溶 | exsolution | 冷卻到固溶線下，固溶體分成兩相（條紋長石） |
| CIPW 標準礦物 | norm | 由岩石化學分析計算出的理論礦物組成 |
| 傳輸定律 | transport law | 通量 = −常數 × 強度變數梯度（Darcy、Fick、Fourier） |
| 活化能 | activation energy | 反應發生必須越過的能量障壁 |
| Arrhenius 方程式 | Arrhenius equation | k = A e<sup>−Ea/RT</sup> |
| 封存溫度 | closure temperature | 子元素不再擴散逸失、定年時鐘開始的溫度 |
