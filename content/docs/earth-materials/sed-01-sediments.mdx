**這講在回答**：沉積物從哪裡來？岩石怎麼被拆成碎屑和溶解的離子？碎屑的大小、形狀、分選告訴我們什麼？生物和化學作用又產生哪些沉積物？（羅立老師，對應課本 Ch11–12；投影片是英文，名詞中英都要會。）

**考前 30 秒**

1. 沉積物來源：火成、變質、沉積岩的**風化**。物理風化（沿裂隙破碎：冰凍融解、鹽晶成長、植物根）增加表面積，讓化學風化更快。
2. 雨水溶有 CO₂，pH ≈ **5.3**，微酸 → 加速**水合、碳酸化、水解**（橄欖石碳酸化、鉀長石水解成高嶺石）；化學風化會**移除大氣 CO₂**。
3. **Udden–Wentworth 粒徑**：黏土 < 1/256 mm（0.004）< 粉砂 < 1/16 mm（0.0625）< 砂 < 2 mm < 礫；每級 ×2。
4. **分選（sorting）**：粒徑分布集中程度；海灘、沙漠砂分選好，冰磧分選差。★ 2025 名詞解釋
5. **組構成熟度** = 圓度 + 分選：未成熟 → 次成熟 → 成熟 → 超成熟。**風**磨蝕比河流有效好幾個數量級（空氣黏度低、沒有緩衝），風砂表面有霧面撞擊痕。
6. 抗風化礦物：石英、石榴子石、磁鐵礦、鈦鐵礦、鋯石、電氣石 → **砂積礦床**（金、鈦鐵礦、鑽石、錫石）。
7. 生物碳酸鹽：有孔蟲、顆石藻、珊瑚（霰石）→ 隨時間變成**低鎂方解石**；**CCD** 以下碳酸鹽溶光，只剩**矽質軟泥**（矽藻、放射蟲）。
8. 蒸發岩順序：**碳酸鹽 → 石膏／硬石膏 → 岩鹽 → 鉀鹽**；條帶狀鐵礦層（BIF）只在前寒武紀（3.8–1.8 Ga、0.8–0.6 Ga）。
9. 冰磧（till）**沒有分選**、礫石有擦痕；冰水沉積有分選（kame、esker、紋泥 varve）。

## 1. 風化

### 物理風化

岩石沿**裂隙**破開：
- **岩石尺度**：節理（構造作用、火成岩冷卻、侵蝕抬升卸壓時釋放應力）。
- **礦物尺度**：解理、顆粒邊界。
- 機制：水的**冰凍與融解**、裂隙中**鹽晶成長**、**植物根**生長。
- 意義：提供水（最主要的化學風化劑）進入的通道，並**增加表面積**讓化學風化更快。

### 化學風化

雨水溶有 O₂ 和 CO₂，呈微酸性：大氣 CO₂ 約 390 ppmv 時 **pH ≈ 5.3**，透過**水合**與**碳酸化**反應加速礦物風化：

- 橄欖石的碳酸化：Mg₂SiO₄ + 4CO₂ + 4H₂O → 2Mg²⁺ + 4HCO₃⁻ + H₄SiO₄
- 鉀長石的水解：2KAlSi₃O₈ + 2H⁺ + 9H₂O → Al₂Si₂O₅(OH)₄（高嶺石）+ 2K⁺ + 4H₄SiO₄

這些反應把大氣的 CO₂ 變成 HCO₃⁻ 帶進河流海洋，**移除大氣 CO₂**，是長時間尺度的氣候調節器。

## 2. 碎屑：粒徑、分選、圓度 ★

### 粒徑

碎屑的粒徑和**源岩的粒徑**有關，搬運時因**破碎與磨蝕**而變小。顆粒越細，越容易被水或風搬運。

| 名稱 | 粒徑（mm） | 對應的岩石 |
|---|---|---|
| 巨礫 boulder | > 256 | 礫岩 |
| 中礫 cobble | 64–256 | 礫岩 |
| 細礫 pebble | 4–64 | 礫岩 |
| 粒 granule | 2–4 | 礫岩 |
| 砂 sand | 1/16–2 | 砂岩 |
| 粉砂 silt | 1/256–1/16 | 粉砂岩 |
| 黏土 clay | < 1/256 | 黏土岩、頁岩 |

這是 **Udden–Wentworth 粒徑**，每一級是上一級的 1/2（×2 或 ÷2）。量粒徑：用不同孔徑的篩子過篩，或用雷射／XRD 等方法。

### 分選與圓度

<SortRoundFig />

- **分選（sorting）**：沉積物的**粒徑分布**；分選好 = 大小一致（多數海灘砂、沙漠砂），分選差 = 大小混雜（多數冰河沉積）。（2025 名詞解釋 Sorting）
- **圓度（roundness）**：從來源搬到沉積地點的過程中，**物理磨蝕和進一步化學風化**使顆粒變小、變圓。用和已知圓度的顆粒比對來估計：角狀、次角狀、次圓、圓狀。

### 組構成熟度

| 成熟度 | 特徵 | 意義 |
|---|---|---|
| 未成熟 immature | 角狀、分選差，大量泥和砂混在一起 | 幾乎沒有搬運 |
| 次成熟 submature | 泥被洗掉，但顆粒仍角狀、分選差 | |
| 成熟 mature | 分選好、次角狀 | 搬運很久，或高能環境強烈攪動 |
| 超成熟 supermature | 分選好、圓 | |

**影響成熟速率的因素**：
- **搬運介質**：水的黏度會**緩衝**顆粒間的碰撞；空氣黏度低、沒有緩衝，所以**風的磨蝕比河流有效好幾個數量級**，風吹的顆粒表面布滿細小撞擊痕，呈**霧面（frosted）**。
- **顆粒的抗磨蝕力**：有好**解理**的礦物容易破、**軟**的礦物容易被磨、**易溶**的礦物容易溶掉。例外：金（硬度 2.5–3）非常有延展性，能吸收撞擊而不破。

### 抗風化礦物與砂積礦床

能撐到最後的礦物：主要造岩礦物中的**石英**（火成）、**石榴子石**（變質）；副礦物中的**磁鐵礦、鈦鐵礦、鋯石、電氣石**。比重大的抗風化礦物在河流和海灘中被集中，就是**砂積礦床（placer deposit）**：金、鈦鐵礦、鑽石、錫石（SnO₂）。

## 3. 生物產生的沉積物

### 碳酸鹽沉積物

- **演化**：前寒武紀的碳酸鹽多為化學沉澱；**寒武紀生物大爆發**後轉為生物成因，顯生宙碳酸鹽岩變多。
- 生物碳酸鹽主要是 CaCO₃（石灰岩）：**高鎂方解石**（有孔蟲 Globigerina，含數 % Mg）、**方解石**（顆石藻）、**霰石**（珊瑚、耳石；霰石是高壓穩定相）。生物做的碳酸鹽**會隨時間變成穩定的低鎂方解石（< 5 mol% Mg）**，所以大多數石灰岩是方解石。
- 碎裂方式：波浪水流搬運、其他生物攻擊 → 粒徑**雙峰分布**：礫到砂（破碎骨骼）和泥（骨骼磨碎，或鈣質綠藻如 Penicillus 崩解）。
- **糞粒（pellets、peloids）**：許多生物排遺形成的砂粒大小顆粒。
- **珊瑚礁**：下古生代起出現；藻類 + 造礁珊瑚共生；需要溫暖、清澈、**水深 < 20 m**（光合作用）；低潮時暴露在波浪中，生長與破壞動態平衡，**對環境變化很敏感**。
- **無機碳酸鹽：鮞粒（ooid）**：次圓、砂粒大小，由霰石或方解石**同心層**包覆；出現在**強水流攪動**的地方，因為顆粒必須持續滾動，層才會完整包一圈而不是只長一邊。薄片下看得到層間的小不整合和霰石的放射狀生長。由鮞粒組成的叫**鮞狀石灰岩**。

### 深海：鈣質軟泥、矽質軟泥與 CCD

- 浮游生物沉到海底：**有孔蟲、顆石藻 → 鈣質軟泥**；**矽藻、放射蟲（和海綿骨針）→ 矽質軟泥 → 燧石**。
- **CO₂ 在高壓、低溫下溶解度較大** → 深海冷而高壓，碳酸濃度高，**溶解方解石**。
- **CCD（碳酸鹽補償深度）**：碳酸鹽沉降量等於溶解量的深度；以下沒有碳酸鹽沉積。**霰石的補償深度比方解石淺**（霰石較易溶）。**溶躍面（lysocline）**是溶解開始明顯的深度，通常在方解石飽和面之下。
- 矽質軟泥**沒有深度限制**；侏羅紀以來，CCD 以下的最深海底都覆蓋矽質軟泥。

### 煤與油氣

- **煤**：志留紀（約 420 Ma）第一批陸生植物出現後，植物碎屑才成為沉積物的一部分。形成條件：**埋藏速度 > 氧化分解速度**（例：河口三角洲）。腐爛的有機物消耗氧，Fe³⁺ 不能形成，沉積物呈**灰到黑色**。大量埋藏有機碳會**降低大氣 CO₂**（例：石炭紀）。
- **石油**：沉積物中動植物殘骸埋藏後的**油母質**分解，**油窗約 60–120 °C、2–4 km**。
- **天然氣**：更高溫（100–120 °C 以上）、更深（3–6 km）。再深 → **石墨**。

## 4. 化學沉澱的沉積物

### 蒸發岩

岩石風化產物中約 **20 %** 以溶液移走（Ca²⁺、Mg²⁺、Na⁺、K⁺、SO₄²⁻、Cl⁻、HCO₃⁻…），濃縮到飽和就沉澱。蒸發岩**搬運很少**、**常成層**（礦物、粒徑或雜質濃度的變化）。

<EvaporiteFig />

- 海水：如果完全蒸乾，**岩鹽最多**；**硬石膏**在較高溫、高鹽度時比石膏有利。最易溶的鉀鹽最後才出現（投影片：鉀石鹽 KCl 在 90 % 以上海水蒸發、> 34 °C）。
- 乾燥氣候的**鹽湖**還會有硼酸鹽，例如硼砂 Na₂B₄O₅(OH)₄·8H₂O。
- **紋泥（varve）**：一年一層的沉積。
- 例：美國新墨西哥州白沙國家公園（石膏砂丘）；地中海晚中新世（10–5 Ma）的大量岩鹽。岩鹽密度低，形成**鹽丘、底辟**。

### 條帶狀鐵礦層（BIF）

- 世界最主要的**鐵礦來源**。
- **只出現在前寒武紀**：約 3.8–1.8 Ga，以及 0.8–0.6 Ga。
- 2.8–2.2 Ga 的典型 BIF：明顯的**公分級條帶**：富矽層（燧石或碧玉 = 含細赤鐵礦的燧石；石英）與富鐵層（磁鐵礦、赤鐵礦；菱鐵礦、鐵白雲石、含水鐵矽酸鹽）交替；在**主要缺氧的海洋**、**浪基面以下**形成，層可以連續數百公里。
- 2.2–1.8 Ga：條帶較不發達，常有鮞狀組織（燧石基質中的磁鐵礦–赤鐵礦鮞粒），形成於淺水台地。

## 5. 冰河沉積

- 移動的冰會**磨光**底下的岩石，留下擦痕。
- **冰磧（till）**：從冰層末端或停滯冰塊融化釋出的沉積物，**沒有分選**，很多巨礫有**刻面與擦痕**。
  - **底積冰磧（lodgement till）**：在冰層底部形成，極為緊密。
  - **消融冰磧（ablation till）**：融水帶走細粒後留下的粗粒殘留物。
- **冰水沉積（stratified meltwater deposits）**，有分選、有層理：
  - **冰礫阜（kame）**：沿冰河側邊流動的水沉積。
  - **蛇丘（esker）**：冰下隧道中流動的水沉積。
  - **紋泥（varve）**；外洗平原（outwash plain）。
- **岩石冰河（rock glacier）**：岩屑和冰混合緩慢流動。

<summary>自我檢測 5</summary>

1. 冰磧和冰水沉積最大的差別？
2. lodgement till 和 ablation till 的差別？
3. kame 和 esker 各在哪裡沉積？

**答案**：(1) 冰磧由冰直接堆積，沒有分選、礫石有刻面與擦痕；冰水沉積由融水搬運，有分選和層理。(2) 底積冰磧在冰層底部形成、非常緊密；消融冰磧是融水帶走細粒後剩下的粗粒殘留物。(3) Kame 沿冰河側邊的水流沉積；esker 在冰下隧道中的水流沉積。

## 容易混淆

| 這個 | 那個 | 差別 |
|---|---|---|
| 物理風化 | 化學風化 | 破碎、成分不變／和水 O₂ CO₂ 反應、成分改變 |
| 分選 | 圓度 | 粒徑是否一致／稜角是否磨圓 |
| 成熟 | 超成熟 | 分選好、次角狀／分選好、圓 |
| 水的磨蝕 | 風的磨蝕 | 黏度高、有緩衝／黏度低、霧面撞擊痕、有效很多 |
| 高鎂方解石、霰石 | 低鎂方解石 | 生物原生／隨時間轉變、大多數石灰岩 |
| 溶躍面 | CCD | 溶解開始明顯／沉降 = 溶解，以下沒有碳酸鹽 |
| 鈣質軟泥 | 矽質軟泥 | 有孔蟲、顆石藻，受 CCD 限制／矽藻、放射蟲，沒有深度限制 |
| 石膏 | 硬石膏 | CaSO₄·2H₂O／CaSO₄，較高溫高鹽 |
| 冰磧 | 冰水沉積 | 無分選／有分選、成層 |
| kame | esker | 冰河側邊／冰下隧道 |
