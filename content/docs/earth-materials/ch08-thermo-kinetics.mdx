**這章在回答**：自然界為什麼會變化？往哪個方向變、最後停在哪裡（熱力學）？變得多快（動力學）？為什麼火柴一擦就燒、女王頭卻要幾千年才風化，明明都是和氧反應？

**考前 30 秒**

1. 第一定律 **ΔE = Q − W**（進入系統的熱為正、系統對外作功為正）；膨脹功 **W = PΔV**。
2. **焓 H ≡ E + PV**；等壓下 **ΔH = Q<sub>P</sub>**；ΔH < 0 放熱、> 0 吸熱。★ 2024 C2 推導
3. **熵** ΔS ≡ Q<sub>rev</sub>／T；第二定律 **ΔS ≥ Q／T**，隔離系統總熵只增不減；第三定律 lim<sub>T→0</sub> S = 0。
4. **G = H − TS**，**ΔG = ΔH − TΔS**；ΔG < 0 自發、= 0 平衡、> 0 非自發。★ 2024 C3 推導
5. **(∂G／∂T)<sub>P</sub> = −S**（升溫 G 降，熵大的降得快）；**(∂G／∂P)<sub>T</sub> = V**（加壓 G 升，體積大的升得快）。★ 2022 E3
6. 平衡：G 最低，且所有**強度變數**（T、P、μ）在系統內都相同。★
7. **相律 P + F = C + 2**；等壓相圖 F = C + 1 − P；二元共晶點 F = 0。★
8. 相圖名詞：**液相線、固相線、固溶線、共晶點**；**槓桿定律**算比例。★ 每年必考
9. 傳輸定律 **J = −常數 × d(強度變數)／dx**：Darcy、Fick、Fourier；**Arrhenius k = A e<sup>−Ea/RT</sup>**。★
10. 定年要成立：封閉系統、衰變常數固定、知道初始子元素；**封存溫度**以下時鐘才開始走。

## 1. 基本名詞

- **熱力學**（heat in motion）研究熱、功、電能、化學能等能量的轉換，是工業革命想讓蒸汽機效率最大化的產物，所以很多名詞帶著歷史痕跡。熱力學給出自然反應的**方向**與最後的**平衡狀態**；**動力學**研究**速率**。
- **系統**：必須說清楚空間範圍——一顆被晶面包圍的單晶、被圍岩包住的岩漿庫、一座湖，或湖中想像的 1 m³ 水。

<FigSource s="White (2013)；課堂投影片 Ch8"><SystemTypesFig /></FigSource>

- **熱與功**：ΔE = Q − W。**進入系統的熱為正，系統對外作的功為正**。膨脹功 W = P × ΔV（P 是外部壓力）。Joule 的實驗證明熱和功等價。
- **狀態變數 vs 過程變數**：T、P、V、E、H、S 只看現在的狀態；Q、W 和路徑有關。

<StateFunctionDemo />

- **強度變數**：與系統大小無關，描述局部狀態：T、P、ρ、μ、濃度。**廣度變數**：與大小成正比，系統加倍它也加倍：m、V、E、H、S。
- **能量 = 強度變數 × 廣度變數**（例：PV、TS、μn）。

## 2. 三大定律與 H、S、G ★

| 定律 | 內容 | 式子 |
|---|---|---|
| 第一定律：能量守恆 | 能量不能創造或銷毀，只能轉換 | ΔE = Q − W |
| 第二定律：熵增 | 隔離系統的總熵在自然過程中增加，最大時達到平衡 | ΔS<sub>total</sub> ≥ 0 |
| 第三定律：絕對零度 | 0 K 時完美晶體的熵為零 | lim<sub>T→0</sub> S = 0 |

### 焓 H

廣度變數，定義 **H ≡ E + PV**。等壓下，焓的變化直接等於吸收或放出的熱（例：1 atm 下冰融化、水蒸發）。**放熱 ΔH < 0、吸熱 ΔH > 0**。

【推導 ★ 2024 C2】由 ΔU = Q − W，推導恆壓下 ΔH 與 Q 的關係。

**解**：
1. 定義：U（或 E）是內能、Q 是系統吸收的熱、W 是系統對外作的功、P 是壓力、V 是體積、H ≡ U + PV 是焓。
2. 恆壓下只有膨脹功：W = PΔV，代入第一定律：ΔU = Q<sub>P</sub> − PΔV → **Q<sub>P</sub> = ΔU + PΔV**。
3. 由焓的定義：ΔH = ΔU + Δ(PV) = ΔU + PΔV + VΔP。恆壓 ΔP = 0，所以 ΔH = ΔU + PΔV。
4. 比較 2 和 3：**ΔH = Q<sub>P</sub>**。恆壓下焓變就是系統吸收（ΔH > 0）或放出（ΔH < 0）的熱。

### 熵 S

廣度變數，描述系統的無序程度。**可逆反應**中，系統在等溫下得到或失去的熱：ΔS ≡ Q<sub>rev</sub>／T。可逆反應以無限小的步驟進行、系統始終平衡；逆轉時系統與環境都不變，總熵變化為 0。

**實際上自然界的反應都是不可逆的**：實際的 Q 不等於可逆時的熱，還會伴隨額外的熵產生，所以 **ΔS ≥ Q／T**。自然過程有方向性，總是朝熵增進行。

### 吉布斯自由能 G

$$G = H - TS, \qquad \Delta G = \Delta H - T\Delta S \;(\text{定溫})$$

結合第一、第二定律，描述**定溫定壓**下系統的反應方向：

| ΔG | 意義 |
|---|---|
| < 0 | 自發，系統往自由能低的方向進行 |
| = 0 | 平衡 |
| > 0 | 非自發，需要外界作功 |

【推導 ★ 2024 C3】由第一、第二定律推導如何用 G 判斷定溫定壓下過程的自發性。

**解**：
1. 定義：H 焓、T 絕對溫度、S 熵、Q 系統吸收的熱、G ≡ H − TS 吉布斯自由能。
2. 第二定律：ΔS ≥ Q／T → **Q ≤ TΔS**（不可逆取 \<、可逆取 =）。
3. 由 C2，恆壓下 Q = ΔH，代入：**ΔH ≤ TΔS**，即 ΔH − TΔS ≤ 0。
4. 定溫下 ΔG = ΔH − Δ(TS) = ΔH − TΔS，所以 **ΔG ≤ 0**。
5. 結論：定溫定壓下自發（不可逆）過程 ΔG < 0；平衡（可逆）ΔG = 0；ΔG > 0 的過程不會自發發生（逆反應才是自發的）。兩個相的 G 相等的時候就是相平衡點。

## 3. G 隨溫度、壓力與成分的變化

**等壓下**，升溫時 G 降低，降低的速率由熵決定：

$$\left(\frac{\partial G}{\partial T}\right)_P = -S$$

推導：dG = dH − d(TS) = dH − TdS − SdT；dH = TdS + VdP，等壓 dH = TdS → dG = −SdT。

<MeltingGDemo />

**等溫下**，加壓時 G 增加，增加的速率由體積決定：

$$\left(\frac{\partial G}{\partial P}\right)_T = V$$

推導：dG = TdS + VdP − TdS − SdT，等溫 dT = 0 → dG = VdP。

【例題 ★ 2022 E3】單成分系統的等溫 G–P 圖，A、B、C 三條直線分別是固、液、氣。(1) 斜率等於哪個參數？(2) 怎麼判斷誰是哪一相？(3) 各壓力區間誰是平衡相？(4) 兩條相交處的垂直虛線代表什麼？

**解**：(1) (∂G／∂P)<sub>T</sub> = **V（莫耳體積）**。(2) 氣體體積最大 → **斜率最陡**的是氣體；液體次之；固體體積最小 → 斜率最緩。(3) 每個壓力下 **G 最低**的相穩定：低壓是氣體、中壓是液體、高壓是固體。(4) 兩線交點 G 相等 = 兩相平衡：氣–液交點是**沸騰／凝結（蒸發）**，液–固交點是**熔融／凝固**。（水例外：冰的體積比水大，所以加壓反而讓冰融化。）

**G 是狀態變數**，和路徑無關：

$$\Delta G = (-S\,\Delta T)_P + (V\,\Delta P)_T \quad(\text{固定成分})$$

**成分改變**時，用**化學勢** μ<sub>i</sub> = (∂G／∂n<sub>i</sub>)<sub>T,P,n<sub>j</sub></sub>（定溫定壓下，增加一莫耳成分 i 時 G 的變化率）：

$$\Delta G = -S\Delta T + V\Delta P + \sum_i \mu_i \Delta n_i, \qquad G = \sum_i \mu_i n_i$$

自由能也是**強度變數（μ）× 廣度變數（n）**的總和。化學勢隨莫耳分率降低而對數下降：μ<sub>i</sub> = μ<sub>i</sub><sup>∗</sup> + RT ln x<sub>i</sub>（μ<sub>i</sub><sup>∗</sup> 是純物質 i 的化學勢；x<sub>i</sub> → 1 時 μ<sub>i</sub> = μ<sub>i</sub><sup>∗</sup>）。

### 熱力學平衡 ★

1. 所有自然反應持續往**降低 G** 的方向變化，直到 G 最低、ΔG = 0。
2. 系統內所有**強度變數（T、P、μ）都保持固定**。如果不是，就會試圖消除梯度：溫度梯度 → 熱從高溫流到低溫；壓力梯度 → 物質從高壓流到低壓；化學勢梯度 → 物質從高 μ 擴散到低 μ；電勢梯度 → 電荷流動。（2024 填充 B10：平衡時所有的 **強度** 變數保持固定。）

## 4. 相圖 ★

知道每個礦物的 H 和 S，就能算出任何溫壓下的 G，G 最低的就穩定；畫成圖就是**相圖**。

### 單成分相圖與相律

平衡時兩相的 ΔG = 0，所以 −ΔS ΔT + ΔV ΔP = 0，相界的斜率是 **Clapeyron 方程式**：

$$\frac{dP}{dT} = \frac{\Delta S}{\Delta V}$$

<Al2SiO5Fig />

**吉布斯相律**：

$$P + F = C + 2$$

P：共存的相數；F：自由度（可以獨立改變而不改變相組合的變數數目）；C：成分數；2：溫度和壓力。
- 單成分（C = 1）：**不變點** F = 0（三相）、**單變線** F = 1（兩相）、**雙變區** F = 2（一相）。
- 固定壓力的溫度–成分圖：**F = C + 1 − P**。

<GraphiteDiamondDemo />

### 二元共晶系統：透輝石–鈣長石 ★

礦物和岩石通常不只一種成分，會出現哪些相不只由溫壓決定，也和成分有關。多維相圖很難畫，一般**固定一個變數（如壓力）**畫 2D 的溫度–成分圖。

**為什麼加了東西熔點會下降？**（食鹽水比純水凝固點低）溶液中 H₂O 的化學勢 μ = μ<sup>∗</sup> + RT ln X 比純水低（X < 1），固體要在更低溫才能和它平衡。推出來是**凝固點下降方程式**：ln X = (ΔH<sub>fus</sub>／R)(1／T<sub>m</sub> − 1／T)。所以兩種礦物混合時，熔點都會往中間降，交在共晶點。

<EutecticDemo />

- **液相線（liquidus）**：高於此線全為液體；冷卻碰到它開始結晶。
- **固相線（solidus）**：低於此線全為固體（共晶系統中就是通過共晶點的水平線）。
- **共晶（eutectic）**：在特定成分和溫度下，兩種（以上）固體同時從液體結晶。**共晶點**是液體能存在的最低溫度。
- **共晶點的自由度**：等壓下 F = C + 1 − P = 2 + 1 − 3 = **0**，是等壓不變點，溫度停住直到液體用完。
- **槓桿定律**：兩相區內，液體重量／鈣長石重量 = 對面那段 ÷ 這段，也就是**某相的比例 = 整體成分點到「另一相」那端的距離 ÷ 連結線全長**。
- 岩漿快速冷卻會來不及結晶，形成**玻璃**。
- 組織：**輝綠組織（ophitic）**——輝石大晶體包住斜長石長條；同時結晶的共晶組織：**文象花崗岩**（石英與鹼性長石楔形共生）、**花斑組織 granophyric**（石英與鈉長石穿插）。

【例題 ★ 完整解】70 wt% An 的熔體從 1600 °C 冷卻，描述結晶過程。

**解**：
1. 1600 °C：全部液體，F = 2。
2. 約 1440 °C 碰到液相線，開始析出**鈣長石**（純 An）。
3. 繼續降溫，鈣長石一直析出，液體成分沿液相線往共晶點（42 % An）移動，F = 1。例如 1350 °C 時液體約 54 % An，液體比例 = (100 − 70)／(100 − 54) ≈ 65 %。
4. 1274 °C（共晶點）：液體 42 % An，比例 = (100 − 70)／(100 − 42) ≈ 52 %；透輝石和鈣長石同時結晶，三相共存，F = 0，溫度不變直到液體用完。
5. 1274 °C 以下：全部固體，透輝石 30 % + 鈣長石 70 %。最先結晶的鈣長石成為較大的斑晶，周圍是共晶的細粒混合物。

### 一致熔融與不一致熔融

- **一致熔融（congruent melting）**：固體熔成和自己**相同成分**的液體（例：鈉長石；石英–霞石系統中央的鈉長石把相圖分成兩半）。（2022 英文名詞 B5）
- **不一致熔融（incongruent melting）**：固體熔成**另一種固體 + 成分不同的液體**。例：**頑火輝石加熱到 1557 °C**，在**包晶點**分解成鎂橄欖石 + 富 SiO₂ 的熔體，這叫**包晶反應（peritectic）**。反過來冷卻時，橄欖石會和岩漿反應長出斜方輝石的反應邊（原本被鉻鐵礦包住的橄欖石，外面變成 Opx）。

### 完全固溶體：橄欖石、斜長石 ★

<SolidSolutionDemo />

- **完全固溶體**（2024 C4）：兩端成分在固態下可以**任意比例互溶**，形成單一結構的連續系列。橄欖石 Fo（Mg₂SiO₄，1890 °C）–Fa（Fe₂SiO₄，1205 °C）就是例子。**形成條件**：兩種替換的離子**電價相同、半徑相近**（Mg²⁺ 0.72 Å、Fe²⁺ 0.78 Å），結構相同，所以在所有溫度都能互換，相圖上沒有共晶點，只有一個透鏡形的「液相線＋固相線」兩相區。
- 斜長石 Ab（鈉長石）–An（鈣長石）也是。岩漿庫對流造成溫度上下起伏，或複雜擴散，讓斜長石長出**震盪環帶（oscillatory zoning）**。

【例題 ★ 2024 C5】70 % Mg₂SiO₄ 的岩漿從 1900 °C（A）冷卻，分析 1750 °C（B）和 1650 °C（C）時的岩漿成分、析出的橄欖石成分、兩者比例。

**解（方法）**：
1. 在 A 點（1900 °C）高於液相線，全為液體 Fo70。
2. B 點：從 (Fo70, 1750 °C) 畫水平連結線，左端碰液相線讀出**液體成分 x<sub>L</sub>**，右端碰固相線讀出**橄欖石成分 x<sub>S</sub>**（比 70 更富 Mg）。
3. 槓桿定律：液體比例 = (x<sub>S</sub> − 70)／(x<sub>S</sub> − x<sub>L</sub>)；橄欖石比例 = (70 − x<sub>L</sub>)／(x<sub>S</sub> − x<sub>L</sub>)。
4. C 點同樣做一次：溫度越低，兩端都往 Fa 移，液體比例越少。
5. 以上面互動圖的示意曲線：B 點液體約 Fo63、橄欖石約 Fo87，液體約 70 %；C 點液體約 Fo48、橄欖石約 Fo76，液體約 23 %。**考試要用考卷附圖、直尺量**，數字會不一樣，但步驟相同。

### 固溶線與離溶：鹼性長石、鉀鹽–岩鹽 ★

- **固溶線（solvus）**：分隔單一固溶體區域和兩個（以上）固相共存區域的線。高溫時兩端可完全互溶，冷到固溶線下就**離溶（exsolution）**成兩相。
- **鹼性長石**：0.5 GPa 下形成的**超固溶（hypersolvus）花崗岩**：先析出單一的透長石，冷卻時離溶成**條紋長石（perthite）**；0.2 GPa 下的**亞固溶（subsolvus）花崗岩**：固溶線和固相線相交，一開始就析出鈉長石固溶體和正長石固溶體兩種長石。

【例題 ★ 2025 C5–C7（27 分）】鉀鹽 KCl–岩鹽 NaCl 相圖。

**C5 名詞**：液相線（高於此全為熔體）、固相線（低於此全為固體）、固溶線（以下單一固溶體離溶成兩相）、共晶點（考卷用語；這張圖中是液相線與固相線相切的**最低熔點**）。在圖上標註時要四個都標清楚。

**C6**：72 mol% NaCl 從 800 °C（O）冷卻。

**C7（純化岩鹽）**：
1. **加熱到液相線以上**（約 > 750 °C，依圖）使整塊雜鈉鉀岩完全熔融。
2. **慢慢降溫進入「熔體 + 岩鹽固溶體」兩相區**，剛跨過液相線時析出的晶體最富 NaCl。
3. 在該溫度**把晶體和熔體分離**（過濾、倒出熔體），取出晶體。
4. 把晶體**重新加熱熔化，再重複 2–3**（分步結晶）：每做一次晶體就更接近純 NaCl，最後得到近乎純的岩鹽。
5. 也可以說明：低溫（固溶線下）雖然會離溶出岩鹽相，但兩相細密共生、難以物理分離，所以最好在高溫的兩相區用分步結晶取鹽。

## 5. 動力學：速率、傳輸、衰變與封存溫度 ★

地球為了消除強度變數的梯度、達到平衡而不停變化。熱力學說平衡長什麼樣，**動力學**才說多快。速率差異極大，從火山氣體爆發到板塊緩慢移動，但都遵守類似的法則。

### 傳輸定律

$$J_x = -\text{常數} \times \frac{d(\text{強度變數})}{dx}$$

| 定律 | 流動的東西 | 驅動的梯度 | 常數 |
|---|---|---|---|
| **Darcy** | 流體 | 水頭（壓力）dh/dx | 水力傳導係數 K<sub>h</sub> |
| **Fick** | 原子擴散 | 濃度 dc/dx | 擴散係數 D |
| **Fourier** | 熱傳導 | 溫度 dT/dx | 熱傳導係數 K<sub>T</sub> |

負號表示從高往低流。三者數學形式一樣，懂一個就懂全部。（2024 填充 B11：各種物質流動都可用 **傳輸** 定律描述。）

### Arrhenius 方程式

$$k = A\,e^{-E_a/RT}$$

k：反應速率常數、A：頻率因子、E<sub>a</sub>：活化能、R：氣體常數、T：絕對溫度。溫度越高、活化能越低，反應越快。擴散係數也一樣：D = D₀ e<sup>−E/RT</sup>。

**回答開頭的問題**：火柴燃燒和女王頭風化都是和氧反應，ΔG 都 < 0（熱力學上都會發生），差在**速率**：摩擦提供能量越過活化能、燃燒放熱又持續提高溫度（指數加速）；常溫下砂岩的化學風化活化能高、溫度低，所以要幾千年。

### 放射性衰變與定年

| 衰變 | 例子 | 變化 |
|---|---|---|
| β⁻ | ⁸⁷Rb → ⁸⁷Sr | 中子變質子，Z + 1 |
| β⁺／電子捕獲 | ⁴⁰K → ⁴⁰Ar | 質子變中子，Z − 1 |
| α | ¹⁴⁷Sm → ¹⁴³Nd | 放出 ⁴He，Z − 2、A − 4 |
| 自發分裂 | ²³⁸U、²³⁹Pu | 核分裂成兩半，留下分裂徑跡 |

**年齡方程式**：D = D₀ + N(e<sup>λt</sup> − 1)。要成立需要：**封閉系統**、**衰變常數 λ 固定**、**知道初始子元素 D₀**（最好是 0）。

**諧和曲線（Concordia）**：始終封閉的含 U 岩石，²⁰⁶Pb/²³⁸U 對 ²⁰⁷Pb/²³⁵U 作圖會落在一條隨年齡變化的曲線上；落在曲線上的叫諧和年齡（2021 名詞解釋 Concordia age、2022 填充 C37）。

### 封存溫度 ★

<ClosureFig />

**Dodson 方程式**：

$$T_c = \frac{E/R}{\ln\!\left(\dfrac{A R T_c^2 D_0 / a^2}{E \, dT/dt}\right)}$$

封存溫度由**擴散動力學（E、D₀）、粒徑 a、幾何因子 A、冷卻速率 dT/dt** 決定：顆粒越大、冷卻越快、活化能越高 → 封存溫度越高。

## 容易混淆

| 這個 | 那個 | 差別 |
|---|---|---|
| 狀態變數 | 過程變數 | 只看狀態（H、S、G）／看路徑（Q、W） |
| 強度變數 | 廣度變數 | 與大小無關（T、P、μ）／成正比（V、H、S） |
| ΔH | ΔG | 等壓下的熱／定溫定壓下的方向 |
| (∂G/∂T)<sub>P</sub> | (∂G/∂P)<sub>T</sub> | −S／V |
| 單變線 | 不變點 | 兩相、F = 1／三相、F = 0 |
| 液相線 | 固相線 | 開始結晶／完全固化 |
| 固相線 | 固溶線 | 液固界線／兩種固體離溶的界線 |
| 共晶 | 包晶 | 液體 → 兩種固體同時結晶／固體 → 另一種固體 + 液體 |
| 一致熔融 | 不一致熔融 | 熔成同成分液體／熔成另一固體 + 不同成分液體 |
| 共晶系統 | 固溶體系統 | 析出純礦物、液體成分變／析出的固體成分也會變 |
| 熱力學 | 動力學 | 方向、終點／速率 |
