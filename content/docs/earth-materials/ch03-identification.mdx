**這章在回答**：拿到一顆礦物，可以看哪些物理性質來辨認它？這些性質各自是由內部什麼原因造成的？需要定量時，用哪些儀器？

**考前 30 秒**

1. 九種物理特性：**晶癖、晶簇產狀、顏色、光澤、條痕、解理、斷口、硬度、比重**（加上磁性、遇酸反應）。
2. **晶癖 ≠ 晶形**：晶癖泛指一般外形（含因環境限制長出的不規則面），晶形是規則幾何外形。影響晶癖：晶體結構、生長環境（冷卻速率、過飽和度）、各晶面相對生長速率、晶種外形。
3. 顏色主要來自**吸收光譜**：**晶場轉換**（過渡金屬 d 軌域被周圍**陰離子（配位基）**的靜電場分裂）、**分子軌域轉換**（電荷在相鄰離子間轉移，藍寶石 Fe²⁺–Ti⁴⁺）、**色心**（晶體缺陷抓住電子，紫螢石、煙水晶）。★ 填充題常考
4. 光學效應：變彩（蛋白石，SiO₂ 球繞射）、貓眼（平行纖維包裹體）、暈彩（拉長石層狀結構干涉）、星光（定向針狀包裹體）。
5. 解理 = **鍵結弱或面間距大**的原子面；五類：平面、柱狀（輝石 ~90°、角閃石 ~120°）、立方、菱面體、八面體。
6. 莫氏硬度：滑石、石膏、方解石、螢石、磷灰石、正長石、石英、黃玉、剛玉、金剛石。
7. 比重取決於**組成原子的原子量**和**晶體結構的堆積密度**（霰石 2.95 > 方解石 2.71，因為 Ca 配位數 9 > 6）。★
8. 磁性：反磁性（大多數）、**順磁性（有不成對電子，被磁鐵微弱吸引）**、鐵磁性（磁鐵礦、磁黃鐵礦）；**居禮溫度**以上失去自發磁性。★
9. 布拉格定律 **nλ = 2d sinθ**。

## 1. 晶癖與晶簇產狀

<FigSource s="課堂投影片 Ch2–3"><FormFig /></FigSource>

- **晶癖**：泛指礦物的一般外形，包括因生長環境限制而出現的不規則面。**晶形**：外觀呈現規則幾何形狀。
- 晶癖例子：柱狀（電氣石）、稜柱狀（透輝石）、針狀（沸石）、板狀（重晶石）、刀刃狀（藍晶石）、纖維狀（天青石）、樹突狀、層狀（白雲母）。
- **影響晶癖的原因**：① 晶體結構（岩鹽的立方排列）、② 生長環境條件（冷卻速率、過飽和度——雪花的形狀隨溫度與水氣飽和度改變）、③ 各晶面的相對生長速率（長得快的面會消失、長得慢的面留下來）、④ 晶種的外型。同一成分不同結構也會有不同晶癖：α 硫（斜方）與 β 硫（單斜）。
- **晶簇產狀**：除非結晶良好，大部分礦物以小顆粒集合體出現：顆粒狀（橄欖石）、帶狀（瑪瑙）、葡萄狀（針鐵礦、玉髓）、腎形（赤鐵礦）、晶洞（石英）、鮞狀（鮞粒灰岩）、豆狀（鋁礬土）、層狀、乳房狀、鐘乳石狀。

## 2. 顏色、光澤與條痕

### 顏色與光澤的基本觀念

- 顏色對許多礦物是**極不可靠**的性質。**金屬光澤**的礦物顏色單一、容易辨認（但表面會氧化，要看新鮮面）；**非金屬**礦物顏色樸素、常有變化。
- 少數非金屬礦物有獨特顏色：**孔雀石（綠）、藍銅礦（藍）、薔薇輝石（玫瑰紅到粉紅）、綠松石（藍綠）**，還有菱錳礦、硫、青金石。4 萬 5500 年前的洞穴壁畫用的是赭石（含鐵氧化物），壁畫上的碳酸鈣沉積用鈾系定年。
- **光澤**：礦物表面在反射光下的外觀特性（光照到礦物會反射、散射、繞射、吸收、穿透、放出螢光）。金屬光澤＝不透明礦物強烈反射白光（黃鐵礦）；非金屬光澤反射較散（方解石）。非金屬光澤再分：金剛、玻璃、樹脂、珍珠、油脂、絹絲、泥土光澤。琥珀是樹脂光澤，但**不是 IMA 認可的礦物**（有機）。
- **透明度**：不透明（opaque，可見光完全穿不過）、半透明（translucent，透光但看不透）、透明。

### 顏色的三種成因 ★

可見光波長約 **400–750 nm**。礦物的顏色和它含有的特定原子、或結構中原子位置與可見光的交互作用有關：電子吸收了某些波長的光躍遷到較高能階，剩下沒被吸收的波長組合起來就是我們看到的顏色。

<FigSource s="課堂投影片 Ch3；LibreTexts Chemistry"><CrystalFieldFig /></FigSource>

**① 晶場轉換（crystal field transitions）**：通常和**過渡金屬元素**有關。過渡金屬離子的五個 d 軌域，在礦物中被周圍**陰離子（配位基）**的靜電排斥作用分裂成能量較高的 e<sub>g</sub> 和較低的 t<sub>2g</sub>。分裂後的能階差 Δ<sub>o</sub> 落在可見光範圍，電子躍遷時吸收特定波長；Δ<sub>o</sub> 的大小也決定電子傾向高自旋還是低自旋。

- 同樣是 Fe²⁺，位置不同顏色不同：**橄欖石**（Fe²⁺ 六配位）黃綠波段吸收最少 → **綠色**；**鐵鋁榴石**（Fe²⁺ 八配位）橘紅波段吸收最少 → **紅色**。
- 同樣是 Cr³⁺：**紅寶石**（剛玉 Al₂O₃）紅、**祖母綠**（綠柱石 Be₃Al₂Si₆O₁₈）綠，因為周圍結構不同、晶場強弱不同。

**② 分子軌域轉換（molecular orbital transitions）**：價電子在相鄰的陽離子之間轉移（電荷轉移），例如 Fe²⁺ + Ti⁴⁺ → Fe³⁺ + Ti³⁺。**藍寶石**（含 Fe、Ti 的剛玉）的藍色就是這樣來的。

**③ 色心（color centers）**：晶體結構有缺陷時產生。
- **螢石 CaF₂ 的紫色**：某些 F⁻ 位置缺失，鄰近的陽離子釋放電子，電子被困在陰離子空位中，形成色心。
- **煙水晶**：Al³⁺ 佔據 Si⁴⁺ 的位置，電價差由 H⁺ 平衡；受放射線照射後形成電洞色心，吸收特定波長而呈褐色。

<FigSource s="課堂投影片 Ch3"><ColorCausesFig /></FigSource>

| 效應 | 例子 | 原因 |
|---|---|---|
| 變彩 play of color | 貴蛋白石 SiO₂·nH₂O | 微小 SiO₂ 球規則排列，**繞射**光線；不同角度看到不同顏色 |
| 貓眼 chatoyancy | 金綠寶石（貓眼石）BeAl₂O₄ | 內部**平行纖維或針狀包裹體**反射光線，形成一條亮帶 |

| 星光 asterism | 玫瑰石英、星光藍寶石 | **定向排列的針狀包裹體**（金紅石）反射、散射成星形 |

### 條痕

礦物粉末的顏色，比塊體顏色可靠。例：赤鐵礦條痕**紅褐**、閃鋅礦**淡黃褐**、黃鐵礦**綠黑**；大多數非金屬光澤礦物的條痕是**白色**。（2022 考過填充。）

## 3. 解理、斷口與硬度

### 解理 ★

**解理是晶體結構中鍵結弱、或原子面間距大的面造成的。**（2025 名詞解釋 Cleavage）

<FigSource s="課堂投影片 Ch3"><CleavageTypesFig /></FigSource>

| 類型 | 組數與角度 | 例子 |
|---|---|---|
| 平面解理 planar | 1 組 | 白雲母（層狀矽酸鹽，層間只有 K⁺ 鍵結） |
| 柱狀解理 prismatic | 2 組 | 輝石（~87°／93°）、角閃石（~124°／56°） |
| 立方解理 cubic | 3 組互相垂直 | 岩鹽 NaCl |
| 菱面體解理 rhombohedral | 3 組彼此**不**呈 90° | 方解石 CaCO₃ |
| 八面體解理 octahedral | 4 組（8 個面）相交成八面體 | 螢石 CaF₂ |

<FigSource s="課堂投影片 Ch3"><PyxAmphFig /></FigSource>

- **斷口**：沒有特定方向的破裂（高嶺土、陽起石）；貝殼狀、纖維狀、不規則。
- **裂理（parting）**和解理的差別（2022 考題）：解理是結構本身鍵結弱的面，**每一處都可以裂**、平整重複；裂理沿雙晶面、離溶片層或包裹體造成的弱面，**只在特定位置、間距較大**，不是所有同種礦物都有（例：剛玉、磁鐵礦、輝石）。兩者都是沿平面裂開。

## 4. 比重、磁性與遇酸反應

### 比重 ★

$$G = \frac{\text{物質密度 (g/cm}^3)}{\text{水的密度 (g/cm}^3)}$$

**結晶物質的比重取決於兩件事**（2025 填充 B21、B22）：

1. **組成原子的原子量**：結構相同、陽離子不同時，原子量越大比重越大。同結構的斜方碳酸鹽：霰石 CaCO₃ < 菱鍶礦 SrCO₃ < 碳鋇礦 BaCO₃ < 白鉛礦 PbCO₃。
2. **晶體結構的密度（堆積方式）**：同樣是 CaCO₃，**霰石 2.95 > 方解石 2.71**，因為霰石中 Ca 的配位數較大（9 vs 6），堆得較緊密。（**陽離子配位數較大，密度較高**。）

### 磁性 ★

<FigSource s="Iacovacci et al. (2016)；課堂投影片 Ch3"><MagnetismFig /></FigSource>

| 磁性 | 微觀原因 | 例子 |
|---|---|---|
| 反磁性 diamagnetic | 電子全部成對，外加磁場時產生微弱反向磁化、被輕微排斥 | **大多數礦物**（石英、方解石） |
| 順磁性 paramagnetic | 有**不成對電子**，磁矩亂排；外加磁場時順向排列、被微弱吸引，移除後消失 | 含 Fe²⁺、Mn²⁺ 的礦物（黑雲母、橄欖石、石榴子石） |
| 鐵磁性 ferromagnetic | 磁矩在磁區內自發平行排列，移除外場仍保留磁性 | **磁鐵礦** Fe²⁺Fe³⁺₂O₄、**磁黃鐵礦** Fe₁₋ₓS |

**居禮溫度**：鐵磁性物質加熱超過這個溫度，熱擾動破壞磁區的自發排列，變成順磁性（磁鐵礦約 580 °C）。岩石從高溫冷卻通過居禮溫度時，會把當時的地磁場方向「鎖」進去，這就是古地磁的原理。（2024 名詞解釋 Curie Temperature、2025 Paramagnetic mineral）

### 遇酸反應

碳酸鹽礦物滴鹽酸會冒泡：**2H⁺ + CO₃²⁻ → H₂O + CO₂↑**。方解石冷稀鹽酸就劇烈冒泡；白雲石要磨成粉或加熱。

<summary>自我檢測 4</summary>

1. 結晶物質的比重取決於哪兩個因素？各舉例。
2. 為什麼霰石比方解石重？
3. 解釋 paramagnetic mineral，舉一例。
4. 什麼是居禮溫度？和古地磁有什麼關係？

**答案**：(1) 組成原子的原子量（霰石 < 菱鍶礦 < 碳鋇礦 < 白鉛礦）和晶體結構的堆積密度（霰石 > 方解石）。(2) 霰石中 Ca 的配位數較大，原子堆積較緊密。(3) 順磁性礦物含有不成對電子（常是 Fe²⁺、Mn²⁺），平時磁矩亂排互相抵消，在外加磁場中會順著磁場排列而被微弱吸引，移除磁場後磁性消失；例：黑雲母、橄欖石。(4) 鐵磁性物質失去自發磁化、變成順磁性的溫度（磁鐵礦約 580 °C）；岩石冷卻通過居禮溫度時記錄當時的地磁場方向。

## 5. 定量分析的儀器

| 儀器 | 原理 | 得到什麼 |
|---|---|---|
| 偏光顯微鏡 | 偏振光穿過薄片（Ch6） | 光學性質、雙晶（微斜長石格子雙晶、斜長石鈉長石雙晶）、組織 |
| **XRD** X 光繞射 | X 光在原子層間繞射，nλ = 2d sinθ | 晶面間距 d → 鑑定礦物、晶胞參數 |
| SEM 掃描式電子顯微鏡 | 電子束掃描表面；背向散射電子影像（BSE）亮度隨平均原子序 | 表面形貌、成分差異影像 |
| **EPMA** 電子探針顯微分析 | 電子束激發特徵 X 光（WDS／EDS） | 微米級的定量化學成分（例：普通輝石的 EDS 譜線、石榴子石 Ca 環帶） |
| TEM／HRTEM 穿透式／高解析穿透式電子顯微鏡 | 電子穿透超薄樣品 | 奈米尺度結構、晶格影像（例：赤鐵礦奈米顆粒） |

### 布拉格定律 ★

X 光波長 0.2–100 Å，能量和穿透力都比可見光大。X 光射向晶體，一部分在第一層原子散射，沒散射的穿到下一層再散射……兩層散射光的**路徑差 = 2d sinθ**，當它是波長的整數倍時波峰疊加、繞射增強：

$$n\lambda = 2d\sin\theta$$

<BraggDemo />

XRD 圖的橫軸是 2θ、縱軸是強度；每一根峰對應一組晶面（例：石英的 (100)、(101)、(112)、(211)），用布拉格定律換成 d 值，和資料庫比對就能鑑定。

【例題 ★ 完整解】用 Cu Kα（λ = 1.5406 Å）量到一根峰在 2θ = 26.64°，對應的晶面間距是多少？

**解**：θ = 13.32°，sinθ = 0.2304。n = 1 時 d = λ／(2 sinθ) = 1.5406／0.4608 = **3.34 Å**，是石英 (101) 的最強峰。

【換你算】同一台儀器，d = 4.26 Å 的峰會出現在 2θ = ？（答案：sinθ = 1.5406／8.52 = 0.181，θ = 10.42°，2θ ≈ 20.8°，石英 (100)。）

<summary>自我檢測 5</summary>

1. 寫出布拉格定律並解釋各符號。
2. XRD、EPMA、SEM、TEM 各用來得到什麼資料？
3. HRTEM 和 EPMA 的英文全名是什麼？

**答案**：(1) nλ = 2d sinθ：n 是繞射階數（整數）、λ 是 X 光波長、d 是原子層（晶面）間距、θ 是 X 光入射角；路徑差 2d sinθ 為波長整數倍時建設性干涉。(2) XRD：晶面間距、鑑定礦物；EPMA：微區定量化學成分；SEM：表面形貌與 BSE 成分影像；TEM：奈米尺度內部結構。(3) HRTEM：High-Resolution Transmission Electron Microscopy（高解析穿透式電子顯微鏡）；EPMA：Electron Probe Micro-Analysis（電子探針顯微分析）。

## 容易混淆

| 這個 | 那個 | 差別 |
|---|---|---|
| 晶癖 | 晶形 | 一般外形（可含不規則面）／規則幾何外形 |
| 晶場轉換 | 分子軌域轉換 | 單一離子的 d 軌域分裂／電子在兩個陽離子之間轉移 |
| 色心 | 雜質致色 | 結構缺陷（空位）困住電子／外來離子或包裹體 |
| 變彩 | 暈彩 | 蛋白石 SiO₂ 球繞射／拉長石層狀結構干涉 |
| 解理 | 裂理 | 結構固有弱面／雙晶面、離溶等缺陷造成 |
| 順磁性 | 鐵磁性 | 移除外場就消失／自發排列、保留到居禮溫度 |
| 比重兩因素 | — | 原子量（換陽離子）／堆積密度（換結構） |
| 方解石 | 霰石 | 三方、Ca 六配位、2.71／斜方、Ca 九配位、2.95 |
| SEM | TEM | 看表面／看穿透的內部結構 |
