## 期末：名詞比較（2019–2024）

<details>
<summary>Joint vs Fault（2019–2022、2024）</summary>

都是脆性破裂面。**節理**：沒有可察覺剪位移的破裂（Mode I 張開為主），⊥ σ3，常成組規則出現，可被礦物充填成脈。**斷層**：沿破裂有明顯剪位移（Mode II／III），和 σ1 約夾 30°，常有擦痕、斷層泥、角礫。關連：節理可以再活動成斷層；斷層尖端與周圍伴生節理（翼裂隙、羽狀節理）。

</details>

<details>
<summary>Stretching lineation vs Intersection lineation（2019–2022）；vs Crenulation lineation（2023、2024）</summary>

都是線理。**伸張線理**：礦物或顆粒集合體被拉長排列，平行應變橢球 X 軸，代表**運動（剪動）方向**。**交線線理**：兩組面（例：層面 S₀ 與劈理 S₁）的交線，常平行褶皺軸，不代表運動方向。**皺紋線理**：早期葉理被後期小褶皺（皺紋）彎曲，皺紋樞紐連成的線，代表後期褶皺軸，是兩期變形的證據。

</details>

<details>
<summary>Porphyroclast vs Porphyroblast（2019–2022）</summary>

都是基質中的大顆粒。**碎斑（porphyroclast）**：原岩中的大顆粒在變形中**殘留**下來（較強硬），周圍基質因動態再結晶變細，常帶不對稱尾巴（σ、δ 型）→ **剪動指標**，見於糜稜岩。**變斑晶（porphyroblast）**：變質作用中**新長出**的大晶體（石榴子石、十字石），內部包裹體軌跡（Si）和外部葉理（Se）的關係可判斷結晶與變形的先後（前、同、後構造）。

</details>

<details>
<summary>Fault-propagation fold vs Fault-bend fold（2019–2024）；vs Fault-detachment fold（2023）</summary>

都是斷層相關褶皺。**斷層轉折褶皺**：上盤越過斷坡–斷坪轉折時被動彎曲，斷層已切穿；前翼傾角由斷坡角決定，褶皺形狀在滑移過程中大致固定。**斷層擴展褶皺**：斷層尖端還在往前擴展，前方岩層褶皺吸收位移，前翼陡甚至倒轉、褶皺緊閉、向下收斂到斷層尖端（三角剪切）。**滑脫褶皺**：在弱滑脫層（鹽、頁岩）之上褶皺，下方沒有斷坡，弱層在核部加厚。

</details>

<details>
<summary>Flexural slip/flow folding vs Neutral-surface folding（2019）</summary>

曲滑：層間沿層面滑動、平行褶皺、層面有垂直褶皺軸的擦痕、翼部剪應變最大、樞紐為 0；曲流：層內流動代替層間滑動。中立面：單一強硬層外弧伸張、內弧縮短，中立面應變為 0，應變集中在樞紐；外弧張裂、內弧逆斷層與小褶皺。

</details>

<details>
<summary>Ptygmatic fold vs Plumose structure（2021）</summary>

兩者無直接關連（考的是兩個名詞）。**腸狀褶皺（ptygmatic fold）**：強硬薄層（常為長英質脈）在較弱基質中被縮短形成的不規則、圓滑、像腸子般的拱彎褶皺，層厚大致不變，常見於混合岩、片麻岩，代表高黏度對比與高溫韌性。**羽狀構造（plumose structure）**：節理面上像羽毛的紋路，從破裂起點向外輻射（羽軸 + 羽枝），指示**破裂傳播方向**，代表脆性張裂。對比：一個是韌性褶皺、一個是脆性破裂面。

</details>

<details>
<summary>Screw dislocation vs Edge dislocation（2022）</summary>

都是晶體中的**線缺陷**，差排移動（滑移）是晶體塑性的主要機制。**刃差排**：晶格多插入半個原子面，**Burgers 向量 ⊥ 差排線**，可以滑移也可以爬移（climb，需擴散、高溫）。**螺旋差排**：原子面繞差排線呈螺旋，**Burgers 向量 ∥ 差排線**，可交叉滑移（cross-slip）。實際差排多為混合型。

</details>

<details>
<summary>Pseudotachylyte vs Mylonite（2022–2024）</summary>

假玄武玻璃：地震快速滑動的摩擦熱使岩石局部熔融、急冷，深色玻璃質脈、可注入圍岩，脆性、高應變率、較淺。糜稜岩：韌性剪切帶中晶體塑性與動態再結晶使粒徑變小、有葉理與伸張線理，較深較高溫、緩慢。兩者可共存（同震脆性與震間韌性交替）。

</details>

<details>
<summary>Griffith vs Coulomb criteria（2023）</summary>

都是破壞準則。Griffith：微裂隙尖端應力集中，拋物線 τ² = 4T(σn + T)，適用張力與低壓區（張裂、混合破裂），C = 2T。Coulomb：直線 τ = C + μσn，適用壓力區（剪裂，裂面與 σ1 約 30°）。合併成 Griffith–Coulomb 包絡線。

</details>

<details>
<summary>Pressure solution vs Dislocation creep（2023）</summary>

都是韌性變形機制。壓溶：流體輔助的溶解–擴散–沉澱，低溫（成岩到低度變質），在高應力接觸面溶解、低應力處沉澱，形成縫合線、壓力影、劈理，近似牛頓流、和粒徑有關。差排潛變：晶格內差排滑移加爬移，較高溫，產生晶格優選方位、動態再結晶、波狀消光，冪律流 ė ∝ σⁿ（n ≈ 3），和粒徑無關。

</details>

<details>
<summary>Thin Skin vs Thick Skin Tectonics（2024）</summary>

都是褶皺逆衝帶的構造樣式。薄皮：變形只在**基底滑脫面**（頁岩、蒸發岩、超壓層）以上的沉積蓋層，基盤不參與，逆衝斷層向下收斂到滑脫面（台灣西部麓山帶）。厚皮：**基盤**也參與變形，高角度逆斷層切入基盤，常為舊正斷層反轉。

</details>

## 期末：單一名詞解釋（2012–2018 與 2013 範例卷）

| 名詞 | 年份 | 解釋 |
|---|---|---|
| Thin skin tectonics | 2012、2014、2015、2018、範例 | 變形只在基底滑脫面以上的沉積蓋層，基盤不參與 |
| Transpression | 2012、2014、範例 | 走滑加上垂直剪動帶的縮短（transtension 為伸張） |
| Mylonite | 2012、2014、範例 | 韌性剪切帶中動態再結晶使粒徑變小、具葉理與線理的斷層岩 |
| Cataclastic flow | 2012、2015、2018、範例 | 顆粒破碎、滑動、轉動的碎裂作用分布在寬帶中，中尺度看似韌性流動 |
| Parasitic fold | 2012、2014、2018、範例 | 大褶皺翼部與樞紐上的小褶皺，翼部呈 S／Z、樞紐呈 M／W，可推大褶皺位置 |
| Recrystallization | 2012、範例 | 變形中或變形後晶粒邊界遷移、亞晶粒旋轉形成新的無應變晶粒（動態／靜態） |
| S-tectonite | 2012、範例 | 葉理發達、線理不明顯的變形岩（扁平應變，k < 1）；L-tectonite 相反 |
| Transposition | 2012、2014、範例 | 強烈變形使舊面（層面）被褶皺、拉斷後轉成和新葉理平行，原始層序被打亂 |
| Dislocation | 2012、範例 | 晶體中的線缺陷（刃、螺旋差排），移動造成晶體塑性變形 |
| Stretching lineation | 2012、2018、範例 | 顆粒或礦物被拉長排列，平行 X 軸，指示運動方向 |
| Fault valve | 2014、範例 | 斷層像閥門：高孔隙壓使斷層破裂滑動 → 流體排出、壓力下降、礦物沉澱封閉 → 壓力再累積，週期性重複（Sibson） |
| Stylolite | 2014、範例 | 壓溶形成的鋸齒狀面，⊥ 最大壓應力，不溶物殘留其上 |
| Vergence | 2014、2015、範例 | 不對稱褶皺的倒向（較緩翼往較陡翼方向，或軸面傾向的反方向），指示構造運動方向 |
| Boudinage | 2014、範例 | 強硬層在層平行伸張下被拉成香腸狀串腸，頸縮處常有脈 |
| Petrogenetic grid | 2014、範例 | 溫壓圖上畫出各變質反應線，用礦物組合限定岩石形成溫壓 |
| Byerlee's law | 2015、2018 | 岩石摩擦強度 τ = 0.85σn（< 200 MPa）、τ = 50 + 0.6σn（> 200 MPa），幾乎與岩性無關 |
| Duplex | 2015、2018 | 頂板逆衝斷層與底板逆衝斷層之間由多個斷片（horse）疊成的構造 |
| Plumose structure | 2015、2018 | 節理面上的羽狀紋，從破裂起點向外輻射，指示破裂傳播方向 |
| Core-mantle structure | 2015 | 大晶粒核心被細小動態再結晶新晶粒包圍（核–幔構造），中溫差排潛變的特徵 |
| Ptygmatic fold | 2015、範例 | 強硬薄層在弱基質中形成的圓滑不規則腸狀褶皺 |
| Crack-and-seal | 2015、2018 | 裂隙反覆微小張開、隨即被礦物封填，形成纖維狀脈與包裹物條帶 |
| Separation | 2015 | 斷層兩側同一標誌層在某方向（走向或傾向）上的視錯距，不一定等於真正位移（net slip） |
| Sheath fold | 2018、範例 | 樞紐被強烈剪切拉長、彎成像刀鞘的褶皺，長軸平行剪動方向，見於強剪切帶 |
| Cleavage refraction | 2018 | 劈理穿過不同強度岩層時改變角度：強硬層中和層面夾角大、軟弱層中較小 |

<summary>2013 範例卷其餘名詞（約 50 個）</summary>

| 名詞 | 解釋 |
|---|---|
| Antithetic fault | 和主斷層傾向相反的次要斷層（同向為 synthetic） |
| Flow structure | 岩漿或熔岩流動時礦物、氣孔排列形成的原生構造 |
| Transtension | 走滑加上垂直剪動帶的伸張 |
| Klippe | 飛來峰：逆衝岩席被侵蝕後殘留、四周被斷層包圍的外來岩體孤島 |
| Allochthon | 外來岩體：被逆衝斷層從遠處搬來的岩體 |
| Autochthon | 原地岩體：逆衝斷層下盤、沒有被搬動的岩體；構造窗中可見 |
| Fault-end fold | 斷層末端位移漸減處伴生的褶皺 |
| Décollement | 滑脫面：沿弱層的近水平基底斷層，上下變形樣式不同 |
| Cutoff | 斷層切斷地層的交線（上盤切斷線、下盤切斷線） |
| Riedel shear | 剪切帶中先形成的同向（R）與反向（R′）剪裂，和主斷層夾約 15° 與 75° |
| Crystal plasticity | 晶體內差排滑移、雙晶等造成的永久變形，不失去內聚力 |
| Diffusional mass transfer | 原子經晶格、晶界或流體擴散移動造成的變形（擴散潛變、壓溶） |
| Homologous temperature | 同系溫度 T/T<sub>m</sub>（絕對溫度），> 0.5 時潛變明顯 |
| Defect | 晶格缺陷：點缺陷（空位、間隙）、線缺陷（差排）、面缺陷（晶界、雙晶面） |
| Burgers vector | 描述差排造成晶格錯位方向與大小的向量；刃差排 ⊥ 差排線、螺旋差排 ∥ |
| Pressure solution | 高應力接觸處溶解、擴散、在低應力處沉澱的變形機制 |
| Foam structure | 退火後晶界平直、三晶交會夾角約 120° 的平衡組織 |
| Annealing | 變形後在高溫靜態再結晶、晶粒長大，降低應變能 |
| Superplastic creep | 細粒岩石以晶界滑動為主的大應變潛變，晶粒保持等軸、無優選方位 |
| Synform | 向下閉合的褶皺（不論地層新老）；antiform 向上閉合 |
| Polyharmonic folding | 不同厚度層同時褶皺，產生不同波長疊加的褶皺 |
| Dip isogon | 褶皺層上下界面傾角相同點的連線，用來分類褶皺（Ramsay 1A–3） |
| Enveloping surface | 包絡面：連接一串小褶皺樞紐（或同側）的假想面，代表較大尺度的層位態 |
| Kink | 膝折：平直翼、尖銳樞紐的小褶皺，常成帶，見於片狀岩石 |
| Crenulation cleavage | 皺紋劈理：早期葉理被小褶皺皺起，翼部重新排列形成新劈理 |
| Pressure shadow | 壓力影：剛性顆粒兩側低應力處沉澱新礦物（石英、方解石、綠泥石） |
| Paragneiss | 副片麻岩：原岩為沉積岩的片麻岩 |
| Orthogneiss | 正片麻岩：原岩為火成岩的片麻岩 |
| Transecting cleavage | 斜切劈理：劈理和褶皺軸面斜交、不平行（常見於橫壓） |
| Shear zone | 剪切帶：應變集中、兩側相對剪動的帶狀區域，韌性時不失去內聚力 |
| Geothermobarometry | 地溫壓計：用平衡礦物對的成分推算形成溫度與壓力 |
| Metamorphic field gradient | 變質野外梯度：野外各點最高溫壓連成的曲線（不是單一岩石的 P–T 路徑） |
| Thermochronology | 熱年代學：用不同封存溫度的定年系統重建岩石冷卻與抬升歷史 |

</details>
